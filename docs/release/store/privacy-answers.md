## 2. Google Play — 데이터 보안 양식

|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 예 |
| 수집한 모든 사용자 데이터가 전송 중 암호화되나요? | **예** (API·동기화 모두 HTTPS — Tailscale Funnel TLS) |
