# [제품명] 계정 삭제 안내

[제품명]([운영자])의 계정과 데이터를 지우는 방법입니다.

## 1. 앱에서 바로 삭제하기 (권장)

**휴대폰 (iPhone·Android)**
1. 아래 탭 **더보기** → **설정**
2. 맨 위 **계정 카드**(이메일이 보이는 칸)를 누릅니다
3. 화면 맨 아래 **계정 삭제**
4. 확인 칸에 **삭제**라고 입력하고
   - 이메일·비밀번호로 가입했다면 **비밀번호**를 입력
   - Google로만 가입했다면 **Google로 다시 로그인**(로그인 후 10분 안에 삭제)
5. **계정 삭제**를 누르면 끝납니다

**컴퓨터 (macOS·Windows)**
1. **설정** → **계정** 탭
2. 맨 아래 빨간 **계정 삭제**
3. **삭제** 입력 + 비밀번호(또는 Google·Apple로 다시 로그인) → **계정 삭제**

> Apple로만 가입한 계정은 지금은 컴퓨터 앱에서 삭제할 수 있습니다. [확인 필요: iOS에 Apple 로그인 출시 시 휴대폰에서도 가능하도록 수정 후 이 문장 삭제]

## 2. 앱을 쓸 수 없을 때 — 이메일로 요청
앱을 지웠거나 로그인할 수 없으면 **[privacy@도메인]** 으로 다음을 보내 주세요.
- 제목: `계정 삭제 요청`
- 가입한 이메일 주소(Google·Apple로 가입했다면 그 계정의 이메일)
- 가입 방법(이메일·Google·Apple)

본인 확인을 위해 **가입한 이메일 주소에서 보내 주세요.** 보낸 주소가 다르면 추가 확인을 요청할 수 있습니다. 확인 후 **10일 이내**에 삭제하고 결과를 알려 드립니다.

## 3. 삭제되는 데이터 (즉시)
삭제를 누르는 순간 서버에서 한 번에 지워지고, 로그인된 다른 기기에서도 지워집니다.
- 계정 정보: 이메일, 비밀번호(해시), Google·Apple 연결 정보
- 모든 콘텐츠: 할 일·체크리스트·알림, 리스트·폴더·태그·필터, 일정, 메모·링크·위키, 일기와 AI 대화, 성장 기록(경험치·캐릭터·주간 목표·리포트), 작업 지도, 앱 설정
- 로그인 세션(모든 기기 로그아웃)
- 푸시 알림 기기 정보와 알림 발송 기록
- AI 사용량 기록

삭제한 계정은 **되돌릴 수 없습니다.**

## 4. 남는 데이터와 기간
| 무엇 | 얼마 동안 | 이유 |
|---|---|---|
| 서버 백업 안의 사본 | 최대 **14일**, 이후 자동 삭제 | 장애 복구용. 백업을 복원하면 삭제한 계정을 다시 지웁니다 |
| 기기에만 있던 데이터(AI 비서 대화 기록, Google·맥 캘린더 캐시, 위젯 정보) | 그 기기에서 로그아웃하거나 앱을 지울 때까지 | 서버에 없던 데이터라 기기에서 지워야 합니다. 삭제를 진행한 기기에서는 함께 지워집니다 |
| Google·Apple 계정 쪽 "이 앱 연결" 기록 | 이용자가 해제할 때까지 | Google 계정 › 보안 › 타사 앱 연결, Apple ID › Apple로 로그인에서 직접 해제하세요 [확인 필요: Apple 토큰 자동 폐기 도입 후 문구 수정] |

법령상 보관 의무가 있는 데이터는 현재 없습니다(무료 서비스, 결제 없음).

## 5. 계정은 두고 일부만 지우려면
할 일·메모·일기 등은 앱에서 하나씩 삭제할 수 있습니다. 휴지통에서 영구 삭제하면 서버와 다른 기기에서도 지워집니다. 서버 백업 안의 사본은 14일 뒤 사라집니다.
