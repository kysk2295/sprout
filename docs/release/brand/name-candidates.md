# 정식 제품명 후보 — 1차 선별 (코드네임 `sprout`)

> 작성 2026-10-05 · 상태: **1차 선별(예비 조사)** · 법적 검토가 아니다. 모든 판정은 **확인 필요**.
> 조사 방법: 웹 검색(App Store·Google Play 노출 앱, 상표 공개 DB 기사), `.com`은 whois, `.app`은 Google Registry RDAP 조회(2026-10-05 시점). 앱스토어 앱 내부 검색, KIPRIS·USPTO 직접 검색은 하지 않았다. 등록 가능 여부는 등록기관에서 직접 확인해야 한다.

## 전제

- 제품: 무료 할 일·캘린더 앱(Mac·Windows·iOS·Android) + 성장 루프(주간 목표·KPI → XP → 동물 캐릭터 거북이·다람쥐·고양이·수달이 아기·꼬마·친구·단짝·전설로 자람).
- 한국어 우선, 영어 병행. 로고 방향은 새싹·성장 + 체크 표시·캘린더.
- **"TickTick"과 비슷한 이름은 쓰지 않는다**(Tick-, -tick, 똑딱류 반복 음절 제외).
- 좋은 이름 기준: 짧다(2~3음절), 한·영 둘 다 발음된다, 성장과 실행(해냄)을 함께 떠올리게 한다.

## 추천 상위 3개

1. **해싹 (Haessak)** — 지어낸 합성어라 상표 식별력이 가장 높고, `.com`·`.app` 둘 다 비어 있었다. "해(실행) + 싹(성장)"이 제품의 두 축(편한 할 일 + 성장 루프)을 그대로 담는다. 로고도 "체크 표시에서 돋는 싹" 또는 "해 + 싹"으로 풀기 쉽다. 남은 숙제는 발음이 비슷한 보안 회사 **한싹**과의 유사 판단이다.
2. **꿈틀 (Kkumteul)** — 작은 움직임이 쌓여 자란다는 이야기를 만들기 좋고 "꿈"이 들어 있다. 스토어에 같은 이름 생산성 앱은 안 보였다. 영어 표기(예: Kumtle)를 따로 정해야 하고 `.com`은 이미 등록돼 있다.
3. **움틈 (Umteum)** — "움트다"에서 온 말로 성장의 시작을 뜻하고, 캐릭터의 "아기" 단계와 잘 맞는다. 같은 이름의 조향 스튜디오가 있지만 업종이 다르다. 영어 발음은 다소 어색하다.

차선: **도담** — 뜻은 가장 따뜻하지만 "도담도담" 앱이 많아 스토어 검색에서 묻힐 위험이 있다.

## 사용자가 직접 할 확인 절차

1. **KIPRIS 상표 검색** (kipris.or.kr → 상표)
   - 후보마다 한글·영문·발음이 비슷한 변형을 모두 검색한다. 예: 해싹 / Haessak / 한싹 / 해삭.
   - 분류: **9류**(다운로드 가능한 앱·소프트웨어), **42류**(SaaS·온라인 소프트웨어 제공). 필요하면 **41류**(교육·엔터테인먼트, 캐릭터 성장 요소 대비)도 본다.
   - 상태가 "등록"·"출원"인 것 모두 확인. "거절"·"소멸"이어도 메모해 둔다.
2. **해외 상표**: USPTO(tmsearch.uspto.gov)와 WIPO Global Brand Database에서 영문 표기로 9·42류 검색. 영어권 출시 전 필수.
3. **앱스토어 검색**: 한국·미국 App Store와 Google Play 각각에서 후보 이름을 직접 검색해 생산성·라이프스타일 카테고리의 같은/비슷한 이름 앱을 확인한다(웹 검색은 스토어 내부 검색보다 누락이 많다).
4. **도메인 조회**: 가비아·후이즈 같은 국내 등록기관이나 Namecheap·Cloudflare Registrar에서 `.com`·`.app`·`.kr`·`.co.kr` 등록 가능 여부를 직접 조회한다. 이 문서의 whois/RDAP 결과는 2026-10-05 시점 스냅샷이다. 아직 사지 말고, 상표 확인 후 결정한다.
5. **SNS 핸들**: 인스타그램·X·유튜브에서 같은 이름 계정이 비어 있는지 본다.
6. **한국어 어감 체크**: 주변 5~10명에게 이름만 들려주고 처음 떠오르는 이미지(예: 꿈틀 → 벌레?, 해싹 → 해삭?)와 받아 적은 철자를 모은다. 소리만 듣고 바로 검색해 찾을 수 있는지도 본다.
7. **영어 발음 체크**: 영어 사용자에게 영문 표기를 읽게 해 보고, 읽기 어려우면 영문 브랜드용 별도 표기를 정한다.
8. 최종 후보 1~2개는 출원 전에 변리사 상담을 받는다.
