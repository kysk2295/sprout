## 수집/검증의 한계와 남은 범위
전체 TickTick UI 수집 또는 전체 v1 구현 완료를 의미하지 않는다.
- 필터 편집 모달·태그 부모 선택은 기존 Mac 영상/관찰 자료를 근거로 구현. 이번 라이브에서 필터 생성 진입점 재확인은 하지 못했다.
- 전역 Ctrl+Shift+A 등록 코드 포함. CUA의 앱 대상 키 입력으로는 OS 전역 실행을 확인하지 못했다. ⌘N은 확인.
- 반복·알림의 모든 팝업 조합, 모든 테마/접근성/Windows 동작, 월300개 성능 검증은 미완료.
- 검색은 로컬 데이터, 설정은 스마트 목록/외관/단축키. 계정·클라우드·캘린더 구독은 별도 서버/인증 연동이 필요하며 이번 구현에 포함하지 않았다.
- 성장·동기화·알림 레일 등 기존 미구현 기능은 전체 제품 후속 작업으로 남아 있다.
- 목록·태그 조직 순서를 드래그하는 기능과 일부 세부 TickTick 시각적 차이는 남아 있다.
