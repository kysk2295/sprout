## 3. Windows 체크리스트 (사용자)
1. 사이트에서 **1.0.2** 받아 설치(SmartScreen → 추가 정보 → 실행). 이미 깔린 옛 버전에서는 로그인하지 말 것.
2. 로그인 → 할 일 목록이 휴대폰·Mac과 같은지.
3. 할 일 하나 만들기 → 휴대폰·Mac에 3초 안에 보이는지. 반대로 휴대폰에서 만든 것이 Windows에 보이는지.
4. 앱을 최소화 10분 → 다시 열고 3번 다시.
5. 일기 · 캘린더 · AI 비서 한 번씩 열어 캡처.
6. 안 되는 게 있으면 그 화면 캡처 + 설정 › 동기화 상태 캡처.
