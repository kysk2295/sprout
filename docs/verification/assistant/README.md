## 실시간 대화 (2026-10-04)
Ollama stream=true의 NDJSON을 웹 개발 서버와 Electron IPC로 전달. 내부 사고 필드는 전달하지 않고 content만 처리한다. reply 메시지는 스트림에서 점진적으로 표시, 일정 생성/조회는 완전한 구조화 응답 검증 후 실행한다. 진행 단계, 실제 수신 글자 수와 경과 시간, 중단/재시도/입력 복구, 결과 카드, 다음 초안 작성, 읽는 위치 유지와 ‘최신으로’ 버튼을 추가했다.
자동 테스트: UTF-8이 2바이트씩 분할된 스트림 복원, 완료 표시 누락/서버 오류 거부, reply 미리보기 및 create의 미확정 완료 메시지 숨김. typecheck, desktop data tests, production build 통과.
실모델 UI: 내일 조회에서 수신 중 155자/34초 표시 후 결과 카드 반환. 처리 중 다음 초안 보존. 중단 후 안내/재시도 표시와 초안 유지, 재시도 시 다음 초안 유지 확인. 위로 스크롤 시 ‘최신으로’ 표시 확인.
일반 안내 질문은 DB를 변경하지 않는 자연어 스트림으로 분리했다. 실제 모델 답변이 생성 중인 16초/246자 및 27초/425자에서 문장 일부를 확인했다. 이후 중단 시 받은 문장을 ‘중단 전 받은 답변’으로 유지함을 확인. `streaming-progress.png`는 완료 전 실제 스트림 화면이다. 안내 질문에 쓰기가 발생하지 않는 회귀 테스트도 통과했다.
