# 18 · 노트 리스트 · 칸반 보기 (실제 앱 관찰)

- 확인: 2026-10-04, TickTick macOS 앱(다크 테마, 창 1378×884). 칸반은 조사용 리스트 `sprout UI 조사`에서만 바꿔 보고 다시 리스트 보기로 되돌렸다. 개인 리스트 이름·항목은 적지 않는다.
- 쓰는 곳: [11 메모함](../screens/11-notes.md), [14 작업 지도](../screens/14-work-map.md), [10 AI 사용량](../screens/10-ai-usage.md)의 카드·그룹 모양.

## 1. 노트 리스트 (리스트 종류 = 노트)
| 항목 | 관찰 |
|---|---|
| 머리 | 일반 리스트와 같다(57px, 제목 20/700, 오른쪽 정렬·`⋯`). 부제목 없음 |
| 추가 바 | 같은 38px 바. 문구만 `"<리스트>"에 메모 추가하기` (할 일 리스트는 `할일 추가`) |
| 행 | 체크박스 자리에 **문서 아이콘**. 그 밖에는 할 일 행과 같다(높이 40, 제목 한 줄, 오른쪽 메타) |
| 그룹 | 할 일 리스트와 같은 그룹 머리(`이름 N`, 접기 화살표) |
| 상세 | 행을 누르면 오른쪽 상세 패널(336). 체크박스·날짜 줄 없이 제목 + 본문 편집 |

## 2. 칸반 보기 (리스트 `⋯` → 보기 아이콘: 목록 · 칸반 · 타임라인)
실측 좌표는 창 기준(x는 레일 55 + 사이드바 261 뒤).
| 항목 | 값 |
|---|---|
| 열 폭 | **258** (x 290–548). 열 사이 간격 16 [다음 열이 없어 추정 — 새 열 버튼이 열 끝에서 24 오른쪽] |
| 열 머리 | y 77 중심. `미분류 5` (이름 600 · 개수 회색) + 오른쪽 `+` · `⋯` |
| 새 열 | 마지막 열 오른쪽에 강조색 `+ 새로운 열` (텍스트 버튼) |
| 카드 | 배경 `#212121`, 테두리 1px `#262626`, 모서리 약 4. **한 줄 40 · 날짜 있으면 56**, 카드 간격 8, 첫 카드 y 101 |
| 카드 안 | 왼쪽 16에 체크박스(14) → 8 띄고 제목(13.5/600). 둘째 줄에 날짜(10.5, 강조색 — 리스트 행의 날짜 색과 같다) |
| 노트형 항목 | 체크박스 대신 문서 아이콘(노트 리스트 행과 같다) |
| 머리 | 리스트 보기와 같다(제목 + 오른쪽 정렬·`⋯`). 추가 바는 없고 열 머리의 `+`로 추가 |
| `⋯` 메뉴 | 보기 아이콘 3개 · 완료된 항목 숨기기 · 자세히 보기 · 옵션 보기 · 새로운 열 · 공유 · 목록 활동 |

## 3. 공백
- 열 끌기(순서 바꾸기)·카드 끌기 모양, 열 `⋯` 메뉴 항목, 열 접기는 이번에 보지 않았다 → 14 작업 지도에서 [임시]로 두고 다음 관찰 때 채운다.
