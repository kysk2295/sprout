## 1. 탭 바
- **[확인] 화면 아래 떠 있는 알약 모양(iOS 26 유리 효과)**, 좌우 여백 약 16, 홈 표시줄 바로 위. 옛 버전은 바닥에 붙은 평평한 막대였다.
- **[확인] 아이콘만, 글자 없음.** 선택한 탭 = 강조색으로 **채운** 아이콘(할 일 = 채운 체크 사각형, 캘린더 = 채운 달력 + 오늘 날짜 숫자). 나머지 = 회색 선 아이콘.
- **[확인] 기본 예**: 할 일 · 캘린더(날짜 숫자) · 집중(동그라미) · 매트릭스(네 칸) · ⋯. 다른 캡처: 할 일 · 캘린더 · 습관 · 카운트다운 · 검색 · 설정.
- **[확인] 설정 → 탭 바**: "켬" 묶음(빨간 −, 이름 + 한 줄 설명, 오른쪽 끌기 손잡이) · "끔" 묶음(초록 +) · **"탭 최대 개수 5"**. 할 일 탭은 끌 수 없다. 켠 탭이 최대 개수를 넘으면 마지막 칸이 **⋯(더보기)** 가 된다 [추정 — 캡처의 ⋯ 탭].
- **[확인] 검색 탭을 끄면 목록을 아래로 당겨 검색**, 설정 탭을 끄면 서랍 위쪽 ⚙로 간다(2018 블로그).
- 탭을 다시 누르면 맨 위로 [추정, iOS 관례].
- 크기 [임시]: 알약 높이 58, 아이콘 25, 모서리 반지름 = 높이 절반.

## 2. 목록 화면 해부 (오늘 · 리스트)
- **[확인] 머리 두 줄**: 첫 줄 = 왼쪽 **둥근 ☰**(유리 원 약 40), 오른쪽 **둥근 ⋯**. 둘째 줄 = **큰 제목**(굵게 약 28, 왼쪽 정렬, 리스트 이모지가 있으면 앞에 붙음 "💼 Work"). 스크롤하면 큰 제목이 접힌다 [추정, iOS 관례].
- **[확인] 회색 바닥 위 흰 묶음 카드.** 묶음(만료됨 · 오늘 · 다음 7일 · 날짜 없음, 또는 섹션)마다 카드 하나, 모서리 약 14, 카드 사이 약 10, 좌우 여백 약 12.
- **[확인] 묶음 머리**: 카드 맨 위 줄, 이름 굵게(약 15) + 오른쪽 **개수 + ⌄**. 만료됨 머리에는 데스크톱처럼 "미루기"가 붙는다 [추정 — 모바일 캡처에서는 보지 못함, 데스크톱 02 §5].
- **[확인] 행**: 체크박스(둥근 모서리 사각, 약 18, **테두리 = 우선순위 색**: 높음 빨강 · 중간 노랑 · 낮음 파랑 · 없음 회색, 안쪽은 아주 옅은 같은 색) · 제목(약 16) · **오른쪽 끝 날짜/시각**(작게 약 12, 오늘·미래 = 강조색 "Today"·"15:00"·"19 Jan", 만료 = 빨강 "14 Jan"). 날짜 아래에 반복·알림 같은 작은 아이콘이 한 줄 더 붙을 수 있다.
- **[확인] 하위 할 일**: 부모 오른쪽에 ›(또는 ⌄) — 누르면 펼침, 하위는 한 칸 들여 표시.
- **[확인] 행 사이 선 없음**(카드 안에서 간격만). 한 줄 행 높이 약 44~46 [임시].
- **[확인] FAB**: 오른쪽 아래, 탭 알약 바로 위, 지름 약 56 강조색 원 + 흰 +.
- **[확인] 빈 상태**: 가운데 그림 + "All tasks are completed" + 작은 회색 "Take it easy".
- **[확인] 목록 ⋯ 메뉴(iOS)**: Edit · View › · Background · Show Details · Show Completed · Group & Sort · Manage Section · Select · More ›. 오른쪽 위 둥근 ⋯에서 떨어지는 팝오버, 줄마다 왼쪽 아이콘.
- **[확인] 여러 개 고르기(iOS)**: 머리가 "Select All · n Selected · 파란 ✓"로 바뀌고, 체크박스가 **둥근 고르기 원**, 아래 탭 알약 자리에 짧은 알약(날짜 · 이동 · 삭제 · ⋯). **Android**: "← n Selected" 머리, 묶음 머리가 대문자(OVERDUE·TODAY), 아래 막대 "Select All" + 아이콘들.

## 3. 리스트 서랍
- **[확인] 왼쪽에서 화면 약 80%를 덮는 판**(뒤는 어둡게). ☰를 누르거나 목록에서 오른쪽으로 밀어 연다.
- **[확인] 순서**: 맨 위 계정 줄(아바타 · 이름 · 🔔 알림 · ⚙ 설정) → 스마트 목록(Today 아이콘에 오늘 날짜 숫자, Tomorrow, Next 7 Days, Inbox, Tags ›, 사용자 필터) → 구분선 → 리스트(이모지 아이콘)·폴더(›, 누르면 펼침) → 구분선 → Trash → 맨 아래 **"+ Add"**(List · Filter · Tag 메뉴)와 오른쪽 관리 아이콘(스마트 목록 보이기/숨기기).
- **[확인] 스마트 목록 아이콘은 여러 색**(Today 주황·빨강 달력, Tomorrow 주황 해돋이, Inbox 빨강 상자, Tags 청록). 선택 행 = 옅은 파랑 둥근 면.
- **[확인] 스마트 목록 설정**: 시트 위 세그먼트 "Smart Lists | Tags", 줄마다 Show/Hidden(⌃⌄).
- **[확인] 리스트 추가 시트**: ✕ · "Add List" · ✓, 이름 칸, 색 견본 줄, 보기 종류(List · Kanban · Timeline 그림 카드), Folder ›, List Type ›, Show in Smart List ›.
- **sprout 메모**: 아이콘·그림은 직접 그린다(색 배치만 비슷하게).

- **[확인] 오른쪽으로 밀기 → 왼쪽에 칸 2개**: **완료(초록) · 고정(노랑)**.

## 5. 길게 누르기 · 끌기
- **[확인] 행 길게 누르기 = 날짜와 여러 속성을 바꾸는 메뉴**(TidBITS). 정확한 모양 캡처는 없다 → sprout 시안은 "날짜 줄 + 우선순위 깃발 + 고정·이동·태그·삭제" [임시].
- **[확인] 길게 누른 채 끌면 순서 바꾸기**(행이 떠오르고 그림자), 다른 행 위 오른쪽으로 끌면 **하위 할 일로 만들기**(`list-view` 03·05).
- **[확인] 시간 글자 길게 누르기 → 진행률 막대**(MakeUseOf) — v1 밖.

## 6. FAB · 빠른 입력 시트 (`add-tasks` 01~08)
- **[확인] + 누르면** 목록이 어두운 덮개로 가려지고, **키보드 바로 위에 흰 카드**(위 모서리만 둥글게)가 붙는다.
- **[확인] 카드 구성**: ① 제목 칸(자리 표시 "What would you like to do?") ② "Description" 회색 줄(항상 보임) ③ **도구 막대**: 날짜 · 우선순위(깃발) · 태그 · 리스트(상자) · 템플릿 · ⋯ 그리고 오른쪽 끝 **파란 원 ↑ 보내기**(빈칸이면 흐림).
- **[확인] 도구 막대 ⋯** → Image · Convert to Note · Full-Screen · **Settings**. Settings = "Edit actions"(날짜·우선순위·태그·리스트·템플릿 순서 끌기, 빼기) + More(Image·Convert to Note·Full-Screen) + "Reset Default".
- **[확인] 자연어 하이라이트**: "Meeting **at 9** on **tomorrow**" — 인식된 글자에 옅은 파랑 칠. 날짜 아이콘이 **파란 테두리 칩 "Tomorrow, 09:00"** 으로 바뀐다.
- **[확인] + 길게 누르기 = 음성 입력**, + 끌어 놓기 = 그 자리에 추가(research 20 §2).
- 보낸 뒤 카드가 비운 채 남아 연속 입력 [추정 — 데스크톱과 같음, 실기기 확인].

## 7. 할 일 상세 (`task-details` 01~33)
- **[확인] 행을 누르면 아래에서 반쯤 올라오는 시트**(위 모서리 둥글게, 뒤는 어둡게). 위로 끌면 **전체 화면**(머리가 "‹ Inbox ⌃⌄"로 바뀜).
- **[확인] 위에서부터**: 왼쪽 **리스트 이름 ⌃⌄**(누르면 이동 시트) · 오른쪽 **둥근 깃발**(우선순위 팝오버: High · Medium · Low · No Priority, 깃발 색, 지금 값 ✓) · **둥근 ⋯** → 다음 줄 **체크박스 + 날짜**(강조색 "Sat, 17 Jan" / "Tomorrow, 15 Jan, 09:00", 비면 회색 "Date & Reminder") → **제목**(약 20, 중간 굵기) → **설명**(회색 자리 표시) → 맨 아래 도구 줄: **태그 · 체크리스트로 바꾸기(≡) · 첨부(클립)**.
- **[확인] 체크리스트 모드**: 체크 아이콘이 목록 아이콘으로, 항목마다 작은 체크박스 + 오른쪽 끌기 손잡이(≡).
- **[확인] 설명 편집 중 키보드 위 서식 막대**(제목 크기·굵게·인용·체크·목록 등, 마크다운). v1은 [다음] 후보.
- **[확인] 상세 ⋯ (iOS, Android 모두 아래 시트)**: 위 **큰 아이콘 줄** Pin · Share · Won't Do · Delete, 아래 목록 Add Subtask · Link Parent Task · Start Focus · Convert to Note · Attachment · Tags · Task Activities · Add to Live Activity, "More" 아래 Comment · Location Reminder · Copy Link…, 위 "Edit"로 순서·표시를 바꾼다.
- **[확인] 이동 시트 "Move to"**: ✕ · 제목 · 검색 칸 · 리스트 목록(이모지, 지금 리스트에 ✓) · "+ Add List".
- 첨부는 이번 조사에서 뺐다(요청 범위).

## 8. 날짜 선택 시트 (`task-details` 01)
- **[확인] 아래 시트**: 왼쪽 둥근 ✕ · 가운데 세그먼트 **Date | Duration** · 오른쪽 **파란 원 ✓**.
- **[확인] Date 탭**: 월 머리("January" + ‹ ›) · 요일 머리(M T W T F S S, 주 시작 설정 따름) · 날짜 칸(오늘 = 강조색 채운 원) · 아래 둥근 카드 **Time · Reminder · Repeat**(값 "None" + ⌃⌄).
- **[확인] Duration 탭**: Date 칸 / Time 칸 두 칸(강조색 값 "14 Jan, Wed" · "17:00 - 18:00", 아래 회색 "Today" · "Duration: 1 hour") · All Day 토글 · "Floating Time ⌃⌄" · Reminder(“On time ×”) · Repeat.
- **[추정] 빠른 날짜 줄(오늘·내일·다음 주·오늘 밤 아이콘)**: 데스크톱·옛 모바일에는 있었지만 **최신 iOS 날짜 시트 캡처에는 없다**. TidBITS가 말한 "미래 날짜 버튼 사용자 지정"은 스와이프/길게 누름 날짜 메뉴 쪽으로 읽힌다.
- 시간 = iOS 휠 [추정, 캡처 없음]. 알림 목록 = 데스크톱 03 §3.2와 같다고 본다.
- **[확인] 다시 알림(스누즈) 시트(앱 안)**: 15분 · 30분 · 1시간 · 3시간 / 내일 · 오늘 저녁 · 다음 시간 · 직접 — 8칸 격자 + "Modified Time".

## 10. 캘린더 (모바일)
- **[확인] 머리**: 왼쪽 **둥근 보기 전환 버튼**(칸 모양 아이콘), 가운데 **월 이름**("October"/"January"), 오른쪽 **오늘로 가기**(달력 아이콘) + **⋯**.
- **[확인] ⋯ 메뉴**: Filter View Range · View Options · Arrange Tasks · Calendar Subscription · Share · Print.
- **[확인] 월 보기**: 칸마다 날짜 숫자(오늘 = 강조색 원) + 리스트 색 옅은 띠에 제목(잘림), 주 번호(W22) 표시 옵션.
