# TickTick Mac 직접 조사 · 2026-10-03

사용자 요청: 데스크톱 앱을 직접 조사하고 UI/UX를 sprout에 구현한다.
조사 환경: 실행 중인 `com.TickTick.task.mac`, 한국어, Dark. 메인 창 1378×884, 설정 창 800×680. 개인 할 일·계정 정보는 기록하지 않는다. 아래는 실제 UI 및 접근성 트리로 확인한 결과이며, 기존 영상/도움말 기반 추정과 충돌하면 이 기록을 우선한다.

## 셸 / 명령 메뉴

- ⌘K: 폭 560의 독립 팝업. 상단 검색 입력 높이 약 55, 행 40. 기본 첫 항목 `할 일 추가 ⌘N`.
- 그룹: 공통 작업 / 내비게이션 / 지원. 빠른 추가, 주 창, 미니 창, 할일, 달력, 검색, 설정, 스마트 목록, 도움말, 단축키.
- `내일` 입력 시 `내일로 이동`과 `"내일" 검색`만 남는다. 결과 첫 행 선택 강조.
- ⌘F: 검색 팝업. 작업·태그·목록·필터를 검색. 빈 상태 설명과 닫기 버튼. 결과 없음은 클라우드 검색 링크(서버 없는 sprout에는 구현하지 않음).
- ⌘N: 별도 추가 팝업(폭 600, 높이 약 114). 제목 입력, 아래 날짜·우선순위·리스트와 오른쪽 `추가` 버튼.
- 입력 초안 `sprout UI 조사 내일 오후 3시`: `내일 오후 3시`가 파란 링크로 인식되고 하단 `내일, 오후 3:00` 표시. 초안 취소, 저장하지 않음.

## 확인된 단축키

| 기능 | Mac 키 |
|---|---|
| 명령 메뉴 | ⌘K |
| 검색 | ⌘F |
| 새 할 일 팝업 | ⌘N |
| 전역 퀵 추가 | ⌃⇧A |
| 주 창 표시/숨기기 | ⇧⌘E |
| 미니 창 표시/숨기기 | ⇧⌘O |
| 설정 | ⌘, 또는 G → S |
| 전체 / 오늘 / 내일 / 다음 7일 / 기본함 | G → A / T / R / N / I |
| 완료 / 계획 취소 / 휴지통 | G → C / W / G |
| 아래 작업 / 하위 작업 | Enter / Shift+Enter |
| 작업 삭제 | ⌘Backspace |
| 실행 취소 / 다시 실행 | ⌘Z / ⇧⌘Z |
| 날짜 / 우선순위 / 태그 / 리스트 입력 | * / ! / # / ~ 또는 ^ |
| 캘린더 일 / 주 / 월 / 오늘 | D 또는 1 / W 또는 2 / M 또는 3 / T |

기존 문서의 '내일 = G→M' 추정은 틀렸다. G→M은 내게 할당이다. 일부 원본 한국어 설명에는 번역 오류가 있으므로 기능에 맞게 표기한다.

## 설정

- 별도 800×680 창, 왼쪽 220px 탐색, 오른쪽 580px 내용. 닫기는 왼쪽 위.
- 탐색: 계정 / 프리미엄 / 기능 모듈 / 스마트 목록 / 알림 / 날짜 & 시간 / 외관 / 더 보기 / 통합 및 가져오기 / 협업 / 메모지 / 단축키 / 정보.
- sprout v1에 없는 유료·집중·습관·협업·메모지 등은 조사 참고만 하고 기능을 추가하지 않는다.
- 스마트 목록의 정확한 용어: 전체, 오늘, 내일, 다음 7일, 기본함, 태그, 필터, 완료, 계획 취소, 휴지통. 각 항목 표시 옵션은 보이기 / 숨기기 / 비어있지 않으면 표시.
- 날짜 & 시간: 일주일을 시작하는 요일, 추가 달력, 주 번호 표시, 시간대.
- 외관 상단 탭: 테마 / 앱 아이콘 / 표시. 테마는 색상 견본 격자, 하단 시스템 외관에 따라 다크 테마 자동 전환.
- 표시: 글자 크기 3개, 사이드바 개수 3개, 완료 스타일 기본값/취소선.
- 알림: OS 설정 이동, 완료 소리, 이메일 알림. 계정 관련 개인 정보는 수집하지 않음.
- 더 보기: 언어, 열 때 우선 켜짐, 로그인 시 자동 실행, 시작 시 최소화, 날짜 인식/인식 문자열 삭제, 태그 인식/이름에서 태그 제거, URL 분석.
- 할 일 기본값: 날짜, 날짜 모드, 지속 시간(현재 1시간), 시각 알림(현재 정각), 종일 알림(현재 없음), 중요도, 태그, 목록, 기본 추가 위치, 지연된 할일 표시 위치.
- 설정값은 읽기만 했으며 변경하지 않음.

## 날짜 선택기

빠른 추가 초안에서 날짜를 눌러 확인. 상단 `날짜 / 지속 시간`, 오늘·내일·다음 주·달 아이콘, 일요일 시작 월 달력, 시간·알림·반복 행. 반복 행을 누르면 하단 메뉴가 펼쳐짐. 팝업 경계 밖 메뉴는 캡처에서 잘리는 경우가 있어 전체 내용은 추가 확인 필요.

## 리스트·태스크 후속 확인 (10월 4일)
- 폴더 메뉴: 목록 추가 / 편집 / 상단 고정 / 그룹해제.
- 일반 리스트 메뉴: 편집 / 상단 고정 / 공유 / 복사 / 기록 보관소 / 삭제.
- 목록 추가 창: 이름, 색상 견본, 보기 유형(목록/칸반/타임라인), 폴더, 목록 유형, 스마트 목록에 표시, 취소/저장. 오른쪽에 목록 미리보기.
- 조사 전용 리스트 `sprout UI 조사`와 `조사 A — 날짜 없는 할 일` 1개를 생성했다. 개인 기존 항목은 편집하지 않았다. 날짜 팝업 확인 중 조사 태스크에 오늘 날짜를 저장했다.
- 태스크 메뉴: 날짜 바로가기 4개, 우선순위 깃발 4개, 하위 할일 추가, 상단 고정, 계획 취소, 이동, 태그, 포커스 시작, 복사, 링크 복사, 메모장 열기, 노트로 변환, 삭제.
- 목록 더 보기: 보기 유형, 완료된 할일 숨기기, 자세히 보기, 옵션 보기, 새로운 열, 공유, 목록 활동, 인쇄.
- 정렬 버튼: 그룹화하기 / 정렬하기 각각 하위 메뉴. 새 일반 리스트는 두 값 모두 사용자 설정.
- 팝업 Escape가 닫히지 않는 경우가 있었다. 자동화 도구 전달 문제와 실제 동작을 구분하지 못해 Esc 의미는 확정하지 않는다.

## 2026-10-04 추가 실측: 배치와 분할
- 1378×884 창에서 배치 패널은 x1154부터 끝까지 약224px. 탭은 `목록 / 태그 / 우선 순위`, 행은 약18px 높이·3px 간격의 색 막대다.
- 우상단 필터: 날짜 없음(기본 체크), 만료됨, 노트 숨기기, 작업 계층 구조 숨기기. 노트는 sprout v1 범위 밖.
- 태스크 레일 우클릭 → `캘린더와 함께 보기`: 왼쪽은 기존 사이드바·태스크·상세, 오른쪽 약320px 일간 캘린더. 기존 캘린더 더보기에는 분할 항목이 없었다.
- 위 조작은 화면 탐색만 수행했다. 기존 사용자 태스크를 드래그하지 않았다.
