# 틱틱 조사: 필터 (사용자 정의 스마트 리스트)

- 출처: [TickTick Help — Filters](https://help.ticktick.com/articles/7055782240994721792) (2026-09-13 확인)

## 기본
- 필터는 사이드바에서 **리스트 아래**에 표시된다. 안 보이면 설정 → 스마트 리스트에서 "필터"를 표시로 바꾼다.
- 필터를 잘 쓰려면 태스크를 만들 때 시간, 태그, 우선순위 같은 속성을 붙여 두는 게 좋다고 안내한다.

## 조건 설정 두 가지
| 방식 | 내용 |
|---|---|
| 일반 필터 | 리스트, 태그, 날짜 등 속성으로 거르고, 키워드로 내용도 거른다. 예: "오늘 읽을 것" |
| 고급 필터 | 여러 조건을 **AND / OR**로 묶는다. 리스트, 날짜, 우선순위, 태그 조건. 같은 속성을 여러 개 고를 때 권장된다 |
- **미리보기** 버튼으로 조건에 맞는 태스크를 미리 보고 조건을 고칠 수 있다.

## sprout v1
- PRD의 "사용자 필터(태그·우선순위·날짜 조합)"가 이것이다. v1에서는 일반 필터를 넣고, 고급 필터(AND/OR)는 후보로 둔다.
- 데이터: `filters(id, name, rule_json, sort_order)`. rule_json 하나로 일반과 고급을 같은 구조로 표현해 두면, 나중에 고급 필터를 추가하기 쉽다.
- 필터 결과는 로컬 SQLite 쿼리로 계산한다(로컬 퍼스트).
