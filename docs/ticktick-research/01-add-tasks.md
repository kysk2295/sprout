# 틱틱 조사: 태스크 추가

- 출처: [TickTick Help — Add Tasks](https://help.ticktick.com/articles/7055782422935240704) (2026-09-13 확인)
- 요약 노트이며, 원문을 옮겨 적지 않고 사실만 정리했다.

## 데스크톱 빠른 추가 (v1 대상)
- **위치:** 태스크 목록 화면 맨 위의 "태스크 추가 바". 목록마다 있다(일반 리스트와 스마트 리스트 모두).
- **Enter:** 입력한 내용으로 태스크를 만든다.
- **Shift+Enter:** 제목을 입력하던 중에 설명(메모) 입력으로 넘어간다. 설명까지 쓴 뒤 **Cmd+Enter**(Windows는 Ctrl+Enter)로 만든다.
- **오른쪽 드롭다운:** 우선순위 설정, 첨부 추가, 템플릿에서 선택, "입력창 설정"(입력창 스타일 전환)을 제공한다.
- **전역 추가 단축키:** Windows `Alt+Shift+A`, **Mac `Cmd+Shift+A`**. 도움말은 공통으로 `Shift+Alt+A`라고 적지만, 공식 [Mac 페이지](https://ticktick.com/mac)는 Cmd+Shift+A다. 다른 앱을 쓰는 중에도 추가 바가 뜬다.

## 스마트 인식 (자연어)
- 제목에 날짜·시간을 쓰면 인식해서 마감일과 알림을 자동으로 설정한다. 예: "Meeting at 9 tomorrow".
- **인식 취소:** Delete 키를 누르거나, 인식된 시간 부분을 클릭하면 인식을 풀고 일반 텍스트로 남긴다.
- 설정에서 끌 수 있다: 설정 → 일반 → 스마트 인식 → 스마트 날짜 파싱. 상세 문법은 [02-smart-recognition.md](02-smart-recognition.md)에 정리한다.

## 태스크 기본값
- 새 태스크에 자동으로 채워지는 속성(날짜, 리스트, 우선순위)을 미리 정해 둔다.
- 위치: 설정 → 일반 → 태스크 기본값.

## 기타 추가 경로 (v1 범위 판단)
| 경로 | 내용 | v1 |
|---|---|---|
| 위젯 "+" | 위젯의 +를 누르면 추가 화면으로 바로 이동 | 모바일 최소형에서 검토 |
| 음성 | 모바일에서 +를 길게 눌러 음성 입력. 좌우로 끌면 녹음 모드(최대 30분). 시간 정보는 인식해서 반영 | 제외 |
| 이메일 | 전용 주소로 메일을 보내면 태스크가 됨(공용 주소, 개인 주소 2종) | 제외 |
| Siri | iOS 설정에서 켜면 Siri로 추가. "미리 알림" 자동 가져오기 옵션 | 제외 |
| 클립보드 | 복사한 내용에 시간 정보가 있으면 앱을 열 때 추가를 제안. 여러 줄을 복사하면 일괄 추가를 제안 | 제외(후보) |

## sprout 명세로 넘길 결정 포인트
- 한국어 자연어("내일 9시 회의")를 인식 대상 1순위로 둔다. PRD의 가정 A6에 해당한다.
- 전역 단축키 기본값을 틱틱과 같은 `Shift+Alt+A`로 할지 정해야 한다. 틱틱과 동시에 설치하면 충돌할 수 있다.
