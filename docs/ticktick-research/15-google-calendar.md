# 틱틱 조사: 구글 캘린더 연동

- 출처: [TickTick Help — Google Calendar](https://help.ticktick.com/articles/7055781593733922816) (2026-09-13 확인)

> ⚠️ **PRD와 다른 점:** 틱틱의 구글 "구독"은 **양방향**이다. 틱틱에서 일정을 추가·수정·삭제하면 구글에도 반영된다. sprout v1은 Q6에서 "구글 읽기 전용"으로 정했으므로, 이 부분은 **틱틱 동급이 아니다.** 유지할지 사용자 확인이 필요하다.

## 두 가지 방식
| 방식 | 방향 | 결과 |
|---|---|---|
| 구글 캘린더 구독 | 구글 일정을 틱틱에 표시. 틱틱에서의 추가·수정·삭제도 구글에 반영 | 사이드바 "구독 캘린더"에 계정의 일정이 보인다 |
| 구글 캘린더 통합 | 틱틱 리스트 ⇄ 구글 캘린더 양방향 | 고른 리스트의 **시간 있는 태스크가 구글 일정**이 되고, 구글 일정은 고른 리스트의 태스크가 된다 |

## 구독 흐름 (데스크톱)
1. 아바타 → 설정 → 연동 & 가져오기 → Google → "구글 캘린더에서 구독"
2. 구글 로그인·권한 동의
3. 설정 화면에 구독한 계정이 보인다.
4. 사이드바 **"구독 캘린더"** 영역에서 해당 계정의 모든 일정을 본다. 구독 캘린더 목록의 입력창에서 일정을 바로 추가할 수도 있다.

## 통합 옵션
- 동기화할 틱틱 리스트와 구글 캘린더를 고른다.
- 구글에서 넘어온 태스크에 붙일 **기본 태그**(기본값 "GCal")를 정한다. 리스트를 "전체"로 고르면 **기본 리스트**도 정한다.
- 동기화하지 않는 것: 구글의 근무 위치 일정, 부재중 일정, 오늘 이전에 만든 일정.
- 통합을 해제해도 이미 동기화된 내용은 양쪽에 남는다. 구글에서는 출처가 "TickTick"인 일정을 지우고, 틱틱에서는 "GCal" 태그로 모아서 일괄 삭제하라고 안내한다.

## 기타 구독
- CalDAV: 설정 → 연동 & 가져오기 → 캘린더 구독 → 캘린더 추가 → CalDAV. 계정, 비밀번호, 서버 주소, 이름을 입력한다.
- 로컬 캘린더, iCloud, 아웃룩, Exchange, URL(ICS)도 지원한다.

## sprout v1 반영 (현재 결정 기준)
- 구현: 구독 방식 중 **읽기**만 한다. 사이드바 "구독 캘린더" 영역과 캘린더 오버레이를 틱틱과 같은 위치에 둔다.
- 추가·수정·삭제 버튼은 숨기거나 비활성으로 두고, 쓰기는 v1 이후로 미룬다(PRD 백로그의 "구글 캘린더 쓰기").
