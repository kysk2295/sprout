# 틱틱 조사: 그룹·정렬

- 출처: [TickTick Help — Manage Tasks with Group & Sort](https://help.ticktick.com/articles/7056594711640801280) (2026-09-13 확인)

## 개념
- **그룹**은 태스크를 기준에 따라 묶는 것이고, **정렬**은 각 그룹 안의 순서를 정하는 것이다. 둘은 따로 고른다.
- **여는 곳(데스크톱):** 리스트를 열고 오른쪽 위 정렬 버튼을 누른다.

## 그룹 기준
| 기준 | 묶이는 방식 | 쓸 수 있는 곳 | v1 |
|---|---|---|---|
| 사용자 지정(섹션) | 일반 리스트에서 `...` → 섹션 추가. 예: 독서 리스트 → 소설/역사/업무 | 일반 리스트 | 포함 |
| 리스트 | 태스크가 속한 리스트별 | 스마트 리스트, 폴더 | 포함 |
| 시간 | 오늘 / 내일 / 다음 7일 / 나중 / 기한 지남 | 전체 | 포함 |
| 우선순위 | 높음 / 중간 / 낮음 / 없음 | 전체 | 포함 |
| 태그 | 태그별 | 전체 | 포함 |
| 담당자 | 공유 리스트의 담당자별 | 공유 리스트 | 제외 |
| 생성 시간 | 만든 시점별 | 전체 | 포함 |

## 정렬 기준
| 기준 | 옵션 |
|---|---|
| 날짜 | 마감일 순 |
| 우선순위 | 높은 순 |
| 생성 시간 | 최신순 / 오래된순 |
| 수정 시간 | 최신순 / 오래된순 |
- 수동 드래그 정렬도 있다([05-list-view.md](05-list-view.md)). 수동 정렬과 자동 정렬이 어떻게 공존하는지는 확인이 필요하다.

## 대표 조합 (틱틱 안내 예시)
- 최근 추가 확인: 그룹 = 생성 시간, 정렬 = 생성 시간 최신순
- 리스트별 마감 확인: 그룹 = 리스트, 정렬 = 날짜 (폴더·스마트 리스트에서)
- 중요도 확인: 그룹 = 사용자 지정, 정렬 = 우선순위

## 기타
- 칸반 뷰도 같은 그룹·정렬을 쓴다. 그룹이 곧 칸반 열이 된다. v1에서는 칸반을 제외한다.
- FAQ에 "기본 날짜 정렬로 되돌리기"가 있다(본문 미확인).

## 데이터 모델 영향
- 리스트별 보기 설정이 필요하다: `view_settings(list_id, group_by, sort_by, sort_dir)`. 기기 사이 동기화 대상이다.
- 사용자 지정 그룹은 `sections(id, list_id, name, sort_order)`로 두고, 태스크에 `section_id`를 둔다.
- 수동 정렬용으로 태스크에 `sort_order` 필드를 둔다.
