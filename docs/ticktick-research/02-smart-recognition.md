# 틱틱 조사: 스마트 인식

- 출처: [TickTick Help — Smart Recognition](https://help.ticktick.com/articles/7081924556310446080), [Add Tasks](https://help.ticktick.com/articles/7055782422935240704) (2026-09-13 확인)
- 상태: **부분 조사.** 반복, 미리 알림, 미룬 알림 섹션은 접힌 탭이라 아직 펼쳐서 확인하지 못했다. 기호 문법(`#`, `~`, `!`)은 아직 출처를 찾지 못했다.

## 확인된 동작
- **켜기/끄기:** 아바타 → 설정 → 스마트 인식. 세부 항목은 "스마트 날짜 파싱" 등이다.
- **적용 범위:** 빠른 추가, 음성 입력 등으로 태스크를 만들 때 날짜와 시간을 인식해 알림까지 설정한다.
- **제목에서 날짜 문구를 지울지** 사용자가 설정할 수 있다(지우기 또는 남기기).
- **모호한 시각은 가장 가까운 미래의 유효한 시각으로 해석한다.** 예: 지금이 오후 4시일 때 "밤 9시"는 오늘 밤 9시가 된다.
- **인식 취소:** Delete 키를 누르거나 인식된 부분을 클릭한다(Add Tasks 문서 기준).
- 인식 대상 섹션은 날짜와 시간, 반복, 미리 알림, 미룬 알림이다. 세부 내용은 미확인이다.
