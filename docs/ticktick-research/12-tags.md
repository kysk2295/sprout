# 틱틱 조사: 태그

- 출처: [TickTick Help — Manage Tasks with Tags](https://help.ticktick.com/articles/7055782255804809216) (2026-09-13 확인)

## 기본
- 한 태스크에 태그를 **여러 개** 붙일 수 있다. 분류, 상태, 장소 같은 용도로 쓴다.
- 태그는 사이드바에서 **리스트 아래**에 표시된다. 안 보이면 설정 → 스마트 리스트에서 "태그"를 표시로 바꾼다.

## 태그 붙이기 (데스크톱)
1. 태스크 우클릭 → 태그 → 기존 태그를 고르거나 새로 만든다.
2. 만들거나 편집할 때 **`#` 입력** → 새 태그를 만들거나 기존 태그를 고르는 드롭다운이 뜬다. `#` 기호 문법의 출처가 이것이다([02-smart-recognition.md](02-smart-recognition.md)의 남은 조사 해결).
3. 태스크를 사이드바의 태그 위로 끌어 놓는다.

## 관리
- 사이드바에서 태그 **우클릭 → 고정, 편집, 삭제**. 편집을 누르면 태그 편집 화면으로 간다.
- **2단계 태그:** 사이드바에서 태그를 다른 태그 **아래로** 끌어 놓으면 부모 태그가 지정된다. 편집 화면에서 부모를 고를 수도 있다. 2단계까지만 된다.
- **순서:** 사이드바에서 끌어서 바꾼다.
- 목록을 태그별로 그룹화할 수 있다([08-group-sort.md](08-group-sort.md)).

## 데이터 모델 영향
- `tags(id, name, color, parent_id, sort_order, pinned)`. `parent_id`는 한 단계만 허용한다.
- `task_tags(task_id, tag_id)`.
