## 조사 공백 (도움말만으로는 채울 수 없는 것)
1. **시각 명세:** 사이드바 폭, 아이콘 레일, 행 높이, 글꼴, 색, 여백, 호버·선택 상태. 도움말에는 수치가 없다.
2. **전체 단축키 표:** 앱의 `?` 화면에만 있다.
3. **우클릭 메뉴 전체 항목:** 태스크, 리스트, 태그, 폴더 각각.
4. **빈 상태·오류·로딩 화면**, 설정 화면 구조.
5. 스마트 인식의 반복·미리 알림 문법, 기호(`~`, `!`) 문법. 도움말 탭이 접혀 있다.
6. 반복·하위 태스크 FAQ 본문(한 회차만 수정, 최대 깊이 등).

→ 1~4는 **틱틱 앱(웹 또는 데스크톱)을 직접 열어 화면을 캡처하고 측정**해야 채울 수 있다.

## PRD에 반영할 발견
- 스마트 리스트에 **"내일"** 추가 (04)
- **분할 보기**가 PRD 7.1 "캘린더 오른쪽 패널"의 정확한 원형 (14)
- 하위 태스크와 체크 항목을 **분리** (11)
- 반복에 **완료일 기준**이 있어서 RRULE만으로는 부족 → `repeat_from` 필드 (07)
- 구글 연동 방향이 틱틱과 다름 → 사용자 결정 필요 (15)
- 틱틱은 Mac에서 캘린더 다중 선택·미루기·명령 메뉴를 지원하지 않음 → sprout는 Mac에서도 지원(동급 이상) (06, 10, 16)
