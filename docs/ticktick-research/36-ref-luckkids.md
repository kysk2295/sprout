## 0. 프로젝트 요약
- 습관 목록(30개, 6개 범주: 집 정돈·셀프케어·건강·일·마인드셋·자기계발)을 골라 알림 시각을 정한다. 습관 하나를 하면 캐릭터가 **1%씩** 자라고, 4단계를 거쳐 100%가 된다.
- 가입하면 캐릭터가 무작위로 배정되고, 닉네임과 "행운의 한마디"를 정한다. 다 키운 캐릭터는 "내가 모은 럭키즈"에 쌓인다. 친구를 초대하면 "가든"에 친구 캐릭터가 함께 있고, 리그(순위)가 있다. 프로필 카드를 이미지로 저장·공유한다.
- 탭 4개: 홈 · 습관 · 가든 · 설정.

## 1. 캐릭터 그림
| 무엇 | 관찰 | 우리가 가져갈 기법 |
|---|---|---|
| 재질 | 무광 비닐·점토 인형 같은 3D 렌더. 표면이 부드럽고 살짝 반투명(속살 빛이 비치는 느낌). 강한 하이라이트는 없고 넓고 흐린 빛 | SVG로 흉내: 면마다 **둥근 음영**(밝은 쪽 흰색 섞음, 그늘 쪽 차가운 남회색 섞음) + 흐린 흰 하이라이트 하나 + 바닥 접촉 그림자 |
| 선 | 외곽선이 없다. 형태는 명암으로만 읽힌다 | 진한 선(#3A3A3A)을 버리고, **같은 색 계열의 얇은 선**(0.9px, 반투명)만 남긴다. 작은 크기에서 형태가 무너지지 않게 하는 안전선 |
| 비율 | 머리 = 몸 한 덩어리. 아래에 짧은 다리 + 고무장화 같은 큰 발 | 큰 머리 + 짧은 몸은 우리 42 비율 그대로. 발은 둥근 발 두 개(장화는 쓰지 않는다) |
| 얼굴 | 아주 작은 점 눈 두 개 + 가는 웃는 선. 표정이 거의 없고 몸 모양이 감정을 맡는다 | 우리는 반대로 **큰 눈 + 빛점 두 개 + 볼 번짐**(표정 8종이 필요하다 — 40 §6). 대신 얼굴 부품을 줄여 깔끔하게 |
| 색 | 캐릭터마다 한 색 계열(초록·노랑·분홍·하늘·파랑) + 안쪽에 살짝 무지갯빛 그라데이션(알 단계) | 종마다 **한 색 계열** + 소품 한 색. 그늘을 남회색으로 섞어 노랑·하늘색도 탁해지지 않게 |
| 성장 4단계 | LV1 동글한 알 덩어리 → LV2 작은 반구 → LV3 무늬·테두리가 생김 → LV4 모티프 완성(꽃잎·잎 모양) + 발. 크기도 커진다 | 단계마다 **실루엣이 바뀐다**는 원칙은 42와 같다. 우리는 탈바꿈(애벌레 → 나비, 올챙이 → 개구리)으로 더 크게 바꾼다 |
| 모티프 | 행운 상징(구름·해·네잎클로버·토끼·터키석)을 캐릭터로 만들었다 | 우리 모티프는 **새싹·정원**(브랜드 "꿈틀" + 달력 새싹 로고). 상징을 그대로 쓰지 않는다 |

## 2. 색과 배경
- **다크가 기본이다.** 앱 화면 대부분이 검정(거의 #000) 바탕에 짙은 회색 카드(약 #1C1C1E)다. 밝은 테마 화면은 보드에 나오지 않는다.
- **브랜드 초록 하나**가 모든 강조를 맡는다: 체크 원, `+` 버튼, 진행 막대, 숫자(`1/4`, `+6`), 주요 버튼, 탭 선택. 다른 색은 범주 아이콘에만 있다.
- **캐릭터 5색 팔레트**: 캐릭터마다 이름 붙인 색(Lucky Green·Yellow·Pink·Light Blue·Deep Blue) + 다크 바탕용 진한 단계 3개(검정에 섞은 30%·50%·70% 정도). 범주·카드·공유 카드 색이 이 표에서 나온다.
- 발표 보드는 초록·노랑·파랑·보라 단색 그라데이션 판을 쓰지만, 앱 안에서는 **캐릭터 장면만** 색이 풍부하다(하늘 그라데이션 + 둥근 언덕 + 풀). 나머지 UI는 무채색이다.
- 공유 카드: 흰 바탕에서 캐릭터 색으로 번지는 옅은 그라데이션 + 캐릭터 색 굵은 글자.
- **가져갈 것:** "UI는 차분한 무채색, 색은 강조 하나 + 캐릭터 자리"라는 배분. 다크 면 단계(바탕 / 카드 / 칸)를 세 단계로 나누는 것. 5색 + 진한 단계 표.

## 3. 배치와 카드
- **홈 = 장면이 화면 끝까지.** 상태 막대 뒤까지 하늘이 깔리고, 화면 위 2/3에 언덕·풀밭과 받침 위 캐릭터가 있다. 위에는 주 달력 띠(요일 + 날짜, 오늘은 흰 원, 한 날은 옅은 원)가 장면 위에 겹친다.
- **유리 카드:** 장면 아래쪽에 반투명 짙은 초록 카드(배경 흐림)가 얹힌다. 안에 큰 숫자 `75%` + 작은 이름 `럭키즈 성장률` + 말풍선 칩 `한 단계 남았어요`(꼬리 달린 검정 칩) + 굵은 초록 막대(둥근 끝). 오른쪽 위 초록 알약 `프로필 보기 ›`.
- 카드 모서리는 크다(약 16~20), 휴대폰 화면 틀은 40 안팎. 카드 사이 간격이 넉넉하다.
- 습관 목록: 범주 머리(둥근 사각 안 3D 아이콘 + 이름 + 접기 ⌃), 행(제목 + 회색 시각 + 오른쪽 초록 체크 원 또는 회색 `+` 원). 맨 위 범주 칩 줄(테두리 알약 + 작은 아이콘, 고른 칩은 초록 테두리).
- 오늘 습관: 큰 제목 `오늘의 습관` + 오른쪽 초록 `1/4`, 회색 한 줄 `지금까지 1개 완료했어요!` + 초록 `숨기기`. 행은 빈 원 체크 + 범주 아이콘 + 제목 + 시각.
- 가든: 3열 격자, 칸마다 짙은 둥근 사각에 캐릭터 하나. 내 칸에는 초록 `나` 배지. 비어 있는 칸은 흐린 실루엣. 목록 보기로 바꾸면 썸네일 + 이름 + `77네잎` 같은 점수.
- 토스트: 화면 아래 가운데 짙은 회색 알약 + 초록 체크 + `습관이 추가되었어요`.
- 대화 상자: 짙은 카드, 굵은 두 줄 제목 + 회색 설명 + 두 버튼(회색 `거절하기` / 초록 `친구하기`, 같은 폭).
- **가져갈 것:** 장면 + 유리 카드 구성, 큰 숫자 + 작은 단위(`%`), 꼬리 달린 칩, 굵은 둥근 막대, 같은 폭 두 버튼, 짙은 토스트 알약.

## 4. 글자
- 한글 산세리프(Pretendard 계열로 보임)를 굵게 쓴다. 섹션 제목은 아주 굵고 크며 자간이 좁다. 본문은 가볍고 회색.
- 숫자는 크게(`75%`의 `%`는 절반 크기), 강조색 숫자가 많다(`1/4`·`+6`).
- 앱 안 글자 크기 단계가 적다: 큰 제목 / 행 제목 / 회색 보조 / 아주 작은 탭 이름.
- 영문 로고는 굵은 기하학 산세리프 소문자.
- **가져갈 것:** 큰 제목을 지금(20px)보다 굵고 크게, 자간을 좁게. 큰 숫자 + 작은 단위. 단계 수는 적게.

## 5. 성장과 모으기를 보여 주는 법
- 성장은 **% 하나**로만 보여 준다(경험치·레벨 숫자 없음). 다음 단계까지 남은 것은 말풍선 칩 한 줄.
- 성장 단계표: 캐릭터 4개를 크기 차이로 나란히 + 아래 초록 `LV2` 배지.
- 다 키운 캐릭터는 홈 카드 `내가 모은 럭키즈`에 작은 얼굴 5개 + 개수로 쌓인다.
- 가든(친구)·리그(시상대 1·2·3 메달)로 사회적 모으기.
- 우리와 다른 점: 우리는 레벨·XP가 있고(10 §6), 종이 바뀌지 않으며, 옷을 모은다. 그래서 **% = 다음 레벨까지**로 바꿔 쓴다(레벨 숫자는 작은 배지로).

## 6. 꾸미기
- 옷·장식을 입히는 화면은 **없다.** 개인화는 이름 짓기·한마디·공유 카드 색뿐이다.
- 그래서 우리 옷장(43 §5)은 이 레퍼런스에서 **카드·격자 기법만** 가져온다: 짙은/옅은 둥근 칸 + 가운데 큰 그림 + 아래 이름, 고른 칸은 강조색 테두리, 잠긴 칸은 흐린 실루엣.

## 7. 움직임·작은 인터랙션 [정지 이미지라 대부분 추정]
- 온보딩 연속 화면에서 보이는 흐름: 손가락 그림이 가리키는 말랑한 덩어리를 **누른다** → 이름 입력 → `두근두근, 럭키즈가 탄생하고 있어요!` + 작은 알 → **화면 전체가 초록으로 번쩍** → 캐릭터 등장 + `행운 카드 받아보기`. 탄생을 기다리게 하는 짧은 연출.
- 토스트·말풍선 칩·초대 대화 상자가 있다. 버튼 눌림·칩 등장은 보이지 않는다.
- 우리 쪽은 이미 42 §4·43 §4에 움직임이 있다. 이 레퍼런스에서는 **"태어나는 순간을 기다리게 하는 한 박자"**만 가져온다(씨앗 깨기 앞에 잠깐 흔들림).

## 8. 온보딩·그림 쓰는 법
- 온보딩 화면은 짙은 초록 단색 그라데이션 바탕 + 가운데 물체 하나 + 위 두 줄 굵은 문장 + 아래 꽉 찬 초록 버튼. 한 화면에 한 가지 일만.
- 범주 아이콘은 광택 있는 3D 아이콘(집·하트·전구·책·가방·말풍선) — 같은 빛 방향, 같은 둥근 모서리.
- 앱 아이콘: 검정 둥근 사각 안에 빛나는 초록 덩어리. 잠금 화면 알림에도 같은 덩어리.
- 소개 사이트: 굵은 소문자 로고 + 작은 색 점·마름모 몇 개 + 큰 둥근 빛 원 위 캐릭터 무리.

## 9. 왜 고급스럽고 재밌어 보이나
1. **절제된 배분.** UI는 거의 무채색이고, 색과 질감은 캐릭터와 장면에만 몰려 있다. 그래서 캐릭터가 더 비싸 보인다.
2. **캐릭터 그림의 완성도.** 같은 조명·재질·비율로 다섯 종 × 네 단계를 그려서 한 가족으로 보인다.
3. **반복되는 둥근 모양.** 앱 아이콘·빛 원·버튼·카드 모서리가 모두 같은 말랑한 둥근 꼴이다.
4. **큰 숫자 하나.** 화면마다 가장 중요한 숫자 하나가 크게 있다(`75%`, `1/4`).
5. **장면 위 유리 카드.** 정보가 장면을 가리지 않고 장면 위에 떠 있어 깊이가 생긴다.
6. **브랜드 색 하나를 끝까지.** 체크·막대·버튼·숫자·탭이 같은 초록이라 정돈돼 보인다.
7. **다크 면 단계가 분명하다.** 바탕·카드·칸이 세 단계로 나뉘어 검정 화면이 평평하지 않다.

- 이번에 새로 짚은 것: ① 얼굴이 몸 높이의 3~5%로 아주 작고 볼이 없다 ② 렌더가 진짜 경로 추적(면광·AO·속살 빛·접촉 그림자) ③ 단계 차이 = 실루엣 하나 ④ 캐릭터를 공개하기 전에 이름부터 짓게 하고, 화면 가득 빛 번쩍 뒤 등장(공개가 보상) ⑤ 홈·온보딩·가든 모두 장면이나 단색 판이 화면 끝까지 — 흰 빈 페이지가 없다.
- §10 표의 "3D 렌더를 쓰지 않는다"는 49에서 뒤집는다(결정 ①): 미리 구운 3D 스프라이트(Blender 절차 생성, 우리 캐릭터). 고무장화·그루터기·행운 모티프·문구는 여전히 쓰지 않는다(49 §0).
