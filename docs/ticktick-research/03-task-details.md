# 틱틱 조사: 태스크 상세·편집

- 출처: [TickTick Help — Task Details and Editing](https://help.ticktick.com/articles/7055782408586526720) (2026-09-13 확인)
- 데스크톱 기준 요약. 원문을 옮기지 않고 사실만 정리했다.

## 상세 영역에서 편집하는 속성
| 속성 | 데스크톱 동작 | v1 |
|---|---|---|
| 날짜 | 태스크 우클릭 → 날짜 → 오늘/내일/다음 주/직접 지정. 또는 상세 영역의 "마감일"을 클릭해 날짜와 시간을 고른다 | 포함 |
| 기간 | 날짜 선택기에서 "기간" 탭으로 바꿔 시작과 끝을 지정. 하루 안(9:00–12:00)도, 여러 날(종일 켜고 날짜 범위)도 된다 | 포함 |
| 알림·반복 | 별도 문서(효과적인 알림, 반복 설정)에서 다룬다 | 포함, 조사 필요 |
| 리스트 이동 | 우클릭 → 이동, 또는 상세 영역 **하단의 리스트 필드**를 클릭. 리스트 이름을 입력해 검색할 수 있다 | 포함 |
| 우선순위 | 4단계: 높음, 중간, 낮음, 없음 | 포함 |
| 본문 | 텍스트를 선택하면 서식 도구가 뜬다(제목, 굵게, 형광펜, 기울임, 밑줄 등). `/`를 치면 제목·목록 같은 문단 스타일, 첨부, 하위 태스크를 넣는 메뉴가 뜬다 | 포함(서식 범위 결정 필요) |
| 태그 | 우클릭, 또는 상세 영역 **오른쪽 아래 `...` → 태그**. 기존 태그를 고르거나 새로 만든다 | 포함 |
| 체크 항목 | 상세 영역 **오른쪽 위 토글**로 "본문"과 "체크 항목" 모드를 전환한다. 항목 직접 편집, 오른쪽 삭제 버튼, `≡`를 끌어 순서 변경, 항목별 알림 | 포함(PRD의 하위 태스크) |
| 첨부 | 이미지, 녹음, 파일, 동영상. 무료는 하루 1개·10MB, 유료는 하루 199개·태스크당 39개·20MB | 제외(파일 보관함은 v1 이후) |
| 진행률 | 마감일 아래 선에 마우스를 올려 %를 설정. 체크 항목이 있으면 완료 비율로 자동 계산된다(4개 중 1개 완료면 25%) | 후보 |

## 추가 기능 (상세 영역 오른쪽 위 `...` 메뉴)
| 기능 | 내용 | v1 |
|---|---|---|
| 고정(Pin) | 목록 맨 위에 항상 표시 | 포함 |
| 공유 | 텍스트, 이미지, 일정으로 공유 | 제외 |
| 하지 않음(Won't Do) | 삭제하지 않고 포기 처리. 사이드바의 "하지 않음" 리스트와 목록 하단 "완료 & 하지 않음" 영역에 표시. 다시 시작할 수 있다 | 포함 |
| 댓글 | 공유 리스트에서 협업용, 개인 리스트에서는 메모용 | 제외 |
| 링크 복사 | 태스크 링크를 다른 태스크에 붙이면 클릭해서 이동한다 | 후보 |
| 복제 | 태스크를 복사해 수정 | 포함 |
| 템플릿으로 저장 | 반복 업무를 템플릿으로 저장 | 제외 |
| 활동 기록 | 수정 이력 보기 | 제외 |
| 노트로 변환 | 태스크와 노트를 서로 변환 | 제외(노트 기능 없음) |
| 집중 시작 | 태스크에서 바로 뽀모도로 시작 | 제외(뽀모도로는 v1 이후) |
| 메뉴 편집 | `...` → 더보기 → 편집으로 메뉴 항목 고정/해제, 순서 변경 | 제외 |

## 화면 명세로 넘길 레이아웃 단서
- 상세 영역은 목록 오른쪽에 뜨는 패널이다. 위쪽에 체크박스, 마감일, 우선순위가 있고, 오른쪽 위에 본문/체크 항목 토글이 있다.
- 가운데는 제목과 본문(또는 체크 항목)이다.
- 아래쪽 바에는 왼쪽에 리스트 필드, 오른쪽에 `...` 메뉴(태그 등)가 있다.
- 태스크 행 **우클릭 메뉴**에서 날짜, 이동, 태그를 바로 바꿀 수 있다. 우클릭 메뉴 전체 항목은 추가 조사가 필요하다.
