## 1. 틱틱 습관·집중 화면 (성장 탭의 "틱틱 디자인 언어" 기준)
- 습관 탭은 **습관 목록**이고, 습관 아이콘을 **한 번 누르면 체크인**된다. 시간대(아침·오후 등)를 정하고 알림을 붙일 수 있다 — Jake Ward, 검색 요약.
- 습관마다 **상세 대시보드**: 머리 통계(연속 일수·총 체크인), 체크인한 날이 찍힌 **월 달력**, 월 체크인률, 그 달의 기록(로그) — Jake Ward.
- 체크인 통계: 이번 주 체크인은 바로 보이고, 월 단위 진행은 프리미엄. 체크인 데이터의 "더보기" → 습관별 **1년 히트맵** — Habit Review 도움말(검색 요약).
- 무료는 습관 약 5개, 습관 통계는 프리미엄(리뷰 기준, **미확인** — 정책은 바뀔 수 있음).
- 집중: **뽀모(카운트다운) / 스톱워치(카운트업)** 두 모드를 전환해도 연결된 할 일·누적 시간이 유지된다. 뽀모 중 일시정지는 최대 3회(2020 블로그). 백색소음 여러 종.
- 집중 통계는 **개요·일·주를 가로로 넘기는 슬라이드**로 나누고, 전날·전주 대비 비교, 목표 달성률 원그래프, 리스트·태그별 시간 그래프를 보여 준다. Apple 건강(마음챙김)에 집중 시간을 넘긴다.
- **배지**: 완료한 할 일 수, 형성한 습관, 집중 시간, 사용 기간 등 "지속되는 행동"을 세어 자동으로 준다 — Badges 도움말(검색 요약). 획득 순간의 축하 화면·잠긴 배지 표시는 **미확인**.
- 틱틱에는 캐릭터·나무 같은 "자라는 그림"이 없다(블로그 2020 기준) → 성장 그림은 sprout가 새로 설계하되 카드·통계 슬라이드·히트맵 문법은 틱틱 것을 쓴다.

## 2. 캐릭터·성장형 습관 앱
- **Finch 온보딩**: 기능 소개 대신 **알 부화**로 시작 → 색·이름·성격 하나(호기심·연민·논리 등) 고르기 → **큰 카드형 선택지**로 긴 퀴즈 → 그 뒤 소프트 페이월(ScreensDesign). "나를 돌보는 것이 펫을 돌보는 것"이라는 문장을 일찍 보여 준다.
- **Finch 홈**: 목표를 끝낼 때마다 차는 **에너지 바**가 핵심이고, 목표 완료 시 **색종이(confetti)** 같은 작은 애니메이션. 목표를 "영역(Areas)"으로 묶는다. 에너지가 차면 펫이 **하루 모험**을 떠났다가 돌아와 발견한 것을 들려준다.
- **Finch 성장 단계**: 아기 → 유아 → 어린이 → 청소년 → 어른 5단계. 레벨이 아니라 **모험 일수**로 자란다(아기 7일, 유아 15일, 어른까지 누적 67일 — 팬 위키, **미확인** 수치). 단계마다 몸이 조금 커지고 **꾸밀 수 있는 부위가 늘어난다**.
- Finch는 **하루를 빠져도 벌하지 않는다**(공식 소개·사용기). 주간 목표를 친구와 나누는 가벼운 소셜이 있다.
- **Habitica**: 화면 위 머리(Header)에 아바타 + **HP(빨강)·EXP(노랑)·MP(파랑, 10레벨부터) 막대**, 각 막대 오른쪽에 `현재/최대` 숫자. 레벨이 오르면 **팝업**(소셜 공유 버튼 포함, 설정에서 끌 수 있음), 레벨업 시 HP가 가득 찬다.
- Habitica는 할 일을 못 하면 **HP가 깎이는 벌점형** — Finch와 반대 축. sprout PRD의 "벌주지 않는" 방향은 Finch 쪽에 가깝다(판단).
- **Forest**: 집중 시작 시 묘목을 심고, 시간 동안 **씨앗→새싹→묘목→나무→꽃 핀 나무** 5단계로 자란다(리뷰). 중간에 "포기"하면 **시든 나무**가 숲에 남는다. 끝낸 세션은 나무 한 그루로 숲(컬렉션)에 쌓인다.
- 레벨업 **전체 화면** 축하 연출의 정확한 구성(Finch 단계 상승 화면 등)은 **미확인** — 영상·실기기로 확인 필요. 피크민류는 조사하지 못함(**미확인**).

## 3. 공유 확장(iOS) · 공유 대상(Android) — "수집함에 저장"
- **iOS 두 방식**: `SLComposeServiceViewController`는 시스템 작성 시트(편집 가능한 글 상자 + 미리보기 + 설정 줄 + 게시 버튼)를 그대로 쓰고 바꿀 여지가 적다. `UIViewController`를 직접 쓰면 화면을 마음대로 만들지만 내용 검사·설정 줄을 직접 구현한다(Apple 가이드, diamantidis).
- **메모리 한도 약 120MB**: 넘으면 iOS가 확장을 바로 죽인다. 디버그 빌드가 더 잘 넘고, **시뮬레이터에서는 한도가 꺼져 있어** 실기기로만 확인된다(Kulman, Flutter 이슈). React Native로 확장 화면을 그리면 이 한도에 걸리기 쉽다(Kraaft — RN 경험담).
- **App Groups**: 앱과 확장은 기본적으로 저장소가 따로라 서로 못 읽는다. App Group을 켜야 공유 `UserDefaults(suiteName:)`와 공유 컨테이너 폴더를 쓴다. 큰 파일을 URL 스킴으로 넘기지 말고 공유 컨테이너에 쓰라는 권고(Apple, bitcot).
- `NSExtensionActivationRule`: 기본값 `TRUEPREDICATE`(항상 표시)는 **App Store 심사에서 안 된다** — 받는 형식(URL·글·이미지 개수)을 명시해야 한다.
- **Todoist**: 공유 확장에서 할 일 이름을 고치고 **프로젝트·마감일·우선순위**를 고른 뒤 추가. 기존 할 일에 첨부로 붙이는 길도 있다.
- **Raindrop**: 공유 메뉴에서 **컬렉션을 고르고(안 고르면 "Unsorted") 태그를 붙여 Save**. **Things**: 웹 공유 시 기사 제목이 할 일 제목, 링크는 메모로 들어간다(틱틱 Android 공유와 같은 규칙 — research 20 §6).
- 저장 후 "저장됨" 확인을 잠깐 보이고 시트가 **스스로 닫히는지**는 앱마다 확인 못 함(**미확인**). Apple Notes·Notion·Pocket 공유 화면도 이번엔 확인 못 함.
- **Android**: 매니페스트에 `ACTION_SEND` + `category.DEFAULT` + `mimeType="text/plain"`(필요하면 `image/*`, 여러 개는 `ACTION_SEND_MULTIPLE`) intent-filter를 단 Activity가 받는다. 글은 `Intent.EXTRA_TEXT`로 읽는다. 받는 화면 모양은 앱이 자유롭게 정한다(Android 문서).

## 4. 채팅형 AI 비서 (모바일)
- **진입 경로**: Claude iOS는 홈 위젯(새 대화 · **받아쓰기 모드로 바로 열기**), 제어 센터·잠금 화면 컨트롤, **동작 버튼**(설정 → 동작 버튼 → 컨트롤 → "Open Claude"), "Ask Claude" 앱 인텐트(Siri·Spotlight·단축어·공유 메뉴)를 제공한다.
- **Gemini(Android)**: 전원 버튼 길게·"Hey Google"·아래 모서리 스와이프로 **현재 앱 위에 뜨는 하단 패널**("Ask Gemini" 입력 + 마이크 + Live). 긴 답은 패널을 펼쳐 본다. 질문 뒤 다른 앱으로 가도 되고, 끝나면 **알림 + 떠 있는 버튼**으로 돌아온다(개편 중 기능, 일부 **미확인**).
- **오류·중단**: ChatGPT는 답을 생성 중 "중지"하면 "The operation was aborted" 류 오류와 함께 **다시 생성(Regenerate)** 을 띄우는 사례가 보고됐다. 네트워크 오류 시 안내는 "중지 → 다시 생성/재시도"(OpenAI 도움말).
- **답하는 중 보내기**: 생성 중 입력한 메시지를 **대기열에 쌓아 순서대로 보내는** 방식과 진행 중인 답을 **바로 조정(steer)** 하는 방식이 섞여 있다(서드파티 확장·이슈 트래커 기준, ChatGPT 공식 동작은 **미확인**).
- **Todoist Ramble**: 말하면 화면이 **실시간으로 할 일 카드로 바뀌고**(말로 고치면 카드도 고쳐짐) 끝나면 **수집함으로 바로 가서 검토**한다. iOS 홈·잠금 화면 단축어로 연다. 베타 성공률 약 40% → 62%(TechCrunch).
- **틱틱 AI**: 모바일 전용 "AI Voice Add" — 자연어로 말하면 날짜·리스트·태그·우선순위를 알아보고 **여러 할 일로 자동 분리**. 그 밖에 한 번의 지시로 할 일 만들기·쪼개기를 하는 AI Assistant, MCP 연동(What's New, 리뷰). 화면 배치는 **미확인**.
- 공통 패턴(관찰 합의, 수치 없음): 입력창은 **화면 맨 아래 고정**, 답은 **글자 단위로 흘러나오고**, 생성 중에는 보내기 버튼이 **중지 버튼**으로 바뀐다.

## 5. 기분 일기 앱
- **Daylio**: **얼굴 5개**(침울 → 매우 좋음) 중 하나 + 미리 정한/직접 만든 **활동 아이콘** 여러 개 → "두 번 탭으로 기록". 날마다 기분 색이 칠해져 **Year in Pixels**(1년 = 점 365개 한 장)로 모인다.
- **How We Feel**: 먼저 **4분면**(에너지 높/낮 × 기분 좋/나쁨, 빨·파·초·노)을 고르고, 그 안에서 **감정 단어**(전체 144개 중)를 고른다. "좋다·괜찮다" 같은 흐린 말은 쓰지 않는다.
- **stoic.**: **아침 준비**(오늘 계획·할 일)와 **저녁 돌아보기**(습관·안내형 질문)로 하루를 나누고, 하루 중 기분 체크인 → 기분에 맞는 질문을 보여 준다.
- **Apple Journal**: 사진·운동·장소·사람으로 기기 안에서 묶은 **"추천 순간"** 카드에서 일기를 시작하거나, 감사·친절·목적 같은 **회고 질문**을 받는다. 위젯은 연속 일수나 시간대별 질문을 보여 준다.
- **Rosebud(AI 일기)**: 위기 상황은 다루지 못한다고 **한계 문서**에 밝히고 전문가·**Find a Helpline**·나라별 번호(미국 988, 영국 116 123 등)로 안내한다. 한 리뷰는 "자살"이라는 단어를 직접 쓸 때만 경고가 떴다고 지적(검색 요약에만 나옴, 원 출처 **미확인**).
- **위기 안내 패턴**: Anthropic은 실시간 분류기(재현율 높은 1차 + 정밀도 높은 LLM 검증 2차)로 위험이 확인되면 **대화 안 배너**로 상담 번호를 띄우고, 대화는 계속할 수 있게 둔다(PMC 논문 요약). 고정 "988 안내"를 항상 노출하는 앱도 있다.
- Reflectly의 위기 대응 화면은 이번 조사에서 확인 못 함(**미확인**).

## 6. 마인드맵·칸반의 모바일 축소
- **틱틱 칸반(모바일)**: **한 화면에 열 하나**, 좌우로 넘긴다. 열 이름을 누르면 **모든 열을 격자로 보는 창**이 떠서 바로 이동. +는 **지금 보이는 열**에 추가. 할 일을 **화면 아래로 끌어 놓으면 열을 고르는** 방식으로 옮긴다. 열 머리 `⋯` → 이름 바꾸기·추가·"열 관리"(끌어서 순서). 카드에 하위 할 일 진행 **작은 원그래프**와 설명 미리보기(2020 블로그).
- **Trello 모바일**: 역시 **한 번에 열 하나**를 보고 가로로 넘긴다. 열이 많으면 좌우 스크롤이 불편하다는 불만이 많다(커뮤니티).
- **Notion 모바일**: 보드 보기 지원, 카드 끌어 옮기기·상세 열기 가능(용어집 요약). 열 넘김 방식은 **미확인**.
- **MindNode / Xmind**: 폰에서는 **지도 ↔ 개요(들여쓰기 목록) 전환**이 핵심. MindNode는 개요에서 추가·삭제·들여쓰기·내어쓰기·끌어서 재배치가 되고, 문서는 **마지막에 본 보기로 다시 열린다**. Xmind도 버튼 하나로 Outliner ↔ 지도.
- **Miro 모바일**: 보드를 열면 **기본이 보기 전용**(끌어서 둘러보기만, 물건이 안 움직임) — 편집은 따로 켠다. 템플릿·내보내기·발표 모드 등은 모바일에서 안 된다.
- 정리: 폰에서 그래프를 그대로 편집시키는 앱은 없다 → **목록(개요)이 기본, 그림은 보기 위주**로 줄이는 것이 공통.

## 7. 한국 특화
- **카카오톡 '나와의 채팅'**: 나만 있는 채팅방에 메모·링크·사진을 모은다. 다른 대화의 말풍선을 **길게 눌러 "나에게"** 로 보낸다(카카오 공식). 한국 사용자에게 "나중에 볼 것 = 나에게 보내기" 습관이 널리 퍼져 있다(블로그 다수, 정량 **미확인**). 다른 앱의 공유 시트에서도 카카오톡 → 나와의 채팅을 고를 수 있다(일반 사용 관찰).
- **109 (자살예방상담전화)**: **2024-01-01부터** 1393 등 흩어진 자살예방 상담 번호를 **109로 통합**, 24시간 365일. 문자·SNS 상담은 "마들랜"(129 보건복지상담센터 안내).
- **1577-0199 (정신건강위기상담전화)**: 2025 정신건강사업안내에 계속 포함, **24시간 365일 운영 중**(국립정신건강센터·보건복지부). 129 안내도 "자살예방 상담은 109로 통합, 1577-0199·1388 등은 **본래 역할대로 운영**"이라고 적는다.
- 주의: 정책브리핑(2023)은 1577-0199를 "109로 통합되는 8개 번호"에 넣었고, 일부 지역 센터 공지는 "1577-0199가 109로 바뀌었다"고 적었다. 현재 공식 안내(129, 2025 사업안내)는 **둘 다 살아 있음** → 화면에는 **109를 맨 위**, 1577-0199를 보조로 둔다. 출시 직전 한 번 더 확인.

## 8. sprout 명세로 넘길 결정 포인트
- **성장 탭 문법**: 틱틱 습관 상세(머리 통계 → 월 달력 → 로그)와 집중 통계(가로 슬라이드 개요·일·주)를 그대로 빌리고, 맨 위에만 캐릭터 + XP 막대(Habitica식 `현재/최대` 숫자)를 얹을지.
- **진화 기준**: XP 레벨(Habitica)인지, 꾸준한 날 수(Finch 모험 일수)인지. 벌점 없음은 Finch 쪽으로 고정할지.
- **레벨업·진화 연출**: 전체 화면 1회 + 끌 수 있는 설정(Habitica)으로 할지. 할 일 완료 때는 작은 애니메이션만(Finch confetti).
- **온보딩 성격 고르기**: Finch처럼 부화 → 이름 → 성격 하나 → 큰 카드 질문 몇 개. 질문 수 상한을 정해야 함.
- **공유 확장 구현 방식**: RN 화면 대신 **네이티브(Swift) 작은 화면** + App Group 공유 폴더에 써 두고 앱이 깨어날 때 동기화 — 120MB 한도와 RN 확장 경험담 근거. 화면 구성은 Raindrop형(제목·미리보기·[저장], 고르기 칸은 선택)으로 최소화하고, 수집함이 기본 목적지라 "프로젝트 고르기"는 뺄지.
- **Android 공유**: `text/plain` + `image/*`만 받을지, 여러 개(`SEND_MULTIPLE`)까지 받을지.
- **AI 대화 진입**: 위젯·동작 버튼·단축어는 [다음](research 20 §5와 같은 판단), v1은 탭 안 화면 + 하단 입력창 + 중지 버튼 + 실패 시 "다시 시도" 카드. 주 2회 상한이 있으니 **답하는 중 추가 입력은 막을지 대기열로 쌓을지** 결정.
- **일기 기분 입력**: Daylio 얼굴 5개(빠름) vs How We Feel 4분면+단어(정밀). 1년 픽셀 보기를 성장 탭과 겹치지 않게 둘 곳.
- **위기 안내**: AI 공감 대화에서 위험 신호 시 **대화 안 배너**(109 · 1577-0199, 누르면 전화 앱), 대화는 막지 않음. 판정은 서버에서. 설정·일기 화면에도 항상 보이는 고정 안내 한 줄을 둘지.
- **작업 지도(모바일)**: 기본은 **개요(들여쓰기 목록)**, 그래프는 보기 전용(Miro 기본 보기 모드처럼), 칸반은 틱틱식 한 열씩 + 열 이름 탭 → 열 격자.
- **카카오톡 습관 흡수**: 온보딩·빈 수집함 안내에 "카카오톡 '나에게 보내기'처럼 공유 → sprout" 문구를 둘지.
