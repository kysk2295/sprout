# 틱틱 조사: 캘린더 (주 뷰·보기 옵션)

- 출처: [Week View](https://help.ticktick.com/articles/7055782149730861056), [Calendar View Options](https://help.ticktick.com/articles/7055782085826445312) (2026-09-13 확인)
- 월 뷰, 일정표(Agenda), 캘린더 구독은 별도 조사로 남긴다.

## 주 뷰 구조
- **위: 종일 태스크 바.** 시간이 없는 태스크, 종일 태스크, 여러 날에 걸친 태스크가 표시된다. 아래 가장자리를 끌면 높이를 바꿀 수 있어서, 겹치지 않게 더 많이 볼 수 있다.
- **아래: 세로 타임라인.** 시간이 정해진 태스크가 블록으로 표시된다.
- 완료한 태스크는 옅은 색으로 표시된다.
- 데스크톱 전용 뷰로 **다중일 뷰**(예: 10일, 3~5일)와 **다중주 뷰**(2~3주)가 있다. v1에서는 일/주/월만 만들고 이 둘은 후보로 둔다.

## 추가
| 동작 | 데스크톱 |
|---|---|
| 종일 태스크 | 날짜 옆 빈 곳 클릭 |
| 시각 태스크 | 타임라인 클릭 → 기본 길이의 태스크가 생김 |
| 기간 태스크 | 타임라인에서 누른 채 끌기 |
| 여러 날 태스크 | 날짜 칸에서 누른 채 끌어 여러 날 선택 |

## 편집
- **길이 조절:** 블록 가장자리에 마우스를 올려 위아래 화살표가 뜨면 끈다.
- **시간 이동:** 블록을 끌어 놓는다. 화면 가장자리까지 끌면 다음 주로 넘어가고, 작은 달력 위에 놓으면 그 날짜로 바뀐다.
- **복제:** Ctrl(Mac: Option)+끌기. 상세는 [06-desktop-interactions.md](06-desktop-interactions.md).
- **날짜 없는 태스크 배치:** 오른쪽 위 `...` → "태스크 배치"로 패널을 열고, 태스크를 캘린더로 끌어 놓는다. PRD 7.1의 "오른쪽 패널"이 이것이다.

## 이동·보기
- 이전·다음 주: 트랙패드 두 손가락 좌우 스와이프, 오른쪽 위 ←/→ 버튼, 키보드 화살표.
- **오늘** 버튼(오른쪽 위)으로 오늘로 돌아간다.
- 확대·축소: 트랙패드 핀치, 또는 Ctrl+휠.
- **시간대 숨기기:** 숨긴 구간을 클릭하면 펼치고, 펼친 구간 안을 클릭하면 다시 접는다. 숨긴 구간의 가장자리를 끌어 범위를 바꾼다. 예: 새벽 시간 숨기기.

## 보기 옵션 (오른쪽 위 `...` → 보기 옵션)
| 옵션 | 내용 | v1 |
|---|---|---|
| 색상 | 태스크 색 기준: 리스트 / 태그 / 우선순위(고정색). 리스트·태그 기준이면 항목별 색 지정 | 포함 |
| 리스트 필터 | 캘린더 **왼쪽 위 아이콘**으로 보여줄 리스트를 고른다 | 포함 |
| 스타일 | 모던 / 클래식, 항목 아이콘 표시 여부. 아이콘을 숨겨도 Alt(Option)를 누르고 있으면 잠깐 보인다 | 모던 한 가지로 시작 |
| 추가 시간대 | 타임라인에 시간대를 최대 5개(현재 + 4개) 나란히 표시 | 제외 |
| 완료 표시 | 완료한 태스크와 구독 일정 표시 | 포함 |
| 체크 항목 표시 | 태스크의 체크 항목을 캘린더에 표시 | 후보 |
| 앞으로의 반복 표시 | 반복 태스크의 미래 회차를 캘린더에 표시 | 포함 |
| 습관·집중 기록 표시 | | 제외 |

## 일괄 작업·미루기
- Ctrl(Mac: Cmd)+클릭 또는 드래그로 여러 개 선택 → 끌어서 옮기거나 우클릭 메뉴.
- **미루기:** 여러 개를 선택한 뒤 "미루기" 버튼으로 한꺼번에 뒤로 민다.
- 둘 다 **Windows·웹만 지원하고 macOS는 아직 미지원**이다. sprout는 Mac에서도 지원한다.

## 캘린더 뷰 전체 목록
- 출처: [📆 Calendar](https://help.ticktick.com/articles/7055782166172532736)
- 주 뷰, 월 뷰, **연 뷰**(생산성 한눈에 보기), 리스트 뷰(날짜별 태스크), 그리고 보기 옵션과 리스트 필터가 있다.
- v1: 일·주·월 뷰. 연 뷰와 일정표(Agenda) 뷰는 후보다.

## 구글 캘린더(PRD C)와의 연결
- 출처: [Calendar Subscriptions](https://help.ticktick.com/articles/7055781614550253568)
- 틱틱이 구독할 수 있는 캘린더: 로컬 캘린더, 구글, iCloud, 아웃룩, Exchange, CalDAV, URL(ICS).
- 반대 방향으로, 다른 캘린더 앱에서 틱틱을 구독하는 기능도 있다. v1에서는 제외한다.
- 구독 캘린더는 태스크와 같은 캘린더에 겹쳐 보이고, 색과 완료 표시 옵션을 공유한다.
- 구글 구독의 세부 설정 화면(계정 연결, 캘린더 선택)은 하위 문서에서 조사한다.
