# 틱틱 조사: 알림

- 출처: [TickTick Help — Effective Reminder Feature](https://help.ticktick.com/articles/7055782395743567872) (2026-09-13 확인)

## 설정
- **만들 때:** 제목 아래 달력 아이콘 → "알림 설정".
- **상세에서:** 제목 위 "날짜 & 알림" → "알림".
- 한 태스크에 **알림을 여러 개** 걸 수 있다.
- 사용자 지정 알림 시각을 둘 수 있다. 예: 몇 분 전, 며칠 전. 세부 FAQ는 미확인이다.
- **끝날 때 알림:** 기간이 있는 태스크는 알림에서 "끝날 때"를 체크하면 종료 시각에도 알린다.

## 알림 팝업
- 시간이 되면 팝업이 뜬다. 버튼: **닫기, 집중 시작, 완료, 다시 알림(스누즈)**.
- 앱 밖과 잠금 화면에서도 뜬다.
- v1: 집중 시작은 뽀모도로가 없으므로 뺀다. 닫기, 완료, 스누즈를 넣는다.

## 기타
| 기능 | 내용 | v1 |
|---|---|---|
| 이메일 알림 | 웹 설정 → 알림 & 통지에서 켠다 | 제외 |
| 위치 알림 | 모바일 전용. 장소에 도착하면 알림 | 제외 |
| 알림음 | 설정 → 소리 & 알림 → 알림음. 우선순위별로 다른 알림음을 쓸 수 있다 | 후보 |
| 지속 알림(Constant Reminder) | 별도 문서, 미확인 | 조사 필요 |

## sprout 구현 메모
- 데스크톱은 Electron 메인 프로세스에서 알림을 예약한다(OS 알림 + 앱 안 팝업). 모바일은 로컬 알림으로 예약한다.
- 로컬 퍼스트이므로 **알림은 서버 푸시가 아니라 기기에서 예약하는 방식**이 기본이다. 다른 기기에서 태스크를 바꾸면 동기화될 때 예약을 다시 계산한다.
- 데이터: `reminders(id, task_id, trigger)`. trigger는 "마감 N분 전"이나 "끝날 때" 같은 상대 시각, 또는 절대 시각으로 둔다.
