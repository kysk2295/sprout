# 틱틱 조사: 데스크톱 인터랙션

- 출처: [TickTick Help — Desktop Interaction Tips](https://help.ticktick.com/articles/7351523697951244288) (2026-09-13 확인)
- 데스크톱 명세의 핵심 근거 문서. Windows 기준 키로 적고, Mac 대응 키는 확인된 것만 적었다.

## 태스크 목록
| 동작 | 입력 | 결과 |
|---|---|---|
| 개별 다중 선택 | Ctrl+클릭 (Mac: Cmd+클릭으로 추정, 확인 필요) | 여러 태스크 선택 |
| 범위 선택 | 첫 태스크 클릭 → Shift+마지막 태스크 클릭 | 사이의 태스크 전부 선택 |
| 키보드 범위 선택 | Shift+↑/↓ | 선택 확장 |
| 박스 선택 | 빈 곳에서 드래그 | 영역 안의 태스크 선택 |
| 일괄 편집 | 여러 개를 선택하면 **오른쪽에 일괄 편집 도구 모음**이 뜬다 | 마감일, 우선순위, 리스트, 태그 등을 한 번에 변경 |
| 일괄 오늘로 | 선택 후 Ctrl+0 | 선택한 태스크 전부 오늘로 |
| 이동 | ↑/↓ | 태스크 또는 리스트 사이 이동 |
| 리스트로 이동 | 태스크에 마우스를 올리면 왼쪽에 보이는 **햄버거 아이콘**을 사이드바 리스트로 끌어 놓기 | 해당 리스트로 이동 |
| 스마트 리스트로 끌기 | 사이드바의 오늘/내일 등에 놓기 | 해당 마감일이 자동 설정 |
| 태그로 끌기 | 사이드바의 태그에 놓기 | 태그가 바로 붙음 |
| 하위 태스크 만들기 | 다른 태스크의 **아래쪽, 살짝 오른쪽**에 놓기 | 들여쓰기되며 하위 태스크가 됨. 들여쓰기 밖으로 끌면 관계 해제 |
- 끌어서 옮기는 동작은 여러 개를 선택한 상태에서도 된다.

## 태스크 상세·편집기
| 동작 | 입력 | 결과 |
|---|---|---|
| 몰입 쓰기 모드 | Ctrl+Alt+0 (Mac: Cmd+Shift+0) | 전체 화면 편집 |
| 태스크 링크 삽입 | `[[` 입력 | 드롭다운에서 태스크를 찾아 링크 삽입 |
| 문단 서식 메뉴 | `/` 입력 → ↑/↓ → Enter | 제목, 글머리표 등 적용 |
| 글자 단위 선택 | Shift+←/→ | |
| 단어 단위 선택 | Ctrl+Shift+←/→ | |

## 캘린더
| 동작 | 입력 | 결과 |
|---|---|---|
| 복제 | Ctrl(Mac: Option)을 누른 채 다른 시간대로 끌기. 웹 Mac은 Cmd | 태스크 복사본 생성 |
| 다중 선택 | Ctrl+클릭, 또는 일/주/다중일 뷰의 타임라인에서 박스 드래그 | 일괄 이동·편집·삭제. **Windows·웹만 지원, Mac 미지원** |
| 체크박스 보이기 | Alt(Mac: Option) 누르고 있기 | 상세를 열지 않고 캘린더에서 바로 완료 처리 |
| 날짜 이동 | ←/→/↑/↓ | 이전·다음 일/주/월 |
| 가로 스크롤 | 일/주/다중일 뷰에서 Shift+휠 | 날짜를 가로로 넘김 |
| 타임라인 확대·축소 | Ctrl(Mac: Cmd)+휠 | 시간 칸 높이 조절 |

## 전역
- 글자 크기: Ctrl/Cmd + `+` / `-`, Ctrl/Cmd+0으로 기본값 복원.
  - **충돌 주의:** 목록에서 태스크를 선택한 상태의 Ctrl+0은 "오늘로 설정"이다. 선택 상태에 따라 의미가 달라지는 것으로 보이며, 명세에서 확정해야 한다.
- 단축키 전체 목록은 앱 **왼쪽 아래 `?` → 단축키**에 있다. 별도 문서 "Desktop Shortcuts"에서 조사한다.

## sprout v1 반영
- 전부 v1 대상이다(PRD의 "키보드만으로 모든 조작", "드래그", "일괄 변경").
- 제외: `[[` 태스크 링크(후보), 몰입 쓰기 모드(후보).
- Mac에서 캘린더 다중 선택이 안 되는 것은 틱틱의 한계이므로, sprout는 Mac에서도 지원한다(동급 이상).
