# 틱틱 조사: 다단계 태스크(하위 태스크)

- 출처: [TickTick Help — Multilevel Tasks](https://help.ticktick.com/articles/7055782219767349248) (2026-09-13 확인)
- 틱틱에는 **하위 태스크**(독립 태스크가 부모 아래로 들어간 것)와 **체크 항목**(태스크 안의 단순 체크리스트, [03-task-details.md](03-task-details.md))이 **따로 있다.** PRD의 "하위 태스크(체크리스트)"를 이 둘로 나눠야 한다.

## 만들기 (데스크톱)
1. 상세 영역 오른쪽 아래 `...` → 하위 태스크 추가
2. 태스크 우클릭 → 하위 태스크 추가
   - 첫 하위 태스크를 입력하고 Enter를 누르면 같은 단계의 하위 태스크를 계속 만든다.
3. 태스크에 마우스를 올려 햄버거 아이콘을 잡고, 대상 태스크의 오른쪽 아래로 끌어 놓는다.

## 보기
- 목록에서 부모 태스크 **오른쪽의 화살표**로 하위 태스크 전체를 펼치거나 접는다.

## 부모 연결·해제
- **연결:** 우클릭, 또는 `...` → 부모 태스크 연결. 여러 개를 선택해 한꺼번에 같은 부모에 연결할 수 있다.
- **해제:** 같은 메뉴에서 연결된 태스크 옆 ✖️를 누르거나, 연결된 부모에 마우스를 올려 "연결 해제"를 누르거나, 끌어서 들여쓰기 밖으로 뺀다.

## FAQ (본문 미확인)
- 무한 단계까지 쪼갤 수 있나
- 다단계 태스크의 정렬 규칙
- 하위 태스크가 캘린더 뷰에 표시되나
- 하위 태스크와 체크 항목이 부모의 진행률에 영향을 주나

## 데이터 모델 영향
- 태스크에 `parent_id`를 둔다. 최대 깊이는 FAQ를 확인한 뒤 정한다.
- 체크 항목은 별도 테이블 `check_items(id, task_id, title, done, sort_order, reminder_at)`로 둔다.
