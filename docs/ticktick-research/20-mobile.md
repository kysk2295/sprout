## 1. 내비게이션
- 화면 아래 **탭 바**. 기본 탭은 태스크(할일) 중심이고, 설정 → 탭 바에서 캘린더 · 뽀모도로 · 습관 · 매트릭스 · 검색 · 설정 등을 켜고 끄고 순서를 바꾼다.
- 할일 탭은 마지막으로 연 리스트를 보여 주고, 왼쪽 위 버튼으로 리스트 서랍(스마트 리스트·리스트·태그)을 연다(일반 사용 관찰 — 수치 미확인).
- 스마트 리스트 **"오늘"** 위에 동그란 "하루 계획(Plan Your Day)" 버튼이 있다(TidBITS). v1 밖.

## 2. 빠른 추가
- 목록 오른쪽(또는 왼쪽) 아래에 떠 있는 **+ 버튼**. 누르면 키보드 위에 추가 창이 뜬다.
- + 버튼을 **끌어서** 목록의 특정 위치(그룹·순서)에 놓으면 그 자리에 할 일이 추가된다.
- + 버튼을 **길게 누르면 음성 입력**(좌우로 끌면 녹음 모드). 시간 표현은 인식한다 — research 01.
- 추가 창: 제목 입력 + 설명 줄 + 아래 **도구 막대**(날짜 · 우선순위 · 태그 · 리스트 이동 등). 도구 막대의 `⋯` → 설정에서 순서를 바꾼다.
- 스마트 인식: 날짜·시간 문구를 마감·알림으로 바꾸고 하이라이트한다. 기호 `!`(우선순위) · `#`(태그) · `~`(리스트)가 모바일에서도 동작한다.
- 클립보드: 복사한 글에 시간이 있으면 앱을 열 때 추가를 제안(research 01, v1 제외 후보).
- 그 밖의 경로: 위젯의 + · Siri · 단축어 · URL 스킴 · **공유 시트**(§6) · Android 상주 알림의 +(§5).

## 3. 목록·스와이프
- 기본 스와이프: **오른쪽 = 완료 · 고정**, **왼쪽 = 이동 · 삭제 · 날짜 변경**(왼쪽으로 밀면 버튼 3개가 드러난다).
- 사용자 지정(설정 → 일반 → 스와이프 동작): 짧게 오른쪽 · 길게 오른쪽 · 짧게 왼쪽 · 길게 왼쪽 네 칸에 `없음 · 완료 · 마감일 · 우선순위 · 이동 · 삭제`(나중 버전은 `집중 시작`도)를 고른다. "설정 초기화" 있음. `없음`은 실수로 완료하는 것을 막는 용도.
- 날짜 스와이프의 빠른 선택(아침·오후·저녁·밤, "다음 주" = 7일 뒤/다음 월요일)도 설정에서 바꾼다.
- 행을 **길게 누르면** 날짜 등 메뉴(TidBITS). 체크박스 = 완료, 행 누름 = 상세.
- 완료는 "완료 보기"를 켜면 쉽게 되돌린다(데스크톱과 같은 완료 영역 — 02 §0).

## 4. 알림
- 시간이 되면 알림. 버튼: 닫기 · 집중 시작 · **완료** · **다시 알림(스누즈)**(research 09).
- **Android**: 잠금 화면에서 바로 완료·스누즈 가능. **iPhone**: 잠금을 풀고 알림을 펼쳐야 버튼을 쓸 수 있다(Apple 커뮤니티 — iOS 동작 방식).
- **계속 알림(Constant Reminder)**: 완료하거나 스누즈할 때까지 1분마다 울린다. v1 제외(research 09 "후보").
- 하루 요약 알림(정해진 시각에 오늘 할 일 개요) — v1 밖.
- 위치 알림은 모바일 전용 — v1 제외(research 09).

## 5. 위젯·상주 알림
- iOS: **대화형 "오늘" 위젯**(체크박스로 바로 완료, 제목 누르면 편집), 위젯의 +로 추가 창, 잠금 화면 Live Activity.
- Android: 홈 위젯 + **상주 알림**(알림 서랍·잠금 화면에 오늘 목록과 +). +는 알림 안에서 입력하지 않고 앱의 빠른 추가 창을 띄운다.
- sprout v1: 위젯·상주 알림 모두 **[다음]**(PRD §7.2 F와 같은 판단 — 네이티브 확장 비용이 큼).

## 6. 공유 시트 (다른 앱 → 틱틱)
- iOS **공유 확장**으로 다른 앱에서 할 일을 만든다. 공유 화면에서 제목 외 속성(메타데이터)도 고를 수 있다.
- Android 공유: 공유한 제목·글이 할 일 제목이 되고, **링크는 할 일에 붙어 남는다**(설명 쪽).
- 화면 배치(공유 카드 크기·버튼 문구)는 **미확인** → sprout 24 명세는 [임시]로 두고 실기기에서 확인한다.

## 7. sprout 명세로 넘길 결정 포인트
- 탭 바 구성(틱틱은 사용자 지정) → v1은 고정 3탭으로 줄일지.
- 스와이프: 틱틱 기본값(오른쪽 완료·고정 / 왼쪽 이동·삭제·날짜)을 그대로 두고, 사용자 지정은 [다음].
- 알림: 기기 로컬 예약(research 09 sprout 메모) — 다른 기기에서 바꾼 값은 앱이 깨어날 때 다시 계산.
- 공유: 틱틱은 "할 일"로 받지만 sprout는 **수집함 항목**으로 받는다(PRD §8 출시 경로 7, 11 v3) — 차이를 명세에 적는다.
