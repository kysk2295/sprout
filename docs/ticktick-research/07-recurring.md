# 틱틱 조사: 반복 태스크

- 출처: [TickTick Help — Set Up Recurring Tasks](https://help.ticktick.com/articles/7055782206349770752) (2026-09-13 확인)

## 설정 위치
- 태스크 상세 → "날짜 & 반복" → "반복".

## 반복 종류
| 종류 | 내용 |
|---|---|
| 기본 | 매일, 매주, 매월, 매년. 예: 매월 20일은 달력에서 20일을 고르고 반복을 "매월"로 한다 |
| 사용자 지정 — 마감일 기준 | 정해 둔 일정에 맞춰 반복한다. 예: 매주 금요일 13:00 |
| 사용자 지정 — 완료일 기준 | **이전 태스크를 완료한 시점부터** 다음 일정을 계산한다. 예: 3일마다 운동. 화요일에 하면 금요일, 금요일 대신 토요일에 하면 다음은 화요일 |
| 사용자 지정 — 특정 날짜 | 달력에서 하루 또는 여러 날을 직접 고른다 |

## FAQ 항목 (본문은 접혀 있어 미확인)
- 반복 끝내기 방법
- "종료일"과 "N회 후 종료"의 차이
- 반복 중 한 회차만 수정하기
- 앞으로의 모든 회차를 표시하기

## sprout 데이터 모델 영향
- 마감일 기준과 특정 날짜는 RRULE(`FREQ`, `INTERVAL`, `BYDAY`, `RDATE`)로 표현한다.
- **완료일 기준은 RRULE로 표현할 수 없다.** 태스크에 `repeat_from: 'due' | 'completion'` 필드를 둔다. 완료할 때 다음 회차의 마감일을 "완료 시각 + 간격"으로 계산한다.
- 종료 조건: `UNTIL`(종료일) 또는 `COUNT`(N회).
- "한 회차만 수정"은 반복 태스크의 회차 예외 처리가 필요하다. FAQ를 확인한 뒤 PRD 데이터 모델에 반영한다.
