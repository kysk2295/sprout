# 틱틱 조사: 리스트 뷰

- 출처: [TickTick Help — List View](https://help.ticktick.com/articles/7055782365863346176) (2026-09-13 확인)

## 동작
- **형태:** 태스크를 세로 목록으로 보여주고, 위아래로 스크롤해서 훑어본다.
- **그룹·정렬:** 여러 정렬 방식을 제공한다. 상세 내용은 Group & Sort 문서에서 확인한다(20개 이상의 그룹×정렬 조합).
- **드래그 정렬:** 태스크를 잡고 끌어서 원하는 위치에 놓는다.
- **드래그로 하위 태스크 만들기:** 태스크를 다른 태스크의 **오른쪽 아래**로 끌어 놓으면 그 태스크의 하위 태스크가 된다.
- **고정:** 상세 영역 오른쪽 위 `...` → 고정. 고정한 태스크는 목록 맨 위에 계속 표시된다.
- **일괄 편집(데스크톱):** Shift를 누른 채 여러 태스크를 고르거나, 첫 태스크와 마지막 태스크를 골라 범위를 선택한 뒤 한꺼번에 처리한다.
- **스와이프(모바일):** 왼쪽으로 밀면 이동·삭제·날짜 변경, 오른쪽으로 밀면 완료·고정. 설정 → 일반 → 스와이프 동작에서 바꿀 수 있다. v1 모바일 최소형에서는 완료 스와이프만 검토한다.
- **다른 뷰:** 칸반, 타임라인. v1에서는 제외하고 리스트 뷰만 만든다.

## 화면 명세로 넘길 결정 포인트
- 드래그 놓는 위치에 따라 결과가 다르다(행 사이 = 순서 변경, 행 오른쪽 아래 = 하위 태스크). 놓을 위치를 미리 보여주는 표시를 명세에 넣는다.
- 여러 개 선택은 Shift 범위 선택을 기본으로 한다. Cmd/Ctrl 개별 선택 여부는 Desktop Interaction Tips 문서에서 확인한다.
