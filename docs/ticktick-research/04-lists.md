# 틱틱 조사: 리스트·스마트 리스트

- 출처: [TickTick Help — Manage Tasks with Lists](https://help.ticktick.com/articles/7055782283059396608) (2026-09-13 확인)

## 스마트 리스트
- **조건으로 태스크를 걸러 보여주는 리스트**다. 기본 제공 5개:
  - 오늘, 내일, 다음 7일: 마감일이 해당 기간인 태스크
  - 받은함: 분류 전 태스크를 임시로 두는 곳. **숨기거나 지울 수 없다.**
  - 나에게 할당됨: 공유 리스트에서 나에게 배정된 태스크. 공유 기능이 없으므로 v1에서는 제외한다.
- **표시 설정:** 아바타 → 설정 → 스마트 리스트. 항목마다 "표시 / 숨김 / 비어 있지 않을 때만 표시" 중에서 고른다.
- PRD와 비교하면 v1 스마트 리스트는 오늘, 내일, 다음 7일, 받은함, 완료됨이다. 틱틱에 맞춰 "내일"을 추가해야 한다.

## 일반 리스트
- **만들기(데스크톱):** 사이드바 "리스트" 제목에 마우스를 올리면 오른쪽에 `+`가 뜬다. 누르면 만든다.
- **속성:** 이름, 색, 폴더, 표시/숨김. 이모지를 리스트 아이콘으로 쓸 수 있다(별도 문서).
- **편집:** 모바일은 왼쪽으로 밀어서 고정/편집/삭제를 연다. 데스크톱은 우클릭 메뉴로 추정되며 확인이 필요하다.
- **리스트 배경:** 모바일 전용이라 v1에서는 제외한다.

## 폴더
- 출처: [Manage Tasks with Folders](https://help.ticktick.com/articles/7055782296019795968)
- **폴더는 리스트를 묶는 단위다.** 예: "생활" 폴더 안에 일상, 장보기, 운동 리스트.
- **만들기 1:** 리스트를 다른 리스트 위로 끌어다 놓으면 팝업이 뜨고, 이름을 입력하면 두 리스트를 담은 폴더가 생긴다.
- **만들기 2:** 리스트 편집 화면 → 폴더 → 폴더 추가 → 이름 입력 → 완료.
- **폴더 해제(데스크톱):** 폴더를 우클릭한다(모바일은 왼쪽 스와이프나 길게 누르기).
