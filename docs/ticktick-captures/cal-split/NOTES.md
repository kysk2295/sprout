## 레이아웃
- 캘린더(왼쪽, 약 65%) + **리스트 패널(오른쪽, 약 35%)**. 두 영역은 별개의 흰 카드처럼 간격을 두고 떨어져 있다.
- 오른쪽 패널은 목록 화면과 같은 머리글이다: `☰` · 리스트 이모지 + 이름 · 정렬 · `...`.
- 추가 바: `+ Add task to "Content Work"` — 추가될 리스트 이름이 들어간다.
- 그룹: `⌄ Today 2`, `⌄ No Date 5`, `⌄ Later 2` 등.

## 행의 색 표현 (중요)
- **체크박스 테두리 색 = 우선순위.** 빨강 = 높음, 노랑 = 중간, 파랑 = 낮음, 회색 = 없음. 목록 화면 전체에 적용된다.
- 폴더나 스마트 리스트를 볼 때 행 **왼쪽 끝에 세로 색 막대**가 붙는다(해당 태스크 리스트의 색). 행 오른쪽 메타에는 리스트 색 점 + 이모지 + 리스트 이름.
- 행에 마우스를 올리면 오른쪽 끝에 `...`, 왼쪽에 드래그 손잡이 `≡`가 보인다.

## 끌어서 일정 잡기
- 오른쪽 목록의 행을 캘린더 칸이나 시간대로 끌어 놓는다. 동작 규칙은 [research 14](../../ticktick-research/14-calendar-month-split.md).
