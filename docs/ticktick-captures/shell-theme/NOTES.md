# shell-theme — 관찰 노트 (Mac)

- 근거 프레임: [zq f0027 외관 설정 + 다크 테마](../_video/zqGeCiSgFOk/f0027.jpg), zq 영상 sheet02~08(다크 테마 전반), [8.0 f0104](../_video/aJ0ELyY215A/f0104.jpg)(Sky 테마), [QKA 영상](../_video/QKAA8p3PY_8/SOURCE.md)(Default 테마 + 배경 이미지)

## 테마 선택
- 설정 → Appearance → Theme 탭. Color Series 12개(Default, Sky, Turquoise, Teal, Matcha, Sunshine, Peach, Lilac, Ebony, Navy, Gray, **Dark**) + Season/City 일러스트 시리즈.
- 하단 토글: **"Auto switch dark theme according to system appearance."** (8.0에서는 "Follow System Dark Mode")

## 다크 테마 (Dark)
- 창 전체가 거의 검정(#1C1C1C 전후)이고, 레일·사이드바·목록·상세 사이 구분은 아주 옅은 선뿐이다.
- 글자: 제목은 밝은 회색, 보조 텍스트·개수는 어두운 회색.
- 선택 항목은 한 단계 밝은 회색 둥근 배경.
- 강조색(파랑)은 그대로다: 날짜 텍스트, OK 버튼, 토글.
- 우선순위 색(체크박스 테두리), 리스트 색 점, 태그 알약 색도 그대로 쓴다.

## 색 테마 (Sky 등)
- 아이콘 레일이 테마색으로 채워지고, 선택 배경에 테마색이 옅게 섞인다. 강조색(오늘 원, 버튼)도 테마색을 따른다(Default 테마에서는 검정).

## sprout v1
- Default(흰색) + Dark + 색 테마 몇 개(Sky 등)로 시작하고, 시스템 다크 모드를 따라가는 토글을 둔다. 일러스트 시리즈는 제외한다.
- 모든 색은 토큰(배경, 표면, 선, 글자 1·2·3, 강조, 우선순위 4색)으로 정의해서 테마를 바꿀 수 있게 만든다.
