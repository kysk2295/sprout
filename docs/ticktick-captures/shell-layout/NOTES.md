## 4단 구조 (왼쪽 → 오른쪽)
| 영역 | 폭(창 대비, 추정) | 내용 |
|---|---|---|
| 1. 아이콘 레일 | ~5% | 맨 위 신호등 버튼 아래에 아바타(프로 배지). 이어서 태스크(체크, 선택 시 파란 채움) · 캘린더 · 습관(네 칸) · 집중(과녁) · 카운트다운 · 검색. 맨 아래에 동기화 · 알림(종) · 도움말(?) |
| 2. 사이드바 | ~20% | 스마트 리스트(오늘 11 · 내일 7 · 다음 7일 24 · 나에게 할당됨 · 받은함 10), 구분선, "Lists" 소제목, 리스트(이모지 아이콘 + 이름 + 개수, 폴더는 왼쪽에 `›` 접기 표시), 구분선, 완료됨 · 휴지통 |
| 3. 목록 | ~44% | 머리글: 사이드바 접기 아이콘 + 리스트 제목(굵게, 큼) · 오른쪽에 정렬 아이콘 · `...`. 아래에 회색 둥근 "+ Add task" 입력 바. 그룹 헤더(`⌄ Today 4`, 접기 가능, 굵게 + 회색 개수). 행: 체크박스(둥근 사각) · 제목 · 오른쪽 정렬된 **파란 시간**(07:00) 또는 날짜(Mon). 선택된 행은 옅은 회색 둥근 배경. 메모가 있는 태스크는 체크박스 대신 문서 아이콘을 표시(추정) |
| 4. 상세 | ~31% | 머리글: 체크박스 · 세로 구분선 · **파란 날짜/시간**("Today, Sep 6, 09:00 - 10:…") · 오른쪽에 깃발(우선순위). 제목(굵게, 큼), 오른쪽에 본문/체크 항목 전환 아이콘. 설명 한 줄, 체크 항목 목록(행마다 체크박스 + 옅은 구분선). 하단 바: 왼쪽에 리스트 이동(`⇥ Inbox`), 오른쪽에 서식(A) · 댓글 · `...` |

## 시각 언어
- 배경은 흰색이다. 사이드바와 목록 사이, 목록과 상세 사이는 옅은 세로 구분선으로만 나눈다. 그림자나 카드가 없는 평면 스타일이다.
- 강조색은 파랑 하나다. 선택된 레일 아이콘, 시간·날짜 텍스트, 상세의 날짜에 쓴다.
- 개수·보조 텍스트는 옅은 회색, 본문은 거의 검정이다.
- 선택 상태는 둥근 모서리의 옅은 회색 배경이다(사이드바 받은함, 목록 행 모두 같다).
- 아이콘은 가는 선 스타일, 리스트 아이콘은 컬러 이모지다.
- 8.0에는 "Flat / Card" 인터페이스 스타일과 색 테마(레일이 파란 채움이 됨)가 있다. 영상 [aJ0ELyY215A](../_video/aJ0ELyY215A/SOURCE.md) 참고.

## sprout v1 적용
- 레일 항목 중 v1에 있는 것: 태스크, 캘린더, 검색, 동기화, 알림, 도움말, 아바타. 습관·집중·카운트다운 자리에는 v1에서 **성장(캐릭터)** 하나를 둔다.
- 사이드바의 "나에게 할당됨"은 공유 기능이 없으므로 제외한다.
