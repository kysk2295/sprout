# shell-search — 관찰 노트 (Mac)

- 근거 프레임: [zq f0150 검색 팝업](../_video/zqGeCiSgFOk/f0150.jpg), [zq f0152 검색 결과 화면](../_video/zqGeCiSgFOk/f0152.jpg) (다크 테마)

## 1단계: 검색 팝업
- 아이콘 레일의 **돋보기**를 누르면(툴팁 "Search") 화면 가운데에 팝업이 뜬다.
- 머리: 돋보기 아이콘 + 입력칸, 오른쪽에 입력 지우기(원 안 ×)와 닫기(×). 입력칸 아래에 파란 밑줄(포커스).
- **입력하는 대로 바로 결과가 나온다.** 결과는 종류별 소제목으로 묶인다:
  - **Tasks:** 체크박스(우선순위 색) + 제목. **일치 부분은 노란 형광 강조.** 본문에서 찾으면 아래에 발췌("…ilk, **sand**wiches, beefy…"). 오른쪽에 리스트 이름(색 점 + 이름).
  - **Filters:** 필터 아이콘 + 이름. 리스트와 태그도 같은 방식으로 묶이는 것으로 보인다(추정).
- 하단 문구: "Not found yet? **Try Cloud Search.**"(파란 링크)

## 2단계: 검색 결과 화면 (Enter)
- 목록 영역 전체가 검색 결과로 바뀐다. 머리: `×` · **"Search Sandy"**(검색어는 파랑) · 연필(검색어 수정).
- 필터 칩(드롭다운): **All Dates · All Lists · All Tags · All Status**
- 오른쪽 위 버튼: **"Save as filter"** — 이 검색 조건을 필터로 저장한다.
- 결과 행은 목록 화면과 같다(왼쪽 리스트 색 막대, 태그 알약, 오른쪽 리스트 이름).
