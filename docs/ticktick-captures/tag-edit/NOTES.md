## 사이드바 Tags 구역
- 소제목 "Tags"에 마우스를 올리면 오른쪽에 `...`과 `+`가 나타난다(`⌄`로 구역 접기).
- 태그가 없을 때 안내 문구(옅은 카드): "Categorize your tasks with tags. Quickly select a tag by typing "#" when adding a task"
- 태그 행: 태그 아이콘 + 이름 + 오른쪽 색 점 + 개수.

## Add Tag 모달
- 왼쪽 위 빨간 닫기 점, 제목 "Add Tag".
- Tag Name 입력(포커스 시 파란 테두리).
- Color: 없음(사선) · 빨강 · 주황 · 노랑 · 연두 · 초록 · 파랑 · 보라 · 사용자 지정(원).
- Parent Tag: 드롭다운 "None"(2단계 태그).
- Cancel · Save(파랑, 이름이 비어 있으면 흐림).

## 태그 표시
- 목록 행: 제목 아래 줄에 **색 배경 알약**(예: 빨간 배경 "youtube").
- 상세: 제목 아래에 알약 목록 + 옆에 `+`(태그 추가) 버튼.
