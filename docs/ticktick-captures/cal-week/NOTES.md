# cal-week — 관찰 노트 (데스크톱)

- 근거 프레임: [EUB f0026 주 뷰 + 태스크 팝오버](../_video/EUBxb9MgYWg/f0026.jpg), [MhY f0166](../_video/MhYkPy6xK4M/f0166.jpg). 일 뷰 = EUB f0022 (같은 구조, 한 열).
- 머리글은 [cal-month/NOTES.md](../cal-month/NOTES.md)와 같다.

## 구조
- **위: 종일 영역.** 날짜 머리(숫자, 오늘은 파란 원) 아래로 종일·여러 날 태스크가 막대로 쌓인다. 여러 날 막대는 열을 가로지른다(예: 9~10일 "Write YouTube script 13:00").
- **왼쪽: 시간 눈금.** "08:00", "10:00" 형식, 정오는 **"Noon"**으로 표기.
- **숨긴 시간대:** 새벽 구간이 회색 블록 "00:00 - 07:00" 하나로 접혀 있다.
- **현재 시각:** 눈금 칸에 빨간 알약 라벨("09:02") + 전체 폭을 가로지르는 옅은 빨간 선.
- **시각 블록:** 리스트 색 파스텔 배경, 제목(2줄까지) + 시간 범위("10:00-12:00"). 지난 블록은 더 옅다.

## 블록 클릭 → 태스크 팝오버
- 흰 카드(그림자), 블록 옆에 뜬다. 목록 화면의 상세 패널과 **같은 구성의 축소판**이다.
  - 머리: 체크박스 | 달력 아이콘 + 날짜 범위("Jun 11, 08:00 - 09:00", **지난 시각이면 빨강**) … 깃발.
  - 제목(굵게) + 본문/체크 항목 전환 아이콘, 본문 영역.
  - 하단: 리스트(이모지 + "Me") … 서식(A) · 댓글 · `...`.
