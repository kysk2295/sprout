## 데스크톱 앱 안 추가 바
- 목록 머리 아래 회색 둥근 입력창 `+ Add task`. 스마트 리스트에서는 `+ Add task to "Inbox"`.
- 옛 버전 문구: `Add task to "Inbox", press Enter to save.` → 현재는 짧아졌다.
- Enter = 만들기, Shift+Enter = 설명 입력 → Cmd+Enter = 만들기(도움말).
- 오른쪽 드롭다운: 우선순위, 첨부, 템플릿, 입력창 설정(도움말).

## 스마트 인식 하이라이트 (iOS 캡처로 확인)
- 입력 "Plan next week **fri 13pm**"에서 인식된 날짜 부분이 **옅은 파란 배경**으로 강조된다.
- 입력창 아래 칩 줄 첫 칸에 인식 결과 **"📅 Fri, 13:00"**(파란 글자, 강조 테두리)가 나타난다. 이어서 깃발(우선순위) · 태그 · 리스트 이동 · 템플릿 · `...` 아이콘, 오른쪽 끝에 파란 원형 전송 버튼.
- 인식 취소: Delete 키 또는 강조된 부분 클릭(도움말).
- `~` 리스트, `#` 태그도 같은 방식의 토큰이다([task-global-add](../task-global-add/NOTES.md), [tag-edit](../tag-edit/NOTES.md)).

## 남은 확인
- 데스크톱에서 하이라이트 색과 칩 위치가 같은지는 영상에서 직접 보지 못했다. iOS 기준으로 설계하고, 데스크톱 추가 바 오른쪽 끝에 인식 결과 칩을 두는 안을 기본으로 한다.
