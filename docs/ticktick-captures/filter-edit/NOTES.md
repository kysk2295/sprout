# filter-edit — 관찰 노트 (Mac, 2026)

- 근거 프레임: [QKA f0126 Edit Filter](../_video/QKAA8p3PY_8/f0126.jpg), 같은 영상 f0127~0128. 도움말은 [SOURCES.md](SOURCES.md), 조사 노트 [13](../../ticktick-research/13-filters.md)

## Edit Filter 모달
- 왼쪽 위 빨간 닫기 점, 가운데 제목 "Edit Filter".
- 분절 탭: **Normal / Advanced**.
- 이름 입력(왼쪽에 아이콘/이모지).
- 조건 행 (라벨 왼쪽, 입력 오른쪽):
  | 라벨 | 입력 |
  |---|---|
  | Lists | 드롭다운 "All" |
  | Tags | 드롭다운 "All" |
  | Date | 드롭다운 "The Previous 2nd Day ~ Today" (상대 기간) |
  | Priority | All(선택) · High · Medium · Low · None — 여러 개 선택 |
  | Include | 텍스트 "Input task keywords" |
  | Type | All · Task(✓) · Note |
- 하단: Cancel · **Save**(테마 강조색. 이 테마에서는 검정).

## 사이드바
- 필터는 "Filters" 구역에 아이콘 + 이름으로 표시된다. 필터 화면의 추가 바는 `Add task to "Inbox"`.
