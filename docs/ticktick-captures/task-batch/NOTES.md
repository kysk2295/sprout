# task-batch — 관찰 노트 (데스크톱 캘린더)

- 근거 프레임: [EUB f0088 미루기 메뉴 + 일괄 도구 모음](../_video/EUBxb9MgYWg/f0088.jpg). 목록 화면 일괄 편집은 도움말 [SOURCES.md](SOURCES.md)

## 다중 선택 표시
- 선택된 태스크 막대는 **파란 테두리**로 감싸진다(배경은 흰색으로 바뀜).

## 하단 떠 있는 도구 모음
- 화면 아래 가운데에 흰 둥근 바가 뜬다. 아이콘 순서: 날짜 · **미루기(시계)** · 우선순위(깃발) · 리스트 이동 · 태그 · 삭제 · `...`

## 미루기 메뉴 (시계 아이콘 클릭)
- Postpone by 15 mins · 30 mins · 1 hour · 2 hours · 1 day · 1 week · Custom
- 시간 단위 미루기는 시각이 있는 태스크에 쓴다(예: 10:00 → 10:15).
- 틱틱은 이 기능이 Windows·웹 전용이다. sprout는 Mac에서도 지원한다.
