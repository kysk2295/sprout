## 전역 빠른 추가 바
- 전역 단축키(영상에서는 ⌃⇧A)를 누르면 **화면 위쪽 가운데에 가로로 긴 흰 둥근 바**가 뜬다. 그림자가 있고, 다른 앱 위에도 뜬다.
- 왼쪽에 틱틱 로고(체크 원), 그 옆에 커서.
- 자리 표시 문구: **"Tap Enter to add a task; tap Tab to add a task description"** — Enter를 누르면 만들고, Tab을 누르면 설명 입력으로 넘어간다(앱 안 추가 바는 Shift+Enter).

## `~` 리스트 선택 (f0027)
- 제목 뒤에 `~`를 입력하면 **커서 바로 아래에 리스트 드롭다운**이 뜬다.
- 항목: Inbox → 리스트들(이모지 + 이름). 폴더는 오른쪽 `›`로 하위 메뉴가 열린다(Work › Social Media, General).
- 고르면 입력창에 **"~ 🖥General" 토큰**으로 표시되고, 태스크는 그 리스트로 들어간다(f0029).
- 같은 방식으로 `#` = 태그(도움말 확인), 날짜 자연어 = 스마트 인식이 쓰인다. `!` 우선순위 문법은 아직 영상에서 확인하지 못했다.
