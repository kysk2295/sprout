# shell-sidebar — 관찰 노트 (8.0 데스크톱)

- 근거 프레임: [f0061](../_video/aJ0ELyY215A/f0061.jpg), [f0108](../_video/aJ0ELyY215A/f0108.jpg) (8.0), 공식 [Mac 스크린샷](../shell-layout/site-mac-preview.png) (8.0 이전 스타일)

## 8.0 사이드바 구성 (위 → 아래)
1. **스마트 리스트:** All · Today(날짜 숫자가 들어간 달력 아이콘) · Tomorrow · Next 7 Days · Inbox
2. 구분선
3. **Lists** 소제목(옅은 회색, 작게) → 리스트: 이모지 아이콘 + 이름 + **오른쪽 끝에 리스트 색 점**
4. **Filters** 소제목 → 필터(예: "Top Tasks This Week", 아이콘 있음)
5. **Tags** 소제목 → 태그(태그 아이콘 + 이름 + 오른쪽 색 점)
6. 구분선
7. Completed · Trash

- 선택 항목: 테마색이 옅게 섞인 둥근 배경.
- 8.0 이전(공식 Mac 스크린샷)에는 색 점 대신 **개수**가 오른쪽에 있었고, 폴더에는 왼쪽 `›` 접기 표시가 있다. 개수를 보여줄지 색 점을 보여줄지는 설정 항목일 가능성이 있다(확인 필요).

## 아이콘 레일 (8.0, Sky 테마)
- 레일 전체가 **테마색으로 채워진다**(Sky = 파랑). 아이콘은 흰색 반투명이고, 선택된 항목은 흰 사각 배경 + 테마색 아이콘이다.
- 위 → 아래: 아바타(프로 배지) · 태스크 · 캘린더 · 네 칸(매트릭스) · 과녁(집중) · 시계(추정) · 달력+별(추정) · 검색 · (여백) · 동기화 · 알림 · 도움말.
- 레일 아이콘 각각이 무엇인지는 다른 프레임에서 확인이 필요하다(추정 표시).
- **툴팁으로 확인됨**(웹 버전, [hL f0024](../_video/hLWIRnKAg6I/f0024.jpg) 및 같은 영상 f0016~0025): Search · Task · Calendar View · 시계 = **Habit Tracker** · 네 칸 = **Eisenhower Matrix** · 과녁 = **Pomodoro**. 달력+별은 **Countdown**으로 추정된다. 레일 순서는 버전·설정(Features 페이지에서 켜고 끔)에 따라 다르다.

## 추가 구역
- **Calendar Subscription** 구역(태그 아래): 구독한 계정 이메일 + 개수. `+`로 캘린더 추가 — [cal-subscription/NOTES.md](../cal-subscription/NOTES.md)
- 구역 소제목(Lists, Filters, Tags, Calendar Subscription)에 마우스를 올리면 `⌄` 접기, `...`, `+`가 나타난다.
- 2025 이전 스타일에서는 리스트 아이콘이 이모지 대신 `≡`(기본 아이콘)이고, 오른쪽에 색 점 + 개수가 **둘 다** 보인다(zq 영상).
