## 머리글 줄
- 체크박스 → 세로 구분선 → **달력 아이콘 + 파란 날짜 텍스트.** 예: "Oct 12, 273d left"(남은 일수 표시), "Today, Sep 6, 09:00 - 10:…"(기간).
- 오른쪽 끝: 깃발(우선순위). 없음이면 테두리만 있는 깃발이다.

## 본문
- 제목: 굵게, 크게. 오른쪽에 **본문 ↔ 체크 항목 전환 아이콘**(목록 모양).
- 설명이 비어 있으면 자리 표시 문구가 보인다: "Write something or type / for commands".
- 체크 항목 모드: 행마다 체크박스 + 옅은 구분선(공식 스크린샷).

## 하단 바
- 왼쪽: 리스트 이동 버튼(`⇥` 아이콘 + "Inbox").
- 오른쪽: 서식(A 밑줄) · 댓글 · `...`.
