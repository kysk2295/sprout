# settings-account — 관찰 노트 (데스크톱)

- 근거: 도움말 FAQ [12-desktop-account-data.png](../_help/faq-028672/12-desktop-account-data.png) (같은 섹션 14~17번에 관련 화면 더 있음), 8.0 영상 [f0103](../_video/aJ0ELyY215A/f0103.jpg), zq 영상 f0182

## Account 페이지
- 위: 아바타(프로 배지) · 이름 · "Expire Date: 2024-09-12 **Renew**"(프리미엄 만료일).
- 카드 1: Email → 주소(회색) · Password → **Change Password**(파란 링크)
- 카드 2: Backup & Restore → **Generate Backup** · **Import Backups** · Manage Account → **Delete Account**(빨간 링크)
- 카드 3: Login Devices → **Manage**
- 8.0 버전(f0103)은 가운데 정렬 레이아웃이다: 큰 아바타 + 이름 + 이메일 + 가입 안내 문구, 아래에 Sign Out 버튼과 빨간 "Delete Account".

## sprout v1
- 유지: 아바타·이름·이메일, 비밀번호 변경(이메일 로그인일 때), 로그인 기기 관리, 로그아웃, 계정 삭제(개인정보 보호 요건).
- 백업: Generate Backup(내보내기)은 v1 후보. 동기화가 있으므로 Import는 제외한다.
- 프리미엄 만료일·Renew는 제외한다(영구 무료). 그 자리에 **캐릭터 레벨 요약**을 둘 수 있다.
