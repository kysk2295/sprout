# task-context-menu — 관찰 노트 (8.0 데스크톱)

- 근거 프레임: [f0108](../_video/aJ0ELyY215A/f0108.jpg) (TickTick 8.0 공식 영상, Mac, Sky 테마). 도움말 이미지는 [SOURCES.md](SOURCES.md).

## 여는 위치
- 목록에서 태스크 행을 우클릭한다. 메뉴는 커서 근처에 뜨는 흰 둥근 카드이고 그림자가 옅다.
- 마우스를 올린 행 **왼쪽 바깥에 `≡` 드래그 손잡이**가 나타난다.

## 메뉴 구성 (위 → 아래)
| 구역 | 항목 |
|---|---|
| **날짜** (소제목 + 아이콘 한 줄) | 오늘(해) · 내일(해 뜨는 모양) · 다음 주(달력 +7) · 날짜 지정(달력) · 날짜 지우기(×) |
| **우선순위** (소제목 + 깃발 한 줄) | 높음(빨강) · 중간(주황) · 낮음(파랑) · 없음(테두리만) — 현재 값은 옅은 회색 사각 배경 |
| (구분선 없이) | 하위 태스크 추가 · 부모 태스크 연결 · 고정 · 하지 않음 · 이동 › · 태그 › |
| 구분선 | 집중 시작 › |
| 구분선 | 복제 · 링크 복사 · 스티키 노트로 열기 · 노트로 변환 · 삭제 |
- 항목마다 왼쪽에 가는 선 아이콘이 있고, 하위 메뉴가 있으면 오른쪽에 `›`가 붙는다.

## sprout v1
- 유지: 날짜 줄, 우선순위 줄, 하위 태스크 추가, 부모 연결, 고정, 하지 않음, 이동, 태그, 복제, 링크 복사, 삭제.
- 제외: 집중 시작, 스티키 노트로 열기, 노트로 변환(v1에 해당 기능 없음).
