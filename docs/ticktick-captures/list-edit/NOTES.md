# list-edit — 관찰 노트 (데스크톱)

- 근거 프레임: [EUB f0072 Edit List](../_video/EUBxb9MgYWg/f0072.jpg), 같은 영상 f0073(색 선택 팔레트). 도움말은 [SOURCES.md](SOURCES.md)

## Edit List 모달
- 두 칸 구성: **왼쪽 입력 폼 + 오른쪽 실시간 미리보기**(리스트 화면의 축소 그림, 선택한 색·뷰 형태가 바로 반영됨). 오른쪽 위에 `×`.
- 폼 항목:
  | 항목 | 입력 |
  |---|---|
  | 이름 | 텍스트 입력. 왼쪽에 아이콘/이모지 버튼(📅) |
  | List Color | 없음(사선) · 빨강 · 주황 · 노랑 · 연두 · 초록 · 파랑 · 보라 · 사용자 지정(무지개 원 → 팔레트: Macaron, Morandi, Rococo, Classic 등 계열별 색) |
  | View Type | 리스트 / 칸반 / 타임라인(프리미엄 배지) — 아이콘 3개 분절 버튼 |
  | Folder | 드롭다운("Work") |
  | List Type | 드롭다운("Task List" / Note List) |
  | 체크박스 | "Do not show in Smart List" (?) |
- 하단: Cancel(흰 버튼) · **Save(파랑)**.

## Add List (2026 버전) — [QKA f0008](../_video/QKAA8p3PY_8/f0008.jpg)
- Edit List와 같은 두 칸 구성이다. 차이점:
  - 왼쪽 위에 빨간 닫기 점, 제목 "Add List".
  - 이름 앞 아이콘 버튼의 기본값이 `≡`이고, 누르면 **이모지 선택기**(검색, 자주 쓰는 항목, 사람 & 몸 등 분류)가 뜬다(f0009~0010).
  - 체크박스 대신 **"Show in Smart List" 드롭다운**("All tasks")이 있다.
  - Save 버튼이 테마 강조색(이 테마에서는 검정)이다.

## 사이드바의 폴더 표시 (같은 프레임)
- 폴더는 `⌄` 펼침 표시 + 폴더 이모지 + 이름. 하위 리스트는 들여쓰기된다.
- 보관한 리스트는 "Archived Lists" 폴더처럼 접혀서 휴지통 위에 있다.

## sprout v1
- View Type은 리스트 한 가지뿐이다(칸반·타임라인 제외). 선택지는 숨기고 자리만 남긴다.
- List Type(노트)은 제외한다.
