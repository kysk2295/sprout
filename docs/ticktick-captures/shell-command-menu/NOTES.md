## 모양
- ⌘K를 누르면 화면 가운데 위쪽에 흰 둥근 팝업이 뜬다. 그림자가 있고, 목록·캘린더 등 **어느 화면에서든 같은 모양**이다.
- 첫 줄: 자리 표시 문구 **"Type a command or search"** + 오른쪽에 `⌘ K`.
- 구분선 아래 명령 목록. 행마다 왼쪽에 아이콘, 가운데에 이름, 오른쪽에 회색 단축키가 있다. 선택 행은 옅은 강조 배경이고 ↑/↓로 이동한다.

- **"G then X" 연속 입력 단축키**가 있다. G를 누른 뒤 글자를 하나 더 누르면 해당 스마트 리스트나 설정으로 이동한다.
- 검색어를 입력하면 명령과 리스트, 태스크가 함께 걸러지는 것으로 보인다(GIF 앞부분만 확인).
