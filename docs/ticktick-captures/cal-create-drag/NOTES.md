# cal-create-drag — 관찰 노트 (데스크톱)

- 근거 프레임: [EUB f0052 빠른 만들기 팝오버](../_video/EUBxb9MgYWg/f0052.jpg). 같은 영상의 f0058(리스트 선택), f0063(우선순위 메뉴), 주 뷰 드래그 생성은 f0022~0025, f0076~0080 참고. 도움말은 [SOURCES.md](SOURCES.md)

## 빈 칸 클릭 → 빠른 만들기 팝오버
- 클릭한 날짜 칸이 **옅은 파랑으로 강조**된다(주 뷰에서 드래그하면 그 시간 범위가 강조됨).
- 칸 옆에 흰 팝오버가 뜬다.
  - 머리: 달력 아이콘 + 파란 날짜("Jun 12") … 깃발.
  - 큰 자리 표시 문구: **"What would you like to do?"**
  - 하단 왼쪽: 리스트 이동 버튼(`⇥ Inbox`).
- 키보드 흐름(영상의 키캡 표시): 제목 입력 → **↓ 키로 리스트 선택 드롭다운**(f0058), 우선순위 메뉴 High/Medium/Low/None(f0063) → **Enter로 확정**. 팝오버를 닫으면 태스크가 칸에 막대로 생긴다.

## 기타
- 머리글의 `+` 버튼도 같은 팝오버를 연다(추정, 확인 필요).
- 태스크를 완료하면 아래쪽 가운데에 검은 토스트 **"Task completed ⟲"**(되돌리기)가 잠깐 뜬다(MhY 영상 여러 프레임).
