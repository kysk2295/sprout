## 캘린더 `...` 메뉴 (f0103)
- View Options · Arrange Tasks · Subscribe Calendar · Print (각각 왼쪽에 선 아이콘)

## View Options 모달 (f0069)
- 가운데 뜨는 흰 모달, 제목 "View Options" + 오른쪽 위 `×`.
- 옅은 회색 카드 여러 개로 묶인 행:
  1. Color (?) → 값 "Lists ⌃⌄" (Lists / Tags / Priority) · Style → "Simple ›" · Show Weekends [토글 켬]
  2. Show Completed [켬] · Show Check Item [끔] · Show All Repeat Cycle [끔]
  3. Show Habit · Show Focus Records (?) · Show Countdown [모두 끔]
  4. Additional Time Zone (?) [끔]
- 토글은 켜면 파랑, 끄면 회색이다. (?) 아이콘에는 설명 툴팁이 붙는다.
- Color 값을 누르면 드롭다운: **Lists ✓ · Tags · Priority** — [EUB f0070](../_video/EUBxb9MgYWg/f0070.jpg)
