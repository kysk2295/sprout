## 머리글
- 왼쪽: 사이드바 접기 아이콘(`☰` 모양) + 리스트 제목(굵게, 큼).
- 오른쪽 아이콘: **전구(추천 태스크, 오늘 리스트에만)** · 정렬(`⇅`) · `...`.

## 추가 바
- 회색 둥근 입력창에 `+` 아이콘.
- 문구: 일반 리스트는 "Add task", **스마트 리스트는 "Add task to "Inbox""** — 스마트 리스트에서 추가하면 어느 리스트로 들어가는지 알려준다.

## 그룹
- `⌄ 그룹명 개수` 형태(굵은 제목 + 옅은 회색 개수). 클릭하면 접힌다.
- 오늘 리스트의 그룹 순서: **Overdue(기한 지남) → Today**.
- **Overdue 그룹 오른쪽에 파란 "Postpone"(미루기) 링크**가 있다. 기한 지난 태스크를 한 번에 미룬다.

## 행
- 왼쪽: 둥근 사각 체크박스 → 제목.
- 오른쪽 메타(오른쪽 정렬, 작은 글씨, 순서대로): **태그 알약**(예: "Important", 옅은 분홍 배경 + 진한 글씨) → 리스트(이모지 + 회색 이름, 스마트 리스트에서만) → 반복 아이콘 → 알림(시계) 아이콘 → 날짜/시간.
- **날짜 색:** 기한 지남 = 빨강("Jan 9", "Yesterday"), 오늘·시간 = 파랑("Today", "7:30 AM"), 미래 = 회색("Oct 12", "Jul 11").
- 행 사이는 옅은 가로 구분선. 선택된 행은 옅은(테마색이 섞인) 둥근 배경.
- 행에 마우스를 올리면 왼쪽 바깥에 `≡` 드래그 손잡이가 나타난다.

## 빈 상세
- 아무 태스크도 선택하지 않으면 오른쪽 상세 영역에 옅은 선화 일러스트가 보인다(책상 소품 그림).

## 빈 목록
- 리스트에 태스크가 없으면 가운데에 일러스트(체크리스트 종이 + 연필 + 반짝이) + **"No tasks"** + 회색 보조 문구 **"Click the input box to add"** — [QKA f0012](../_video/QKAA8p3PY_8/f0012.jpg).
- 모두 완료했을 때는 다른 일러스트 + **"All tasks are completed"** (2024 영상 MhY sheet06).

## 완료 토스트
- 태스크를 완료하면 아래쪽 가운데에 검은 둥근 토스트 "Task completed ⟲"가 잠깐 뜬다(되돌리기). 리스트로 옮기면 "Moved to …" 토스트가 뜬다.
