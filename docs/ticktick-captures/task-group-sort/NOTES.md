## 정렬 버튼(⇅) 메뉴 (10)
- 목록 머리의 ⇅를 누르면 작은 팝오버가 뜬다:
  - Group by → 현재 값 "Custom ›"
  - Sort by → 현재 값 "Date ›"
- 각 행의 `›`를 누르면 선택지 하위 메뉴가 열린다(그룹 6종, 정렬 4종).

## 리스트 `...` 메뉴 (02)
- **View** 소제목 + 아이콘 3개: 리스트(선택, 파랑) · 칸반 · 타임라인
- Show Completed · Show Details · View Options
- (구분선) **Add Section** · Share · List Activities · Print ›
- "Add Section"이 사용자 지정 그룹(섹션)을 만드는 진입점이다.

## 참고: 같은 캡처의 사이드바
- 폴더 "Work"가 펼쳐져 있고 하위 리스트(Creative Work, Admin)가 들여쓰기된다. 접힌 폴더 "Projects", 보관함 "Archived Lists"는 왼쪽에 `›`가 있다.
- 행 오른쪽 날짜 표기: 반복 태스크 "⟲ Tue", 올해가 아닌 날짜 "Jul 11, 2026", 본문이 있는 태스크는 체크박스 대신 문서 아이콘을 쓴다.

## sprout v1
- View 줄은 리스트만 둔다(칸반·타임라인 제외). Share, List Activities, Print는 제외한다.
