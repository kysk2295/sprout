## 설정 창 구조
- 앱 위에 뜨는 **모달 창**이다. 왼쪽 위에 빨간 닫기 버튼 하나만 있다.
- 왼쪽 메뉴(구분선으로 네 묶음):
  1. Account · Premium
  2. Features · Smart Lists · Notifications · Date & Time · **Appearance** · More
  3. Integrations & Import · Collaborate · Sticky Note · Hotkeys
  4. About
- 선택 항목은 옅은 회색 둥근 배경이다.

## 외관(Appearance)
- 위쪽 가운데 분절 탭: **Theme / App icons / Display**.
- 카드 한 장 안에 두 줄:
  - Interface Style → 오른쪽 값 "Flat ›" (Flat / Card 선택. f0105~0106에서 두 스타일 미리보기)
  - Follow System Dark Mode → 토글
- **Color Series**(색 사각 + 이름): Default(흰색) · Sky(선택 ✓) · Turquoise · Teal · Matcha · Sunshine · Peach · Lilac / Ebony · Navy · Gray · Dark
- **Season Series**(일러스트 배경, 프리미엄 배지): Spring · Summer · Autumn · Winter
- **City Series**(일러스트 배경, 프리미엄 배지)
