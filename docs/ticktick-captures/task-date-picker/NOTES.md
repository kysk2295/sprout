# task-date-picker — 관찰 노트 (Mac)

- 근거 프레임: [zq f0042 날짜 선택기](../_video/zqGeCiSgFOk/f0042.jpg), [zq f0043 선택 후](../_video/zqGeCiSgFOk/f0043.jpg) (다크 테마). 도움말 이미지는 [SOURCES.md](SOURCES.md) (28장, 기간·반복·알림 화면 포함)

## 여는 곳
- 태스크 상세 머리의 **"Due Date"**(날짜가 없을 때) 또는 날짜 텍스트를 클릭한다. 머리 바로 아래에 팝오버가 뜬다.
- 태스크 우클릭 메뉴의 날짜 줄에서 "날짜 지정" 아이콘을 눌러도 뜬다.

## 팝오버 구성 (위 → 아래)
1. 분절 탭 **Date / Duration**.
2. **빠른 선택 아이콘 4개:** 오늘(해) · 내일(해 뜨는 모양) · 다음 주(달력 +7) · 달 모양(오늘 밤 또는 다음 주 월요일로 추정, 확인 필요).
3. **월 달력:** "May 2025" + 오른쪽 `‹ ○ ›`(○는 오늘로 이동). 요일 S M T W T F S(주 시작 설정을 따름). 선택한 날은 파란 원, 다른 달 날짜는 흐리게.
4. 행 3개(오른쪽 `›`로 하위 설정이 열림): **Time** · **Reminder** · **Repeat**
5. 버튼: **Clear**(회색) · **OK**(파랑)

## 선택 후
- 상세 머리 텍스트가 **"Tomorrow, May 31"**(파랑)로 바뀌고, 목록 행 오른쪽에 "Tomorrow"가 붙는다(f0043).

## 남은 조사
- Duration 탭 내부(시작·끝 시각, 종일), Time·Reminder·Repeat 하위 화면은 도움말 이미지([SOURCES.md](SOURCES.md))에서 확인한다.
