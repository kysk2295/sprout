# settings-smart-lists — 관찰 노트 (데스크톱)

- 근거: 도움말 [02-desktop-how-to-enable-smart-lists.png](../_help/manage-tasks-with-lists-396608/02-desktop-how-to-enable-smart-lists.png) (설정 창, 메뉴 항목 이름이 "Smart List", 단축키 메뉴가 "Shortcuts"인 약간 옛 버전)

## 화면
- 설정 창 → 왼쪽 메뉴 **Smart List**. 오른쪽 제목 "Smart List".
- 옅은 회색 카드 3개로 묶인 행. 행마다 아이콘 + 이름 + 오른쪽 값 `Show ⌃⌄` / `Hide ⌃⌄`(누르면 Show / Hide / Show if not empty 선택).
  1. All [Show] · Today [Show] · Tomorrow [Show] · Next 7 Days [Show] · Assigned to Me [Hide] · Inbox [Show] · Summary [Hide]
  2. Tags [Hide] · Filters [Hide]
  3. Completed [Show] · Won't Do [Hide] · Trash [Show]
- 기본값 기준으로 보면 Tags·Filters 구역도 여기서 켜야 사이드바에 보인다.
