# task-subtask — 관찰 노트 (데스크톱)

- 근거: 도움말 [06-create-subtasks](../_help/multilevel-tasks-349248/06-desktop-create-subtasks.png), [13-link-parent-task](../_help/multilevel-tasks-349248/13-desktop-link-parent-task.png) (07~09, 14, 17~19에 단계별 화면 더 있음). 조사 노트 [11](../../ticktick-research/11-subtasks.md)

## 상세 패널 `...` 메뉴 (06)
- 상세 패널 오른쪽 아래 `...`을 누르면 위로 열린다:
  - Add Subtask · Pin · Won't Do · Tags · Upload Attachment · Start Focus ›
  - (구분선) Task Activities · Save as Template · Duplicate · Copy Link · Convert to Note
  - (구분선) Print · Delete
- 태스크 우클릭 메뉴와 항목 구성이 다르다(상세 메뉴에는 Attachment, Activities, Template, Print가 있다).

## 우클릭 메뉴의 Link Parent Task (13)
- 우클릭 메뉴 3번째 구역 첫 줄 "Add Subtask" 아래에 **"Link Parent Task"**. 누르면 부모로 삼을 태스크를 고르는 목록이 뜬다(14).
- 이 캡처의 날짜 줄은 아이콘 4개(오늘·내일·다음 주·날짜 지정)다. 8.0 캡처에는 날짜 지우기(×)가 추가돼 5개다.

## 목록 표시
- 부모 행 왼쪽에 `⌄`/`›` 펼침 표시, 하위 태스크는 들여쓰기된다(Windows 위젯 이미지에서도 같다).
- 우선순위가 있는 태스크는 **체크박스 테두리 색**(빨강/주황/파랑)으로 구분된다. 06 캡처에서도 확인된다.
