## 설정 → Hotkeys 화면
두 구역이고, 행마다 왼쪽에 동작 이름, 오른쪽에 키가 있다. **바꿀 수 있는 키는 테두리 입력칸 + `×`(지우기)**, 바꿀 수 없는 키는 회색 글자만 표시된다. 맨 아래 오른쪽에 "Reset Default" 버튼.

### General
| 동작 | Mac 키 | 변경 |
|---|---|---|
| Sync | ⌘S | 불가 |
| Cancel | (되돌리기 아이콘 표기) | 불가 |
| Undo | ⌘Z | 불가 |
| Redo | ⇧⌘Z | 불가 |
| Print | ⌘P | 가능 |
| Open Command Menu | ⌘K | 불가 |
| Shortcuts | ? | 불가 |

### Global Action — 앱이 뒤에 있어도 동작하는 단축키
| 동작 | Mac 키 (영상 속 값) |
|---|---|
| Quick Add | ⌃⇧A |
| Show/Hide Main Window | ⇧⌘E |
| Show/Hide Mini Window | ⇧⌘O |
| Start/Abandon Pomo | ⇧⌘P |
| New Sticky Note | ⇧⌘N |

## 기존 조사와 다른 점
- Quick Add: 공식 Mac 페이지는 Cmd+Shift+A, 이 영상은 ⌃⇧A다. 사용자가 바꿀 수 있는 값이므로 **기본값은 확정되지 않았다.**
- 명령 메뉴(⌘K)가 **Mac에서도 동작한다.** 도움말의 "Mac 미지원"은 옛 정보다.

## sprout v1
- General: Sync, Undo, Redo, Open Command Menu, Shortcuts는 그대로 따른다. Print는 제외한다.
- Global Action: Quick Add, Show/Hide Main Window, Show/Hide Mini Window(메뉴바 창)만 둔다. Pomo와 Sticky Note는 제외한다.
