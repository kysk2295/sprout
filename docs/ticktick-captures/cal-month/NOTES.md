## 캘린더 공통 머리글 (모든 뷰 동일)
- 왼쪽: 사이드바 접기 아이콘(▯|) → **"June 2025"** (굵게, 큼).
- 오른쪽: `+` 버튼(테두리 있는 정사각) → **뷰 전환 드롭다운** "Month ⌄"(테두리 버튼) → 분절 버튼 `‹ | Today | ›` → `...`.

## 뷰 전환 메뉴 (f0021)
| 항목 | 오른쪽 표기(단축키/값) |
|---|---|
| Day | D/1 |
| Week | W/2 |
| Month ✓ | M/3 |
| Agenda | A/4 |
| (구분선) | |
| Multi-Day | "1 Day" (일 수 설정) |
| Multi-Week | "4 Weeks" (주 수 설정) |
- 현재 뷰는 왼쪽에 파란 체크. 캘린더 화면에서는 **D/W/M/A 또는 1/2/3/4 한 글자 단축키**로 전환된다(영상에 키캡 표시).

### 2026 버전 메뉴 — [QKA f0102](../_video/QKAA8p3PY_8/f0102.jpg)
- Day D/1 · Week W/2 · Month M/3 · **Year Y/4** · Agenda **A/5** · (구분선) · Multi-Day "5 Days" · Multi-Week "4 Weeks" ✓
- Year 뷰가 추가되면서 Agenda 단축키가 A/5로 밀렸다. **sprout는 2026 배치를 기준으로 삼는다.**
- 2026에서는 오늘 표시 원과 선택 강조가 테마 강조색을 따른다(이 영상은 검정). 태스크 막대 왼쪽에 진한 색 세로 줄이 붙고, 시간은 12시간제("1:00 PM")로 표시된다(설정값).

## 월 그리드
- 요일 머리(Mon…Sun), 옅은 회색. 주 시작 요일은 설정할 수 있다(2024 영상은 Sun 시작 + 주 번호 "W33" 표시).
- 칸 왼쪽 위 날짜 숫자: 이번 달은 진하게, 다른 달은 회색. 달의 첫날은 "Jun 1", "Jul 1"로 월 이름을 붙인다.
- **오늘:** 파란 원 안의 흰 숫자.
- **태스크 막대:** 리스트 색의 옅은 파스텔 배경 + 같은 계열의 진한 글씨, 시간은 오른쪽 정렬("16:00"). 한 칸에 4줄까지 보이고 넘치면 회색 **"+N"** 칩.
- 여러 날 태스크는 칸을 가로질러 **하나의 막대**로 이어진다.
- 지난 날짜·완료한 태스크는 더 옅게 표시된다.
- 이번 달이 끝난 뒤의 칸은 옅은 회색 배경이다.

- 단축키 D/W/M/A, 1/2/3/4를 그대로 따른다.
