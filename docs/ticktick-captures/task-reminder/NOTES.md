# task-reminder — 관찰 노트

- 근거: 도움말 [03-how-to-set-a-reminder](../_help/effective-reminder-feature-567872/03-desktop-how-to-set-a-reminder.png). ⚠️ 이미지 속 UI는 **iOS**다. 데스크톱은 날짜 선택기의 Reminder 행에서 같은 목록이 열린다. 조사 노트 [09](../../ticktick-research/09-reminders.md)

## 알림 목록 (날짜 선택기 → Reminder, 시간이 없는 종일 태스크 기준)
| 항목 | 보조 표기 |
|---|---|
| None ✓ | |
| On the day | (09:00) |
| 1 day early | (09:00) |
| 2 days early | (09:00) |
| 3 days early | (09:00) |
| 1 week early | (09:00) |
| Custom › | |
| **Constant Reminder** | 토글(켜면 확인할 때까지 계속 울림) |
- 종일 태스크의 기본 알림 시각은 09:00이다(설정값으로 추정).
- 시각이 있는 태스크는 "On time", "5 minutes early" 같은 목록으로 바뀐다(Repeat 이미지의 "Reminder On time" 표기로 확인).

## Custom 알림
- 작은 모달, 분절 탭 **Day / Week**.
- 휠 3개: [On the day / 1 day early / 2 days early …] [시] [분].
- 지난 시각을 고르면 빨간 경고 "The reminder has expired."
- 버튼: Cancel · Add. 한 태스크에 여러 개를 추가할 수 있다.
