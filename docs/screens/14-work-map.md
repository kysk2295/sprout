## 0. 그래프 보기 (기본) — 2026-10-04 사용자 결정
사용자 말: "작업 지도는 그래프 노드화 — 연결이 되어서 랭그래프처럼 보여주는 것", "새 할 일이 생기면 자동으로 나누고, 칸반 보드도 있으면 좋아", 선·노드 종류는 "추천대로". 틱틱에 없는 화면 → [sprout]. 모양은 시안 ③의 부품(열 머리 글자, 칸반 카드)을 노드로 그대로 쓴다.

### 0.2 선 3종 (+ 자동 출처선)
| 선 | 모양 | 누가 | 규칙 |
|---|---|---|---|
| **포함** | 회색 실선 곡선(1.5px) | AI 자동 / 사용자가 옮김 | 영역→주제→할 일. 할 일 1개는 한 곳에만 |
| **순서**(먼저 해야 함) | 진한 회색 실선 + 화살표. AI 제안은 **점선** + 선 옆 `✓ ✕` | 사용자: 할 일 노드에 마우스를 올리면 아래에 점(손잡이) → 끌어서 다른 할 일에 놓기. AI: 제목으로 순서가 보이면 제안("초안" → "검토") | 고리(A→B→A)는 만들 수 없음(놓는 순간 거부 + 토스트 `순서가 돌고 돌아서 이을 수 없어요`). 뒤 할 일 카드에 `먼저 N`. 앞 할 일을 끝내면 토스트 `이제 '<뒤 할 일>'을 시작할 수 있어요` |
| **목표 연결** | 주황 실선 + 화살표(목표 → 할 일). AI 제안은 점선 + `✓ ✕` | 사용자: 목표 노드 손잡이를 끌어 할 일에 놓기. AI: 새 할 일·목표가 생기면 관련 있는 것끼리 제안 | 연결된 할 일을 모두 끝내면 토스트 `'<목표>'에 연결된 할 일을 다 끝냈어요 · 달성으로 표시` — 누르면 성장 탭과 같은 달성 처리(XP는 성장 규칙 그대로, 자동 지급 안 함) |
| 출처(자동) | 회색 점선 | 자동(`notes.task_id`) | 메모 → 그 메모로 만든 할 일. 메모 보이기를 켰을 때만 |
- 선을 누르면 선택(강조) → Delete 또는 우클릭 `연결 끊기`. AI 제안 `✕` = 무시(같은 제안을 다시 하지 않음).
- **관련**(다른 영역끼리 같은 사람·키워드) 선은 **[다음]** — 지도가 복잡해지는지 보고 정한다.

### 0.3 새 할 일 자동 분류
- 어디서 만들든(추가 바·빠른 추가·메뉴바 미니 창·AI 비서·메모 전환) 새 할 일은 **바로 저장**하고 분류는 뒤에서 한다(입력이 느려지지 않게).
- 5초 동안 모아서 한 번에 요청(최대 20개) — Mac mini 부담 줄이기. 결과가 오면 토스트 `AI가 '<제목>'을 학교 › 운영체제에 넣었어요 · 바꾸기`(여러 개면 `새 할 일 3개를 정리했어요 · 보기`).
- AI가 확신이 없으면 **미분류**에 두고 `확인 필요` 꼬리표. 억지로 넣지 않는다.
- AI를 쓸 수 없으면(오프라인·Mac mini 꺼짐) 미분류에 두고, AI가 돌아오면(앱 포커스·10분마다) 다시 시도.
- 이미 분류된 할 일은 제목을 고쳐도 자동으로 옮기지 않는다(✦ 다시 정리에서만).
- 같은 요청에서 순서·목표 연결 **제안**도 함께 받는다(점선).

### 0.4 영역과 리스트
- **영역은 리스트와 별개**다. 리스트 = "어디에 저장했나"(사용자가 만든 틀), 영역 = "무슨 일인가"(AI가 나눈 의미). 리스트 이름은 AI가 나눌 때 **힌트로만** 쓴다. [다음] 영역 `⋯` → `리스트로 만들기`.

## 3. 구성 요소와 상태
| 요소 | 상태 |
|---|---|
| 카드 | 기본 · 호버(배경 한 단계 밝게) · 선택(강조색 1px 테두리) · 끄는 중(살짝 기울고 그림자, 원래 자리에 점선 자리 표시) · 완료(체크 후 0.4초 뒤 사라짐, 보기 옵션에서 `완료 보이기`면 남고 흐리게) |
| 직접 옮긴 카드 | 호버 시 제목 옆 📌(3차 글자) + 툴팁 `직접 옮긴 항목 — AI가 다시 정리해도 그대로예요` |
| 최근 정리로 바뀐 카드 | 제목 끝 강조색 점(5px). `바뀐 것 보기`를 누르면 그 카드들만 2초간 강조 테두리. 다음에 화면을 열면 점 사라짐 |
| 열 `⋯` | `이름 바꾸기` · `다른 영역과 합치기 ›`(영역 목록) · `세부 주제 추가` · 구분선 · `영역 삭제` (할 일은 미분류로 — 할 일 자체는 지우지 않음, 확인 대화 상자) |
| 세부 주제 머리 `⋯`(호버) | `이름 바꾸기` · `다른 주제와 합치기 ›` · `주제 삭제`(카드는 영역 바로 아래로) |
| 이름 바꾸기 | 그 자리에서 입력칸. Enter 저장 · Esc 취소 · 빈칸/20자 넘음 거부 |
| 열 머리 `+` | 열 맨 위에 입력 카드. Enter = 기본함에 할 일 생성 + 이 영역에 직접 배치(📌). 날짜 인식은 02와 같다 |
| ✦ AI로 다시 정리 | 누르면 아이콘이 돌고 알림 띠 자리에 `할 일 32개를 정리하는 중… ■ 멈추기`. 끝나면 알림 띠 |
| AI 쓸 수 없음 | ✦ 비활성 + 툴팁 `지금은 AI를 쓸 수 없어요. 직접 영역을 만들어 정리할 수 있어요.` 화면은 그대로 쓸 수 있다 |
| 처음(분류 없음) | 보드 가운데: 지도 아이콘 + `할 일을 영역별로 한눈에 보여 드려요` + `학교·회사·개인처럼 AI가 나눠 드리고, 직접 고칠 수도 있어요` + [AI로 정리하기](주 버튼) · [직접 영역 만들기] |
| 할 일 없음 | `정리할 할 일이 없어요` + [할 일 목록 열기] |
| 보기 옵션(거름틀) | 팝오버: `완료한 항목 보이기`(끔) · `날짜 없는 항목 보이기`(켬) · `범위: 모든 리스트 / 고른 리스트 ›` |
| 머리 `⋯` | `AI 분류 모두 지우기`(직접 옮긴 것은 남김) · `직접 옮긴 것도 AI에 맡기기` · 구분선 · `작업 지도 도움말` |

## 4. 인터랙션
| 동작 | 결과 |
|---|---|
| 카드 끌기 → 다른 열·주제 | 그 영역·주제로 이동, 📌(직접 옮김). 열 머리에 놓으면 주제 없이 영역 바로 아래 |
| 카드 끌기 → 같은 주제 안 | 순서만 바뀐다(이 화면 안의 순서, 리스트 순서와 별개) [임시] |
| 열 머리 끌기 | 열 순서 바꾸기 [임시 — 틱틱 칸반 열 끌기 미확인] |
| 카드 클릭 / 체크박스 | 상세 열기 / 완료(02 완료 동작 · XP 포함) |
| 카드 우클릭 | 02의 태스크 메뉴 + 맨 위 `영역 옮기기 ›` |
| AI 정리 | 미완료 할 일·일정 중 **직접 옮기지 않은 것**만 대상. 사용자가 만든·이름 바꾼 영역은 이름을 바꾸지 않는다 |
| 되돌리기 | 방금 정리 전 상태로(정리 뒤 사용자가 옮긴 카드는 그대로) |
| 자동 정리 | 새 할 일은 만들 때마다 자동 분류(§0.3). ✦ 다시 정리는 전체를 다시 나눈다(직접 옮긴 것 제외) |
| 키보드 | ←→ 열 이동, ↑↓ 카드 이동, Enter 상세, Space 완료 [임시] |

| `map_areas` | common + `name`, `parent_id`(null = 영역, 값 = 그 영역의 세부 주제), `sort_order`, `source`(`ai`/`user`), `color`, `archived_at` | 이름을 사용자가 바꾸면 `source=user` → AI가 이름을 바꾸지 않는다. 보관 = `archived_at` |
| `task_areas` | common + `task_id`, `area_id`(영역 또는 세부 주제), `source`(`ai`/`user`), `state`(`ok`/`review`), `run_id` | 할 일 1개당 1행(id = task_id로 결정적). `source=user`면 AI가 덮어쓰지 않는다. `review` = 확인 필요 |
| `map_links` | common + `kind`(`sequence`/`goal`), `from_type`(`task`/`kpi`), `from_id`, `to_id`(할 일), `source`(`ai`/`user`), `state`(`suggested`/`accepted`/`dismissed`) | 순서·목표 연결 선. 무시한 제안은 `dismissed`로 남겨 다시 제안하지 않는다 |
- 읽기: `tasks`(삭제·취소 제외, 기간·거름틀 조건) + `task_areas` + `map_areas` + `map_links` + 이번 주 `kpis` + (메모 보이기) `notes.task_id`.
- AI 입력: 할 일 **제목**·리스트 이름·날짜 유무 + 현재 영역·주제 이름 + 이번 주 목표 이름(성장과 같은 범위: 제목까지). 출력은 앱이 검증: 존재하는 id만, 영역 ≤ 8 · 영역당 주제 ≤ 8 · 이름 ≤ 20자, 확신 낮음 → `review`, 순서 제안은 고리 검사 후에만.
- 되돌리기: ✦ 다시 정리 직전 `task_areas`/`map_areas` 스냅숏을 기기에 보관(마지막 1회) [임시].
- 모델 호출: 오너 개발판은 지금 AI 비서와 같은 경로(SSH → Mac mini Ollama), 배포판은 `POST /ai/classify`(JWT, 서버 상한) — PRD AI 원칙.
- ⚠️ 새 테이블 3개 → 서버 스키마·`server/db/migrations`·동기화 규칙 변경이 필요하다. 구현 전에 사용자 승인(2026-10-04 설명함).

## 7. 구현 메모 (2026-10-04, v1.2 구현 때 명세와 달라진 점)
- **상세**: 카드·할 일 노드를 누르면 작업 지도 안 오른쪽에 02와 같은 상세 패널(`DetailPane`, 기본 폭 298 = 앱 실측)이 열린다. 다른 화면으로 넘어가지 않는다.
- **자동 분류 범위**: 이 기기에서 작업 지도 기능이 처음 돈 시각(`sprout.map.since`) 뒤에 만든 할 일만 자동으로 나눈다. 그 전 할 일은 처음 화면의 [AI로 정리하기]·✦로 나눈다. 영역이 하나도 없으면(처음 상태) 자동 분류는 쉰다.
- **자동 분류 토스트**: 앱 공용 토스트를 쓴다. 한 개면 `AI가 '<제목>'을 학교 › 운영체제에 넣었어요` + ⟲(= 바꾸기: 미분류로 돌리고 직접 고른 것으로 침), 여러 개면 `새 할 일 N개를 정리했어요`(보기 단추 없음).
- **미분류 규칙**: 확신 낮음·이름 규칙 위반·영역 8개 초과 → 미분류 + `확인 필요`(행은 남겨 다시 묻지 않음). 주제 8개 초과면 영역 바로 아래. 영역 삭제·AI 분류 지우기로 미분류가 된 할 일도 자동 분류는 다시 건드리지 않고 ✦에서만 다시 나뉜다.
- **AI 출력**: 할 일·목표는 짧은 키(t1, g1…)로 보내고 받는다. 작은 모델이 `tasks[]` 모양으로 답하거나 confidence를 빠뜨리면 보통(0.7)으로 받는다.
- **카드 우클릭**: 02 태스크 메뉴 대신 `영역 옮기기 ›` · 열기 · 완료 · 삭제만 [임시] (02 메뉴에 맨 위 항목을 끼울 수 없어서).
- **같은 주제 안 순서 바꾸기**: 이번에 안 함 [다음] — `task_areas`에 순서 칸이 없다.
- **기간**: 보드는 기간 없이 `전체`, 그래프만 `이번 주 · 전체`. 이번 주는 앱 캘린더와 같이 일요일 시작. `완료한 항목 보이기`는 최근 30일 완료까지.
- **목표 달성 제안**: 작업 지도가 열려 있을 때 화면 아래 안내로 띄운다(`달성으로 표시` = 성장 탭과 같은 `setGoalProgress`).
- **집중 보기**: 그 영역에 화면을 맞출 뿐 다른 영역을 숨기지는 않는다.
- **메모 노드**: 거름틀 `메모 보이기`를 켜면 할 일 오른쪽에 점선 카드 + 점선(출처)으로 붙는다.
- **열 머리 `+`**: 날짜 인식 없이 제목만(02 추가 바에도 아직 날짜 인식이 없다).
- **되돌리기**: ✦ 다시 정리만 되돌린다(마지막 1회, 기기 `sprout.map.undo`). 합치기·이름 바꾸기·삭제는 되돌리기 없음.
- **배치**: dagre 결과에서 영역 덩어리를 정한 순서(미분류 맨 오른쪽)로 다시 늘어놓고, 주제 열은 위를 맞춘다.
- **E2E 수정(2026-10-04, 실제 Mac mini AI):** 서버가 JSON 스키마를 강제하지 못해(11 v3-7 메모) AI 응답이 맨 배열·설명 글 섞임으로 올 수 있다 → `parseAiJson`이 받아 준다. 처음 열 때 전체 맞춤이 너무 작아 글자를 못 읽던 것 → **처음은 0.8배 아래로 줄이지 않고 뿌리를 위·가운데에**, `⤢`·Esc는 0.5배까지. **배율만 기억**(위치는 지도가 바뀌면 의미가 없어 매번 뿌리 기준). 집중 보기는 1.25배까지. 같은 주제 열에 쌓인 할 일끼리의 순서 선은 카드 사이 틈에 묻혀서 **오른쪽으로 휘어 오른쪽 가운데로 들어가게**(시안 ③-b). 점 격자 색이 안 보이던 것(SVG 속성에 CSS 변수) 고침. ✦ 다시 정리 중 다른 화면에 갔다 오면 진행 띠가 사라지고 ✦를 또 누를 수 있던 것 → 진행 상태를 화면 밖에 둬서 돌아와도 보인다. 보드 열 머리에 카드를 놓으면 아무 일도 없던 것 → 영역 바로 아래로(§4). 머리 제목이 22px·다른 자리이던 것(`.workspace h1`이 덮음) → 수집함·태스크 머리와 같게. 미니맵을 앱 공용 비서 단추 위로.
