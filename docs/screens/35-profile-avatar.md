**sprout v1**: 사진 올리기 대신 **캐릭터 + 배경색 고르기**(틱틱에 없는 부분 — 틱틱 디자인 언어로 새로 설계). 사진 올리기는 **[다음]**(저장소·용량·검열이 필요 — 서버 파일 저장소가 생길 때).
틱틱 그림·아이콘 원본은 쓰지 않는다. 그림은 전부 sprout가 직접 그린 단순 벡터(성장 캐릭터 `CharacterArt` + 이 명세의 얼굴 8종).

## 1. 고를 수 있는 것
### 1.1 종류 3가지 (`avatar_json.kind`)
| kind | 내용 | id |
|---|---|---|
| `follow` | **내 캐릭터 따라가기** — 지금 내 성장 캐릭터·단계를 그대로(진화하면 아바타도 자란다). 성향 조사 전이면 알 | 없음 |
| `char` | 성장 캐릭터 4종 × 5단계 = 20개 (거북이·다람쥐·고양이·수달, 아기~전설) — 내 종이 아니어도 고를 수 있다 | `otter-3` 꼴 |
| `face` | 아바타 전용 얼굴 8종: 토끼 · 곰 · 병아리 · 개구리 · 판다 · 여우 · 선인장 · 버섯 | `rabbit` 등 |

- 얼굴 화풍 = 성장 캐릭터와 같음: 둥근 머리 · 큰 점 눈(흰 반짝임) · 분홍 볼터치 · 짧은 입, 진한 선 `#3A3A3A`. 24px에서도 읽히게 눈 지름 ≥ 머리의 1/6, 가는 선·작은 장식 없음.
- 도형은 데이터 하나(`packages/schema/src/avatar.ts` `AVATAR_FACES`)로 두고 데스크톱(SVG)·휴대폰(react-native-svg)이 같은 데이터를 그린다.

### 1.2 배경색 8가지 (`avatar_json.color`)

### 1.3 기본값 [제안 — 사용자 확인]
- **아무것도 안 고른 계정 = 지금처럼 글자 아바타**(이메일 첫 글자, 강조색 원). 이유: 이미 쓰는 사람은 레일 모양이 갑자기 바뀌지 않고, 틱틱도 사진을 올리기 전엔 기본 그림이다.
- 고르기 창을 처음 열면 **"내 캐릭터 따라가기"가 맨 앞 추천 칸**(이름 아래 "추천")이고 미리 보기에 그 모양이 보인다 → 한 번 누르면 성장 루프가 앱 전체에 보인다.
- 대안(사용자가 고르면 바꿈): 새 계정 기본을 `follow`로. 코드에서는 `DEFAULT_AVATAR`(null = 글자) 한 줄.
- 모르는 id·깨진 JSON·모르는 색 → 글자 아바타(색만 모르면 green).

## 3. 데스크톱
### 3.1 레일 아바타 메뉴 (01 §3.1 갱신)
- 아바타 클릭 → 아바타 아래 오른쪽으로 `Popover.menu`(폭 200). 항목(틱틱 순서 + sprout 한 줄):
  1. **프로필 이미지 바꾸기** (아이콘 smile) → 메뉴가 닫히고 같은 자리에 고르기 팝오버
  2. 구분선
  3. **설정** `⌘,` → 설정 창(지금 동작)
  4. **통계** → 성장 탭(틱틱 통계 자리 = sprout 성장)
  5. **로그아웃** → 확인 대화상자(설정 › 계정과 같은 문구)
- 툴팁(title) = 이메일. 키보드: Enter/Space로 열기, Esc로 닫기.
- 상태: 기본 / 호버(밝기 +4%·포커스 링) / 메뉴 열림(강조색 2px 링).

### 3.2 고르기 팝오버
```
┌ 프로필 이미지 ─────────────── ✕ ┐
│   ( 큰 미리 보기 64 )  이름 / "내 캐릭터 따라가기" │
│ 배경색  ● ● ● ● ● ● ● ●            │
│ ── 추천 ──                         │
│ [내 캐릭터 따라가기]                 │
│ ── 성장 캐릭터 ──                   │
│ 거북이  ○ ○ ○ ○ ○ (아기~전설)       │
│ 다람쥐  ○ ○ ○ ○ ○                  │
│ 고양이 …  수달 …                    │
│ ── 얼굴 ──                         │
│ ○ ○ ○ ○ / ○ ○ ○ ○ (4칸 × 2줄)        │
│ 글자로 되돌리기                      │
└────────────────────────────────┘
```
- 폭 320, 최대 높이 = 창 높이 − 16(넘치면 안쪽 스크롤). 레일 아바타 기준이면 오른쪽 아래, 설정 창이면 아바타 아래 가운데.
- 칸 = 40px 원(배경색 + 그림), 고른 칸 = 강조색 2px 링 + 체크 없음. 호버 = 배경 hover 면. 단계 칸 툴팁 = "수달 · 친구" 꼴.
- **저장은 즉시**: 칸이나 색을 누르는 순간 `user_prefs.avatar_json`에 쓰고 레일·설정이 바로 바뀐다(저장 버튼 없음). Esc·바깥 클릭·✕ = 닫기(이미 저장됨).
- 색 칩: 22px 원, 고른 색 = 링. 글자 아바타 상태에서 색을 누르면 `follow` + 그 색으로.
- "글자로 되돌리기" = `avatar_json` 비우기(null). 이미 글자면 흐리게(비활성).
- 키보드: Tab으로 칸 이동, Enter/Space 고르기, Esc 닫기.
- 빈·오류 상태: DB 쓰기 실패 → 토스트 "저장하지 못했어요"(앱 공통 쓰기 실패 처리 그대로). 로딩 없음(로컬 DB).

### 3.3 설정 › 계정
- 맨 위 72px 아바타를 버튼으로(호버 시 아래에 작은 연필 배지), 이메일 위 줄에 링크 버튼 **"프로필 이미지 바꾸기"**. 둘 다 §3.2 팝오버.

## 4. 휴대폰
- 아바타 자리(§2)에서 **아래 시트**(`src/ui/BottomSheet` — 화면 안 시트, 수집 상세·AI 비서와 같은 방식, 경로 formSheet 아님). 높이 중간 0.72 → 끌어 올리면 전체.
- 시트 머리: 왼쪽 둥근 ✕ · 가운데 "프로필 이미지"(20 §3.2 시트 닫기 규칙, 2026-10-05 — 원래 오른쪽 "완료"). 내용 순서는 데스크톱과 같음: 미리 보기 72 → 색 8개(30px) → 추천 → 캐릭터 4줄 × 5 → 얼굴 2줄 × 4 → 글자로 되돌리기.
- 칸 = 52px 원, 누르면 바로 저장 + 가벼운 햅틱 없음(v1). 아래로 끌기·바깥 누르기·✕ = 닫기.
- 고른 칸 = 강조색 2.5px 링. 접근성 레이블 = "수달 친구 단계", "토끼", "배경 노랑" + 선택됨 상태.

## 5. 데이터
- 동기화 테이블 `user_prefs`에 칸 **`avatar_json text`** 추가(계정 단위 — 데스크톱·휴대폰 같은 값).
  - 모양: `{"kind":"follow"|"char"|"face","id"?:string,"color":"green"}` · `null` = 글자.
  - 읽기·검사·그리기 결정은 공용 `@sprout/schema/avatar`(`parseAvatar`·`resolveAvatar`·`AVATAR_COLORS`·`AVATAR_FACES`·`CHAR_AVATARS`).
  - `follow`는 `characters.species` + `xp_events`로 계산한 단계(`progressFromEvents`)를 쓴다. 저장값에는 종·단계를 넣지 않는다(진화하면 따라가야 하니까).
- 쓰기: 다른 칸 보존, 행 없으면 insert(id = uuid, notify와 같은 규칙).
- 서버: `npm run server:schema`로 `server/db/init/02-schema.sql` 다시 생성 + 이미 데이터 있는 서버용 `server/db/migrations/20261010-avatar.sql`(`ALTER TABLE user_prefs ADD COLUMN IF NOT EXISTS avatar_json text`). 업로드 허용 칸은 `TABLES`에서 자동(서버 재시작 필요). PowerSync 규칙은 `SELECT *`라 그대로.
- **배포 순서: 마이그레이션 → API 재시작 → 앱**(앱이 먼저면 모르는 칸 = 409로 업로드가 계속 재시도).
