## 2. 내비게이션 [틱틱 구조 / v1 줄임]
```
(로그아웃) 로그인 ──▶ 첫 동기화 ──▶ (성향 조사 안 했으면 제안 카드, 건너뛸 수 있음)
                                   │
        ┌───────────── 아래 탭 바 ────────────┐
        │ 오늘(✓)       성장(새싹)       설정(⚙) │
        └──────────────────────────────────────┘
  오늘 ── + 버튼 ──▶ 빠른 입력(키보드 위 시트) ──▶ 날짜 시트(03 축소)
       └─ 행 누름 ──▶ 간단 상세(아래에서 올라오는 시트)
  성장 ── 레벨업·진화 화면(가운데 카드) · 성향 조사(전체 화면)
  설정 ── 계정 · 알림 권한 · 테마 · 완료음 · 앱 정보
  (다른 앱) 공유 ──▶ sprout 공유 카드 ──▶ 수집함에 저장 → 원래 앱으로 돌아감
  (알림) 누름 ──▶ 오늘 탭 + 그 할 일 간단 상세
```
- 탭 바 [틱틱 모양]: 높이 49 + 아래 안전 영역, 아이콘 22 + 글자 10. 선택 = 강조색 `color.accent`, 나머지 `color.text.tertiary`. 탭을 다시 누르면 맨 위로 스크롤 [틱틱 관례·임시].
- 딥 링크: `sprout://today`, `sprout://task/<id>`, `sprout://growth` [sprout] — 알림·공유 후 열기에 쓴다.
- Android 뒤로 버튼: 시트 닫기 → 탭 첫 화면 → 앱 나가기.

## 4. 기술 계획
### 4.1 React Native: **Expo 추천** (D2)
| | Expo (개발용 빌드 + prebuild) | 맨 React Native |
|---|---|---|
| 네이티브 모듈 (op-sqlite, 알림, 보안 저장소, 공유 받기) | 설정 플러그인으로 붙음. **Expo Go는 못 씀**(PowerSync 네이티브 SQLite) → 개발용 빌드를 쓴다 | 직접 Xcode·Gradle 설정 |
| iOS 공유 확장(별도 타깃) | `expo-share-intent`(커뮤니티) 또는 Expo 공식 `expo-sharing`의 받기 기능 — 구현 때 둘 중 확인 | Xcode에서 직접 타깃 추가 |
| 빌드 | 내 Mac에서 `expo run:ios/android`(무료) 또는 EAS 클라우드 빌드(무료 한도) | 내 Mac에서 직접 |
| 업데이트 | JS만 바뀐 수정은 앱스토어 심사 없이 배포(EAS Update) 가능 [다음] | 직접 구성 |
| 결론 | **1인 개발에 맞다.** 네이티브 폴더는 생성물로 두고(커밋 안 함) 설정만 관리 | 유연하지만 유지비가 크다 |
- 위치: `apps/mobile`(같은 저장소, npm 워크스페이스). Node 22(`scripts/node22.sh`) — CLAUDE.md 빌드 주의와 같다.
- Metro가 `packages/schema`의 `.ts` 원본을 그대로 읽도록 워크스페이스 설정(감시 폴더·확장자 import 허용) — 구현 첫날 확인할 위험 항목.

### 4.2 로컬 DB·동기화: PowerSync React Native SDK
- `@powersync/react-native` + **`@powersync/op-sqlite`**(새 아키텍처 지원, PowerSync 권장). 스키마는 `@sprout/schema`의 `TABLES`에서 만든다 — 데스크톱과 **같은 원본**.
- 동기화 규칙은 그대로(`owner_id = auth.user_id()`, 23개 테이블 전부 내려받음). 모바일이 안 쓰는 일기·위키도 내려오지만 자기 데이터이고 크기가 작다 → **서버 변경 없음**. 모바일 전용 묶음(일부 테이블만)은 [다음](서버 규칙 변경이라 승인 필요).
- 업로드는 데스크톱과 같은 `POST /sync/upload`(PUT = 있으면 덮어쓰기라 같은 id를 두 번 보내도 안전).
- **공용 로직 옮기기(코드 구조 변경, 구현 때)**: 지금 할 일 완료 → XP 지급(`grantTaskXp`), 목표 진행, 수집 항목 만들기(`itemRow`)가 데스크톱 화면 코드(`apps/desktop/src/renderer/src/data/*`)에 있다. 모바일이 같은 규칙을 쓰도록 DB 쓰기 문장을 만드는 순수 함수를 `packages/`(예: `@sprout/schema/mutations`)로 옮긴다. 이미 공용인 것: `recognition`(자연어), `time`(날짜·알림 시각·반복), `growth`(XP·레벨·조사).

### 4.3 로그인: 같은 JWT API
- `POST /auth/login`·`/signup`·`/refresh`·`/logout`, `GET /auth/me` 그대로. 토큰은 `expo-secure-store`(iOS 키체인·Android Keystore).
- 리프레시 토큰은 쓸 때마다 바뀌므로 **새로 고침은 본 앱만** 한다. 공유 확장은 키체인 공유 그룹에서 액세스 토큰만 읽는다(24 §데이터).
- 화면은 [08](08-login.md) 카드를 휴대폰 폭에 맞춰(좌우 여백 24, 입력·버튼 높이 44, 폭 꽉 참) 같은 문구·같은 오류 6종. 소셜 로그인·비밀번호 찾기는 08과 같이 [다음]. 첫 로그인 데이터 규칙도 08 §8과 같다(휴대폰에는 로그인 전 데이터가 없으니 항상 내려받기).

### 4.4 알림: **로컬 알림 추천** (D3)
| | 로컬 예약 (추천) | 서버 푸시 |
|---|---|---|
| 동작 | 앱이 로컬 DB의 `tasks`·`reminders`를 보고 OS에 예약(`expo-notifications`) | 서버가 시각마다 APNs/FCM으로 보냄 |
| 오프라인 | 울린다 | 안 울린다 |
| 서버 변경 | **없음** | 기기 토큰 테이블 + 시각 스케줄러 + Apple 푸시 키 → **승인 필요한 인프라 변경** |
| 약점 | 다른 기기에서 바꾼 알림은 휴대폰 앱이 깨어나 동기화해야 다시 예약된다 | 구현·운영 부담, Mac mini가 꺼지면 안 울림 |
- 규칙(03 §7과 같게): 앞으로 **48시간** 안 알림을 예약, 최대 **50개**(iOS 대기 알림 64개 한도 아래). 바뀔 때마다 다시 계산: 앱 시작·앞으로 올 때·동기화로 `tasks`/`reminders`가 바뀔 때·백그라운드 새로 고침(`expo-background-task`, OS가 허락할 때) [임시].
- 알림 시각 계산은 공용 `reminderFireTime()`(packages/schema/time). 종일 할 일 알림 기본 09:00(03 §3.2).
- 알림 모양 [틱틱 research 09·20]: 제목 = 할 일 이름, 본문 = `오늘 오후 3:00 · 기본함`. 버튼 **완료 · 다시 알림**(iOS는 알림을 펼쳐야 보임, Android는 바로). 다시 알림 = 15분 [임시](선택지 5·15·30분·1시간·내일은 길게 눌러 고르기는 [다음]).
- 알림에서 **완료**: 앱을 열지 않고 로컬 DB에 완료 + XP(공용 규칙) 기록, 다음 연결 때 업로드. 반복 할 일은 03 §8 규칙으로 다음 회차.
- 울린 기록·다시 알림 시각은 기기에만(`local_reminder_state`, 03 §9).
- 권한: 첫 할 일에 알림이 생기는 순간 OS 권한을 묻는다(앱 첫 실행에 바로 묻지 않음) [임시]. 거부 상태면 설정 탭에 `알림이 꺼져 있어요 · 설정 열기`. Android 13+ 알림 권한, Android 12+ 정확한 알람 권한(`SCHEDULE_EXACT_ALARM`) 확인.
- 데스크톱과 휴대폰이 둘 다 울린다(틱틱도 기기마다 울림). 한쪽에서 완료하면 동기화 뒤 다른 쪽 예약은 취소된다.

### 4.5 오프라인
- 모든 화면이 로컬 SQLite로 동작(KR2): 추가·완료·스와이프·목표 체크·성장 계산·알림 예약. 연결되면 자동 업로드.
- 공유 확장은 오프라인이면 기기 안 대기열에 넣고, 본 앱이 열릴 때 넣는다(24).
- 동기화 상태 표시: 설정 탭 계정 줄 + 오늘 머리 오른쪽 작은 점(08 §6과 같은 뜻: 회전 = 동기화 중, 빨간 점 = 오프라인·오류) [임시].
- AI 기능은 모바일 v1에 없다 → Mac mini가 꺼져도 영향 없음. 수집 항목 분류는 데스크톱(또는 [다음] 서버 AI 프록시)이 한다.
