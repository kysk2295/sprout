## 0. 결정 (확정 2026-10-05 — 아래 "제안"이 그대로 결정)
> **2026-10-05 개정(D11, 사용자 결정 "데스크톱 기능 전부 모바일에도")**: 아래 D4(탭 3개)·D5·M1(두 단계)·M3 일부·§1 "v1 밖" 표의 할 일 기능은 **D11이 대신한다**. 모바일 v1 = 데스크톱과 같은 기능(할 일·리스트·폴더·태그·필터·스마트 목록 전부, 캘린더, 검색, 수집함, 성장, 일기, 작업 지도, AI 비서, 설정·계정). 탭 바 = 시안 mobile-sprout A0/A1의 **[다음] 5칸**(할일 · 캘린더 · 수집함 · 성장 · 더보기). 구글·Apple 캘린더 일정만은 컴퓨터의 기기 데이터라 휴대폰에 없다(§7).

### 3.1 아래 여백 규칙 (탭 바·+ 버튼·홈 표시줄 — 2026-10-05 레이아웃 점검)
숫자는 한 곳(`src/ui/tabBarSpace.ts`의 `useTabBarSpace()`)에서만 계산한다. 화면마다 `140`, `insets.bottom + 120` 같은 숫자를 두지 않는다.
- **탭 알약**: bottom = `max(아래 안전 영역 − 12, 12)`(홈 표시줄 기기 22, 홈 버튼 기기 12), 높이 58. 화면 바닥 ~ 알약 윗변 = `clear`.
- **탭 바가 보이는 화면((tabs) 안: 할 일·캘린더·수집함·위키 주제·성장·더보기·설정·외관·계정)의 스크롤 목록**: 맨 아래까지 내리면 마지막 줄이 알약 위에서 끝나야 한다 → `paddingBottom = pad`(알약 위 24). **+ 버튼이 있는 화면(할 일·캘린더)**은 `padFab`(+ 버튼 위 16).
- **+ 버튼**: 알약 위 14, 오른쪽 18(`src/ui/Fab.tsx` 하나를 같이 쓴다). **그 화면 위에 다른 화면·시트가 올라오면(빠른 입력·상세·검색 등) 숨긴다** — 시트 위로 + 가 비쳐 보이지 않게 [틱틱].
- **토스트**: + 버튼이 떠 있으면 그 위(+ 버튼 위 12), 없으면 알약 위 14(21 §2 "탭 바·+ 버튼 위").
- **탭 바 밖 화면**(루트 스택: 일기·작업 지도·검색·리포트·AI 비서 전체 화면 등)은 탭 바가 없으므로 `아래 안전 영역 + 여유`만.
- **아래 시트·입력 카드**: 키보드가 있으면 키보드 바로 위에 붙고, 키보드가 없으면(하드웨어 키보드·키보드 내림) 바닥 줄(도구 막대·입력창·버튼)을 아래 안전 영역만큼 띄워 홈 표시줄·둥근 화면 모서리에 닿지 않게 한다(빠른 입력 22, `BottomSheet`의 footer, AI 비서 반 시트 27).
- 확인 기기: 홈 표시줄 기기(iPhone 17 Pro)와 홈 버튼 기기(iPhone SE 3) 둘 다. 다크 테마도 한 번.

### 3.2 시트 닫기 규칙 (2026-10-05 — 사용자 요청 "모바일에도 닫기 버튼 넣어줘", 데스크톱 오른쪽 패널 ✕와 짝)
**모든 시트는 눈에 보이는 닫기가 있다.** 아래로 끌기(잡는 막대)·바깥(어두운 막) 누르기·Android 뒤로 버튼도 그대로 닫는다 — ✕는 그 위에 하나 더 두는 것.

- **적용**:
  | 시트 | 닫기 |

### 4.2 로컬 DB·동기화: PowerSync React Native SDK
- `@powersync/react-native` + **`@powersync/op-sqlite`**(새 아키텍처 지원, PowerSync 권장). 스키마는 `@sprout/schema`의 `TABLES`에서 만든다 — 데스크톱과 **같은 원본**.

- **공용 로직 옮기기(코드 구조 변경, 구현 때)**: 지금 할 일 완료 → XP 지급(`grantTaskXp`), 목표 진행, 수집 항목 만들기(`itemRow`)가 데스크톱 화면 코드(`apps/desktop/src/renderer/src/data/*`)에 있다. 모바일이 같은 규칙을 쓰도록 DB 쓰기 문장을 만드는 순수 함수를 `packages/`(예: `@sprout/schema/mutations`)로 옮긴다. 이미 공용인 것: `recognition`(자연어), `time`(날짜·알림 시각·반복), `growth`(XP·레벨·조사).

  - 흐름: 누르면 그 버튼 안 스피너 + 잠금 → 애플 시스템 창(이메일 범위만 — 이름은 받지 않음) → `POST /auth/apple/native {id_token, nonce, authorization_code}` → 이메일 로그인과 같은 처리. nonce = 앱이 만든 무작위 값, 애플에는 SHA-256(hex)만(`src/data/apple.ts`).
  - 오류: 창 닫음 = 표시 없음 · 권한 없는 빌드/서버 503 = "Apple 로그인 설정이 아직 없어요" · 애플이 이메일을 안 줌(첫 로그인인데 email 없음, 400 `email required`) = "Apple이 이메일을 보내지 않았어요. 설정 › Apple ID › Apple로 로그인에서 sprout를 지운 뒤 다시 시도하세요." · 나머지는 Google과 같은 표.
  - 설정 › 계정 › 로그인 방법: Apple 칸 = 연결 안 됨이면 `연결`(같은 시스템 창 → `POST /auth/link/apple/native`), 연결됨이면 `연결 해제`(서버가 애플 토큰도 폐기). 애플 로그인 없는 빌드는 "준비 중".
  - 계정 삭제: Apple로만 가입한 계정은 `Apple로 방금 다시 로그인`(같은 계정이면 토큰만 바꿈) → 10분 안 삭제. 애플 로그인 없는 빌드(Android 포함)만 "iPhone 앱이나 컴퓨터 앱(설정 › 계정)에서 삭제할 수 있어요" 안내. 삭제 때 서버가 애플 토큰을 폐기한다(08 §7.1).
- **Google 흐름**: 누르면 → 그 버튼 안 스피너 + 입력·다른 버튼 잠금 → 기기 구글 계정 고르기(iOS: "‘sprout’이(가) 로그인을 위해 ‘google.com’을 사용하려고 합니다" 시스템 창 → 구글 시트, Android: 계정 선택 창) → 받은 ID 토큰을 `POST /auth/google {id_token}` → 이메일 로그인과 같은 처리(08 §8 첫 로그인 규칙 → 저장 → 동기화 시작).
  - 매번 기기 구글 세션을 먼저 지우고 연다 → **항상 계정 고르기가 뜬다**(데스크톱 `prompt=select_account`와 같음)·매번 새 토큰.
  - 라이브러리: `@react-native-google-signin/google-signin`(무료 "Original" API, Expo 설정 플러그인). Android OAuth 클라이언트는 사용자 지정 스킴 리디렉트를 막아서 `expo-auth-session`은 쓰지 않는다.
  - 클라이언트 id는 코드에 넣지 않고 `apps/mobile/.env.local`(git 제외)의 `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` · `EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID`. iOS URL 스킴(iOS 클라이언트 id를 뒤집은 것)은 `app.config.ts`가 같은 값으로 만든다. 두 플랫폼 모두 `webClientId`를 넘겨 **토큰 aud = 웹 클라이언트 id**(서버는 웹 + 데스크톱 id만 알면 됨).
  - **서버 nonce [sprout 보안 설계]**: 무료 API는 nonce를 넣을 수 없다 → 모바일은 nonce 없이 보낸다. 서버는 nonce가 없을 때만 ① 토큰의 `azp`(iOS·Android 클라이언트) ≠ `aud`(웹 클라이언트) — 네이티브 앱이 우리 서버용으로 받은 토큰, ② 발급 10분 안, ③ **한 번만**(jti 또는 토큰 해시를 만료까지 기억)을 확인한다. 데스크톱 토큰은 `azp = aud`라 nonce를 빼고 보내도 통과하지 못한다(social.ts, 시험 있음).
- **상태·오류** (오류는 주 버튼 아래 오류 줄과 같은 자리·같은 빨간 글자)

  |---|---|
  | 진행 중 | 누른 버튼 안 스피너, 나머지 잠금 |

  | Android Google Play 서비스 없음·낡음 | "Google Play 서비스가 필요해요. 업데이트한 뒤 다시 시도하세요" |

- 계정 규칙(식별자 → 확인된 같은 이메일 계정에 연결 → 새 계정)·`created`는 08 §3.1 그대로. 새 계정이면 성향 조사 권유(§2 흐름)도 이메일 가입과 같다.
- **설정 › 계정 › 로그인 방법** (08 §3.1.1 휴대폰판): 이메일 칸 아래 작은 제목 "로그인 방법" + 칸 묶음(`Cells`, 칸 높이 48).
  | 칸 | 오른쪽 |
  |---|---|
  | 이메일 | "✓ 비밀번호 있음" / "비밀번호 없음" (회색) |
  | Google | 연결 안 됨 → 강조색 글자 버튼 **[연결]** · 연결됨 → "연결됨 · ky\*\*\*@gmail.com" + 빨간 **[연결 해제]**(로그인 방법이 이것 하나면 흐림 — 서버도 409) |
  | Apple | iOS 애플 로그인 빌드 = [연결](시스템 창 → `POST /auth/link/apple/native`). 그 밖은 "준비 중"(버튼 없음). 이미 연결돼 있으면 "연결됨 · 가린 이메일" + [연결 해제](서버가 애플 토큰 폐기) — v1.4 초안 |
  - [연결]: 위 Google 흐름과 같은 기기 로그인 → **로그인하지 않고** 지금 세션(Bearer)으로 `POST /auth/link/google {id_token}`. 성공 토스트 "구글 계정을 연결했어요 — 다음부터 'Google로 계속하기'로 들어올 수 있어요"(3.5초). 409는 서버 문구 그대로(이미 다른 sprout 계정 · 이미 다른 구글 계정).
  - [연결 해제]: 확인 창 "Google 연결을 해제할까요?" "다음부터 이 구글 계정으로는 이 계정에 들어올 수 없어요." [취소] [연결 해제(빨강)] → `DELETE /auth/link/google` → 토스트 "Google 연결을 해제했어요".
  - 불러오는 중 = 칸 오른쪽 작은 스피너, 실패 = 칸 묶음 아래 빨간 한 줄 + [다시 시도].
- **완료 기준**
  - [x] 로그인·등록 둘 다 구분선 아래 iOS "Apple로 계속하기(준비 중, 흐림)" · "Google로 계속하기", 폭·높이가 입력칸과 같다(2026-10-05 iOS 시뮬레이터).
  - [x] 구글 id가 없는 빌드에서 Google → "구글 로그인 설정이 아직 없어요", 앱이 죽지 않는다. Apple → 준비 중 안내.
  - [ ] (id 넣은 뒤) iOS·Android 실기기/시뮬레이터에서 계정 고르기 → 로그인 → 동기화. 같은 이메일의 기존 계정이면 그 데이터가 보인다. 취소하면 표시 없음.
  - [ ] 설정 › 계정 › 로그인 방법: 비밀번호 계정에 Google [연결] → 연결됨 + 토스트, 로그아웃 → Google로 계속하기 → 같은 계정. [연결 해제].
  - [ ] 구글로만 가입한 계정 삭제: "Google로 방금 다시 로그인" → 같은 계정이면 데이터 그대로 + 삭제, 다른 구글 계정이면 실패 문구.

### 4.4 알림: **로컬 알림 추천** (D3)
> 2026-10-05: 서버 푸시(FCM, Android 먼저) → [32 푸시 알림](32-push-notifications.md) (확정 v1.0, 서버·휴대폰 구현 — 휴대폰 쪽 메모·0단계 실험 결과는 [32 §17](32-push-notifications.md)). 로컬 예약은 그대로 둔다(32 §4.3). 설정 › 소리와 알림은 이제 하위 화면(32 §7).
| | 로컬 예약 (추천) | 서버 푸시 |
|---|---|---|
| 동작 | 앱이 로컬 DB의 `tasks`·`reminders`를 보고 OS에 예약(`expo-notifications`) | 서버가 시각마다 APNs/FCM으로 보냄 |
| 오프라인 | 울린다 | 안 울린다 |
| 서버 변경 | **없음** | 기기 토큰 테이블 + 시각 스케줄러 + Apple 푸시 키 → **승인 필요한 인프라 변경** |
| 약점 | 다른 기기에서 바꾼 알림은 휴대폰 앱이 깨어나 동기화해야 다시 예약된다 | 구현·운영 부담, Mac mini가 꺼지면 안 울림 |
- 규칙(03 §7과 같게): 앞으로 **48시간** 안 알림을 예약, 최대 **50개**(iOS 대기 알림 64개 한도 아래). 바뀔 때마다 다시 계산: 앱 시작·앞으로 올 때·동기화로 `tasks`/`reminders`가 바뀔 때·백그라운드 새로 고침(`expo-background-task`, OS가 허락할 때) [임시].
- 알림 시각 계산은 공용 `reminderFireTime()`(packages/schema/time). 종일 할 일 알림 기본 09:00(03 §3.2).
- 알림 모양 [틱틱 research 09·20]: 제목 = 할 일 이름, 본문 = `오늘 오후 3:00 · 기본함`. 버튼 **완료 · 다시 알림**(iOS는 알림을 펼쳐야 보임, Android는 바로). 다시 알림 = 설정 › 소리와 알림 › 다시 알림 시간(기본 15분 · 15분·30분·1시간·3시간, 32 §17.8 — 2026-10-05 틱틱과 같게).
- 알림에서 **완료**: 앱을 열지 않고 로컬 DB에 완료 + XP(공용 규칙) 기록, 다음 연결 때 업로드. 반복 할 일은 03 §8 규칙으로 다음 회차.
- 울린 기록·다시 알림 시각은 기기에만(`local_reminder_state`, 03 §9).
- 권한: 첫 할 일에 알림이 생기는 순간 OS 권한을 묻는다(앱 첫 실행에 바로 묻지 않음) [임시]. 거부 상태면 설정 탭에 `알림이 꺼져 있어요 · 설정 열기`. Android 13+ 알림 권한, Android 12+ 정확한 알람 권한(`SCHEDULE_EXACT_ALARM`) 확인.
- 데스크톱과 휴대폰이 둘 다 울린다(틱틱도 기기마다 울림). 한쪽에서 완료하면 동기화 뒤 다른 쪽 예약은 취소된다.

### 4.5 오프라인
- 모든 화면이 로컬 SQLite로 동작(KR2): 추가·완료·스와이프·목표 체크·성장 계산·알림 예약. 연결되면 자동 업로드.
- 공유 확장은 오프라인이면 기기 안 대기열에 넣고, 본 앱이 열릴 때 넣는다(24).
- 동기화 상태 표시: 설정 탭 계정 줄 + 오늘 머리 오른쪽 작은 점(08 §6과 같은 뜻: 회전 = 동기화 중, 빨간 점 = 오프라인·오류) [임시].
- AI 기능은 모바일 v1에 없다 → Mac mini가 꺼져도 영향 없음. 수집 항목 분류는 데스크톱(또는 [다음] 서버 AI 프록시)이 한다.

- 머리: 왼쪽 둥근 **보기 전환**(목록 · 일 · 3일 · 월, 고른 것 ✓ — 주·연 보기는 [다음]) · 가운데 **달**(올해면 `10월`, 다른 해 `2027년 1월`, 누르면 오늘로) · 오른쪽 **오늘로** · **⋯**(완료한 할 일 보기/숨기기 · 날짜 없는 할 일). 기본 보기 = 월 [임시], 고른 보기는 기기 메모리.
- **주 시작 월요일**(2026-10-05 사용자 결정, 데스크톱과 같음). 요일 머리 `월 … 일`, 일요일 글자 빨강 · 토요일 파랑(§7.2).
- **월**: 그 달에 필요한 주만큼(5·6줄). 칸 = 날짜 숫자(오늘 강조색 원, 고른 날 회색 면, 다른 달 흐림) + 리스트 색 18% 옅은 띠에 제목(10, 잘림), 넘치면 `+n`(5줄이면 3줄, 6줄이면 2줄). 막대(종일·여러 날) 먼저 → 시각순. 칸을 누르면 아래에 **그날 목록**(묶음 카드 `오늘 · 10월 4일 일`, 행 = 할 일 탭과 같은 행 — 체크·누르면 상세·길게 누르면 같은 메뉴), 비면 `할 일이 없어요 · + 추가`. 칸을 길게 누르면 그날로 빠른 입력. 위아래로 밀면 달이 바뀐다.
  - **달 접기 [틱틱 목록 캘린더 — research 24 §10]**: 아래 그날 목록을 **위로 끌면 달 칸이 한 주 줄로 접히고**(고른 날이 든 주가 남음), 접힌 상태에서 목록이 맨 위일 때 **아래로 끌거나 한 주 줄을 아래로 끌면 다시 펼친다**. 손가락을 따라 높이가 줄고, 놓으면 두 자리(달 / 한 주) 중 가까운 쪽(빠르게 튕기면 그 방향)으로 220ms 감속 [임시]. 펼친 동안 목록은 스크롤하지 않고 끌기가 접기로 쓰이며, 접힌 뒤에 스크롤한다. 접힌 한 주 줄은 좌우로 밀면 앞뒤 주(고른 날 ±7일), 날짜를 누르면 그날. 보기를 바꾸거나 앱을 다시 열면 펼친 상태 [임시]. 모션 감소 설정이면 애니메이션 없이 바로 바뀐다. 작은 화면(iPhone SE, 6주 달)에서 목록이 1~2줄밖에 안 보이는 문제의 해결.
- **일·3일**: 일 보기는 위에 그 주 7일 줄(날짜 아래 점 = 할 일 있음, 좌우로 밀면 앞뒤 주), 3일은 날짜 머리(좌우로 밀면 3일씩). 그 아래 **종일 줄**(칸마다 3개 + `+n`), **시간 칸**(1시간 56, 왼쪽 `9 AM` 표기 — 06 §4.1 실측), 지금 선 빨강, 처음엔 지금 1시간 전으로 스크롤. 블록 = 리스트 색 22% 면 + 왼쪽 3 색 띠 + 작은 체크 + 제목(+높으면 `오후 3:00-4:00`), 겹치면 열을 나눔(06 §4.2), 끝 없는 시각 할 일은 30분 높이 [임시].
  - **빈 칸 누름** → 그 시각(30분 단위)으로 빠른 입력(22, 보기 `date:YYYY-MM-DDTHH:mm` — 날짜 칩은 안 보이지만 저장 날짜가 그 시각).
  - **블록을 길게 누른 채 끌기** → 15분 단위로 시각 이동, 3일 보기에서는 다른 날 칸으로도(길이 유지, 종일 → 시간 칸이면 그 시각 할 일) + 토스트 `옮겼어요 ⟲`. 길게 누르고 움직이지 않고 놓으면 길게 누름 메뉴(날짜 줄·깃발·고정·이동·태그·삭제). 반복의 미래 회차는 끌 수 없다. 길이 조절(아래 가장자리 끌기)은 [다음].
- **목록**: 고른 날부터 30일, 날짜별 묶음 카드(할 일 있는 날만) + 아래 `다음 30일`. 만료된 것은 할 일 탭의 오늘에서 본다.
- **날짜 없는 할 일**(⋯ → 06 §9 할일 정렬 패널의 휴대폰판): 페이지 시트, 미완료·날짜 없음·하위 아닌 할 일. 행 오른쪽 ＋ = 지금 고른 날(종일)로 일정 잡기 + 토스트 ⟲, 행 누르면 상세.
- 데이터: `tasks`(+`lists` 색, 보관 리스트 제외, 삭제 제외), 쓰기는 `due_at`·`start_at`·`is_all_day`. 반복 미래 회차는 데스크톱 기본(끔)과 같게 그리지 않는다.
- **구글·Apple 캘린더 일정은 휴대폰에 없다**: 16의 구독 일정은 컴퓨터가 OS·구글에서 읽어 기기에만 저장하는 데이터라 동기화되지 않는다. 휴대폰 캘린더는 sprout 할 일과 **sprout 일정(§7.1, 동기화 `events`)**을 그린다(시안 G-3의 "Google · 개인" 행은 컴퓨터 전용).
- **모양(06 §14.2, 2026-10-05)**: 어디에도 취소선 없음. 완료 = 옅게(채움 8%·글자 3단계) + 체크된 칸(리스트 색 채움 + 흰 ✓), 지난 미완료 = 옅은 채움 + 빈 칸 + 글자 한 단계 진하게(2단계). 색 = 리스트 색, 없으면 테마 강조색. 블록 왼쪽 작은 칸은 할 일 = 체크박스(누르면 완료), 일정 = 캘린더 아이콘.
- 완료 기준: 월요일 시작 칸, 칸 띠·`+n`, 날짜 누름 → 아래 목록, 목록 위로 끌기 → 고른 주만 남게 접힘·아래로 끌기 → 펼침(SE 6주 달에서 목록이 화면 대부분), 빈 시간 누름 → 그 시각으로 빠른 입력, 블록 끌기 → 시각·날짜 이동 + ⟲, 날짜 없는 할 일 일정 잡기, 라이트·다크.

### 7.1 sprout 일정 — 06 §14.4의 휴대폰판 (2026-10-05)
- 근거: [06 §14.3·§14.4](06-calendar.md)(데스크톱 확정·E2E 완료), 틱틱 모바일 일정 표시는 데스크톱과 같은 규칙(research 17 §13 — 체크박스 자리 캘린더 아이콘). 일정 **만들기·고치기는 틱틱과 다르다**(틱틱은 연결 캘린더에만 만든다 — 06 §14.4 사용자 결정, 휴대폰도 같은 결정을 따른다).
- 데이터: 동기화 테이블 `events`(06 §14.4.1) 그대로. 회차·기간·할 일 ⇄ 일정 계산은 공용 `@sprout/schema/events`. "내 일정" 색 = `view_settings`(`calendar`) `options_json.myColor`, 없으면 `#E9A23B`. 일정에는 완료·우선순위·리스트·태그·XP가 없다.

| 곳 | 규칙 |
|---|---|

| **캘린더 일·3일** | 종일 줄 칩·시간 칸 블록에 섞여 보인다. 블록 왼쪽 작은 칸 = **캘린더 아이콘**(체크박스와 같은 자리·같은 크기 11, 색 = 일정 색 70% + 글자색 섞음, 06 §14.3). 블록 끌기·길게 눌러 메뉴는 할 일과 같다(아래 끌기). 반복 회차는 늘 계산해서 그리고(06 §14.4.3) 회차는 끌 수 없다 |

**일정 시트** (`/event/<id>`, 할 일 상세와 같은 formSheet 0.6 / 1) [06 §14.4.4 팝오버의 휴대폰판]
- 위 줄: 왼쪽 `● 내 일정`(일정 색 점, 누를 것 없음) · 오른쪽 둥근 ⋯(할 일로 바꾸기 · 복제 · 삭제).
- 🕐 날짜 줄: `10월 12일 (월) 오후 2:00-3:00` / `10월 12일 (월) · 종일` / 여러 날 `10월 12일 - 10월 14일`, 반복이면 ⟲, 알림 수면 🔔. 누르면 **같은 날짜 시트(03·22 §3.3)**를 시트 안에서 연다 — 날짜/기간 탭·종일·시간·알림·반복. ✓ = 저장(`eventSpan` — 시각 하나면 1시간), `날짜 지우기`는 일정에서는 할 수 없다(일정은 날짜가 꼭 있다 — 누르면 시트만 닫고 토스트 `일정은 날짜를 지울 수 없어요`) [sprout]. 날짜 시트는 할 일과 같은 경로 `/date?event=<id>`(85% 시트).
- 제목 입력(20/600, placeholder `일정 제목`) · 📍 장소 한 줄(placeholder `장소`) · 📄 설명 여러 줄(placeholder `설명`). **저장 버튼 없음** — 칸을 벗어나거나 0.6초 쉬면 저장(02 §13·21 §5와 같음). 제목을 비우고 닫으면 원래 제목으로.
- 반복 일정은 v1에서 늘 전체를 고친다(회차를 눌러도 원래 일정) — 06 §14.4.4와 같음.
- 삭제 → 시트 닫힘 + 토스트 `일정을 삭제했어요 ⟲`(5초, `deleted_at`, 되돌리기로 살림).

**빠른 입력의 `할 일 · 일정`** — [22 §3.5](22-mobile-quick-add.md).

**할 일 ⇄ 일정 바꾸기** (06 §14.4.6과 같은 규칙·같은 공용 함수)
- 할 일 → 일정: **상세 ⋯ 시트의 칸 `일정으로 바꾸기`**와 **행 길게 누름 메뉴의 `일정으로 바꾸기`**(휴대폰의 우클릭 자리). 하위 할 일이 있으면 흐리게 + 토스트 `하위 할 일이 있어서 바꿀 수 없어요`. 토스트 `일정으로 바꿨어요 ⟲`(되돌리면 할 일이 돌아오고 일정은 지워짐). 상세에서 바꾸면 상세를 닫고 일정 시트를 연다.
- 일정 → 할 일: 일정 메뉴·일정 시트 ⋯ `할 일로 바꾸기` → 기본함에 같은 제목·설명(장소는 첫 줄 `📍 장소`)·날짜·반복·알림 → 토스트 `할 일로 바꿨어요 ⟲`.

**끌기** (06 §7.2 v1.7 중 휴대폰에 맞는 것만 — 틱틱 모바일 캘린더 끌기는 research에 캡처가 없어 위 §7의 [임시] 규칙 그대로) 
- 일정 블록도 할 일처럼 **길게 누른 채 끌어** 옮긴다(15분 단위, 3일은 다른 날로도, 길이 유지). 놓으면 토스트 `옮겼어요 ⟲`.
- 끄는 동안: 블록이 **15분 칸·날 열에 붙어** 움직이고(손가락을 그대로 따라가지 않음, 06 §7.2 "주·일 시간 칸"), **원래 자리는 옅게(0.4)** 남는다. 미리 보기는 같은 블록·같은 색·비침 0.9.
- 데스크톱 v1.7의 가장자리로 길이 바꾸기·종일 막대 끌기·Esc 취소·가장자리 자동 스크롤은 휴대폰에서 **[다음]**(손가락 조작 근거가 research에 없음 — 틱틱 모바일 캘린더 실측 뒤).

**알림** (06 §14.4.7의 휴대폰판 — 로컬 알림)
- 일정 `reminders`를 할 일 알림과 같은 계산(공용 `eventReminderTimes` — 앞으로 올 회차 하나 기준, 48시간 창)으로 OS에 예약. 할 일 알림과 합쳐 최대 50개(가까운 것부터).
- 제목 = 일정 제목, 본문 = `오늘 오후 3:00 · 📍 장소`(장소 없으면 `· 내 일정`). 버튼은 **다시 알림 하나**(설정의 다시 알림 시간, 32 §17.8) — 완료 없음(카테고리 `sprout-event`). 누르면 `sprout://event/<id>` → 일정 시트.
- 설정 › 할 일 알림 끔(`notify_json.reminders=false`)이면 일정 알림도 예약하지 않는다 [임시 — 따로 켜고 끄기는 다음].
- 알림 id는 `e:`로 시작해 서버 푸시 보고(32 §4.3 `r:`만)에 섞이지 않는다. **서버 푸시(32)에 일정 넣기는 [다음]**.

- 완료 기준: 새 계정 빠른 입력 `일정` → 캘린더 월·일·3일·목록·오늘 목록에 캘린더 아이콘·내 일정 색 · 눌러 시트에서 제목·시간·장소·설명·알림·반복 고침 · 반복 일정이 회차마다 · 블록 끌기 + ⟲ · 할 일 ⇄ 일정 + ⟲ · 삭제 + ⟲ · 1분 뒤 일정 알림(완료 버튼 없음) · 라이트·다크.
- **확인함 (2026-10-05, iOS 시뮬레이터 + Mac mini 서버, 새 계정 → 끝나고 계정 삭제)**: 새 계정 빠른 입력 할 일(기본함 자동) · `일정`(장소·자연어 시각·내 일정 색, 오늘 목록 맨 위 행) · 일정 시트에서 설명·매주 반복 → 월 칸 회차 · 3일 보기 블록 길게 눌러 끌기(15분·다른 날, ⟲) · 길게 누름 메뉴 삭제 ⟲ · 할 일로 바꾸기 · 할 일 길게 누름/상세 ⋯ `일정으로 바꾸기` · 블록 체크박스 자리 = 완료(상세 안 열림) · 완료/지난 미완료 모양 · 일정 알림 도착(본문 `오늘 오후 12:14 · 내 일정`) · Postgres에 `events` 행 동기화 · 라이트·다크. 시뮬레이터에서 알림 펼치기(버튼 보기)는 할 수 없어 `다시 알림만` 버튼은 코드(카테고리 `sprout-event`)로만 확인 — 실기기 확인 남음.

## 8. 검색 (D11 — 시안 H, 04 §검색)
- 들어오는 곳: **더보기 › 검색**, 할 일 탭 머리 **🔍**(⋯ 왼쪽). 틱틱의 "목록을 아래로 당겨 검색"은 당겨서 새로 고침과 겹쳐 쓰지 않는다 [sprout].
- 화면: 위 둥근 검색 칸(자동 포커스) + 둥근 ✕(닫기) · 종류 칩 `할 일 · 수집함 · 일기 · 리스트 · 태그 · 필터`(검색 중이면 개수, 고른 칩에 결과가 없고 다른 칩에 있으면 그쪽으로) · 비었을 때 `최근 검색 · 지우기`(칩, 기기에만 10개) + 새싹 그림 `무엇을 찾을까요?`.
- 규칙(04와 같음): 로컬 SQLite LIKE, `%`·`_`·`\`는 글자 그대로, 삭제한 것 제외. 할 일 = 제목·설명·체크 항목, 미완료 묶음 + `완료` 묶음(계획 취소 포함). 맞는 글자는 검색 노랑, 설명·체크 항목에서 맞으면 아래 줄에 앞뒤 글. 수집함 = 내용·링크 제목·주소. **일기 = 나만 보기(private) 제외**(15). 리스트는 보관 제외.
- 누르면: 할 일 → 상세 시트, 리스트·태그·필터 → 할 일 탭 그 보기, 수집함 → 수집함 탭, 일기 → `/diary?date=`(일기 작업 경로).
- 오프라인에서도 같다. 완료 기준: 특수 문자 검색, 나만 보기 일기 안 나옴, 결과에서 상세·보기 이동.

## 9. 더보기 · 설정 · 리스트 관리 (D11 — 시안 mobile-sprout A1, mobile I-1)
- **더보기 탭**: 큰 제목 `더보기` → 캐릭터 카드(그림·이름·`Lv n · 단계`·XP 막대, 누르면 성장 탭; 조사 전이면 새싹 화분) → `기능` 묶음: 일기(오른쪽 `오늘 아직 안 씀`/`오늘 썼어요`) · AI 비서 · 작업 지도 · 검색 → `앱` 묶음: 설정. 탭 바 고르기 칸은 [다음](D11).
- **설정**은 더보기 안 화면(머리 ‹ 뒤로, 탭 바는 더보기가 켜짐). 프로필 카드 → **계정**(이메일 · 로그인 방법(§4.3.1) · 로그아웃 · 맨 아래 작은 빨간 `계정 삭제`). 칸 추가: `날짜와 시간 — 주 시작 월요일`(고정 표시, 데스크톱과 같음) · `리스트 관리`.
- **계정 삭제**(08 §7.1, 데스크톱과 같은 문구): 누르면 같은 자리 카드 `계정을 삭제할까요?` + 되돌릴 수 없다는 글 → 비밀번호 + 확인 단어 `삭제` → `DELETE /auth/account`. 성공하면 이 기기 데이터를 지우고 로그인 화면 + `계정을 삭제했어요`. 오류: 비밀번호 틀림 · 시도 제한(서버 문구) · 만료 · 연결. 구글·애플로만 가입한 계정(비밀번호 없음)은 비밀번호 칸 대신 데스크톱과 같은 버튼 **`Google로 방금 다시 로그인`** → §4.3.1 기기 구글 로그인 → `POST /auth/google` → **같은 계정이면 토큰만 바꾼다**(로컬 데이터·동기화 그대로, 새 접근 토큰에 `auth_time`) → `다시 로그인했어요. 10분 안에 삭제하세요.` + 확인 단어 `삭제`로 버튼 활성. 다른 구글 계정을 고르면 그 세션을 서버에서 버리고 `로그인을 확인하지 못했어요. 다시 시도하세요. 삭제할 계정과 같은 계정으로 로그인하세요.`(08 §7.1). 서버가 10분이 지났다고 하면(403 reauth required) `보안을 위해 Google로 다시 로그인한 뒤 10분 안에 삭제해 주세요`로 되돌린다. **Apple로만 가입한 계정**은 iOS 애플 로그인 빌드에서 `Apple로 방금 다시 로그인` → 같은 흐름, 애플 로그인이 없는 빌드(Android 등)는 `Apple로만 가입한 계정은 iPhone 앱이나 컴퓨터 앱(설정 › 계정)에서 삭제할 수 있어요` 안내 (v1.4 초안, 2026-10-05 — §4.3.1).
- **리스트 관리**(서랍 아래 관리 아이콘 · 설정): 스마트 목록 표시(전체·오늘·내일·다음 7일·기본함·필터·태그·완료·계획 취소·휴지통 — 보이기 / 숨기기 / 비어 있지 않으면 표시, 기본함은 항상, `user_prefs.smart_list_visibility` 데스크톱과 같은 값) + 보관된 리스트(복원 · 삭제).

## 11. Android 확인 (2026-10-05, 에뮬레이터 Pixel 7 · Android 15 / API 35)
- **빌드**: `npx expo prebuild --platform android` → `npx expo run:android` 그대로 된다(Gradle 9.3.1, compileSdk 36, NDK 27.1.12297006, JDK 21). iOS 공유 확장 플러그인(`plugins/share-extension`)은 Android 프리빌드를 깨지 않는다. app.json의 `android.edgeToEdgeEnabled`는 Expo 57에서 없어진 설정이라 뺐다(Android 16부터 전체 화면 그리기가 기본).
- **확인함**: 새 계정 가입 → 오늘 → 빠른 입력(키보드 위 카드·도구 막대·✦ AI에게) → 체크(완료 토스트·되돌리기, 성장 XP +1) → 5칸 탭(할 일·캘린더·수집함·성장·더보기) → 설정 › 동기화 `방금 전` → 로그아웃·다시 로그인하면 서버에서 완료 기록이 돌아옴 → 계정 삭제.
- **iOS와 다른 점 (고친 것)**
  - 동기화: Android에서는 PowerSync 기본 연결(HTTP 스트리밍, `expo/fetch`)이 `연결 중`에서 멈춰 `오프라인`으로 남았다 → **Android만 WebSocket 연결**(`src/data/db.ts` `CONNECT_OPTIONS`). 같은 PowerSync 서비스·Funnel 주소에서 동작한다.
  - 아래 시트(`BottomSheet`): Android가 알려 주는 키보드 높이에 제스처 막대가 빠져 있어 입력창이 키보드에 반쯤 가렸다 → Android는 아래 안전 여백을 더한다.
  - 반 시트 안 입력창 자동 초점(`autoFocus`)이 Android Modal에서는 키보드를 못 띄웠다 → Android는 350ms 뒤 직접 초점.
- **iOS와 다른 점 (그대로 둠)**
  - 확인 창(로그아웃 등 `Alert`)은 Android 기본 모양(머티리얼 대화 상자, 버튼 글자색 = 시스템 강조색).
  - 뒤로 버튼: 키보드 닫기 → 시트 닫기 → 탭 첫 화면이면 앱 나가기(§2와 같음).
  - 머리 줄은 아직 iOS와 같은 둥근 유리 버튼(§2의 Android 한 줄 머리 "☰ 제목 ⋮"는 틱틱 Android 실측 뒤 [다음]).

## 12. 관계 위키 · 자동 태그 (D11 — [33 §11](33-relations-wiki.md))
- 모바일은 태그 = 위키 페이지를 **보여 주고 ✕로 떼기만** 한다. 자동 태그 파이프라인(사전 검사·AI·일괄·새 태그 만들기·요약·되돌리기)은 **데스크톱에서만** 돌고 결과가 동기화로 온다.
- 행 태그 알약 2개 + `+N` · `[[링크]]` 강조색 글자, 상세 ✦·✕, 리스트·태그 페이지 카드(태그 알약 = 리스트 안 거르기), 더보기 › 태그 목록(종류별), 빠른 입력 `#`·`[[` 제안. 개수·거르기는 accepted 태그만. 자세한 표·완료 기준은 33 §11.
