## 2. 레이아웃
```
메인 (목록)                                          │ 상세 패널 (312px)
┌──────────────────────────────────────────────┐ │ ┌─────────────────────────┐
│ ▯| Inbox                         💡 ⇅ ⋯     │ │ │ ☐ │ 📅 Oct 12, 273d left  ⚑ │ ← 머리 56px
│ ┌──────────────────────────────────────────┐ │ │ ├─────────────────────────┤
│ │ + Add task                              │ │ │ │ Move house           ≣  │ ← 제목
│ └──────────────────────────────────────────┘ │ │ │ [Important] (+)          │ ← 태그
│ ⌄ Overdue 4                       Postpone  │ │ │ Write something or type │ ← 본문 / 체크 항목
│ ☐ Team meeting   💼 Work ⟲ ⏰ Jan 9          │ │ │ / for commands          │
│ ☐ Toothbrush     🏠 Family     Jan 10        │ │ │ (하위 태스크 목록)        │
│ ⌄ Today 4                                    │ │ │                         │
│ ☐ Morning stretch          ⟲ ⏰ 7:30 AM      │ │ ├─────────────────────────┤
│ ...                                          │ │ │ ⇥ Inbox        A  💬  ⋯ │ ← 하단 바 44px
│ ⌄ Completed & Won't Do 5                     │ │ └─────────────────────────┘
└──────────────────────────────────────────────┘ │
```
- 목록 안쪽 좌우 여백 `space.list.gutter` 16px. 목록은 세로로만 스크롤된다. 머리와 추가 바는 스크롤해도 고정된다 [임시].
- 상세 패널은 태스크를 하나 고르면 내용이 채워지고, 아무것도 고르지 않으면 빈 상태를 보여준다(패널 자체는 늘 보인다) [틱틱].

### 기기에만 저장
- 그룹 접힘 상태, 목록 스크롤 위치, 마지막으로 선택한 태스크.

### 쿼리
- 목록은 로컬 SQLite 쿼리 + `watch`로 그린다. 스마트 리스트 조건:
  - Today: `due_at < 내일 0시` AND status=0 (만료됨 포함 — [01 결정](01-app-shell.md))
  - Tomorrow / Next 7 Days: 해당 기간 / All: 휴지통 제외 미완료 전체 / Inbox: Inbox 리스트
  - 리스트 설정 `show_in_smart = none`인 리스트의 태스크는 스마트 리스트에서 뺀다 [틱틱 "Show in Smart List"]
- 반복 태스크를 완료하면: 현재 회차를 완료 기록으로 남기고, 다음 회차 날짜로 같은 태스크를 갱신한다(03에서 상세화).

### 성장 루프 연결 [sprout]
- 태스크를 완료하면(status 0→1) `xp_events`에 "task_completed" 기록 후보를 남긴다. 하루 상한·KPI 판정은 성장 명세(`10-growth.md`)에서 정한다. 완료 취소하면 같은 날 기록을 되돌린다.
