## 0. 사용자에게 먼저 물어볼 것
1. **연결 방법 두 가지를 다 둘까요?** (가) **API 토큰**: 틱틱 웹 › 설정 › 계정 › API Token에서 만든 토큰을 붙여 넣기 — 앱 등록 없이 지금 바로 됨(오너용으로 가장 빠름). (나) **틱틱 계정으로 연결(OAuth)**: 공개 제품용. 개발자 센터에 앱 등록 필요. → 제안: 둘 다. (나)가 기본 버튼, (가)는 아래 접힌 "API 토큰으로 연결".
2. **공개 출시 때 client secret을 어디에 둘까요?** 지금은 개발용 환경 변수(앱 안). 공개 앱에 secret을 넣으면 누구나 꺼낼 수 있다. → 제안: sprout API에 `POST /integrations/ticktick/token`(코드 → 토큰 교환)을 두고 secret은 서버에만 [다음]. 그 전까지 공개 빌드는 (가)만.
3. **다시 가져오기 때 틱틱에서 바뀐 내용도 반영할까요?** 지금: **새 항목만 넣고, 이미 가져온 항목은 건너뛴다**(sprout에서 고친 것을 덮어쓰지 않음). 틱틱에서 나중에 완료한 할 일도 sprout에서는 그대로. → 제안: v1은 지금대로(한 번 옮기는 도구). "틱틱 변경 반영(sprout에서 안 고친 것만)"은 [다음].
4. **id 규칙**: 행 id = `tt-<사용자 해시 6자>-<종류>-<틱틱 id>`. 지시는 `tt-<틱틱 id>`였지만, 공유 리스트처럼 **같은 틱틱 id를 다른 sprout 사용자도 가져오면 서버에서 id가 부딪쳐 한쪽이 조용히 안 올라간다**(서버 업로드가 `ON CONFLICT … WHERE owner_id = 나`). 카톡 가져오기가 지문을 id로 쓰지 않은 것과 같은 이유. → 제안: 지금 규칙 유지.
5. **노트(틱틱 노트 리스트)는 수집함으로** 보낸다. 수집함 자동 분류가 켜져 있으면 AI가 메모·할 일·볼 것·위키로 나눈다(노트가 수백 개면 시간이 걸림). → 제안: 그대로. 대안: 노트를 리스트(노트 리스트 없음 — sprout에 노트 리스트 기능 없음)로 두기는 하지 않는다.
6. **작업 지도 AI 정리는 버튼으로만** 시작한다(가져온 직후 자동으로 하지 않음). 할 일 1,000개면 AI 요청 50번. 가져온 행은 만든 시각을 자동 분류 기준 시각보다 앞으로 두어 "새 할 일 자동 분류"가 몰리지 않게 했다. → 제안: 그대로.
7. **sprout 로그아웃 때 틱틱 연결도 끊을까요?** → 제안: 끊는다(`forgetTickTick()`), 같은 컴퓨터의 다음 사용자가 남의 틱틱을 가져오지 않게. 16 결정 ⑤와 같은 원칙.
8. **완료 기록은 전부**(2010년~지금) 가져온다. 성장 XP에는 넣지 않는다(XP 원장은 sprout에서 한 일만). → 제안: 그대로.

## 1. 틱틱 기준
- 틱틱 자체에도 "설정 › 연동 & 가져오기"에 다른 앱 가져오기가 있다 [틱틱]. 흐름(연결 → 허용 → 가져오는 중 → 끝)을 따른다. 그 밖의 화면 모양은 05 리스트 편집 모달 틀(가운데 480 모달) [sprout].
- 틱틱 로고·아이콘은 쓰지 않는다. "틱틱"은 글자로만.
- 공식 Open API만 쓴다. 비밀번호는 묻지도 저장하지도 않는다. 비공개 API는 쓰지 않는다(research 21).

## 2. 레이아웃
가운데 모달 **480 폭**, 안쪽 여백 24, 머리(제목 15 굵게 + 닫기 X) · 본문 · 바닥 버튼 줄. 화면 높이 85%를 넘으면 본문만 스크롤.
```
틱틱에서 가져오기                                     ✕
──────────────────────────────────────────────────

```

• 반복 규칙 2개는 sprout가 지원하지 않아 … (주의 목록, 캡션)
틱틱 받은함 → sprout 기본함, … 노트는 수집함으로 가요.

- 숫자 칸: 3열 격자, 칸 배경 `color.bg.hover`, 이름 캡션 3차 글자색, 숫자 본문 굵게(고정폭 숫자).
- 진행: 문구 + 4px 막대(강조색). 끝을 모를 때(완료 기록 받기)는 왔다 갔다 하는 막대(움직임 줄이기 설정이면 멈춘 흐린 막대).

## 4. 인터랙션
1. 들어가는 곳: ⌘K 명령 메뉴 "틱틱에서 가져오기"(그룹 "공통 작업"), 설정 › (연동 탭이 생기면 거기, 그 전엔 계정 탭 아래) "틱틱에서 가져오기…". 둘 다 `openTickTickImport()`.
2. 열면 연결 상태를 묻고, 이미 연결돼 있으면 바로 읽기 → 미리보기.
3. **OAuth**: 메인 프로세스가 `http://127.0.0.1:47321/ticktick/callback`에서 잠깐 기다리고 시스템 브라우저로 틱틱 허용 화면을 연다. 돌아온 `state`가 다르면 거부(기다림은 계속), 5분 넘으면 취소, 포트를 다른 프로그램이 쓰면 그 문구. 코드 → 토큰 교환(Basic 인증) → 저장.
4. **API 토큰**: 붙여 넣고 [연결] → 리스트 목록을 한 번 불러 맞는지 확인 → 저장. 입력칸은 비밀번호형, 연결 뒤 비운다.
5. 토큰은 메인 프로세스에만 있다(safeStorage 암호화 파일 `userData/ticktick.bin`, 암호화를 못 쓰면 이번 실행 동안 메모리에만). 화면으로는 넘기지 않는다.
6. **연결 끊기**: 파일 삭제. OAuth 토큰은 틱틱에 폐기 요청(`/oauth/revoke`). 개인 API 토큰은 사용자가 틱틱 설정에서 지운다(안내 문구) [임시].
7. 읽기: 요청 한도를 스스로 지킨다(1분 80·5분 250, 429면 Retry-After 또는 2·4·8·16초) — research 21 §4.
8. 가져오기: 200줄씩 트랜잭션. 중간에 멈춰도 다시 가져오면 빠진 것만 들어간다(id가 정해져 있음).
9. Esc·바깥 클릭 = 닫기(진행 중이면 취소 후 닫기, 가져오는 중에는 막음).
10. [작업 지도에서 AI로 정리하기]: 이번에 새로 넣은 미완료 할 일(다시 가져오기라 새 것이 없으면 전에 가져온 미완료 전체)만 14의 분류기로 20개씩. 시작 전 지도 상태를 보관해 작업 지도 ⋯ › 되돌리기가 된다. 직접 옮긴 것은 건드리지 않는다. AI를 못 쓰면 "나중에 ✦ 다시 정리로" 안내.
11. [캘린더에서 보기]·[작업 지도 보기]: 탭을 옮기고 모달을 닫는다.

## 6. 데이터 매핑 (틱틱 → sprout)
| 틱틱 | sprout | 규칙 |
|---|---|---|
| 프로젝트 그룹 | `folders` | 리스트가 하나라도 들어 있는 것만. id `tt-<u>-folder-<id>`, 기존 폴더 뒤 순서 |
| 프로젝트(kind TASK) | `lists` | 이름 앞 이모지는 `emoji` 칸으로(🏠 집 → 🏠 + 집). color `#RRGGBB`만. `closed` → `archived_at`. kind `normal`, 기존 리스트 뒤 |
| 받은함(`inbox…`) | sprout **기본함** | 새 리스트를 만들지 않음 |
| 프로젝트(kind NOTE) | (리스트 없음) | 그 안 노트는 수집함으로 |
| 칸반 열 | `sections` | 열 순서대로. 할 일의 `columnId`가 오면 `section_id` [임시] |
| 할 일 title / content | `title` / `content` | 체크리스트 할 일은 `desc`를 content로 |
| `kind: CHECKLIST` + `items[]` | `content_mode='checklist'` + `check_items` | items 순서, status 1 → done 1·completed_at |
| `parentId` | `parent_id` | 부모가 가져오기에 없으면 맨 위 단계 |
| priority 0/1/3/5 | 0/1/2/3 | |
| status 0/2/-1 | 0/1/2(하지 않음) | 완료는 `completedTime` → `completed_at` |
| startDate·dueDate·timeZone·isAllDay | `start_at`·`due_at`·`is_all_day`, `time_zone='floating'` | 할 일 시간대(없으면 사용자 시간대 → 기기) 벽시계로. 시작=마감이면 마감만. 종일 여러 날은 끝 미포함으로 보고 하루 뺌 [임시] |
| repeatFlag | `repeat_rule` | `RRULE:` 떼고 sprout 표준 순서로. `TT_*`·WKST는 버림. BYSETPOS 등·음력(ERRULE)·날짜 없는 반복은 반복 없이(개수 알림) |
| repeatFrom "1" / 그 외 | `repeat_from` `completion` / `due` | |
| reminders `TRIGGER:…` | `reminders.trigger` | 시각: `-PT15M` 그대로, `PT0S` → `-PT0M`(정각에). 종일: 그날 0시 기준(`P0DT9H0M0S` → `PT9H`, `-P0DT15H0M0S` → `-PT15H`). 같은 것 하나로. 절대 시각·시작 뒤·날짜 없는 할 일 알림은 버림(개수 알림) |
| tags[] + 태그 목록(label·color·parent) | `tags` + `task_tags` | 이름(대소문자 무시)이 같은 sprout 태그가 있으면 거기 붙임. 부모 태그 → `parent_id`(2단계까지) |
| sortOrder | `sort_order` | 그대로(큰 음수 포함) |
| createdTime / modifiedTime(오면) | `created_at` / `modified_at` | 없으면 만든 시각 = 작업 지도 자동 분류 기준 1초 전, 고친 시각 = 만든 시각 |
| 노트(kind NOTE) | `notes`(수집함) | 내용 = 제목 + 빈 줄 + 본문, 빈 노트는 버림. `source='ticktick_import'`, `fingerprint='ticktick:<id>'`, `captured_at` = 만든 시각. 링크만 있으면 볼 것(AI 없이), 아니면 자동 분류 설정에 따라 AI 대기 |
| 리스트 모름(지운 리스트의 완료 기록 등) | 기본함 | 주의 문구 |
| 댓글·첨부·습관·집중·카운트다운·공유 멤버 | — | 가져오지 않음 [다음] |

- 모든 행 id는 정해져 있다(§0 ④). 다시 가져오면 이미 있는 id는 건너뛴다 = **겹치지 않음, sprout 수정 보존**.
- `owner_id`는 다른 쓰기와 같이 로컬 값으로 넣고, 서버가 업로드 때 로그인 사용자로 바꾼다.
