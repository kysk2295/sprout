## 3. 구성 요소와 상태
| 상태 | 표시 |
|---|---|
| 조사 전 | 방에 **"아직 모르는 알"** + 아래 카드 `나와 닮은 친구를 찾아볼까요?` [시작하기] · `나중에`(10 §2.2). 조사 전 XP는 그대로 쌓인다 |
| 조사 화면(D6) | 전체 화면 모달: 위 진행 막대 `3/8` · 왼쪽 위 ‹ · 가운데 상황 문장(20/700) · 아래 **선택지 카드 2개**(폭 꽉 참, 높이 72, 누르면 바로 다음) → 결과 화면(알 깨짐 애니메이션 · `당신은 몰두하는 고양이형` · 설명 3줄 · 축 막대 · 이름 칸 · [키우기 시작]) — 10 §2.2 그대로 |
| 처음(조사 후, XP 0) | 캐릭터 1단계 + 말풍선 `할 일을 끝내면 ○○가 자라요` |
| 불러오는 중 | 카드 자리 회색 막대 |
| 오프라인 | 차이 없음 — XP·레벨·목표는 로컬 계산(10 §3 상태) |
| 이번 주 목표 없음 | 목표 카드 안 `이번 주 목표가 아직 없어요` + 3차 `컴퓨터의 성장 화면에서 적을 수 있어요` [D7] |

## 4. 인터랙션
| 동작 | 결과 |
|---|---|
| 캐릭터 누름(쓰다듬기) | 깡충 + 하트 + 말풍선 한마디(10 §3.1 문장 규칙) + 가벼운 흔들림 |
| 기분 | 오늘 XP 있음 = 기쁨, 이틀 넘게 없음 = 졸림(`Zzz`), 그 밖 보통(10 §3.1). 시선 따라가기(마우스)는 휴대폰에 없음 → 대신 기기를 기울이면 눈이 살짝 따라감 [다음] |
| XP가 들어옴 | 오늘 탭에서 완료하면 탭 바 성장 아이콘 `+1`(21 §3). 성장 탭에 들어오면 마지막으로 본 뒤 받은 XP만큼 막대가 **차오르는 애니메이션** 한 번 [sprout — 휴대폰은 탭이 나뉘어 있어서] |
| 목표 체크 | 체크박스 톡 + 작은 색종이 + `+30`(10 §3.1). 횟수 목표는 점을 눌러 그 수로 맞춤. 같은 주에 풀면 XP 되돌림(10 §4.2) |
| 레벨업 | 레벨이 오른 걸 **앱이 앞으로 올 때·성장 탭을 열 때** 확인해 가운데 카드(폭 = 화면 − 48): 튀어오름 + `레벨 5가 됐어요` + 받은 XP 내역 [확인]. 단계가 바뀌면 `아기 고양이가 꼬마로 자랐어요` + 진화 애니메이션 1.2초(10 §2.4). 다른 기기에서 오른 레벨도 한 번만 보여 준다 |
| 진화 길 원 누름 | 그 단계 모습 미리보기 말풍선(누른 곳 위), 다른 곳 누르면 닫힘 |
| 7일 막대 누름 | 막대 위 `목 · 14 XP` 말풍선 |
| 당겨서 새로 고침 | 동기화(21과 같음) |
- 모션 감소 설정이면 숨쉬기·색종이·차오르기 없이 값만 바뀐다(10 §3.1).
- 캐릭터 그림: 데스크톱과 같은 자리 표시 벡터(10 §2.2 — 정식 그림 20장 전). 같은 SVG를 RN(`react-native-svg`)에서 그린다 [임시].

## 5. 데이터 (모두 10 §7 그대로)
| 읽기·쓰기 | 테이블 |
|---|---|
| 레벨·단계·XP 막대·그래프·요약 칩 | `xp_events` 합계·날짜별(계산, 저장 안 함 — `levelFromXp`) |
| 캐릭터 | `characters`(species·name·type_code). 조사 결과 쓰기 = 데스크톱 `assignCharacter`와 같은 공용 문장 |
| 목표 | `kpis` WHERE `week_start = 이번 주` — 체크·횟수 쓰기는 데스크톱 `setGoalProgress`와 같은 공용 함수(+30/되돌림, 3개 한도, 전부 +20) |
| 이름 바꾸기 | `characters.name` |
| 기기에만 | 마지막으로 본 레벨·XP(레벨업 화면을 한 번만 보이게, 차오르기 시작점) |
- XP 이중 지급 방지: 결정적 id(`task:<id>:<day>`, `kpi:<id>`) — 휴대폰·데스크톱이 같은 사건을 써도 한 줄로 합쳐진다(10 §7).

## 6. 완료 기준
- [ ] 같은 계정의 데스크톱과 레벨·XP·단계·목표 진행이 같은 숫자로 보인다.
- [ ] 오늘 탭에서 완료 → 성장 탭에 들어오면 막대가 차오르고, 레벨이 넘으면 레벨업 카드가 한 번만 나온다(데스크톱에서 오른 레벨도).
- [ ] 목표 체크 +30, 3개 한도, 전부 달성 +20, 같은 주 체크 해제 되돌림이 데스크톱과 같다.
- [ ] 조사 전 → 휴대폰에서 조사(D6) → 캐릭터·이름이 데스크톱에도 보인다.
- [ ] 캐릭터 쓰다듬기·기분·진화 길 미리보기가 동작하고, 모션 감소 설정에서 멈춘다.
- [ ] 라이트·다크, 작은 휴대폰(폭 360)에서 방·카드가 잘리지 않는다.
