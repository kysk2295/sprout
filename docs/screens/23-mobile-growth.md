| ③ | 요약 칩 줄 | `이번 주 완료 12개 · 🔥 연속 4일 · 총 846 XP`(넘치면 가로 스크롤) |
| ④ | **진화 길** | 5단계 원(지름 44)과 이은 선. 지난 단계 = 강조색 연한 면 + 그 단계 그림, 지금 = 강조색 테두리 + 빛 고리 + 굵은 강조색 이름, 앞 단계 = 실루엣 + 자물쇠 + `Lv 6`. 원을 누르면 그 단계 미리보기 말풍선 |

## 3. 구성 요소와 상태
| 상태 | 표시 |
|---|---|
| 조사 전 | 방에 **"아직 모르는 알"** + 아래 카드 `나와 닮은 친구를 찾아볼까요?` [시작하기] · `나중에`(10 §2.2). 조사 전 XP는 그대로 쌓인다 |
| 조사 시작(D6, B5) | 전체 화면: 오른쪽 위 둥근 `×` · 알(150) · 4종 실루엣(52 × 4) · `나와 닮은 친구를 찾아볼까요?`(24/800) · `할 일을 다루는 방식을 8가지만 물어볼게요. 정답은 없어요. 1분이면 끝나요.` · 아래 [시작하기](키트 큰 버튼 50) · `나중에` |
| 조사 문항(B6) | 머리 둥근 `‹` + 가운데 `3 / 8` · 진행 막대(4) · `상황 3`(3차) · 상황 문장(26/800) · **선택지 카드 2개**(좌우 16, 높이 72, 모서리 14, 왼쪽 `A`/`B` 원) — 누르는 순간 강조색 테두리·면 + 선택 틱 → 0.25초 뒤 다음 문항이 옆에서 밀려 들어옴 |
| 조사 결과(B7) | 알 깨짐 애니메이션 → 캐릭터(150) + 색종이 · `당신은` · `차곡차곡 다람쥐형`(25/800) · 설명 3줄 · 축 막대 2개(`계획 75% · 즉흥` / `몰입 · 멀티 75%`) · `이름을 지어 주세요` 입력(48, 강조색 테두리, 기본값 = 종 이름) · [키우기 시작] · `다시 하기`. 키보드가 뜨면 버튼이 키보드 위로 |
| 처음(조사 후, XP 0) | 캐릭터 1단계 + 말풍선 `할 일을 끝내면 ○○가 자라요` |
| 불러오는 중 | 카드 자리 회색 막대 |
| 오프라인 | 차이 없음 — XP·레벨·목표는 로컬 계산(10 §3 상태). 리포트 화면도 동기화돼 있던 것만 |
| 이번 주 목표 없음 | 목표 카드 안 `이번 주 목표가 아직 없어요` + 3차 `컴퓨터의 성장 화면에서 적을 수 있어요` [D7]. AI 초안 줄이 있으면 그 줄을 먼저 |
| 리포트 없음 | ⑦ 카드 숨김 |

## 4. 인터랙션
| 동작 | 결과 |
|---|---|
| 캐릭터 누름(쓰다듬기) | 깡충 + 하트 + 말풍선 한마디(10 §3.1 문장 규칙) + 가벼운 흔들림 |
| 기분 | 오늘 XP 있음 = 기쁨, 이틀 넘게 없음 = 졸림(`Zzz`), 그 밖 보통(10 §3.1). 기기 기울이면 눈 따라가기는 [다음] |
| XP가 들어옴 | 오늘 탭에서 완료하면 탭 알약의 성장 아이콘 옆 `+1`이 떠올랐다 사라짐(0.9초, 21 §3). 성장 탭에 들어오면 마지막으로 본 뒤 받은 XP만큼 막대가 **차오르는 애니메이션** 한 번 [sprout] |
| 목표 체크 | 체크 톡 + 작은 색종이 + `+30`(10 §3.1). 횟수 목표는 점을 눌러 그 수로 맞춤. 같은 주에 풀면 XP 되돌림(10 §4.2) |
| AI 초안 `+` / `×` | `+` = 그 제목·횟수 그대로 이번 주 목표(`source='ai'`, 5개 한도) · `×` = 숨김(`text_json.dismissed`). 줄을 누르면(고쳐 받기) 토스트 `고쳐서 받기는 컴퓨터에서 할 수 있어요` [D7] |
| 레벨업(단계 그대로) | 앱이 앞으로 올 때·성장 탭을 열 때 확인 → 가운데 카드(폭 345): 튀어오름 + `레벨 5가 됐어요` + 받은 XP 내역 [확인] |
| **진화(단계 바뀜, B4)** | **전체 화면**: 강조색 연한 원형 빛 바탕 · 위쪽에만 색종이 · 옛 모습(96, 흐림) `›` 새 모습(176, 기쁨) · 강조색 알약 `레벨 3` · `아기 다람쥐가 꼬마로 자랐어요`(26/800) · `떡잎이 한 장 더 났어요. 다음 모습은 Lv 6!` · 받은 XP 내역 카드 · 아래 [좋아요] + 3차 `다른 기기에서 오른 레벨도 한 번만 보여 줘요`. 진화 1.2초(옛 → 반짝 → 새) + 성공 흔들림 |
| 진화 길 원 누름 | 그 단계 모습 미리보기 말풍선, 다른 곳 누르면 닫힘 |
| 7일 막대 누름 | 막대 위 `수 · 40 XP` 말풍선 |
| 리포트 행 누름 | 리포트 화면(§2.1) |
| 당겨서 새로 고침 | 동기화(21과 같음) |
- 모션 감소 설정이면 숨쉬기·색종이·차오르기·진화 애니메이션 없이 값만 바뀐다(10 §3.1).
- 캐릭터 그림: 데스크톱과 같은 자리 표시 벡터(`CharacterArt.tsx` — 시안은 같은 SVG를 옮김). RN은 `react-native-svg`로 같은 도형 [임시]. 방 소품도 직접 그린 단순 벡터 [sprout].

## 5. 데이터 (모두 10 §7 그대로)
| 읽기·쓰기 | 테이블 |
|---|---|
| 레벨·단계·XP 막대·그래프·요약 칩 | `xp_events` 합계·날짜별(계산, 저장 안 함 — `levelFromXp`) |
| 캐릭터 | `characters`(species·name·type_code). 조사 결과 쓰기 = 데스크톱 `assignCharacter`와 같은 공용 문장 |
| 목표 | `kpis` WHERE `week_start = 이번 주` — 체크·횟수 쓰기는 데스크톱 `setGoalProgress`와 같은 공용 함수(+30/되돌림, 3개 한도, 전부 +20) |
| AI 초안 줄 | 읽기: 지난주 `weekly_reports.text_json.draft`(이번 주 목표가 없을 때). `+` = `kpis` INSERT(`source='ai'`), `×` = `text_json.dismissed`에 추가 |
| 리포트 | `weekly_reports`(읽기) · `seen_at` 쓰기 · `이번 주로 넘기기` = `kpis` INSERT(공용 함수) |
| 이름 바꾸기 | `characters.name` |
| 기기에만 | 마지막으로 본 레벨·단계·XP(레벨업·진화 화면을 한 번만, 차오르기 시작점) |
- XP 이중 지급 방지: 결정적 id(`task:<id>:<day>`, `kpi:<id>`) — 휴대폰·데스크톱이 같은 사건을 써도 한 줄로 합쳐진다(10 §7).
- 휴대폰은 AI를 부르지 않는다(M-G2) → `/ai/*` 호출 없음.

## 6. 완료 기준
- [ ] 같은 계정의 데스크톱과 레벨·XP·단계·목표 진행이 같은 숫자로 보인다.
- [ ] 오늘 탭에서 완료 → 탭 알약 `+1` → 성장 탭에 들어오면 막대가 차오르고, 레벨이 넘으면 카드, 단계가 바뀌면 전체 화면 진화가 **한 번만** 나온다(데스크톱에서 오른 레벨도).
- [ ] 목표 체크 +30, 3개 한도, 전부 달성 +20, 같은 주 체크 해제 되돌림이 데스크톱과 같다.
- [ ] AI 초안 `+`로 받은 목표가 데스크톱 성장 화면에 `source=ai`로 보이고, `×`로 숨긴 줄은 데스크톱에서도 숨는다.
- [ ] 리포트 화면 숫자가 데스크톱 리포트와 같고, 열면 데스크톱 목록의 새 점도 사라진다. `이번 주로 넘기기`가 데스크톱과 같은 결과.
- [ ] 조사 전 → 휴대폰에서 조사(D6) → 캐릭터·이름이 데스크톱에도 보인다.
- [ ] 캐릭터 쓰다듬기·기분·진화 길 미리보기가 동작하고, 모션 감소 설정에서 멈춘다.
- [ ] 라이트·다크·색 테마, 작은 휴대폰(폭 360)에서 방·카드가 잘리지 않는다 — 시안 B1~B8과 나란히.
