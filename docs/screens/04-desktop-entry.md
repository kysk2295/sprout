# 04 · 데스크톱 진입 동작 (명령·검색·빠른 추가·설정)

상태: 2026-10-04 직접 조사 반영. 사용자의 '데스크톱 앱을 직접 조사하고 구현' 요청에 따라 진행.
근거: [직접 조사](../ticktick-research/live-2026-10-03/README.md). 기존 01의 추정 단축키보다 이 명세를 우선한다.

## 명령 메뉴
- ⌘/Ctrl+K, 폭 560, 상단 검색 55px, 결과 행 40px, 공통 작업/내비게이션/지원 그룹.
- 실제 가능한 항목만 제공: 새 할 일, 할일, 달력, 검색, 설정, 스마트 목록, 단축키.
- 입력하면 제목에 맞는 명령과 검색 진입 행. 위/아래·Enter·Esc. 열 때 입력 포커스, 닫으면 원래 포커스 복구, Tab은 팝업 내 순환.

## 검색
- ⌘/Ctrl+F 및 레일 검색. 작업 제목·메모·리스트·태그 검색. 삭제된 작업 제외, 완료 여부 표시.
- 결과 선택 시 해당 작업 상세 또는 리스트/태그 보기로 이동. 빈 검색과 결과 없음 상태를 구분.
- 로컬 SQLite LIKE, 와일드카드 이스케이프, 오류·로딩 표시. 클라우드 검색은 서버가 없으므로 제공하지 않는다.

## 빠른 추가
- ⌘/Ctrl+N: 폭 600의 팝업. 제목, 날짜, 우선순위, 리스트, 추가 버튼. Enter 저장, Esc 취소. 저장 전 DB에 쓰지 않는다.
- 한국어 '오늘/내일/모레/다음 주 요일/날짜/오전·오후 시각', #기존태그, ~기존리스트, !높음/중간/낮음, 매일·매주 요일을 로컬 인식한다. 확인 가능한 범위를 우선하고 불명확한 문장은 제목으로 남긴다.
- 파싱 결과를 하단 요약으로 확인·수정한다. 인식 해제 버튼은 원문 제목을 유지한다. 인식한 문자열은 입력란 배경에 강조하며 가로 스크롤 위치를 입력과 맞춘다.
- tasks·task_tags·reminders를 한 트랜잭션으로 저장. 실패하면 입력 유지 및 오류 표시, 저장 중 재전송 금지.

## 설정
- Electron: 별도 800×680 설정 창. 웹: 같은 크기의 모달. 탐색 너비 220.
- 구현되는 탭: 스마트 목록, 외관, 단축키. 다른 탭은 해당 기능 구현 때 추가하며 작동하지 않는 버튼을 내놓지 않는다.
- 스마트 목록: 표시/숨김/비어 있지 않으면 표시. 기본함 항상 표시. user_prefs.smart_list_visibility.
- 외관: 기본값/Sky/Dark 견본 + 시스템 다크 모드 연동. user_prefs.theme/follow_system_dark.
- 단축키: 직접 확인한 키를 표시. G→R 내일, G→N 다음 7일. 입력·팝업에서 한 글자 키를 가로채지 않는다.
- 셸 폭/접힘/마지막 선택은 기기 localStorage, 테마는 DB. 재시작 복구.

## 언어·기존 명세 정정
전체 / 완료 / 계획 취소 / 지속 시간 표기를 사용한다. 브랜드 자산은 복사하지 않는다.

## 검증
- 키보드와 클릭으로 모든 진입점 작동, Esc/바깥 클릭 취소, 팝업 중 배경 키 동작 금지.
- 검색한 작업 상세 열기, 완료·삭제 필터, 특수 문자 검색.
- 빠른 추가 저장/취소/중복 전송 방지, 날짜 인식 단위 테스트.
- 설정 저장 후 메인 창 즉시 반영 및 재실행 복원.
