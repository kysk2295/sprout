| 영역 | 내용 |
|---|---|
| 추가 바 (44) | 흰 카드 줄(좌우 12, 모서리 12) `+ 무엇이든 던져 두세요 — 할 일, 링크, 메모`. 누르면 키보드 위 입력 창(22 빠른 입력과 같은 모양, 도구 막대 없음, 보내기만) [sprout] |
| 진행 띠 | 정리 중일 때만: 강조색 연한 면 · 회전 표시 · `카카오톡에서 가져온 312개 정리 중 · 120/312` · 작은 막대(60). 멈춤·AI 없음 문구는 11 v3-4 그대로 |
| 묶음 카드 | 날짜 묶음(`오늘 5` · `어제` · `10월 2일`), 가져온 것은 `카카오톡에서 가져옴 · 10월 2일`. 묶음 머리 44(15/600 + 개수) |
| 행 (62, 두 줄) | 왼쪽 갈래 표시(할 일 제안 = 강조색 점선 체크 칸 · 볼 것 = 사이트 표시 · 위키 = 책 · 메모 = 문서 · 정리 중 = 회전) · 첫 줄 제목(16, 한 줄 말줄임) · 둘째 줄 꼬리표(`할 일 제안 · 내일 오후 3:00` 강조색 / `볼 것` + 도메인 / `위키 · LLM 공부` 초록 / `메모` / `정리 중…` / `카톡` 테두리만 / `할 일로 등록됨`) · 할 일 제안이면 오른쪽 **`등록`**(강조색 알약 버튼) |
| 꼬리표 없는 행 | 정리 전·실패·AI 없음·v2 메모: 둘째 줄에 시각/날짜만(11 v3-3 규칙) |

### 2.4 위키 (C6 목록 · C7 페이지 — 읽기 전용)
| 영역 | 내용 |
|---|---|
| 주제 목록 (C6) | 묶음 카드 `주제 4` → 행(62): 책 아이콘 · 이름 · 둘째 줄 `자료 14 · 방금 바뀜` · 새로 바뀐 주제 강조색 점 · `›`. 카드 아래 3차 `주제 이름 바꾸기·합치기·고치기는 컴퓨터에서 해요. 휴대폰에서는 읽고, AI가 바꾼 것을 되돌릴 수 있어요.` |
| 주제 페이지 (C7, 밀려 들어옴) | 머리: 둥근 `‹` · 오른쪽 둥근 이력(🕘). 제목(24/700) · 3차 `자료 14 · 버전 6 · 방금 정리`. 띠(AI가 바꿨을 때만, 11 v3-5 기준): ✦ `방금 들어온 자료 1개를 '핵심 정리'에 반영했어요` · **되돌리기**. 구역(`개요`·`핵심 정리`·`볼 것`·`관련 주제`·`열린 질문`, 근거 없는 구역 숨김) — 구역 머리 13/600 2차, 줄은 15/23 점 목록, 줄 끝 출처 꼬리표(`카톡 10/2` 등), 새 줄은 강조색 연한 면. 🔒 구역은 머리 옆 `🔒 직접 고침` |
| 🔒 구역의 AI 제안 | 구역 아래 회색 줄 `제안 1개 · 컴퓨터에서 보기` (휴대폰에서 넣지 않음, M-C2) |
| 이력 | 아래 시트: 버전 목록(버전 · 이유 · 시각). 누르면 그 버전 미리보기(읽기만). 되돌리기는 띠의 되돌리기 한 가지만 [임시] |

## 3. 구성 요소와 상태
| 요소 | 상태 |
|---|---|
| 행 | 기본 · 누름(배경 `color.bg.selected`) · 스와이프 열림(§4) · 등록 뒤(꼬리표 `할 일로 등록됨`, `등록` 버튼 사라짐) |
| `등록` 버튼 | 누름 → 바로 할 일 생성(11 v3-3 경로, 날짜 그대로) + 토스트 `할 일로 등록했어요 · 열기`. 날짜가 없거나 고치고 싶으면 행을 눌러 시트에서 |
| 정리 중 | 회전 + `정리 중…` (AI가 실제로 도는 중일 때만 — 휴대폰은 동기화로 받은 `ai_state`로 판단) |
| 실패 | 꼬리표 없이 시각 · 시트 AI 카드 자리에 `정리하지 못했어요` + `컴퓨터에서 다시 정리할 수 있어요` (휴대폰은 AI를 부르지 않음, M-C5) |
| 빈 수집 | 가운데 수집함 아이콘 + `무엇이든 던져 두세요` + 3차 `다른 앱에서 공유 → sprout 를 누르면 여기로 와요 (카톡 '나에게 보내기'처럼)` |
| 빈 볼 것 | `저장한 링크가 여기에 모여요` |
| 위키 주제 없음 | 책 아이콘 + `자료가 쌓이면 주제별로 정리해 드려요`(11 v3-5) |
| 검색 | 🔍 → 머리 자리가 검색칸(`수집함 검색`, 키트 `.m-search`) + 취소. 지금 세그먼트 안에서 글자 부분 일치(11 v2 규칙, `%`·`_` 글자 그대로). 결과 없음 = `"<검색어>"와 맞는 항목이 없어요` |
| 오프라인 | 목록·추가·등록·삭제 그대로(로컬). 위키·볼 것도 로컬 DB에 있는 만큼 |
| 불러오는 중 | 행 자리 회색 막대 |

## 4. 인터랙션
| 동작 | 결과 |
|---|---|
| 행 누름 | 상세 시트(C4). 볼 것 행은 그 앱·브라우저로 열기(시트는 길게 누름 메뉴 `자세히`) |
| 수집 행 **왼쪽 밀기** | `할 일로`(파랑) · `삭제`(빨강) 칸. `할 일로` = 할 일 제안이면 바로 등록, 아니면 22 날짜 시트를 열고 등록. `삭제` = 바로 지우고 토스트 `삭제했어요 · 되돌리기`(5초, 11 v2) |
| 볼 것 행 **오른쪽 밀기** / 동그라미 | 봤어요(`seen_at`) → 다 본 것으로 + 토스트 `봤어요로 옮겼어요 · 되돌리기` |
| 길게 누름 | 메뉴: `할 일로 만들기` · `다른 종류로 ›` · `복사` · (구분선) · `삭제` |
| 출처 꼬리표(위키) | 수집 탭으로 바뀌며 그 항목 상세 시트 |
| 띠 `되돌리기`(위키) | 11 v3-5와 같은 되돌리기(기준 버전으로). 토스트 `되돌렸어요` |
| 세그먼트 | 누르거나 좌우로 밀어 전환. 초안·검색어·스크롤 위치 유지 |
| 당겨서 새로 고침 | 동기화 |
| 탭 알약 수집함 다시 누름 | 맨 위로 |

## 5. 데이터 (모두 11 v3-6 그대로, 스키마 변경 없음)

- 휴대폰은 `/ai/*`를 부르지 않는다(M-C5).

## 6. 완료 기준
- [ ] 휴대폰에서 `등록` → 데스크톱 태스크·캘린더에 같은 할 일, 수집 행 꼬리표가 두 쪽 모두 `할 일로 등록됨`.
- [ ] 공유하기로 넣은 항목이 데스크톱에서 정리되면 휴대폰 수집 행 꼬리표가 동기화로 바뀐다.
- [ ] 볼 것 봤어요·되돌리기, 수집 삭제·되돌리기가 두 기기에서 같다.
- [ ] 위키 페이지가 데스크톱과 같은 내용·출처 꼬리표·새 줄 강조로 보이고, 되돌리기 결과가 같다. 편집 버튼은 없다.
- [ ] 비행기 모드에서 추가·등록·삭제 → 연결 후 올라간다.
- [ ] 시안 C3~C7과 나란히(라이트·다크·색 테마).
