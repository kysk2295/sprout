## 0. 사용자에게 확인할 것
1. **단계 순서**: 환영 → 캘린더 연결 → 성향 조사 → 첫 할 일(v0.2에서 틱틱 가져오기 뺌). → 제안: 그대로(캘린더가 "캘린더 앱"의 첫 기대라 맨 앞, 캐릭터는 데이터가 생긴 뒤 뒤쪽).
2. **언제 뜨나**: 이 기기에서 **새 계정을 만든 직후**(이메일 가입·구글/애플 첫 로그인)만. 다른 기기에서 기존 계정으로 로그인하면 안 뜬다. → 제안: 그대로.
3. **진행 기록 저장**: 동기화 스키마를 바꾸지 않고 **기기 localStorage(계정 id별)**. 그래서 "계정당 한 번"은 "만든 기기에서 한 번"과 같다. 계정 전체로 맞추려면 `user_prefs`에 칸 하나를 더해야 한다(스키마 변경 — 승인 필요). → 제안: v1은 기기 저장.
4. **성향 조사 자동 권하기(10 §2.2 "첫 로그인 직후 카드")**: 이 안내의 4단계로 흡수한다. 안내가 뜬 계정은 따로 한 번 더 뜨지 않는다. → 제안: 그대로. 기존 계정(안내 없음)은 10 §2.2 그대로.
5. **결제 화면**: 없다(틱틱은 온보딩 끝에 페이월). → 제안: 없음.

## 1. 틱틱 기준
- 틱틱 모바일: 소개 → 6단계 → 페이월 [틱틱, 단계 내용은 미확인]. 데스크톱 첫 실행은 확인 못 함 — 사용자 틱틱을 로그아웃해서 보지 않는다(HANDOFF 규칙).
- 따라서 **형식(짧은 단계 카드, 언제든 건너뛰기)** 만 틱틱을 따르고, 단계 내용은 sprout 고유라 틱틱 디자인 언어(가운데 카드 모서리 16 · 강조색 주 버튼 40 · 회색 보조 링크 — 05 모달·10 성향 조사 카드와 같은 말씨)로 새로 그린다 [sprout].
- 캘린더 연결·가져오기는 틱틱처럼 **설정에도 그대로** 있다. 안내는 바로 가는 길일 뿐.

## 2. 레이아웃
- 앱 위를 덮는 반투명 바탕(`color.overlay.scrim`) + 가운데 카드 **480 폭**(창이 좁으면 좌우 24 남기고 줄어듦), 모서리 16, 바탕 `color.bg.popover`, 그림자 `shadow.modal`, 안쪽 좌우 32 · 위 16 · 아래 28. 세로가 모자라면 바탕이 스크롤.
- 쌓임 순서: 앱(서랍 30 · AI 빠른 창 80) < 안내(85) < 다른 창(90 틱틱 가져오기 · 500 성향 조사). 그래서 안내에서 연 창이 안내 위에 뜨고, 닫으면 안내로 돌아온다.
```
 ‹            ● ━ ○ ○ ○              ✕      ← 이전 · 진행 점(현재 = 18px 막대) · 닫기
 ────────────────────────────────────────
            (단계 그림)
          제목 20 굵게
     설명 14, 2줄 이내, 회색
     [ 단계 본문: 연결 행 / 입력칸 ]
 ┌──────────────────────────────────┐
 │            주 버튼 (40)           │
 └──────────────────────────────────┘
              보조 링크(12 회색)
```

## 3. 단계
| # | 단계 | 내용 | 주 버튼 / 보조 |
|---|---|---|---|
| 1 | **환영** | 새싹 그림(직접 그림, 제품 로고 확정 전) + "sprout에 오신 걸 환영해요" + "할 일을 끝낼수록 함께 자라는 친구가 생겨요. 시작하기 전에 1분만 준비해요." + 미리보기 2줄(캘린더·캐릭터, 강조색 아이콘) | **시작하기** / "건너뛰고 바로 쓰기"(= 안내 전체 끝) |
| 2 | **캘린더 연결** | "캘린더를 연결할까요?" + "일정과 할 일을 한 화면에서 봐요. 꿈틀에서 만들거나 고친 일정은 연결한 캘린더에도 저장돼요."(16 v2.1 양방향 — 2026-10-05 바꿈) + 연결 행 2개: **Google 캘린더**(Google 계정의 일정) · **Apple 캘린더**(Mac 캘린더 앱의 일정, iCloud 포함) — 행 오른쪽 `연결` 버튼. 아래 회색 "나중에 설정 › 캘린더에서도 연결할 수 있어요." | 하나라도 연결하면 **다음**, 아니면 **건너뛰기** |
| 3 | **성향 조사** | 캐릭터 4종 실루엣 + "나와 닮은 친구를 찾아볼까요?" + "할 일을 다루는 방식을 8가지만 물어요(1분)." → **시작하기** = 10 §2.2 조사 창(같은 컴포넌트)이 위에 열림. 조사 결과 화면에서 [키우기 시작]을 누르면 안내는 저절로 4단계로 간다(축하는 조사 결과 화면이 맡는다). **이미 캐릭터가 있으면 이 단계는 저절로 넘긴다** | 시작하기 / "나중에" |
| 4 | **첫 할 일** | "오늘 할 일 하나를 적어 볼까요?" + 입력칸(자리 표시 "예: 메일 답장하기") — Enter = **기본함 · 오늘**로 만들고 아래에 ✓ 줄로 쌓임(여러 개 가능). 아래 단축키 3줄: ⌘N 빠른 추가("내일 오후 3시"처럼 쓰면 날짜가 잡혀요) · ⌃⇧A 전역 빠른 추가 · ⌘K "시작 안내"로 다시 열기 | 만들었으면 **sprout 시작하기**, 아니면 **건너뛰고 시작하기** → 안내 끝 |

## 4. 인터랙션
- **건너뛰기·이어 하기·한 번만** (상태 머신 = `data/onboarding.ts`, 시험 `tests/onboarding.test.ts`)
  - 단계마다 결과가 "함(completed)" / "건너뜀(skipped)"으로 남는다. 이전(‹)으로 돌아가 다시 하면 바뀐다.
  - **✕ · Esc = 이번 실행 동안만 닫기.** 다음 실행에 그 단계부터 이어서 연다(진행 중 기록이 남아 있으므로).
  - 마지막 단계를 지나거나 "건너뛰고 바로 쓰기"를 누르면 **끝**. 끝난 계정은 다시 저절로 뜨지 않는다.
  - 저절로 여는 조건: 진행 중 기록이 있으면 이어서, 기록이 없고 **이번에 이 기기에서 새로 만든 계정**이면 처음부터. 그 밖에는 열지 않는다.
- **다시 열기**: ⌘K 명령 "시작 안내"(공통 작업 묶음) · 설정 › 일반 › "시작 안내 다시 보기" [리드가 App.tsx·설정에 연결 — 함수 `openOnboarding()`]. 처음 단계부터 열고 지난 기록은 남긴다. 이미 한 성향 조사는 저절로 넘긴다.
- 키보드: Enter = 포커스된 버튼(환영 단계는 주 버튼에 포커스), 5단계 입력칸 Enter = 할 일 만들기(한글 조합 중에는 무시). Esc = 닫기(위에 다른 창이 열려 있거나 연결 중이면 그쪽 몫).
- 애니메이션: 바탕 페이드 160ms, 단계 바뀔 때 본문이 4px 아래에서 올라오며 나타남 160ms, 진행 점 폭 전환. 시스템 "동작 줄이기"면 모두 끈다.
