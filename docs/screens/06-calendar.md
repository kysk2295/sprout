## 2. 레이아웃
```
레일 │ (왼쪽 패널 223pt, 접힘 기본) │ 캘린더
     │ ┌ 2026년 10월   ‹ ○ ›     ┐ │ ▯ 2026년 10월          [+] [주 ⌄] [‹│오늘│›] ⋯   ← 머리글 56
     │ │ 일 월 화 수 목 금 토      │ │        일     월     화 …                       ← 요일 줄 34
     │ │ (작은 달력, 이번 주 띠)    │ │       27    28    29                            ← 날짜 숫자 줄 34
     │ ├ 전체 ✓                   │ │      [막대 16pt, 줄 간격 19pt]                  ← 종일 영역(내용에 맞춰 자동)
     │ │ › 리스트 ☐               │ │ 12 PM │                                        ← 눈금 55 · 1시간 52
     │ │ › 태그 ☐                 │ │  1 PM │ [시각 태스크 = 한 줄 막대]               │
     │ └ › 캘린더 구독             │ │       │ ●──── 현재 시각(오늘 열에만)             │
```
- 레일에서 캘린더 아이콘을 누르면 **목록 사이드바·목록·상세 패널 자리를 캘린더가 통째로 쓴다** [틱틱]. 상세 패널 대신 블록 옆 팝오버로 태스크를 연다.
- 왼쪽 패널은 머리글의 `▯`로 열고 닫는다. 기본은 닫힘. 폭 **223pt** [실측].
- 창이 좁아질 때: 900px 미만이면 왼쪽 패널은 겹쳐 뜨는 서랍이 된다(01 §2와 같은 규칙) [임시]. 서랍 밖을 누르거나 작은 달력에서 날짜를 고르면 닫힌다. 머리글 제목은 줄바꿈하지 않는다. 칸 폭은 내용과 상관없이 똑같이 나눈다(가로 넘침 없음) [sprout, 2026-10-04 E2E].

### 5.1 세로 스크롤 [틱틱 — research 17 §17, 2026-10-06 사용자 피드백 "상하 스크롤이 틱틱처럼 자연스럽지 않아"]
| 항목 | 규칙 | 출처 |
|---|---|---|
| 방식 | 달을 갈아 끼우지 않는다. **주 줄이 위아래로 끊김 없이 이어진다**(트랙패드 관성 그대로, 브라우저 기본 스크롤). 휠·트랙패드 이벤트를 가로채지 않는다 | [틱틱] |
| 줄 높이 | 남은 높이 ÷ **기준 달**에 필요한 주 수. 기준 달은 처음 열 때·‹ › ← → 오늘·달 고르기·작은 달력으로 갈 때만 바뀌고, **스크롤하는 동안은 그대로**(줄이 커졌다 작아졌다 하지 않음). 창 크기가 바뀌면 같은 주가 맨 위에 남게 다시 나눈다 | [틱틱] / 다시 나누기 [sprout] |
| 멈춘 자리 | 손을 떼고 관성까지 끝나면(`scrollend`) **가장 가까운 주 경계로 부드럽게 맞춤**. 휠 한 칸(노치)처럼 짧게 움직였으면 움직인 방향의 다음 주로. 움직이는 동안에는 맞추지 않는다 | [틱틱 추정] |
| 머리 제목 · 진한 날짜 | 화면 가운데 줄(그 주 목요일)의 달. 스크롤하면서 바로 바뀌고, 그 달 숫자만 진하게·나머지는 회색 | [틱틱] |
| 떠 있는 달 이름 | 스크롤하는 동안 각 달 1일이 든 줄의 첫 칸 위에 "2026년 11월"(굵게 24pt, `color.text.primary`, 날짜 숫자 줄 높이). 멈추고 0.6초 뒤 0.3초 동안 흐려져 사라짐 | [틱틱] / 시간 [임시] |
| ‹ › · ← → | 이전·다음 달 첫 주가 맨 위에 오도록 **부드럽게 스크롤**(8주보다 멀면 바로 이동) | [틱틱] / 움직임 [임시] |
| 오늘 · T · 달 고르기 · 작은 달력 | 그 달 첫 주가 맨 위로(가까우면 부드럽게, 멀면 바로) | [틱틱] |
| 그리기 | 보이는 주 + 위아래 2주만 그린다(가상 스크롤, 2000~2060년). 줄 경계를 넘을 때만 다시 그림 — 픽셀마다 상태를 바꾸지 않는다. 데이터는 기준 달 앞뒤 6주까지 미리 읽어 스크롤 중 막대가 늦게 뜨지 않게 | [sprout] |

- 아래: **필터.** `전체`(켜지면 강조색 글자 + 채운 체크 원) · `› 리스트 ☐` · `› 태그 ☐` · `› 캘린더 구독`. `›`를 누르면 펼쳐서 항목마다 체크칸.
  - 리스트·태그를 하나라도 고르면 "전체"가 꺼지고 고른 리스트에 속하거나 고른 태그가 붙은 태스크만 보인다 [합집합 규칙 임시]. 그룹 체크칸 = 그 그룹 전부 켜기/끄기.
  - 필터는 기기 사이 동기화한다(`view_settings`의 `calendar` 행).

**끄는 동안 모양** [틱틱 실측 — research 17 §14]
- 공통: 4pt 넘게 움직여야 끌기로 본다(그 전에 놓으면 클릭 = 팝오버, ⌘클릭 = 선택). 미리 보기는 **원래 항목과 같은 컴포넌트·같은 색·같은 글자**(제목, 체크박스/일정 아이콘, 바뀐 시각 글자)로 그리고, 살짝 비침(0.9) + 그림자. **원래 항목은 제자리에 옅게(0.4)**. 커서는 보통 화살표(Mac), 가장자리는 ↕/↔. 놓을 때 애니메이션 없음.
- 주·일 시간 칸: 미리 보기가 **15분 칸·놓일 날 열 전체 폭에 붙는다**(포인터를 그대로 따라가지 않음). 기간 블록은 원래 높이, 한 점·종일에서 온 할 일은 한 줄 막대(16pt). 블록 글자의 시각이 놓일 시각으로 바뀐다.
- 주·일 종일 영역: 놓일 날(여러 날이면 그 기간)의 열이 옅은 회색으로 칠해지고, 그 칸의 빈 줄에 막대 미리 보기. 따로 떠다니는 칩은 없다.
- 월 칸: 원래 막대와 같은 모양이 **잡은 자리를 유지한 채 포인터를 따라 떠다닌다**(칸에 붙지 않음). 놓일 날(여러 날 막대면 새 기간 전체)이 옅은 회색으로 칠해진다.
- 가장자리 끌기(시간 칸 ↕, 막대 ↔): 따로 그리지 않고 **블록·막대 자체가 바로 늘어나고 줄어든다**(시각 글자도 바로 바뀜).
- 구독 일정(16)은 쓸 수 있는 캘린더면 꿈틀 일정처럼 끈다(반복 회차는 범위 대화, ⌥ 복제·⌘ 함께 옮기기는 안 됨 — 16 §12.6). 쓸 수 없는 캘린더는 끌 수 없다(누르면 읽기 전용 팝오버). sprout 자체 일정(§14.4)은 할 일과 똑같이 끈다.
- 옮기기·길이 바꾸기는 토스트 없이 바로 저장하고 ⌘Z로 되돌린다 [sprout — 02 §7 되돌리기 규칙].
- 반복 태스크를 옮기면 반복 전체의 기준 날짜가 바뀐다(03 §8 "반복 전체에 적용"). 미래 회차(계산된 표시)는 끌 수 없다 [임시 — 틱틱은 "이번만 / 모든 회차" 대화창, research 17 §14 → [후보]].
- 구현: 계산은 `lib/calendarDrag.ts`(시험 `tests/calendar-drag.test.ts`), 끌기 한 번(Esc·커서)은 `components/calendar/dragSession.ts`.

### 14.3.1 목록(스마트 리스트)의 일정 [틱틱 — research 17 §13.3]
- **오늘 · 다음 7일** 스마트 리스트에 보이는 기간의 일정을 함께 보인다(틱틱 "intelligently displayed in the Today, Next 7 Days smart lists"). **내일**도 같은 규칙 [임시 — 틱틱 미확인].
  - 기간: 오늘 = 오늘과 겹치는 일정, 내일 = 내일과 겹치는 일정, 다음 7일 = 오늘~6일 뒤와 겹치는 일정. 보이기로 둔 캘린더만(16 §2.2). 왼쪽 패널 구독 체크는 캘린더 보기 전용이라 목록에는 상관없다.
  - 놓는 곳: 그룹 기준이 **날짜**(스마트 리스트 기본)면 일정이 시작하는 날의 그룹(이미 시작한 여러 날 일정은 "오늘") **맨 위**에, 종일 → 시작 시각 순 [임시 — 섞는 순서는 틱틱 미확인]. 그 날짜 그룹에 할 일이 없어도 그룹을 만든다. 그룹 머리 개수에 일정도 센다. 그룹 기준이 날짜가 아니면 맨 아래 그룹 **"구독 캘린더"**에 모은다 [임시].
  - 행: 16 §2.4 사이드바 목록 행과 같다 — 체크박스 자리에 회색 캘린더 아이콘, 제목, 오른쪽 날짜(할 일 행과 같은 날짜 글자·색 규칙), 왼쪽 2pt 캘린더 색 줄. 이미 끝난 일정은 옅게.
  - 동작: 누르면 **읽기 전용 팝오버**(16 §3.3 내용, 목록 행은 넓어서 행 아래·제목 시작에 맞춰 뜬다), 우클릭 = "구글 캘린더에서 열기" 한 줄 메뉴. 선택·끌기·키보드 이동·일괄 편집·완료에 **들어가지 않는다**.
  - 사이드바 스마트 리스트 개수에는 넣지 않는다(16 §4.3 그대로) [임시 — 틱틱 미확인]. 할 일이 없고 일정만 있으면 빈 상태 그림을 보이지 않는다.
- 캘린더마다 **"캘린더에서만 보이기"**(틱틱 Show only in calendar)는 [다음] — 16 §2.2 모달에 세 번째 선택지로 더한다. 그전까지 목록에서 빼려면 "숨기기"를 쓴다.

## 14.4 확정 — sprout 자체 일정 (사용자 결정 2026-10-05)
사용자 결정: "일정도 여기서 만들 수 있어야지" → 아래 비교표의 **C안(sprout 자체 일정)**. 캘린더 연결 없이 sprout 안에서 일정을 만들고 PowerSync로 휴대폰까지 동기화한다.
- **틱틱과 다른 점(의도적):** 틱틱은 일정을 스스로 저장하지 않고 연결한 구글·iCloud 캘린더에만 만든다(research 17 §13.1). 사용자가 이 차이를 알고 자체 일정을 골랐다. 그 밖의 **모양·동작은 §14.3의 일정 표시를 그대로** 따르고(체크박스 자리 캘린더 아이콘, 캘린더 색, 완료 없음, 오늘·다음 7일 목록 행), 구독 일정과 다른 점은 **고칠 수 있다**는 것 하나다.
- 이전 비교(참고): A 캘린더 연결만(코드 0) · B 구독 캘린더에 쓰기(틱틱과 같음, 구글 민감 범위 심사) · **C 자체 일정(채택)**. B는 v1 다음 후보로 남긴다.

### 14.4.1 데이터 — 동기화 테이블 `events`
| 칸 | 뜻 |
|---|---|
| `title` | 제목(빈 제목은 저장하지 않음) |
| `notes` | 설명(글자만) |
| `start_at` · `end_at` | 태스크와 같은 floating 표기. 종일 = `'YYYY-MM-DD'`(끝 = 마지막 날, 포함), 시각 = `'YYYY-MM-DDTHH:mm'`. **늘 둘 다 있다**(`end_at >= start_at`). 시각 일정에 길이가 없으면 1시간으로 만든다 |
| `is_all_day` · `time_zone` | 0/1 · `'floating'`(태스크와 같음) |
| `repeat_rule` | 태스크 반복 규칙과 같은 형식(03 §8, `@sprout/schema/time` `parseRule`). 회차는 계산해서 그린다(저장하지 않음). 반복 기준은 늘 "날짜 기준"(완료가 없으므로) |
| `location` | 장소(글자, 선택) |
| `reminders` | 알림 트리거 JSON 배열 — 태스크 `reminders.trigger`와 같은 값(`'-PT0M'`, `'-PT15M'`, `'-P1D'` …). 별도 행 테이블을 두지 않는다 |
| `color` | 일정마다 색 [다음 — v1 화면에는 고르는 곳 없음, 비면 "내 일정" 색] |
| `deleted_at` | 지운 시각(되돌리기용 부드러운 삭제). 읽을 때 늘 `deleted_at IS NULL` |
| 공통 | `id`, `owner_id`, `created_at`, `modified_at` |
- **"내 일정" 캘린더 설정**은 테이블을 따로 두지 않고 `view_settings`의 `calendar` 행 `options_json`에 둔다: `myCal`(왼쪽 패널 보이기, 기본 1) · `myColor`(기본 `#E9A23B` — 스타일 미리 보기의 "일정" 노랑). 기기 사이 동기화된다.
- 일정에는 **완료·우선순위·리스트·태그·하위 할 일·XP가 없다.** 사이드바 스마트 리스트 숫자·성장 XP·주간 리포트 통계에 넣지 않는다(목록 그룹 머리 개수는 구독 일정처럼 일정도 센다 — §14.3.1).

### 14.4.2 만들기 — 빠른 만들기 팝오버의 `할 일 · 일정`
- 팝오버 맨 위에 **세그먼트 `할 일 · 일정`**(옵션 보기 색상 탭과 같은 트랙 모양, 높이 24). 기본 = 할 일. **이 기기에서 마지막으로 고른 쪽을 기억**한다(localStorage `sprout.cal.qc.kind`) — 일정 여러 개를 이어 넣을 때 매번 바꾸지 않게. 세그먼트가 늘 보여서 잘못 고른 상태를 알아챌 수 있다. ⌘1 = 할 일, ⌘2 = 일정(팝오버 안에서만) [sprout].
- **일정**일 때 팝오버: 머리 📅 날짜("10월 12일, 오후 2:00 - 3:00", 누르면 03 날짜 선택기 — 날짜·기간·반복·알림) / 제목 placeholder "일정 제목" / 장소 한 줄 입력(📍, placeholder "장소") / 설명 / 아래 왼쪽 "● 내 일정"(내 일정 색 점, 누를 것 없음). **⚑ 우선순위·체크 항목 아이콘·리스트 고르기는 숨긴다.**
- 시간 칸 클릭(한 시각) → 일정은 그 시각부터 **1시간**. 끌어 만든 범위는 그대로. 종일 칸 = 종일 일정. 알림 기본값은 할 일과 같다(시각 있음 = "정각에", 종일 = 없음).
- 저장 규칙(Enter·바깥 클릭·Esc·한 트랜잭션·실패 시 입력 유지)은 §7.1과 같다.

### 14.4.3 보기 — 캘린더·목록·검색
| 곳 | 규칙 |
|---|---|
| 캘린더 일·주·월 | 구독 일정과 같은 막대·블록(§14.3) — 체크박스 자리 캘린더 아이콘(옵션 "캘린더" 아이콘 토글을 따름), 색 = `events.color` 또는 "내 일정" 색. 지난 일정은 옅게, "완료된 할일 보기"를 끄면 지난 일정 숨김(§14.3과 같음). 반복 회차는 **"반복 주기 표시" 옵션과 상관없이 늘 계산해서 그린다**(일정은 회차마다 실제 약속이므로 — 구독 일정과 같음). 회차 막대도 옅게 하지 않는다 |
| 왼쪽 패널 | 필터 목록 맨 아래(`› 캘린더 구독` 위)에 **`☑ ● 내 일정`** 한 줄: 체크 = 캘린더 보기에 보이기(`myCal`), 색 점 누르면 05 리스트 편집과 같은 9색 줄(없음 제외) → `myColor`. 리스트·태그 필터를 골라도 일정은 이 체크만 따른다 |
| 오늘 · 내일 · 다음 7일 | §14.3.1 구독 일정 행과 같은 자리·같은 모양(체크박스 자리 캘린더 아이콘, 왼쪽 2pt 색 줄, 오른쪽 날짜). 반복 일정은 그 기간의 회차마다 한 줄. 구독 일정과 섞어서 종일 → 시각 순. 눌러서 **고칠 수 있는 팝오버**(§14.4.4), 우클릭 = 일정 메뉴. 선택·끌기·키보드 이동·일괄 편집에는 들어가지 않는다(구독 일정과 같음) |
| 검색(⌘F) | 제목·설명·장소에 검색어가 있는 일정도 결과에 "일정" 묶음으로 보인다. 누르면 캘린더 보기에서 그 날짜로 가서 일정 팝오버를 연다(팝오버는 캘린더 위쪽 가운데 — 막대 옆 맞춤은 [다음]) |
| 그 밖의 목록(리스트·태그·모두·필터) | 일정을 보이지 않는다(일정은 리스트에 속하지 않음). 날짜 그룹이 아닌 오늘·다음 7일에서 일정이 모이는 맨 아래 그룹 이름은 자체 일정이 섞이면 "일정", 구독 일정만이면 "구독 캘린더" |

### 14.4.4 고치기 — 일정 팝오버
- 막대·블록·목록 행을 누르면 **일정 카드 팝오버**(400 폭, 구독 일정 카드 16 §3.3과 같은 줄 구성): 제목(바로 고치는 입력) / 🕐 날짜·시간 줄(누르면 03 날짜 선택기 — 날짜·기간·종일·반복·알림, ⟲ 반복이면 아이콘) / 📍 장소 입력 / 📄 설명 입력 / 아래 "● 내 일정" + 오른쪽 🗑 삭제. 구독 일정 카드와 달리 모든 칸이 입력칸이다.
- 고친 값은 칸을 벗어날 때(또는 날짜 선택기 OK) 바로 저장(02 §13.4 저장 버튼 없음). 제목을 비우고 닫으면 원래 제목으로 돌린다.
- 반복 일정은 v1에서 **늘 전체(모든 회차)를 고친다**. 회차 막대를 눌러도 원래 일정(첫 회차 날짜)을 고친다. "이 회차만"은 [다음].
- **우클릭 메뉴(일정):** 열기 · 할 일로 바꾸기 · 복제 · (구분선) · 삭제.

### 14.4.5 옮기기·길이·삭제
- **끌어 옮기기·가장자리로 길이 바꾸기(막대 끝 = 여러 날 포함)·종일 ↔ 시간 칸·월 칸 이동·⌥ 복제·⌘+클릭 함께 선택·끄는 동안 모양·Esc 취소**는 할 일과 같다(§7.2·§7.3). 시간 칸으로 옮긴 종일 일정은 1시간(할 일은 한 점과 다름 — 일정은 기간이 기본), 종일 영역으로 옮긴 시각 일정은 그날 종일. 반복 일정은 원래 일정만 끌 수 있고(전체가 옮겨짐), 계산된 회차는 끌 수 없다(할 일 규칙과 같음).
- 옮기기·길이는 토스트 없이 저장하고 ⌘Z로 되돌린다. 할 일과 일정을 함께 골라 옮기면 ⌘Z 한 번에 둘 다 돌아간다 [임시 — 마지막 되돌리기 하나만 등록되면 일정 쪽만].
- **삭제:** 팝오버 🗑, 우클릭 "삭제", 고른 뒤 Delete/Backspace → `deleted_at` 기록 + 토스트 "일정을 삭제했어요 ⟲". 휴지통 목록에는 넣지 않는다(일정은 할 일 휴지통 대상이 아님) [sprout].

### 14.4.6 할 일 ⇄ 일정 바꾸기
- 할 일 우클릭 메뉴(02 §9, 캘린더·목록 공통)에 **"일정으로 바꾸기"**: 한 개만 골랐을 때. 제목·설명(체크 항목은 줄마다 "- " 붙여 설명으로)·날짜(시각 하나 = 1시간, 날짜 없음 = 오늘 종일)·반복·알림을 옮기고 할 일은 휴지통으로. 하위 할 일이 있으면 비활성(메뉴 글자 "일정으로 바꾸기 (하위 할 일 있음)"). 토스트 "일정으로 바꿨어요 ⟲" — 되돌리면 할 일이 돌아오고 일정은 지워진다. 사용자가 이미 할 일로 넣어 둔 약속(피부과·미용실 등)을 일정으로 옮기는 용도.
- 일정 우클릭 메뉴 **"할 일로 바꾸기"**: 기본함에 같은 제목·설명(장소가 있으면 설명 첫 줄 "📍 장소")·날짜(기간 유지)·반복·알림의 할 일을 만들고 일정은 지운다. 토스트 "할 일로 바꿨어요 ⟲".
- 바꾸기로 XP는 생기지도 없어지지도 않는다(완료가 아니므로).

### 14.4.7 알림

2026-10-05 E2E(별도 인스턴스 `SPROUT_PROFILE=events`, 임시 로컬 서버 스택에 새 계정 — 끝나고 계정 삭제·폴더·스택 지움)로 확인한 것은 [x].
- [x] 캘린더 `+`·빈 칸 끌기 팝오버에서 `일정`을 골라 만들면 캘린더 아이콘·내 일정 색 블록으로 보인다(장소·알림 "정각에" 저장). 마지막으로 고른 쪽 기억은 시험 코드 없이 localStorage로만.
- [x] 일정을 끌어 옮기고 ⌘Z로 되돌리고, 아래 가장자리로 길이를 바꾼다. 팝오버에서 설명을 고치고 바깥을 눌러 저장, 팝오버 🗑 삭제 → ⌘Z, 고른 뒤 Delete → ⌘Z.

## 16. 공휴일 · 주말 · 추가 달력 · 주 번호 (2026-10-05 — research 17 §15)
사용자 피드백 "공휴일이나 이런 것들이 표시가 안 돼. 주말이나 이것도 확인해 줘." → 틱틱 조사 결과 **틱틱은 한국 공휴일을 보여 주지 않고(한국 계정엔 "휴일 표시" 스위치가 없다), 주말도 칠하지 않는다.** 틱틱(디다·일본)의 "휴일 표시" 기능의 **자리·모양**을 그대로 가져와 한국 공휴일을 sprout가 직접 묶는다. **색은 사용자 결정(2026-10-05): "공휴일은 빨간색으로 표시를 해야지", "주말도 표시를 해야지"** — 틱틱(초록 休 배지, 주말 칠 없음)과 다르다는 걸 알고 고름.
- **배지 뺌(사용자 결정 2026-10-05 "이 휴일 태그 좀 없애 줘. 거슬려.")**: 틱틱/디다의 숫자 오른쪽 위 "휴" 원 배지는 그리지 않는다(모든 곳 — 월·주·일 보기, 작은 달력, 날짜 선택기, 휴대폰). 공휴일은 **빨간 날짜 숫자 + 휴일 이름 글자**로만 알린다(이름 칸이 없는 작은 달력·날짜 선택기는 마우스를 올리면 이름).

### 16.1 설정 › 날짜 & 시간 (새 탭 — 틱틱 같은 이름·같은 순서, 할 일과 외관 사이)
| 행 | 값 | 근거 |
|---|---|---|
| 일주일을 시작하는 요일 | `토요일` / `일요일`(기본) / `월요일` — 값 단추(오른쪽 회색 글자 + ⌄)를 누르면 **앱 메뉴 팝오버**(네이티브 select 아님, 지금 값에 ✓), 고르면 바로 저장·닫힘. 설명 `캘린더·작은 달력·날짜 선택기·위젯이 이 요일부터 시작해요` | [틱틱 주 시작 요일 — research 17 §2] |
| 추가 달력 | `없음`(기본) / `한국 음력` | [틱틱 Additional Calendar — 한국 음력만] |
| 주 번호 표시(W) | 스위치, 기본 끔 | [틱틱] |
| 휴일 표시 | 스위치, **기본 켬**(한국어 사용자 — [제안]) · 설명 `캘린더에 대한민국 공휴일·대체공휴일을 표시해요(2024~2030년)` | [틱틱 Show Holidays] |
- 시간대는 v1 범위 밖. 값은 `view_settings`(`calendar`) `options_json`의 `holidays`·`lunar`·`weekNumbers`·**`weekStart`**(동기화 — 휴대폰 설정 › 날짜와 시간과 같은 값, 서버 변경 없음 — JSON 키 하나라 마이그레이션 없음).
- **주 시작(`weekStart`, 2026-10-06)**: `0` = 일(없으면 이 값) · `1` = 월 · `6` = 토(JS `getDay` 번호). 계산은 공용 `@sprout/schema/weekStart`(`startOfWeek`·`weekHead`·`monthWeeksDays`·`monthGrid42`·`headTone`·`mondayOfRow`).
  - **따르는 곳**: 주·월 보기(범위·요일 머리·세로 스크롤 0번 주), 왼쪽 작은 달력, 날짜 선택기(03), 일기 미니 달력·기분 달력·이어 쓰기 7칸(15·28), 메모·수집함 `이번 주`(11·26), 맥 위젯·iOS/Android 위젯 월 칸(25·36 — 저장 파일 `calendar.weekStart`), 휴대폰 캘린더 월·일 띠·날짜 시트.
  - **따르지 않는 곳**: 성장 주(주간 목표·주간 리포트·점검 XP·작업 지도 이번 주·만료 지난주) — 서버 리포트·XP id 경계라 월요일 고정.
  - **색은 자리가 아니라 요일**: 일요일 빨강 · 토요일 파랑은 어느 열에 있든 그 날에(월요일 시작 = 끝 두 열 토·일, 토요일 시작 = 첫 두 열 토·일). 주말 표시를 끄면 토·일 열이 어디에 있든 빠진다.
  - **주 번호(W)**는 그 줄 안 월요일의 ISO 주(일요일 시작 → 다음 날, 토요일 시작 → 이틀 뒤).
  - **바로 반영**: 설정에서 바꾸면 열린 캘린더(월 보기는 그 주 시작으로 다시 만든다)·작은 달력·날짜 선택기·일기 달력·수집함 묶음이 동기화 행을 읽어 바로 다시 그린다. 위젯은 `view_settings`가 바뀌면 저장 파일을 다시 쓴다.
