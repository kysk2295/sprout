## 2. 레이아웃
```
레일 │ (왼쪽 패널 223pt, 접힘 기본) │ 캘린더
     │ ┌ 2026년 10월   ‹ ○ ›     ┐ │ ▯ 2026년 10월          [+] [주 ⌄] [‹│오늘│›] ⋯   ← 머리글 56
     │ │ 일 월 화 수 목 금 토      │ │        일     월     화 …                       ← 요일 줄 34
     │ │ (작은 달력, 이번 주 띠)    │ │       27    28    29                            ← 날짜 숫자 줄 34
     │ ├ 전체 ✓                   │ │      [막대 16pt, 줄 간격 19pt]                  ← 종일 영역(내용에 맞춰 자동)
     │ │ › 리스트 ☐               │ │ 12 PM │                                        ← 눈금 55 · 1시간 52
     │ │ › 태그 ☐                 │ │  1 PM │ [시각 태스크 = 한 줄 막대]               │
     │ └ › 캘린더 구독             │ │       │ ●──── 현재 시각(오늘 열에만)             │
```
- 레일에서 캘린더 아이콘을 누르면 **목록 사이드바·목록·상세 패널 자리를 캘린더가 통째로 쓴다** [틱틱]. 상세 패널 대신 블록 옆 팝오버로 태스크를 연다.
- 왼쪽 패널은 머리글의 `▯`로 열고 닫는다. 기본은 닫힘. 폭 **223pt** [실측].
- 창이 좁아질 때: 900px 미만이면 왼쪽 패널은 겹쳐 뜨는 서랍이 된다(01 §2와 같은 규칙) [임시]. 서랍 밖을 누르거나 작은 달력에서 날짜를 고르면 닫힌다. 머리글 제목은 줄바꿈하지 않는다. 칸 폭은 내용과 상관없이 똑같이 나눈다(가로 넘침 없음) [sprout, 2026-10-04 E2E].

## 4. 주 보기 · 일 보기 [실측]
### 4.1 구성
| 영역 | 규칙 |
|---|---|
| 요일 줄 | 높이 34, 요일 글자 11pt `color.text.tertiary` 열 가운데. 구분선 없음 |
| 날짜 숫자 줄 | 종일 영역 맨 위 34. 숫자 13pt, 왼쪽 위(왼쪽 여백 8). 오늘 = 22pt 강조색 원 + 흰 숫자. 누르면 그날 일 보기 |
| 종일 영역 | 날짜 숫자 줄 아래 막대(16pt, 줄 간격 19). **높이는 가장 많은 날의 막대 수에 맞춰 자동**(빈 주도 막대 1줄 자리는 둔다). 최대 화면의 40%, 넘치면 영역 안 스크롤. 아래 구분선 |
| 시간 눈금 | 55pt 칸. 글자 "12 PM", "1 PM", 오전은 "0 AM"~"11 AM" (**틱틱 한국어 UI 그대로 영어 표기**), 10pt 회색, 오른쪽 여백 6, 시각 선에 세로 가운데 |
| 시간 칸 | 1시간 **52pt**. 확대·축소(⌘+휠 또는 핀치) 36~120 |
| 접힌 구간 | 00:00–07:00 접기 기능은 둔다(영상 f0026). **기본은 펼침**(실제 앱 기본값) |
| 현재 시각 | **오늘 열에만** 빨간 주황 선(1.5pt) + 열 왼쪽 끝 점 8pt. 다른 열에는 선 없음 |
| 선 | 시각·열 구분선은 아주 옅게(`color.border.row`). 주말·오늘 열 배경 칠 없음 |
| 처음 스크롤 위치 | 오늘이 보이면 현재 시각 1시간 전, 아니면 오전 8시 [임시] |

## 6. 왼쪽 패널 [실측]
- 폭 223. 위: **작은 달력** — 머리 "2026년 10월 ‹ ○ ›"(머리글 높이에 맞춤), 요일 첫 글자, 날짜 칸 29×34.
  - 주 보기: **이번 주 줄 전체를 둥근 띠**로 칠함. 일 보기: 그날만. 오늘은 강조색 원.
  - **태스크가 있는 날 아래 작은 강조색 점.**
  - 날짜를 누르면 그 날짜가 들어간 범위로 이동.
- 아래: **필터.** `전체`(켜지면 강조색 글자 + 채운 체크 원) · `› 리스트 ☐` · `› 태그 ☐` · `› 캘린더 구독`. `›`를 누르면 펼쳐서 항목마다 체크칸.
  - 리스트·태그를 하나라도 고르면 "전체"가 꺼지고 고른 리스트에 속하거나 고른 태그가 붙은 태스크만 보인다 [합집합 규칙 임시]. 그룹 체크칸 = 그 그룹 전부 켜기/끄기.
  - 필터는 기기 사이 동기화한다(`view_settings`의 `calendar` 행).

## 7. 인터랙션
### 7.1 만들기 [실측 — verification/calendar-core]
| 입력 | 결과 |
|---|---|
| 일·주 시간 칸 클릭 | **시작 없는 한 시각**(15분 단위)의 태스크 초안 + 알림 "정각에". 선택 표시는 16pt 한 줄 |
| 일·주 시간 칸에서 끌기 | 시작~끝 범위. **마지막 15분 칸을 포함**한다(11:00→12:00으로 끌면 11:00–12:15). 끄는 방향과 상관없다 |
| 월 칸·종일 영역 빈 곳 클릭 | 그 날짜의 종일 태스크 초안(시각·알림 없음), 칸 옆에 팝오버 |
| 월 칸에서 여러 칸 끌기 | **아무것도 만들지 않는다**(실제 앱에서 두 번 확인) |
| 머리글 `+` | 오늘(일 보기는 보고 있는 날) 종일 초안 |
- **빠른 만들기 팝오버** (카드 400×296): 머리의 📅 강조색 날짜("오늘, 10월 3일" / "10월 12일, 오후 2:00 - 3:15")는 **누르면 03 날짜 선택기**(날짜/지속 시간)로 초안을 고친다 … ⚑ / 제목 "무엇을 하고 싶으신가요?" + 체크 항목 아이콘 / **설명** 입력 / 아래 왼쪽 리스트.
  - 저장: Enter 또는 제목을 쓴 채 바깥 클릭. Esc = 취소. 안쪽 날짜·리스트·우선순위 팝업을 다루는 동안에는 저장하지 않는다.
  - 제목·기간·반복·알림·설명을 **한 트랜잭션**으로 기록. 실패하면 입력을 그대로 두고 오류·재시도. 중복 저장 방지.
  - 위치: 주·월은 선택한 칸 옆, 일 보기의 넓은 칸에서는 칸 가운데.
  - 다른 칸을 눌러 새 초안을 열 때 앞 초안의 저장 완료가 새 팝오버를 닫지 않는다.

### 7.2 옮기기·길이 바꾸기 [틱틱 — research 10]
| 입력 | 결과 |
|---|---|
| 블록 끌기 | 시각 이동(15분 단위), 다른 날 열로 옮기면 날짜도. 끄는 동안 블록 그림자 + 시간 라벨 |
| 블록 위·아래 가장자리 끌기 (커서 ↕) | 시작·끝 바꾸기(최소 15분). 기간 없는 시각 태스크를 늘리면 기간 태스크가 된다 |
| 블록을 종일 영역으로 | 종일 태스크(시각·기간 지움, 날짜 유지) |
| 종일 막대를 시간 칸으로 | 그 시각부터 1시간 기간 태스크 |

사용자 피드백: "일정이랑 할 일을 틱틱처럼 구분해서 보여줘야지". 근거: [research 17 §13](../ticktick-research/17-calendar-live.md)(공식 도움말 2026-09 수정본 + 도움말 그림).
- **용어:** 틱틱에서 "일정" = **구독 캘린더(구글·Apple 등)에서 온 항목**뿐이다. 캘린더 보기에서 만드는 것은 전부 할 일이다. 캘린더를 하나도 연결하지 않은 계정에서는 틱틱도 모든 항목이 할 일(체크박스)이다 → sprout에서 일정이 보이려면 설정 › 연동에서 구글·Apple 캘린더를 연결한다(16 명세).

| 항목 | 규칙 | 출처 |
|---|---|---|
| 모양 | 할 일과 일정은 **같은 막대·블록 모양**(§4.2). 구분은 아이콘과 색으로만 한다 | [틱틱 도움말 Style 그림 — Task·Event 블록이 같은 모양] |
| 할 일 아이콘 | 체크박스(누르면 완료·완료 취소). §14.2 그대로 | [틱틱] |
| 일정 아이콘 | **캘린더 아이콘을 체크박스와 같은 자리·같은 크기(11)**에, 색은 체크박스 테두리와 같은 `color-mix(캘린더 색 70%, color.text.secondary)`(다크는 흰색 쪽 섞음, 지난 일정은 `color.text.tertiary`). 틱틱 그림은 옅은 채움 위 회색이지만 sprout 막대 채움(라이트 60%)이 진해서 회색은 안 보인다. 제목 앞 작은 반복 아이콘 자리가 아니다 | [틱틱 Style 미리 보기 확대] |
| 종류별 아이콘 토글 | 옵션 보기 › 스타일 › **항목 아이콘 표시** 카드 안에 종류별 토글 **할 일 · 캘린더**(틱틱 Task · Calendar. 습관·집중 기록·디데이·노트는 캘린더에 없어서 뺀다). 둘 다 기본 켬. 저장 `options_json.icons`(할 일, §14.2와 같은 키) · `options_json.calIcons`(캘린더). "상세한" 스타일은 늘 둘 다 보인다. 꺼도 ⌥ 누르는 동안 둘 다 보인다 | [틱틱 Show Item Icons 하위 화면] |
| 좁을 때 | 막대·블록 폭이 **48px보다 좁으면 체크박스·일정 아이콘을 숨기고** 제목만(틱틱 "checkbox … automatically hides when space is limited") | [틱틱] |
| 색 | 할 일 = 색상 기준(목록·태그·우선순위), 일정 = 그 캘린더 색(색상 기준과 상관없음) | [틱틱 Task Color 문단 + 16 §3.1] |
| 완료·지난 | 할 일 완료 = 옅게 + 체크된 체크박스(취소선 없음, §14.2). 일정에는 완료가 없고, 지난 일정은 옅게. "완료된 할일 보기"를 끄면 지난 일정도 숨긴다 | [틱틱 Show Completed = 태스크·습관·구독 일정] |

### 14.3.1 목록(스마트 리스트)의 일정 [틱틱 — research 17 §13.3]
- **오늘 · 다음 7일** 스마트 리스트에 보이는 기간의 일정을 함께 보인다(틱틱 "intelligently displayed in the Today, Next 7 Days smart lists"). **내일**도 같은 규칙 [임시 — 틱틱 미확인].
  - 기간: 오늘 = 오늘과 겹치는 일정, 내일 = 내일과 겹치는 일정, 다음 7일 = 오늘~6일 뒤와 겹치는 일정. 보이기로 둔 캘린더만(16 §2.2). 왼쪽 패널 구독 체크는 캘린더 보기 전용이라 목록에는 상관없다.
  - 놓는 곳: 그룹 기준이 **날짜**(스마트 리스트 기본)면 일정이 시작하는 날의 그룹(이미 시작한 여러 날 일정은 "오늘") **맨 위**에, 종일 → 시작 시각 순 [임시 — 섞는 순서는 틱틱 미확인]. 그 날짜 그룹에 할 일이 없어도 그룹을 만든다. 그룹 머리 개수에 일정도 센다. 그룹 기준이 날짜가 아니면 맨 아래 그룹 **"구독 캘린더"**에 모은다 [임시].
  - 행: 16 §2.4 사이드바 목록 행과 같다 — 체크박스 자리에 회색 캘린더 아이콘, 제목, 오른쪽 날짜(할 일 행과 같은 날짜 글자·색 규칙), 왼쪽 2pt 캘린더 색 줄. 이미 끝난 일정은 옅게.
  - 동작: 누르면 **읽기 전용 팝오버**(16 §3.3 내용, 목록 행은 넓어서 행 아래·제목 시작에 맞춰 뜬다), 우클릭 = "구글 캘린더에서 열기" 한 줄 메뉴. 선택·끌기·키보드 이동·일괄 편집·완료에 **들어가지 않는다**.
  - 사이드바 스마트 리스트 개수에는 넣지 않는다(16 §4.3 그대로) [임시 — 틱틱 미확인]. 할 일이 없고 일정만 있으면 빈 상태 그림을 보이지 않는다.
- 캘린더마다 **"캘린더에서만 보이기"**(틱틱 Show only in calendar)는 [다음] — 16 §2.2 모달에 세 번째 선택지로 더한다. 그전까지 목록에서 빼려면 "숨기기"를 쓴다.

## 14.4 제안 — 사용자 확인 전: sprout에서 일정 만들기
틱틱은 일정을 **자체로 저장하지 않는다.** 일정은 구독한 캘린더에 있고, 틱틱에서 만들거나 고치면 그 캘린더(구글·iCloud)로 양방향 동기화된다(구독 캘린더 목록의 입력창 "+ Add agenda to …"). 캘린더 보기 빠른 만들기에 "할 일/일정" 고르기가 있다는 근거는 없다(research 17 §13.1). sprout v1은 16 결정대로 구글·Apple **읽기 전용**이라 지금은 일정을 만들 수 없다.

| 안 | 내용 | 틱틱과 | 품 | 위험 |
|---|---|---|---|---|
| **A. 캘린더 연결만**(지금) | 사용자가 설정 › 연동에서 구글 또는 Apple 캘린더를 연결. 기존 일정이 캘린더 아이콘·캘린더 색으로 구분돼 보이고 오늘·다음 7일에도 나온다 | 보기는 같음, 만들기 없음 | 코드 0 | 없음 |
| **B. 구독 캘린더에 쓰기(양방향)** | 사이드바 구독 캘린더 목록에 추가 바("+ "<계정>"에 일정 추가"), 일정 팝오버에서 제목·시간 고치기·삭제, 캘린더 보기에서 일정 끌기·길이 바꾸기. 구글은 범위를 `calendar.events`(쓰기)로 넓히고, Apple은 EventKit 쓰기 권한(전체 접근)을 받는다 | **틱틱과 같음** | 구글 3~4일 + Apple 2~3일 + 구글 앱 검증 범위 변경(민감 범위 — 심사 항목 늘어남) | 사용자 캘린더를 망가뜨릴 수 있음 → 되돌리기·충돌 처리 필요. 16 결정 "읽기 전용"을 뒤집는 결정 |
| C. sprout 자체 일정 테이블 | `events` 테이블을 PowerSync로 동기화(모바일 포함), 캘린더 빠른 만들기에 할 일/일정 고르기 | **틱틱에 없는 기능**(새로 발명 — CLAUDE.md 원칙과 어긋남) | 스키마·서버·모바일까지 5일+ | 할 일과 개념이 겹쳐 사용자가 헷갈림, 외부 캘린더와 두 벌 관리 |
- **추천: 지금은 A**(연결하면 바로 틱틱처럼 구분된다), 틱틱 동급이 필요하면 **v1 다음에 B**. C는 추천하지 않는다.
