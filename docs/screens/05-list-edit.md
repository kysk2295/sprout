# 05 · 리스트·폴더·태그 관리

근거: [직접 조사](../ticktick-research/live-2026-10-03/README.md), [리스트 조사](../ticktick-research/04-lists.md), [태그 조사](../ticktick-research/12-tags.md).
2026-10-04 직접 확인한 목록 추가/편집과 컨텍스트 메뉴를 구현한다.

- 리스트 추가·편집: 이름, 이모지, 색상(없음 포함), 폴더(없음 포함), 스마트 목록 표시. 취소 시 쓰지 않고 저장 시 한 번 기록한다. sprout v1은 목록 보기와 할 일 유형만 지원하므로 다른 보기·노트 유형 선택지는 두지 않는다.
- 일반 리스트 메뉴: 편집, 상단 고정, 보관, 삭제. 공유는 v1 범위 밖. 복사는 연결 데이터 전체 복제 검증 때 추가.
- 폴더 메뉴: 목록 추가, 편집, 그룹해제. 폴더 해제는 리스트를 루트로 옮기고 폴더만 삭제한다.
- 태그 메뉴: 편집, 상단 고정, 삭제. 삭제 시 태스크는 보존하고 연결만 삭제한다.
- 삭제는 사용자 확인 모달. 리스트 삭제는 안의 태스크를 휴지통으로 보내고 리스트는 보관 상태로 남겨 태스크 복구 후 소속이 유지되게 한다([sprout] 데이터 보존 규칙).
- 보관 목록: 보관 리스트를 펼쳐 보고 복원할 수 있다. 스마트 목록·캘린더는 보관된 리스트의 태스크를 제외한다.
- 폴더 펼침/접힘, 구역 접힘은 기기에 저장. 폴더 선택은 하위 리스트 합친 화면. 접힌 폴더도 작업을 받을 수 있다.
- 상태: 이름 없음 저장 비활성, 실패는 오류 표시와 입력 유지. Esc/취소는 변경 없음. 이름/색/폴더 수정은 저장 후 즉시 사이드바 반영.
- 데이터: lists, folders, tags, task_tags, tasks. 기존 id 유지. 기본함 삭제·보관 금지.
- 검증: 추가·취소·편집·고정·보관/복구, 태그 삭제 후 태스크 보존, 폴더 해제 후 리스트 보존, 재실행 복구.

태그는 기존 Mac 관찰 `tag-edit/NOTES.md`의 부모 태그 선택을 따른다. 최대2단계, 자기 자신·하위 태그를 부모로 고를 수 없다. 부모 삭제 시 자식은 루트로 올라온다. 사이드바 자식은 들여쓴다.
