## 2. 레이아웃
### 2.1 오늘 쓰기 (E1)
| 영역 | 내용 |
|---|---|
| 머리 (52) | 오른쪽 둥근 🔍(검색) · 📅(월 달력 시트) |
| 큰 제목 (48) | **일기** |
| 세그먼트 | `쓰기 · 돌아보기` |
| 주 띠 | 7칸(폭 44): 요일(11, 3차) · 날짜(16) · 기분 색 점(6, 15 §7 색). 고른 날 = 강조색 칸 + 흰 글자. 미래 = 흐림·못 누름. 좌우로 밀면 앞뒤 주 |
| 날짜 줄 | `10월 4일 토요일 · 오늘`(17/700) · 오른쪽 🔒(나만 보기) · `⋯` |
| 기분 | 원 46 × 5(😢 😕 😐 😊 🤩), 고른 것 강조색 테두리 + 연한 면 + 옆 말(`좋았어요`, 강조색) |
| 오늘의 질문 | `? Q. 오늘 가장 뿌듯했던 순간은?` + 오른쪽 `다른 질문`(빈 날에만, 15 §3) |
| 글 | 17/28, 그냥 글자, 0.6초 뒤 자동 저장, 자리 글자 `오늘 하루는 어땠나요?` |
| 오늘 한 일 줄 | 회색 줄(모서리 12): ✓ `오늘 한 일 6개` + `+6 XP` 알약 + `›` (15 §3, 할 일 XP만) |
| 캐릭터 첫 답 칸 | 카드: 캐릭터 얼굴(40) · 3차 `도토리` · 첫 답 두 줄 말줄임 · 오른쪽 `이야기하기`(강조색). 첫 답 전이면 칸 없음, AI 꺼짐이면 15 v0.1 카드(미리 준비한 한마디) |
| 바닥 줄 (34) | 🔥 `4일 연속 기록` … 오른쪽 `오후 11:02 · 자동 저장됨` (나만 보기 날은 `🔒 이 날은 AI가 읽지 않아요`) |
| 탭 알약 | 더보기 선택 |
- 키보드가 올라오면 주 띠·세그먼트가 접히고(스크롤) 글이 키보드 위까지 차지한다.

### 2.2 캐릭터와 이야기 (E2, 밀려 들어옴, 탭 알약 숨김)
| 영역 | 내용 |
|---|---|
| 머리 | 둥근 `‹` · 가운데 캐릭터 얼굴(28) + `도토리와 이야기` · 둥근 `⋯`(기억하기 켬/끔 · 오늘은 혼자 쓸게 · 이 날 대화 지우기) |
| 일기 접힘 줄 | 회색 줄: 기분 얼굴 + 일기 첫 줄 말줄임 + `⌄`(누르면 펼쳐 전체 글) |
| 말풍선 | 캐릭터 = 왼쪽 작은 얼굴(30) + 카드색 면(모서리 16/16/16/4) · 나 = 오른쪽 강조색 연한 면(16/16/4/16), 15.5/22 |
| 할 일로 칩 | 말풍선 안 아래 강조색 테두리 알약 `＋ 할 일로: 면담용 차별점 한 장 정리` |
| 한계 안내 | 입력창 위 3차 `도토리는 친구처럼 들어 주지만 전문 상담은 아니에요` (처음 몇 번만, 15 §3.1) |
| 입력창 | 키트 둥근 입력, 자리 글자 `도토리에게 이야기하기…`, 보내기 원 |

- **종이 페이지**: 모서리 14, 그림자, 바탕 `--diary-paper`와 같은 계산(라이트 = 앱 바탕 92% + #f3e6cf, 다크 = 카드 94% + #3a3226, 트루 블랙 #0d0d0d). 맨 위 **하늘 띠 76**(오늘 = 시간대 하늘, 라이트 계열의 밤은 옅은 밤색, 지난 날 = 그날 기분 색 → 종이), 날짜 숫자 44/800 + `10월 · 월요일` + `오늘` 칩 + `오전 12:35 · 저장됨 ✓`. 오른쪽 위 **책갈피 = 나만 보기**(켜짐 강조색 + 닫힌 자물쇠).

### 8.8 완료 기준 (시안과 나란히, 라이트·다크·360)
- [ ] 오늘 일기를 열면 머리 한 줄 + 인사 + 기분 얼굴 5개가 첫 화면에 있고, 인사의 할 일 수가 오늘 탭과 같다.
- [ ] 기분 → 질문 3개 → 초안 → 저장이 칩만으로 6번 누르기 안에 끝난다. 직접 쓴 답이 초안에 글자 그대로 들어간다(건너뛴 질문은 빠짐).
- [ ] 입력창·빠른 답이 키보드 바로 위에 붙고, 키보드를 끌어 내리면 같이 내려간다. 누르는 것은 모두 44pt 이상.
- [ ] 동의 전·혼자 쓰기·나만 보기에서 `/ai/diary` 호출 0(시험 `mayCallAi`). 동의 카드는 첫 저장 뒤 한 번만.
- [ ] 다듬어 줘가 하루 3번을 넘으면 서버 429 → `오늘은 다 썼어요`. `원래대로`로 처음 초안이 돌아온다.
- [ ] 저장 뒤 첫 답은 일기에 있는 말만 짚는다(시험 문장 3개로 확인, §8.1-7).
- [ ] 화면을 밀어 전날·다음 날, 지난 날은 저장 카드 + 접힌 대화, 빈 지난 날은 그날 기준 질문으로 대화.
- [ ] 기분 달력: 칸 얼굴 = 그날 기분, 칸 누름 = 그날, 이번 달 기분 개수 = 칸 수, 연속 숫자 없음. 데스크톱 같은 날과 기분·글이 같다.
- [ ] 캐릭터는 한 번에 하나만 움직이고(마지막 말), 움직임 줄이기에서 멈춘다. 정원 친구 4종 모두 이름·조사(와/과, 가/이)가 맞다.
