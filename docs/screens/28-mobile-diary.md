## 2. 레이아웃
### 2.1 오늘 쓰기 (E1)
| 영역 | 내용 |
|---|---|
| 머리 (52) | 오른쪽 둥근 🔍(검색) · 📅(월 달력 시트) |
| 큰 제목 (48) | **일기** |
| 세그먼트 | `쓰기 · 돌아보기` |
| 주 띠 | 7칸(폭 44): 요일(11, 3차) · 날짜(16) · 기분 색 점(6, 15 §7 색). 고른 날 = 강조색 칸 + 흰 글자. 미래 = 흐림·못 누름. 좌우로 밀면 앞뒤 주 |
| 날짜 줄 | `10월 4일 토요일 · 오늘`(17/700) · 오른쪽 🔒(나만 보기) · `⋯` |
| 기분 | 원 46 × 5(😢 😕 😐 😊 🤩), 고른 것 강조색 테두리 + 연한 면 + 옆 말(`좋았어요`, 강조색) |
| 오늘의 질문 | `? Q. 오늘 가장 뿌듯했던 순간은?` + 오른쪽 `다른 질문`(빈 날에만, 15 §3) |
| 글 | 17/28, 그냥 글자, 0.6초 뒤 자동 저장, 자리 글자 `오늘 하루는 어땠나요?` |
| 오늘 한 일 줄 | 회색 줄(모서리 12): ✓ `오늘 한 일 6개` + `+6 XP` 알약 + `›` (15 §3, 할 일 XP만) |
| 캐릭터 첫 답 칸 | 카드: 캐릭터 얼굴(40) · 3차 `도토리` · 첫 답 두 줄 말줄임 · 오른쪽 `이야기하기`(강조색). 첫 답 전이면 칸 없음, AI 꺼짐이면 15 v0.1 카드(미리 준비한 한마디) |
| 바닥 줄 (34) | 🔥 `4일 연속 기록` … 오른쪽 `오후 11:02 · 자동 저장됨` (나만 보기 날은 `🔒 이 날은 AI가 읽지 않아요`) |
| 탭 알약 | 더보기 선택 |
- 키보드가 올라오면 주 띠·세그먼트가 접히고(스크롤) 글이 키보드 위까지 차지한다.

### 2.2 캐릭터와 이야기 (E2, 밀려 들어옴, 탭 알약 숨김)
| 영역 | 내용 |
|---|---|
| 머리 | 둥근 `‹` · 가운데 캐릭터 얼굴(28) + `도토리와 이야기` · 둥근 `⋯`(기억하기 켬/끔 · 오늘은 혼자 쓸게 · 이 날 대화 지우기) |
| 일기 접힘 줄 | 회색 줄: 기분 얼굴 + 일기 첫 줄 말줄임 + `⌄`(누르면 펼쳐 전체 글) |
| 말풍선 | 캐릭터 = 왼쪽 작은 얼굴(30) + 카드색 면(모서리 16/16/16/4) · 나 = 오른쪽 강조색 연한 면(16/16/4/16), 15.5/22 |
| 할 일로 칩 | 말풍선 안 아래 강조색 테두리 알약 `＋ 할 일로: 면담용 차별점 한 장 정리` |
| 한계 안내 | 입력창 위 3차 `도토리는 친구처럼 들어 주지만 전문 상담은 아니에요` (처음 몇 번만, 15 §3.1) |
| 입력창 | 키트 둥근 입력, 자리 글자 `도토리에게 이야기하기…`, 보내기 원 |

### 2.3 위기 안내 카드 (E3, 대화 안)
| 영역 | 내용 |
|---|---|
| 카드 | 대화 열 폭, 모서리 16, 빨강 옅은 테두리·면(`color.danger` 35% / 6%, 다크 10%) |
| 머리 | 캐릭터(44, 졸린 얼굴 = 걱정) + `지금 많이 힘들구나. 혼자 견디지 않아도 돼.`(17/700) |
| 설명 | `지금 바로 이야기 들어 줄 사람과 연결할 수 있어. 전화는 무료고 24시간 받아.` |
| 번호 줄 ×2 | 흰 칸(모서리 12): 큰 번호(18/700) + 설명(12.5) + 오른쪽 원 40 전화 버튼 — **109** 자살예방상담전화 · 24시간(초록) / **112 · 119** 위험한 상황이면 지금 바로(빨강) |
| 끝 줄 | 3차 `도토리는 상담사가 아니라서 진단이나 치료 이야기는 할 수 없어. 그래도 여기 있을게.` |
| 입력창 | 자리 글자 `천천히 이야기해도 괜찮아…` (M-D5) |

### 2.4 돌아보기 (E4)
| 영역 | 내용 |
|---|---|
| 머리·세그먼트 | 쓰기와 같음, 세그먼트 `돌아보기` |
| 달 줄 | 둥근 없는 `‹` `2026년 10월`(17/700) `›` · 오른쪽 작은 세그먼트 `월 · 연` |
| 월 달력 | 7열, 칸 높이 52, 모서리 10: 기분 얼굴(21) + 날짜(11). 오늘 = 강조색 테두리, 미래 = 흐림, 빈 칸 = 바탕 |
| 숫자 카드 | 2칸: `4일 · 이번 달 기록` · `🔥 4일 · 연속 기록` |
| 기분 비율 | 막대(9) + 범례 `😊 2 · 🙂 1 · 😐 1` |
| 한 줄 발견 | 스크롤 아래 카드(15 §7 조건) |
| 연 보기 | 12개월 작은 칸 3열(칸 = 기분 색 점) — Daylio Year in Pixels와 같은 생각 |

## 3. 구성 요소와 상태
| 상태 | 표시 |
|---|---|

| 나만 보기 날 | 🔒 강조색, 첫 답 칸 숨김, 바닥 줄 문구 바뀜 |

| AI 없음 | 칸에 `지금은 도토리가 쉬고 있어요. 일기는 그대로 저장돼요` + 다시 시도 |
| 위기 신호 | 앱 단어 검사(AI 부르기 전) 또는 모델 `[[SAFETY]]` → 평소 답 대신 위기 카드(E3), `diary_messages.safety=1` |
| 지난 날 | 주 띠·달력에서 고르면 그날(쓸 수 있음), 일기 없는 날 = 빈 편집기 + 그날 한 일 줄 |
| 빈 일기장 | 캐릭터 + `오늘 하루를 한 줄로 남겨 볼까요?` |
| 오프라인 | 쓰기·기분·달력 그대로(로컬). 대화는 `지금은 도토리가 쉬고 있어요…` |

### 7.2 15 §9 디자인 맞춤(휴대폰 배치)
- **종이 페이지**: 모서리 14, 그림자, 바탕 `--diary-paper`와 같은 계산(라이트 = 앱 바탕 92% + #f3e6cf, 다크 = 카드 94% + #3a3226, 트루 블랙 #0d0d0d). 맨 위 **하늘 띠 76**(오늘 = 시간대 하늘, 라이트 계열의 밤은 옅은 밤색, 지난 날 = 그날 기분 색 → 종이), 날짜 숫자 44/800 + `10월 · 월요일` + `오늘` 칩 + `오전 12:35 · 저장됨 ✓`. 오른쪽 위 **책갈피 = 나만 보기**(켜짐 강조색 + 닫힌 자물쇠).
- **기분 = 캐릭터 화풍 얼굴 5개**(40, 고른 것 1.12배 + 기분 색 링 + 아래 라벨, 나머지는 바랜 색). 다시 누르면 해제.
- **질문 쪽지**(빈 페이지만, 노란 쪽지 −1°): `이 질문으로 쓰기` · `다른 질문 ↻`.
- **줄 노트** 16/28, 0.6초 자동 저장. **오늘 한 일 = 타임라인**(15 §9.5: 시간 · 점 · 제목, 3개 + `＋ N개 더`, 행 누름 = 할 일 상세 시트). 28 §4의 "완료 목록 시트" 대신 15 §9.5처럼 페이지 안에서 펼친다.
- **캐릭터 칸**(페이지 아래 카드 = 15의 곁자리를 휴대폰에 맞춘 것): 캐릭터 56(숨쉬기, 기분 반응 깡충 + 말풍선 2.6초, 나만 보기 = 눈 감음) + 상태별 내용 — 동의 안 함 카드·나만 보기·오늘은 혼자·10자 미만·읽는 중(대기열 위치)·쉬는 중 + 다시 시도·첫 답 미리보기·**위기 카드**.
- **위기 카드 = 차분한 라벤더**(15 §9.4, E3의 빨간 테두리 대신 `--diary-calm` 색), 109 줄이 가장 진함, 번호는 선택 가능한 글자, 희망 문구, 움직임 없음, `accessibilityRole=alert`.
- **바닥 줄**: 새싹 잎 + `N일째 이어 쓰는 중 · 오늘도 이어 가요` … `도토리만 같이 읽어요` / `🔒 이 날은 AI가 읽지 않아요` / `일기는 나만 봐요`.
- **돌아보기**: 이번 달 한 장(하늘 + 땅 + 캐릭터 + 한 줄 발견 말풍선 + 칩 `기록 N일 · 지금 N일 연속 · 가장 길게 N일 · 평균 기분 얼굴`) → 기분 달력(칸 52, 기분 색 20% + 얼굴, 오늘 링, 안 쓴 지난 날 점선, 미래 흐림) → 숫자 카드 2개 → 기분 비율 막대 + 얼굴 범례 → 기억에 남는 날(나만 보기 제외) / `연` = **12줄 × 31칸 모자이크**(칸 = 그날, 달 이름 = 월 보기).
- **동의**: 아래 시트(캐릭터 96 + 사실 3줄 + 한계 문구 + [혼자 쓸게요] [나누기]). ⋯ 메뉴에서 켬/끔.
- **움직임 줄이기**: OS 동작 줄이기 또는 성장 `sprout.growthMotion=reduce`(읽기만) → 숨쉬기·깡충·말풍선 튕김 없음, 페이드만. 위기 카드는 늘 움직임 없음.
