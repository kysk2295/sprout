## 2. 레이아웃
### 2.1 오늘 쓰기 (E1)
| 영역 | 내용 |
|---|---|
| 머리 (52) | 오른쪽 둥근 🔍(검색) · 📅(월 달력 시트) |
| 큰 제목 (48) | **일기** |
| 세그먼트 | `쓰기 · 돌아보기` |
| 주 띠 | 7칸(폭 44): 요일(11, 3차) · 날짜(16) · 기분 색 점(6, 15 §7 색). 고른 날 = 강조색 칸 + 흰 글자. 미래 = 흐림·못 누름. 좌우로 밀면 앞뒤 주 |
| 날짜 줄 | `10월 4일 토요일 · 오늘`(17/700) · 오른쪽 🔒(나만 보기) · `⋯` |
| 기분 | 원 46 × 5(😢 😕 😐 😊 🤩), 고른 것 강조색 테두리 + 연한 면 + 옆 말(`좋았어요`, 강조색) |
| 오늘의 질문 | `? Q. 오늘 가장 뿌듯했던 순간은?` + 오른쪽 `다른 질문`(빈 날에만, 15 §3) |
| 글 | 17/28, 그냥 글자, 0.6초 뒤 자동 저장, 자리 글자 `오늘 하루는 어땠나요?` |
| 오늘 한 일 줄 | 회색 줄(모서리 12): ✓ `오늘 한 일 6개` + `+6 XP` 알약 + `›` (15 §3, 할 일 XP만) |
| 캐릭터 첫 답 칸 | 카드: 캐릭터 얼굴(40) · 3차 `도토리` · 첫 답 두 줄 말줄임 · 오른쪽 `이야기하기`(강조색). 첫 답 전이면 칸 없음, AI 꺼짐이면 15 v0.1 카드(미리 준비한 한마디) |
| 바닥 줄 (34) | 🔥 `4일 연속 기록` … 오른쪽 `오후 11:02 · 자동 저장됨` (나만 보기 날은 `🔒 이 날은 AI가 읽지 않아요`) |
| 탭 알약 | 더보기 선택 |
- 키보드가 올라오면 주 띠·세그먼트가 접히고(스크롤) 글이 키보드 위까지 차지한다.

### 2.2 캐릭터와 이야기 (E2, 밀려 들어옴, 탭 알약 숨김)
| 영역 | 내용 |
|---|---|
| 머리 | 둥근 `‹` · 가운데 캐릭터 얼굴(28) + `도토리와 이야기` · 둥근 `⋯`(기억하기 켬/끔 · 오늘은 혼자 쓸게 · 이 날 대화 지우기) |
| 일기 접힘 줄 | 회색 줄: 기분 얼굴 + 일기 첫 줄 말줄임 + `⌄`(누르면 펼쳐 전체 글) |
| 말풍선 | 캐릭터 = 왼쪽 작은 얼굴(30) + 카드색 면(모서리 16/16/16/4) · 나 = 오른쪽 강조색 연한 면(16/16/4/16), 15.5/22 |
| 할 일로 칩 | 말풍선 안 아래 강조색 테두리 알약 `＋ 할 일로: 면담용 차별점 한 장 정리` |
| 한계 안내 | 입력창 위 3차 `도토리는 친구처럼 들어 주지만 전문 상담은 아니에요` (처음 몇 번만, 15 §3.1) |
| 입력창 | 키트 둥근 입력, 자리 글자 `도토리에게 이야기하기…`, 보내기 원 |

### 8.9 구현 메모 (2026-10-09)
**명세와 달라진 점(구현하며 고침):**
- **정해진 질문·답 저장 = `diary_messages.safety = 2`**(§8.6은 "role buddy/me로 저장 + AI 입력에도 그대로"였다). 스키마 그대로(마이그레이션 없음) — 데스크톱은 이미 `safety≠0` 행을 보이지도 AI에 보내지도 않으므로, 데스크톱 대화 칸에는 AI 대화만 보이고 글(초안)은 같은 `diary_entries.content`로 보인다. **AI 입력 = 일기 글 + AI 대화(safety 0)뿐** — 정해진 질문·답은 이미 글에 들어 있고, 정해진 말로 끝나는 대화를 보내면 모델이 이어 쓰기를 한다. 환각 줄이기(§8.1-7)와 같은 방향.
- 인사·첫 답 전 대화는 **첫 답을 고를 때 한 번에** 저장한다(열기만 한 날에 빈 일기 행을 만들지 않게). 단계는 저장된 내 답 개수로 다시 만든다(0 기분 · 1~3 질문 · 4 초안) — 앱을 닫았다 열어도 같은 자리.
- 기분 대신 글로 답하면(입력창) 기분 없음 + 그 글이 초안 첫 줄, 반응 `그렇구나, 들려줘서 고마워.` → 질문 1.
- 저장 뒤 첫 답은 **저장 직후(또는 동의 카드에서 나누기)에만 저절로** 부른다. 예전에 쓴 날·그냥 쓰기로 쓴 날을 대화로 열면 칩 `느리가 읽고 답해 주기`(열기만 해서 AI를 부르지 않게).
- 그냥 쓰기 머리 `‹`는 대화로가 아니라 일기 밖으로(그냥 쓰기를 기본으로 고른 사람이 갇히지 않게). 대화로 = 도구 막대 💬 · ⋯ `대화로 쓰기`.
- 처음부터 다시 묻기 = 정해진 행만 지움(저장 전에만 ⋯에 보임). 고치기(저장 뒤) = 글만 다시 저장, 정해진 한 줄·첫 답은 다시 안 함.
- `이번 주를 한 줄로 남기기` = 오늘을 그냥 쓰기로 열고 `Q. 이번 주를 한 줄로 남긴다면?` 줄을 넣는다(시안은 토스트만).
- 다듬어 줘는 서버 `/ai/status`의 `usage.daily['diary-polish']`가 있을 때만 보인다 — **배포 전 서버에서는 버튼이 없다**(예전 서버가 `mode`를 모르고 보통 답으로 처리하면 상한 밖 호출이 되므로). 429 `daily` → `오늘은 다 썼어요`.
- 그날 할 일 수(인사): total = 그날 마감인 열린 할 일(오늘 탭 범위·스마트 목록에 보이는 리스트) + 그날 끝낸 할 일, done = 그날 끝낸 할 일. 칩 = 그날 끝낸 제목 최근 2개 · 다음 날 마감 제목 2개(우선순위 순).

| 대화는 질문지가 아니라 메신저로 친구에게 하듯 | 정해진 인사(시간대 + 그날 할 일) → 기분 빠른 답 → `무슨 일 있었어? 편하게 말해 줘. 한 줄도 괜찮아.` → 자유 입력. 캐릭터 답 = `/ai/diary {mode:'chat'}` |

**흐름(`Conversation.tsx`):**
1. 인사 + 기분(처음 쓰는 기기는 소개 한 줄 `안녕, 나는 느리야. 오늘 하루를 편하게 이야기해 줘. 같이 일기로 남겨 줄게.`).
2. 동의 전이면 기분 바로 뒤 대화 안 카드 `느리와 편하게 이야기하고 일기로 정리할까?` + `대화를 일기로 정리하려면 꿈틀 AI가 읽어야 해요.` [혼자 쓸게요] [나누기] — 열 때 시트·첫 저장 뒤 카드·다듬기 시트는 없앴다.
3. 나누기 = 자유 대화(위 표). 혼자 쓰기·나만 보기·이 날은 혼자 = 정해진 질문 3개 → 내 말 그대로 초안(AI 0, §8.3 그대로).
4. 초안 카드: 기분 얼굴 · 제목 · 태그 · 본문(눌러서 고침) · 작은 줄(`내가 한 말로 정리했어요. 느리의 말과 조언은 넣지 않았어요 · 오늘 정리 N번 남음`) · [다시 정리](AI, 내 말 그대로였으면 `다듬어 줘`) [대화 그대로] [더 이야기] … [저장]. 옮기기가 실패하면 한 번 다시, 그래도 안 되거나 한도면 내 말 그대로(토스트).
5. 저장 → 정해진 한 줄 → [더 이야기하기 / 하나 더 남기기] [오늘은 여기까지]. 저장한 편 카드는 그 저장 한 줄 앞에(대화 없이 쓴 편은 맨 위), `고치기` = 그 편만.
- 지난 날 카드(`PastDay`)는 편마다 시각·제목·태그·본문. 그냥 쓰기는 글 전체(머리·태그 줄 포함)를 그대로 고친다. 데스크톱도 같은 흐름·같은 편 보기([15 §10](15-diary.md), 2026-10-09).

### 8.11 v2.2 — 글이 흘러나오고, 기다리는 동안 생각하는 얼굴 (2026-10-09, 사용자 "글자 흘러나오게 하고 생각하는 표정도 넣어줘")
- **실측(Mac mini 서버, Funnel 거쳐, qwen3.5:9b):** 서버·앱은 이미 `stream:true` NDJSON을 줄 단위로 넘기고 있었다(토큰 64조각이 8초 동안 도착). 사람이 느낀 "한꺼번에"는 **첫 글자까지 6~12초**(프롬프트 읽기) 동안 점 세 개만 있고, 글이 네트워크 조각(약 140ms)마다 툭툭 붙고, 옮기기(약 27초)는 끝날 때까지 아무것도 안 보여서다. → 서버는 그대로(배포 없음), 앱만 바꾼다.
- **기다림(첫 글자 전):** 캐릭터 말풍선 하나 = 얼굴 `think`(40 §6) + 좌우 3° 흔들림 1.4초(40 §7, 발밑 기준) + `음…` + 점 세 개. 서버 대기열이면 `차례를 기다리는 중… (앞에 N명)`. 지난 말의 얼굴은 멈춤(움직이는 캐릭터는 하나).
- **받는 중:** 첫 글자가 오면 **같은 말풍선**이 글로 바뀐다(새 줄이 생기지 않음). 얼굴 `smile`(말하는 중, 숨쉬기), 흔들림 멈춤. 글은 네트워크 조각이 아니라 **프레임마다 조금씩** 드러낸다 — 밀린 글을 시간 상수 180ms로 따라잡되(밀린 만큼 빨리, 한 덩어리 40자 ≈ 0.5초) 최소 초당 40자(`revealNext`, 공용). 휴대폰은 30fps(33ms)로 묶는다.
- **다 받으면:** 드러내기가 끝난 뒤(최대 0.8초) 대화 행으로 저장 → 같은 자리에 같은 모양으로 바뀐다(깜빡임 없음 — 저장된 행이 보일 때 받는 말풍선을 내린다). 답이 따뜻하면(고마워·다행·잘했·수고·좋았·멋지·기뻐·축하) 마지막 얼굴 `happy`, 아니면 기분 얼굴 그대로(`replyFaceOf`).
- **움직임 줄이기:** 흔들림·점 움직임 없음(얼굴만 `think`), 글은 받은 조각 그대로(프레임 드러내기 없음).
- **스크롤:** 맨 아래 64px 안에 있으면 따라 내려간다. 위로 올려 지난 말을 읽는 중이면 멈추고, 다시 맨 아래로 오면 다시 따라간다. 내가 보내면 늘 맨 아래로.
- **멈추기:** 받는 중에는 입력창 보내기 자리가 ■(멈추기). 누르면 스트림을 끊는다(서버가 Ollama까지 멈추고, 그 1회는 상한에서 돌려준다 — 기존 규칙). 받은 글은 흐린 말풍선으로 남고 그 아래 `멈췄어.` + 칩 `다시 시도`. 받은 글은 **저장하지 않는다**(대화 행 아님) — 다시 시도하면 그 자리에서 새로 받고, 다른 말을 보내면 사라진다.
- **중간 오류(연결 끊김·시간 초과):** 받은 글은 남기고 얼굴 `sleepy` + `연결이 끊겼어.` + `다시 시도`. 첫 글자 전 오류는 지금 카드(`지금은 …가 쉬고 있어요` + 다시 시도) 그대로.
- **일기로 옮기기(distill) — 결정:** 서버 형식은 그대로 JSON `{title, tags, entry}`(서버 스키마·예전 앱 호환, 본문 먼저 + JSON 꼬리 방식은 서버 계약을 바꿔야 해서 안 함). 앱은 JSON을 화면에 내지 않고, 받는 중인 JSON에서 **제목·본문 글만 뽑아**(`partialDistill`, 공용) `옮기는 중` 카드에 보여 준다:
  - 첫 조각 전: 카드 머리 = 캐릭터 `think`(흔들림) + `일기로 옮기는 중…` + 아래 2px 진행 줄(좌→우로 흐르는 띠, transform만, 움직임 줄이기면 멈춘 띠) + `${이름}의 말은 빼고 내 말로 옮기고 있어`.
  - 제목이 오면 제목, 본문이 오면 본문이 같은 방식으로 흘러나온다. 태그는 끝나고 초안 카드에서.
  - 끝: `parseDistill`로 확정 → 진짜 초안 카드(고치기·태그·저장)로 바뀐다(정리 규칙으로 캐릭터 문장·날짜 머리가 빠져 글이 조금 달라질 수 있음). 모양이 틀려 한 번 더 물으면 카드를 비우고 `한 번 더 옮기는 중…`.
  - 자리: 휴대폰 = 대화 안(초안 카드 자리), 데스크톱 = 초안이 나올 자리(넓은 창은 오른쪽 열, 좁은 창은 대화 안) + 대화에는 생각 말풍선만.
  - 멈추기(■ 또는 카드의 `멈추기`) = 옮기기 취소 → 다시 정리 중이었으면 앞 초안 그대로, 처음이었으면 대화로.
- **성능(39 §11):** 받는 글은 작은 저장소(`createTextStream`, 공용) 하나에 두고 **받는 말풍선(또는 옮기는 중 카드) 하나만** 다시 그린다. 대화 화면 전체는 상태가 바뀔 때만(기다림 → 첫 글자 → 끝·멈춤·오류, 대기열 숫자) 다시 그린다. 움직임은 transform·opacity만.
- **서버:** 바뀐 것 없음 — `/ai/diary {mode:'chat'|'distill', stream:true}` = NDJSON(대기열 줄 → Ollama 줄 → 오류면 `{"error","code"}`), `stream` 없으면 예전처럼 JSON 한 번(예전 앱). 상한은 요청마다 한 번, 사용량(토큰·시간)은 끝 줄에서, 끊으면 Ollama까지 멈추고 돌려줌. 시험(`ai.test.ts`)에 일기 대화·옮기기 스트림 모양을 더했다.
- 완료 기준: ① 보내면 바로 `음…` 생각 말풍선(think + 흔들림) ② 첫 글자부터 같은 말풍선에서 부드럽게 흘러나옴 ③ 다 받으면 깜빡임 없이 대화 행 ④ ■로 멈추면 받은 글 + `다시 시도` ⑤ 위로 올려 읽는 중엔 끌려 내려가지 않음 ⑥ 옮기기: 생각 얼굴 + 진행 줄 → 제목·본문이 흘러나옴 → 초안 카드 ⑦ 움직임 줄이기 ⑧ 받는 동안 대화 목록이 다시 그려지지 않음(받는 말풍선만).
- 구현·실측(2026-10-09): 데스크톱 Electron + 휴대폰 시뮬레이터 Release, Mac mini 서버. 데스크톱 생각 말풍선 7.4초 → 글 7초 동안 흘러나옴 → 행(중복·깜빡임 없음), 옮기기 제목 8.3초·초안 17.7초, ■ 멈추기 → 받은 글 + `다시 시도` → 다시 받음, 위로 올려 읽는 중엔 안 끌려감. 휴대폰 첫 글자까지 약 20초(대화가 길면 프롬프트가 길어짐 — 생각 얼굴이 그 시간을 채움), 옮기기 첫 답 모양이 틀려 `한 번 더 옮기는 중…`으로 다시 받음. 코드: 공용 `diaryTalk.ts` 끝, 데스크톱 `components/diary/Stream.tsx`, 휴대폰 `src/diary/Stream.tsx`.

### 9.2 혼자 쓰기 규칙
- **AI 0회.** 혼자 쓴 장은 어디로도 보내지 않는다. 예외는 ⋯ `느리에게 보여 주기`를 누른 그 장 하나.
- **임시 저장:** 입력이 멈추고 1초 뒤 기기에(`diary-draft-<날짜>`, 기기 저장소 — 동기화 안 함). 저장 전에 나가거나 앱이 꺼져도 다음에 같은 날 혼자 쓰기를 열면 이어서. 저장하면 지운다.
- **저장:** 본문·제목이 모두 비면 단추 흐림. 누르면 `appendSection`으로 그날 글 끝에 새 장(앞 장을 덮지 않음) → 키보드 내림 → M. 기분을 골랐으면 그날 `mood`를 이 값으로.
- **고치기:** 그 장만 같은 메모장으로 열어 저장 = 그 장 자리에서 바꿈(시각 그대로).
- **전환:** 대화 중 ✎ → 대화는 그대로 남고(옮기기 전이면 G의 5분 규칙대로), 혼자 쓴 글은 별도 장. 혼자 쓰는 중 💬 → 임시 저장 후 대화로.
- 지난 날: 기록에서 빈 날 → `그날 이야기 하기` · `혼자 쓰기` 둘.

### 9.4 인터랙션·시간
- 기분 120ms, 보내기 반응 ~300ms(기기), 첫 글자 6~20초(AI), 답 끝 +0.8초, 종이로 접힘 0.4초, 대화↔혼자 전환 0.3초. 움직임 줄이기면 접힘·끄덕·깡충 없음.
- 화면 오른쪽 밀기 = 전날(대화·혼자 같음). 혼자 쓰기 본문에서 아래로 끌면 키보드 내림.
- 새벽 4시 전 = 전날 일기(인사 `늦게까지 수고했어. 어제 이야기 마저 할까?`).
- 시간대 장면: 5–10 dawn · 10–17 day · 17–21 dusk · 21–5 moon(`SCENE_EDGE`·`sceneGlass` 재사용).

### 9.6 완료 기준 (시안 diary-v6과 나란히, 라이트·다크·360)
1. 일기 탭을 열면 0초에 인사 + 기분 5개, 기분만 누르고 나가도 그날 기분이 달력에 보인다.
2. 보내면 0.3초 안에 하트·끄덕·생각 얼굴, 그 뒤 답이 흘러나온다.
3. `여기까지` 또는 앱을 떠난 뒤 5분 → 다음에 열면 종이 한 장이 저장돼 있다(저장 단추 없음).
4. 머리 ✎ → 메모장이 커서·키보드가 올라온 채 열린다. 쓰다가 앱을 꺼도 다시 열면 글이 남아 있다.
5. 저장 → 그날 장 목록에 ✎ 장이 생기고, 앞 장(대화)은 그대로다. 고치기 → 같은 자리에서 바뀐다.
6. 혼자 쓰기 동안 서버로 일기 요청이 0건이다(네트워크 기록으로 확인).
7. 다음에 일기 탭을 열면 마지막에 쓴 방식으로 열린다.
8. 알림의 기분 단추·바로 답장이 앱을 열지 않고 기록되고, 알림에 일기 내용·할 일 제목이 없다.
9. AI가 꺼진 상태에서도 대화 → 일기 한 장(내 말 그대로)까지 끝난다.

### 9.8 구현 메모 (2026-10-13, 휴대폰 — iOS 시뮬레이터 Release + Mac mini 서버로 확인)
- **혼자 쓰기(K·L·M):** `src/diary/SoloWrite.tsx`(메모장·임시 저장 = 기기 파일 `diary-draft-<날짜>`), 그날 장 목록 = `PastDay.tsx`(오늘도). 장 머리 `## 21:18 ✎ — 제목`(schema `parseSections`/`formatSection` + 시험). 확인: ✎ → 커서 → 기분·한 일·시각 넣기 → 저장 → ✎ 장 카드 · 고치기(같은 자리) · 혼자 이어 쓰기.
- **대화(C~H·J):** `Conversation.tsx` 다시 씀 + `Scene.tsx`(장면·받침 위 캐릭터·끄덕·깡충). 확인: 처음 고르기 카드 → 이야기 → 보내자마자 💚 + 끄덕 → 생각 얼굴 → 답 흘러나옴 → 두 번 주고받은 뒤 `여기까지 ✓` → 옮기는 카드 → **자동 저장된 종이 카드**(제목·태그·다시 옮기기·고치기) → 저장 한 줄 + 깡충 → `더 이야기하기 / 오늘은 여기까지`.
  - 명세와 다른 점: 키보드가 오르면 캐릭터는 왼쪽 위가 아니라 **받침 위에서 작게(72)** — AI 비서 채팅과 같은 규칙으로 맞췄다. 🎙 단추는 따로 두지 않고 **키보드의 받아쓰기**를 쓴다(기기 안 처리, 같은 효과). 막힐 때 질문은 **두 번 주고받기 전까지만**(계속 물으면 숙제 같아서, 시뮬레이터에서 매 답마다 질문이 붙는 것을 보고 줄임).
  - 반응 낱말(`reactionOf`): 힘든 말 🫂(충격·답답·서운 등 포함), 좋은 말 💚, 그 밖 ✨ — 기분 1~2면 🫂 쪽.
  - 자동 마무리: 열린 동안 마지막 말 5분 뒤 · 다시 열었을 때 이미 5분 지났으면 바로 · 화면을 떠나면 남은 시간 뒤 화면 밖(`data.autoFinish`, 앱이 켜져 있는 동안). 끝 말까지 남기고 앱이 꺼졌으면 다음에 열 때 이어서 저장.
  - AI 쉼: 받기 시작 전 오류·한도 = 정해진 공감 말(`localReplyOf`, 결 3가지 × 5문장)로 이어 가고, 끝은 내 말 그대로. 받다가 끊기면 지금처럼 `다시 시도`.
  - 일기 머리가 장면 윗줄 색 위에 놓이고(띠 없음) 상태 막대 글자도 장면 밝기로.
- **저녁 알림(A):** `src/notifications/diary.ts` — 카테고리 `sprout-diary` = **답장(글) · 😊 좋았어 · 😣 힘들었어**(안드로이드 단추 3개 한도라 명세의 기분 3개 → 2개). 알림 하나만 예약(다시 계산 때마다), 그날 썼으면 다음 날, 3일 그냥 지나가면 수·일만. 답장 = 질문(정해진 말) + 내 말(AI 행)로 남김 → 일기를 열면 캐릭터가 이어서 답함(확인: `simctl push` → 길게 눌러 답장 → 앱 열기 → 자동 답). 권한이 없으면 **첫 일기를 남긴 뒤 한 번** "저녁에 물어봐도 될까요?"를 묻는다. ⋯ `저녁 알림 켜기/끄기`(기본 켬 21:00, 시각 바꾸기 화면은 [다음]).
- **새벽 4시 전 = 전날 일기**(`diaryToday`).
- **아직 안 한 것:** 홈 위젯(B, [다음]) · 기록 화면(I)의 "이번 달 한 장·1년 전 오늘" 다듬기(지금 기분 달력 그대로) · 데스크톱은 혼자 쓴 장을 읽기만(✎ 표시 없음) · 실기기 확인.

### 10.2 그날의 장면 카드 (`sceneCardOf`, schema 공용·시험)
- 재료: 그날 `diary_entries`(기분·장들) · `diary_photos` 첫 장 · 그날 끝낸 할 일 · 그날 일정 · 캐릭터 마지막 저장 한 줄(없으면 기분별 정해진 말).
- **제목**: 첫 장 제목 → 없으면 첫 장 본문 첫 문장(24자) → 글이 없으면 할 일·일정으로 `○○하고 ○○한 날`(끝낸 할 일 제목 앞 2개 · 일정 제목 1개, 12자씩) → 그것도 없으면 `조용히 지나간 하루`.
- **배경**: 기분 색 띠 + 장면(그날 사진이 없을 때 장면 배경 — 시간대가 아닌 기분: 1~2 rain · 3 day · 4 sunset · 5 flowers, 다크는 밤 짝).
- **칩**: `✓ 할 일 N` · `📅 첫 일정` · `📷 N` · 캐릭터 한 줄(16자).
- 빈 날(아무 재료 없음)은 카드 없음 — 앨범 칸은 빗금.
- 어디에: 휴대폰 일기 머리 아래 "오늘의 장면" 줄(누르면 크게, P1) · 그날 장 목록 맨 위 · 앨범 칸 · 데스크톱 오른쪽 칸.

### 10.3 사진 한 장
- 들어오는 곳: 대화 칩 `📷 사진 한 장` · 혼자 쓰기 도구 `📷` · 그날 장 목록 `＋ 사진`. 고르는 시트(P2): **오늘 찍은 사진 먼저**(기기 사진첩, 권한은 이때 처음), 지금 찍기, 앨범에서.
- 처리: 기기에서 줄이기(긴 변 1600, JPEG 0.8, EXIF 위치 지움) → `POST /media`(이미지 본문, 3MB 상한) → `{id}` → `diary_photos` 행(date · media_id · width · height · sort_order). 오프라인이면 기기에 두고(대기열) 붙으면 올린다.
- 보기: `GET /media/:id`(Bearer, 내 것만) → 기기 캐시(파일). 데스크톱은 메인 프로세스가 받아 렌더러에 데이터 URL로.
- 지우기: 사진 길게 누르기 → 지우기(행 지움 → 서버가 하루 뒤 고아 `media` 정리). 하루 최대 10장(서버 강제).
- 첫 장이 그날의 장면 사진. 끌어서 순서 바꾸기는 [다음].

### 10.4 다시 보기
- **1년·한 달 전 오늘**: 그날 장면 카드가 있으면 일기 탭(오늘) 맨 위 작은 카드(P4). `그날 일기` · `오늘과 이어 쓰기`(그 제목으로 대화 시작: "1년 전엔 ○○했대. 요즘은 어때?" — 정해진 말).
- **이번 달 앨범**: 기록 화면 세그먼트 `달력 · 앨범`. 칸 = 장면 카드 작은 판(3:4). ▶ 넘겨 보기(P3) = 3초마다 다음, 누르면 멈춤, 좌우 탭. 아래 이번 달 세 장(기분 비율 · 좋은 날 자주 한 일 · 많이 쓴 말 — 기기에서).
- 알림(기본 끔): 아침 8:30 1년 전 오늘(제목만) · 매달 마지막 날 21:30 "10월이 21장으로 모였어".

### 10.5 움직임 (시안 §6 표가 기준 — 두 앱 공통)
기분 120ms spring · 보내기 반응 300ms · 생각 1.8s 반복 · 대화→일기 한 장 420ms · 저장 깡충 600ms · 대화↔혼자 쓰기 300ms · 사진 붙이기 500ms spring(−8°→5°) · 장면 카드 생김 700ms(뒤집힘 → 사진 → 칩 60ms 간격) · 앨범 3초/장 · 데스크톱 칸 접기 220ms. transform·opacity만, 움직임 줄이기면 시안 표 오른쪽 칸.

### 10.6 데이터
| 표 | 칸 | 비고 |
|---|---|---|
| `diary_photos`(동기화) | owner_id · date · media_id · width · height · sort_order · created_at · modified_at | 마이그레이션 `20261025-diary-photos.sql` + 동기화 규칙. **순서: 마이그레이션 → 동기화 규칙 → PowerSync 재시작 → API → 앱** |

### 10.7 완료 기준
1. 사진 한 장 → 다른 기기(휴대폰 ↔ 데스크톱)에서 그날 장면 카드에 3초 안에 보임
2. 글 없이 할 일만 끝낸 날도 장면 카드가 있고 제목이 할 일로 지어짐
3. 1년 전 오늘(시험 데이터) 카드 · 앨범 넘겨 보기 · 이번 달 세 장
4. 오프라인에서 붙인 사진이 다시 붙으면 올라감
5. 움직임 표대로(60fps, 움직임 줄이기)
6. 계정 삭제 → 사진도 지워짐
