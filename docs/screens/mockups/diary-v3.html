일기 v3 — 꼭 필요한 것만 (휴대폰 시안)

한 화면에서 기분 고르고 → 쓰고 → 끝. 저장 버튼 없이 저절로 저장되고, 캐릭터는 묻는 한 줄과 다 쓴 뒤 한마디만 한다.
대화로 쓰기·AI 일기 정리·하루 여러 편·제목/태그·통계는 뺀다. 데이터(일기 글·기분)는 그대로라 지난 일기는 다 그대로 보인다.

남기는 것

  • 기분 5개(한 번 누르기)
  • 글 한 칸 — 쓰는 대로 자동 저장(저장 버튼 없음)
  • 캐릭터가 묻는 한 줄(막히면 다른 질문)
  • 다 쓰면 캐릭터 한마디 1개 + 답장 한 번(원하면)
  • 기록 = 기분 달력 + 이번 달 목록(첫 줄 미리보기)
  • 나만 보기(이 날 일기는 AI에 안 보냄)

빼는 것

  • 캐릭터 대화로 쓰기 · 20초 뒤 질문 · 기분 뒤 동의 카드
  • AI 일기 정리(제목·태그 만들기) · 다시 정리 · 대화 그대로 저장
  • 하루 여러 편(시각 머리) — 같은 날은 이어 쓰기
  • 그냥 쓰기/대화로 쓰기 모드 전환
  • 이번 달 기분 분포 · 이번 주 돌아보기 · 좌우로 밀어 날짜 넘기기
  • 그날 끝낸 할 일 목록 · 처음부터 다시 묻기 · 검색(다음 버전)

정해 주실 것

#질문추천이유
①캐릭터와의 대화를 어디까지 남길까?다 쓴 뒤 한마디 + 원하면 짧은 답장(그날 몇 번만)대화로 일기 쓰기는 손이 많이 가고 AI를 기다려야 했다. 쓰기는 혼자, 캐릭터는 읽고 반응하는 친구 역할이 가볍다.
②AI가 일기를 정리(제목·태그·문장 다듬기)할까?안 한다 — 내가 쓴 글 그대로정리 기다림(약 20~30초)·실패·한도가 가장 큰 불편이었다. 일기는 내 말이 남는 게 가치.
③하루 여러 편은?하루 한 편, 다시 열면 이어 쓰기편마다 제목·시각 머리가 생겨 복잡했다. 기존 여러 편 일기는 글 그대로 보인다(데이터 변경 없음).
④데스크톱 일기도 같이 바꿀까?같이 — 같은 흐름(기분 · 글 · 한마디 · 기록)두 앱이 같은 일기를 다른 방식으로 쓰면 헷갈린다.
