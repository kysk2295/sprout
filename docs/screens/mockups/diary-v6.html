느리에게 톡하면,
오늘의 일기가 된다

일기를 그만두는 이유는 대부분 의지가 아니라 마찰이다. 빈 종이, 느낌을 문장으로 옮기는 수고, 열고 저장하는 단계가 마찰이 된다(조사 §1). 그래서 꿈틀 일기는 쓰는 게 아니라 캐릭터에게 이야기하는 것으로 바꿨다. 기분 하나만 눌러도 기록이 되고, 몇 마디 나누면 느리가 내 말투 그대로 일기 한 장으로 옮겨 알아서 저장한다. 저장 단추는 없다.

⏱3초부터알림·위젯에서 기분만 눌러도 그날 기록 끝. 보통 1~2분.
✍︎안 써도 된다칩 탭 · 말하기 · 한 줄. 문장은 느리가 일기로 옮긴다.
♡공감부터0.3초 안에 끄덕임·하트, 그다음 내 말을 짚는 답. 조언은 물을 때만.
✦예쁘게시간대 장면 위 유리 말풍선, 일기는 종이 한 장.

1. 왜 귀찮은가 → 다른 앱은 → 꿈틀은조사한 앱 12개

일기 앱은 정신 건강 도구 가운데 오래 쓰는 비율이 가장 낮다. 첫 주에 열심히 쓰고, 2주째 줄고, 한 달 안에 멈춘다. 습관은 평균 11일째쯤 끊긴다. 아래 표는 불편 하나마다 그걸 가장 잘 푼 앱과 꿈틀의 답이다.

사용자가 겪는 불편잘 푼 앱 · 방법꿈틀 일기
① 빈 종이 — 뭘 쓸지 몰라 열었다 닫는다Reflectly 질문을 한 단계씩 · Rosebud 빈 페이지 대신 질문 · Apple 저널 사진·장소로 쓸거리 제안느리가 먼저 말을 건다. 첫 질문은 오늘 데이터로("퀴즈2 끝냈네!"), 답 칩은 끝낸 할 일·일정에서
② 문장으로 옮기는 수고 — 지치고 힘든 날일수록 못 쓴다마이모리 톡 보내듯 대충 써도 일기로 정리 · 들어주는일기 전화하듯 말로 · 사이다 AI가 대신 써 줌메신저처럼 짧게, 칩, 말하기(기기 받아쓰기). 끝나면 느리가 내 말투 그대로 1인칭 일기로 옮긴다(느리 말은 빼고)
③ 여는 것 자체 — 까먹거나, 앱 찾아 들어가기 귀찮다Daylio 알림 · 두 번 탭 · Finch 열면 바로 체크인저녁 알림에서 바로 답장, 위젯에서 기분 바로 누르기(앱 안 열림). 열면 이미 대화가 시작돼 있다
④ 저장·정리 — 끝맺기·제목 붙이기가 일Rosebud 쓰다 만 글 자동 임시 저장 · Reflectly 끝에 축하저장 단추 없음. 모든 말은 바로 저장, "오늘은 여기까지"나 앱을 떠나면 일기 한 장으로 자동 정리. 제목·태그도 느리가
⑤ 연속 기록 죄책감 — 끊기면 "어차피"Daylio 놓쳐도 벌 없음(Finch 연속 압박과 대조로 호평)연속 숫자 없음. 며칠 만에 와도 "다시 왔네, 반가워". 새벽 4시까지 쓴 건 전날 일기로
⑥ 답을 기다리는 시간 — 우리 AI는 첫 글자까지 6~20초(실측)하루 AI 일기 친구·하루온기 캐릭터·목소리로 공감보내는 순간 0.3초 안에 기기에서 끄덕임 + 내 말풍선에 하트, 생각하는 얼굴. 그동안 AI 답이 흘러나온다
⑦ 형식적인 AI — 조언·요약·보고서 말투How We Feel 감정을 고르는 방식을 좁혀 줌 · Stoic 질문이 좋음 (반면 Rosebud는 무겁다는 평)기존 대화 규칙 유지: 한 말을 그대로 짚어 알아주기, 묻지 않으면 조언 금지, "그냥 들어줘" 칩

2. 한 번 쓰는 흐름초록 = 기기 · 보라 = AI(우리 서버) · 회색 = 사용자 선택

들어오기알림 · 위젯 · 탭저녁 9시(바꿀 수 있음) 알림에서 바로 답장, 위젯 기분 누르기, 또는 일기 탭
0초인사 + 기분느리가 시간대 + 오늘 할 일로 인사. 기분 5개 중 하나 → 여기서 닫아도 기록
10초~이야기칩 · 말하기 · 글. 보내면 즉시 끄덕임 → 공감 답(AI). 2~5번 주고받기
끝오늘은 여기까지칩을 누르거나, 그냥 앱을 떠나도 된다(5분 뒤 자동)
~20초일기 한 장느리가 내 말로 옮김(제목·태그). 자동 저장, 고치기는 선택
나중기록기분 달력 · 일기 목록 · 1년 전 오늘

3. 화면빨간 번호 = 아래 설명

캐릭터는 사용자의 정원 친구(예: 달팽이 "느리"), 장면은 지금 시간대(아침 dawn · 낮 day · 저녁 dusk · 밤 moon)를 따른다. AI 비서 채팅에서 만든 장면·받침·유리 말풍선을 그대로 쓴다.

4. 움직임과 시간지금 AI 비서 채팅 구현을 다시 씀

순간시간무엇이어디서
앱 열기 → 인사0ms인사는 미리 그려져 있다(타자 효과 없음). 느리 숨쉬기 시작기기
기분 누르기120ms콩이 눌렸다 커짐(0.92→1.08→1) + 가벼운 진동. 내 말풍선으로 날아가 앉음기기
보내기~300ms키보드 내려감 · 내 말풍선 위로 · 하트 붙음 · 느리 끄덕 2번 → 생각하는 얼굴기기
첫 글자6~20초(실측)같은 말풍선에서 점 → 글로 바뀜, 프레임마다 흘러나옴. 얼굴 = 말하는 중AI(우리 서버)
답 끝+0.8초답이 따뜻하면 웃는 얼굴, 칩 줄이 아래에서 올라옴기기
오늘은 여기까지~20초말풍선이 종이로 접힘(0.4초) → 제목·본문 흘러나옴 → 저장됨 ✓ · 깡충AI → 기기
움직임 줄이기—끄덕·깡충·접힘 없음, 얼굴만 바뀜. 글은 받은 대로 한 번에기기

5. 지금 일기(28 §8)에서 빼는 것 · 바뀌는 것

빼는 것
  • 초안 카드의 [저장] 단추 → 자동 저장
  • 동의 카드 단계 → 처음 한 번 설정에서 끝내고, 대화 안 카드 없음(기본은 나누기, 첫날 한 줄 안내)
  • "대화 그대로" 단추 → ⋯ 안으로
  • 질문 3개를 정해 두는 단계 → 막힐 때만 질문(20초 무입력)
  • 좌우 밀어 날짜 넘기기 + 주 띠 → 기록 달력 하나
  • 여러 편 이어 붙이기의 시각 머리 → 같은 날 두 번째부터만 작게
새로 생기는 것
  • 저녁 알림 바로 답장 · 기분 단추(A)
  • 홈 위젯 3종(B)
  • 보내자마자 기기에서 하트·끄덕(D)
  • "그냥 들어줘" 칩 · 끝내기 칩(E)
  • 기기 받아쓰기 🎙(F)
  • 앱을 떠나면 자동으로 일기 정리(G)
  • 종이 한 장 + 그날 끝낸 할 일(H)
  • 새벽 4시까지는 전날 일기
