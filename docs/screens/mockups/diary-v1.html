일기 v1 시안 — 종이 페이지 + 곁자리 캐릭터 (15 §9) · 시안 속 "오늘" = 2026-10-24(토)

보는 법 — 기분 얼굴을 눌러 보세요(캐릭터가 기분에 맞게 반응, 낮은 기분엔 웃지 않고 "곁에 있을게"). 질문 쪽지의 다른 질문 ↻은 쪽지를 넘깁니다. 페이지 오른쪽 위 책갈피 = 나만 보기. 왼쪽 달력·목록에서 지난 날을 고르면 페이지가 그날로 넘어갑니다(지난 날 하늘 띠 = 그날 기분 색). 곁자리 캐릭터를 누르면 말풍선. 창 폭 "중간"은 곁자리가 페이지 아래로, "좁게"는 왼쪽 목록이 접힙니다(머리의 달력 버튼). 돌아보기 달력 칸에 마우스를 올리면 첫 줄 미리보기(나만 보기 날은 자물쇠만). 데이터·안전 규칙은 15 §3~§8 그대로입니다.
