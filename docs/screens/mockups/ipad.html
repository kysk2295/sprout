창 폭에 따라 접히는 법 — 같은 화면, 다섯 폭

배치는 기기·방향이 아니라 앱 창의 폭으로 고른다(iPadOS 26은 창을 아무 폭으로나 늘인다). 넓음 ≥ 1100 레일 + 사이드바 + 본문 + 상세 · 보통 768–1099 레일 + 본문 + 상세(사이드바는 ☰로 겹쳐 뜸) · 좁음 600–767 레일 + 본문(상세는 가운데 시트) · 휴대폰 < 600 지금 iPhone 화면 그대로(떠 있는 탭 알약 · + 버튼 · 아래 시트).

키보드 단축키 (하드웨어 키보드)

데스크톱 단축키(01·16)를 그대로 두고 iPad 관례를 더한다. 모두 메뉴 막대(iPadOS 26 — 화면 위에서 아래로 쓸거나 포인터를 맨 위로)와 ⌘ 길게 누르기 판(iPadOS 18 이하)에 이름이 보이게 등록한다. 글 입력 중에는 ⌘ 조합만 동작.
