0. 지금(v2) ↔ v3

같은 종·같은 단계를 나란히 놓았다. v2는 큰 만화 눈 + 빛점 둘 + 볼 번짐 + 진한 소품 여러 개라 "아기 그림"으로 읽힌다. v3는 몸 덩어리 하나가 형태를 맡고, 얼굴은 작은 점 눈 + 가는 입뿐이며, 빛·그림자·속살 빛이 진짜 3D라 "잘 만든 비닐 인형"으로 읽힌다. 아래 그림은 모두 scripts/characters3d에서 Blender로 구운 실제 결과물이다.

왜 유치해 보였나 → v3에서 바꾼 것

  • 얼굴이 화면을 다 먹는다 — 눈이 머리 반지름의 25%, 빛점 둘, 볼 번짐, ω 입. → 눈 = 몸 높이의 약 4%, 빛점 없음(유광 재질이 저절로 빛을 받음), 볼 없음, 입은 가는 선 하나.
  • 가짜 입체 — 그라데이션 하나에 외곽선. → 진짜 빛(왼쪽 위 큰 면광 + 뒤 테두리 빛) · 접촉 그림자 · 맞닿은 곳 어두움(AO) · 속살 빛(subsurface).
  • 소품이 많다 — 단계마다 꽃·리본·별·조각을 얹었다. → 단계마다 실루엣 하나만 바뀐다(씨앗 그릇 → 나선 껍데기 → 껍데기 위 작은 숲).
  • 색이 다 세다 — 채도 높은 파스텔 8~10색. → 종마다 한 색 계열 + 무채색 받침, 강조는 소품 하나.
  • 장면이 없다 — 흰 카드 위 그림. → 끝까지 깔린 3D 정원 장면 + 유리 카드(사용자 추가 요청: "화면에 디자인이 가득 찬").

옷 층은 몸·얼굴을 "그림자만 받는 투명면"으로 두고 구워서, 겹치면 옷이 몸 뒤로 돌아가는 부분은 가려지고 몸에 지는 그림자는 남는다. 목 둘레는 생성기가 몸 표면을 광선으로 재서 맞춘다 — 같은 목도리 정의가 달팽이 친구·전설, 개구리 친구에 그대로 맞는다.

A. 만들기 흐름 — 씨앗 고르기 → 성향 카드 8장 → 부화 → 이름 → 첫 할 일

눌러서 끝까지 진행된다. 씨앗은 좌우로 끌면 돌아간다(12컷 회전). 카드는 고르면 그쪽으로 날아간다. 부화는 씨앗을 세 번 두드린다 — 금 한 줄 → 두 줄 → 빛. 종은 성향 카드가 정한다(10 §2.2 그대로), 씨앗은 껍질 무늬만 정한다(결정 ③).

단계 (49 §5)

  1. 시작 — 새벽 정원 장면이 끝까지. 둥실 뜬 씨앗 하나 + 굵은 두 줄 + 버튼 하나. 한 화면에 한 가지 일.
  2. 씨앗 고르기 — 4개(흙빛·장미·올리브·새벽). 끌면 12컷 회전(30°씩), 놓으면 가까운 컷에서 멈춤. 고른 무늬는 characters.look_json.seed.
  3. 성향 카드 — 10 §2.2의 8문항 그대로, 한 장에 하나. 고르면 카드가 그쪽으로 날아가고 위 씨앗이 조금씩 더 흔들린다(두근). ‹ 이전.
  4. 부화 — 두드림 1 = 흔들 + 금 한 줄, 2 = 금 두 줄, 3 = 화면 빛 번짐(0.35초) → 아기 톡 등장 + 고리 둘 + 빛무리 → 유형 카드가 스프링으로. 움직임 줄이기 = 페이드만.
  5. 이름 — 기본값 = 종 별명, 추천 칩 3개, 10자. 입력하는 동안 캐릭터가 웃는 얼굴.
  6. 첫 할 일 — 추천 칩 또는 직접. 체크하면 +10이 떠오르고 캐릭터가 깡충 + 정해진 한 줄. 진짜 할 일로 저장된다(오늘 목록).
  7. 정원 — 성장 홈으로 페이드. 이후 앱은 오늘 탭부터(할 일 앱이 먼저).

결과 종은 답에서 정해진다(계획·몰입 달팽이 · 계획·멀티 꿀벌 · 즉흥·몰입 애벌레 · 즉흥·멀티 개구리). 위 막대의 종 버튼은 부화 이후 화면을 그 종으로 바꿔 본다.

B. 성장 홈 — 장면이 화면 끝까지, 유리 카드에 큰 숫자 하나

상태 막대 뒤까지 3D 정원(라이트 = 낮, 다크 = 밤). 위에 주 달력 띠, 가운데 이끼 돌 받침 위 캐릭터(숨쉬기), 아래 유리 카드: Lv 배지 + 다음 레벨까지 % + 꼬리 칩 + 굵은 막대 + 옷장·도감·이번 주. 캐릭터를 누르면 웃는 얼굴로 깡충 + 한 줄.

해 보기

  • 캐릭터 크기는 단계와 상관없이 같다(42 §10.6.1 그대로). 성장은 실루엣으로 보인다.
  • 장면은 받침 자리(perch)를 함께 내보내서, 앱이 캐릭터를 그 자리에 얹는다. 장면·캐릭터가 같은 카메라 높이(10°)라 그림자가 맞는다.
  • % = 다음 레벨까지(10 §6 XP 그대로). 큰 숫자 60px/850, 단위 절반 크기.
  • 유리 카드는 캐릭터 화면에서만. 할 일 화면에는 쓰지 않는다(§G).

C. 옷장 — 장면 위 미리보기, 아래 시트

위 절반은 성장 홈과 같은 장면에서 캐릭터를 크게. 아래는 반투명 시트(모자·목·손·등·방). 목도리 칸을 누르면 옷 층이 겹쳐지고 캐릭터가 깡충. 잠긴 칸은 회색 덩어리 + 조건.

옷 층 규칙 (49 §4.3)

  • 옷 1개 = 종 × 단계(× 갈래)마다 한 장, 몸·얼굴은 그림자만 받는 투명면으로 굽는다.
  • 앱은 [몸] [얼굴] [등 옷 뒤] … [목] [손] [모자] 순서로 같은 크기 그림을 겹친다. 기준점 계산이 앱에 없다(구울 때 맞춤).
  • 칸 수는 43 그대로 5칸. 옷 23개 × 4종 × 5단계(+갈래) ≈ 690장 — 처음엔 받은 옷만 내려받는다(§H).

D. 도감 — 모은 모습이 3D 피규어 진열장처럼

밤 정원이 위로 흐리게 깔리고, 3열 유리 칸에 단계별 모습. 아직 안 본 모습은 같은 그림의 어두운 실루엣(앱은 미리 구운 실루엣 층을 쓴다). 칸을 누르면 아래 카드에 이름·생긴 때.

E. 진화 — 실루엣 → 빛 방울 → 새 모습

42 §10.6 순서 그대로, 그림만 3D. 실루엣은 같은 그림의 한 색 층(미리 구움), 빛 방울·고리는 캐릭터 자리에서만. 약 2.5초, 누르면 끝 장면.

  • 0–0.25초 어두워짐 + 옛 모습 웅크림 · 0.26–0.9초 흰 실루엣 꿀렁 세 번 · 0.9–1.2초 빛 방울로 쪼그라듦 · 1.2초 고리 두 겹 + 새 실루엣 톡 · 1.45초 색 그림이 드러남 · 1.66초 이름 카드.
  • 쓰는 속성은 transform·opacity뿐(39 §11).

F. 다른 화면에 보이는 법 — 할 일 화면은 조용하게

오늘(할 일)은 틱틱처럼 차분: 캐릭터는 빈 상태와 완료 순간에만. AI 비서 빈 대화·일기 대화는 캐릭터 자리라 장면을 끝까지 깐다(사용자 추가 요청).

G. 할 일 화면에 "가득 찬" 느낌을 어디까지 — 은은하게 / 과감하게

오늘·캘린더·프로젝트에 같은 장면 언어를 두 단계로 입혀 봤다. 은은하게 = 큰 제목 뒤 장면 띠(200px, 아래로 흰 면에 녹음) + 그림 빈 상태. 과감하게 = 장면 300px + 흰 목록 카드가 장면 위에 뜸 + 탭 막대 뒤 장면 띠. 추천은 은은하게추천 — 목록 첫 줄이 지금과 같은 높이에 오고, 장면은 스크롤하면 사라진다.
