## 0. 문제 (실제 데이터, 2026-10-05 오너 계정)
| 항목 | 값 |
|---|---|
| 미완료 할 일 | 310 |
| **만료됨** | **267 (86%)** — 1주 이내 10 · 1달 이내 33 · 3달 이내 59 · **3달 넘음 165** |
| 위치 | 264개가 기본함 |
| 같은 제목 반복 | 근무 ×7 · 토익공부 ×6 · 마케팅 미팅 ×5 · 디지털시스템 복습 ×5 … (반복 할 일을 손으로 만든 흔적) |

원인: 할 일이 쌓이기만 하고 **빠져나갈 길(안 함·날짜 빼기·보관)이 불편**하다. 만료 목록이 길면 "오늘"이 묻히고, 앱을 여는 것 자체가 부담이 된다(죄책감). 성장 루프와도 충돌한다(빨간 목록 = 실패감).

## 1. 원칙
1. **벌하지 않는다.** 만료 = 실패가 아니라 "다시 정할 일". 문구에 "실패·밀림" 대신 "다시 정하기".
2. **오늘을 지킨다.** 오늘 화면에서 만료가 오늘 할 일을 덮지 않는다.
3. **한 번에 끝낼 수 있게.** 수백 개를 하나씩 고르지 않아도 되는 일괄 정리 + 되돌리기.
4. **틱틱 동작은 그대로 두고 그 위에 얹는다.** 기존 만료됨 묶음·미루기는 틱틱과 같게.
5. AI 없이도 된다. AI는 거들기만(제안), 결정은 사용자.

## 3. sprout 추가 — "밀린 일 정리" 도우미
### 3.1 들어가는 곳
- 오늘·전체 목록에서 만료가 **20개 넘으면**[임시] 만료됨 묶음 맨 위에 카드 한 줄: `밀린 할 일 267개 — 3분이면 정리할 수 있어요 [정리하기]` · `나중에`(7일 동안 숨김).
- ⌘K "밀린 일 정리", 설정 › 할 일 › "밀린 일 정리".
- 틱틱에서 가져오기 끝 화면에도 버튼(가져온 만료가 많을 때).

### 3.2 정리 화면 (대화 상자, 단계 3개)
**① 오래된 것 한꺼번에** — 나이별 묶음 카드
| 묶음 | 기본 제안 | 바꿀 수 있는 것 |
|---|---|---|
| 3달 넘음 (165) | **하지 않음으로 보관** | 날짜만 빼기(리스트에 남김) · 삭제(휴지통) · 하나씩 보기 |
| 1~3달 (59) | 날짜만 빼기 | 하지 않음 · 하나씩 보기 |
| 이미 지난 일정 (시각 있는 것) | **지난 일정으로 완료 처리**(XP 없음) | 하지 않음 · 하나씩 |
- 각 묶음 오른쪽에 개수와 예시 3개 제목. 묶음을 펼치면 체크 해제로 일부 빼기.

**② 같은 일 묶기** — 같은 제목이 3번 이상 만료면 한 줄로: `근무 ×7 · 토익공부 ×6`
- [가장 최근 1개만 남기기] · [반복 할 일로 바꾸기](요일·주기 제안 → 03 반복) · [그대로]

**③ 최근 것 하나씩** (1달 이내, 43개) — 카드 한 장씩, 키보드/클릭 한 번:
- `오늘` · `이번 주`(금요일) · `날짜 고르기` · `날짜 빼기` · `완료했어요` · `하지 않음`
- 단축키 1~6, ←로 이전 카드. 남은 개수 진행 막대. 언제든 `여기까지` 하고 나갈 수 있음.

**끝 화면**: `267개 → 오늘 5 · 이번 주 12 · 날짜 없음 88 · 보관 162` 요약 + **[모두 되돌리기]**(이번 정리 전체 한 번에, 24시간 [임시]) + 캐릭터 한마디("방이 훨씬 넓어졌다!").

### 3.3 데이터 (스키마 변경 없음)
- 하지 않음 = 기존 `status = 2`. 날짜 빼기 = `due_at/start_at = null`(반복 규칙도 null). 완료 처리 = `status = 1, completed_at`.
- **지난 일정 완료 처리와 정리 과정의 모든 완료는 XP를 주지 않는다**(정리로 XP를 얻는 길을 막음) — `xp_events`를 쓰지 않는 별도 경로.
- 되돌리기: 정리 직전 대상 행의 (status, due_at, start_at, repeat_rule, completed_at)을 기기에 스냅숏(마지막 1회) → 한 번에 복원.
- 같은 일 묶기의 "1개만 남기기" = 나머지를 하지 않음(삭제 아님).

### 3.4 구현 규칙 (v1.0 구현, 2026-10-05) — 코드: `data/overdue.ts`, `components/overdue/**`, 시험 `tests/overdue.test.ts`
- **만료 판정** = `due_at` 날짜 < 오늘(목록 "만료됨"과 같음). 시각은 floating이라 기기 시간대와 무관. 진행 중인 기간 할 일은 만료 아님. 부모가 같이 만료면 하위는 부모와 함께 처리(따로 세지 않음). 보관 리스트·휴지통 제외.
- **나누는 순서**: 같은 일(②) > 지난 일정 > 나이. 같은 제목 3번 이상은 ①에서 빼고 ②로(반복으로 바꿀 수 있게). **지난 일정 = 시각 있는 만료 전부(나이 무관)**, 종일·날짜만 있는 일은 아님. 나이: 90일 초과 = 3달 넘음, 31~90일 = 1~3달, 30일 이내 = ③ 하나씩 [임시].
- **같은 제목 정규화**: 전각→반각·소문자·공백/문장부호/기호 제거. **숫자는 남김**("과제 3"≠"과제 4" — 번호를 떼면 오래된 일이 잘못 묶였다).
- **① 묶음 처리 목록**: 3달 넘음 = 하지 않음(추천)·날짜만 빼기·삭제·하나씩·그대로 / 1~3달 = 날짜만 빼기(추천)·하지 않음·하나씩·그대로 / 지난 일정 = 완료 처리 XP 없음(추천)·하지 않음·하나씩·그대로. 펼쳐서 체크 해제한 것은 그대로 둔다. "하나씩"을 고르면 ③ 앞쪽에 붙는다.
- **② 반복 제안**: 같은 요일·7일 배수 → 매주(n주마다, 최대 4) 그 요일 / 같은 날짜·28일 이상 간격 → 매월 / 같은 간격 <7일 → n일마다 / 7일 안에 여러 요일 → 매주 그 요일들 / 그 밖 → 가장 흔한 요일 매주. 고르기 목록 = 추천 + 03 반복 기본 목록 + "직접 고르기"(03 날짜 선택기 반복 패널). 기본 선택은 "가장 최근 1개만 남기기". 반복으로 바꾸면 가장 최근 1개에 규칙을 넣고 **오늘 이후 첫 회차로 옮김(시각 유지)**, 나머지는 하지 않음.
- **③ 하나씩**: 이번 주(금) = 이번 주 금요일(토·일이면 다음 주 금요일, 월요일 시작 주). 날짜 고르기 = 03 날짜만 선택기(시각 유지). ←로 돌아가 다시 정하면 먼저 그 행을 정리 전 값으로 돌린 뒤 적용(하지 않음 → 오늘 등). 끝까지 가거나 `여기까지`면 끝 화면.
- **XP 없는 완료**: `@sprout/schema/taskCore`의 `planCompleteNoXp` — 일반 할 일은 하위와 함께 완료, **반복 할 일은 완료 기록 없이 오늘 이후 첫 회차로 넘김**(남은 회차 없으면 완료). `xp_events`를 쓰지 않고 `sprout:task-done`도 보내지 않는다. 끝 화면에서 `sprout:cleanup-done`(detail `{ tally, seconds }`)을 보낸다.
- **되돌리기 스냅숏**: 기기 `localStorage`(`sprout.overdue.snapshot`), 행마다 처음 값(status·due_at·start_at·is_all_day·repeat_rule·repeat_from·completed_at·deleted_at), 대화 상자를 열 때 정리 세션 id를 기기에 두고 그 세션에서 처음 바꿀 때 지난 스냅숏을 버린다(마지막 1회분). 24시간. 끝 화면 [모두 되돌리기] + **설정 › 할 일 › 마지막 정리 되돌리기**. 알림 행은 건드리지 않는다(날짜 빼기도 알림 행은 남김 — 날짜가 없으면 울리지 않음).
- **들어가는 곳**: 만료됨 묶음 맨 위 카드(오늘·전체 보기, 만료 > 20, `나중에` = 7일, 기기) · ⌘K "밀린 일 정리" · 설정 › **할 일** 탭(새 탭) › 밀린 일 정리 [열기](설정 창에서 누르면 메인 창이 연다) · 틱틱 가져오기 끝 화면 `밀린 일 N개 정리`(만료 > 20) · 오늘 접기 줄 · 어제 띠 [하나씩](그 할 일만 ③으로) · 주간 리포트 줄.
- **AI 꼬리표**: ③을 열면 처음 8장, 그다음 30장씩(90장까지) `/ai/classify`에 번호·제목·리스트·마감일만 보냄. 응답은 `{"items":[{"i":번호,"tag":"event|repeat|week|none"}]}`만 받고, 모양이 틀리거나 AI가 없으면 조용히 꼬리표 없이. 실측: Mac mini qwen3.5:9b 4개 ≈ 9초.
- **끝 화면 문구**: `150개 → 오늘 3 · 이번 주 3 · 날짜 없음 28 · 보관(하지 않음) 99 · 완료 14 · 반복으로 3`, 남은 만료 수, 캐릭터(성장 캐릭터 그림·이름) 한마디 — 다 비우면 "방이 훨씬 넓어졌다! 이제 오늘 할 일만 보여.", 50개 이상이면 "와, 한꺼번에 이만큼이나!", 아무것도 안 바꿨으면 "괜찮아, 다음에 같이 정리하자." [임시]. §6의 "방 장식 정돈 상태"는 [다음](성장 쪽 연결 필요).

## 5. AI 거들기 (선택, 서버 프록시 /ai/classify 재사용, 주간 상한 밖 일반 상한)
- ③ 하나씩 단계에서 카드마다 작은 제안 꼬리표: `지난 일정 같아요` · `반복으로 바꿀까요?` · `이번 주에 할 만해요` — 제목·리스트·날짜만 보냄(성장과 같은 범위).
- AI가 없으면 꼬리표 없이 그대로 동작. 규칙(시각 있는 지난 일 = 일정, 같은 제목 반복)은 AI 없이 앱이 판단.

## 6. 성장 연결
- 정리는 XP를 주지 않는다(3.3). 대신 **캐릭터 반응**: 정리 끝 화면 한마디, 방 장식 하나를 "정돈" 상태로(10 §3.2 장식에 연결, 기기 저장).
- 만료가 많아도 캐릭터는 슬퍼하지 않는다(10 §3.2 원칙 — 시들기 없음).

## 7. 모바일
- 만료됨 묶음 머리 `미루기`, 왼쪽 스와이프 `날짜`(이미 있음) + 길게 눌러 `하지 않음`.
- 정리 도우미 ③은 카드 스와이프 UI(오른쪽 = 오늘, 왼쪽 = 하지 않음, 위 = 날짜 빼기) [sprout], ①②는 같은 묶음 카드.

## 8. 정할 것 (사용자)
1. 3달 넘은 만료의 기본 처리 — **제안: 하지 않음으로 보관**(목록에서 빠지고, 완료됨 옆 "하지 않음" 스마트 목록에 남음)
