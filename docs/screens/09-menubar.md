## 2. 레이아웃
- 메뉴 막대(Mac)·알림 영역(Windows)에 sprout 아이콘(직접 만든 단색 템플릿 아이콘, 틱틱 아이콘 쓰지 않음).
- 아이콘을 누르면 아이콘 바로 아래(Windows는 위)로 패널이 열린다. 다시 누르거나 패널 밖을 누르면 닫힌다. [틱틱]
- 패널 크기 **340×560** [임시 — 2020 캡처 비율], 모서리 10, 그림자. 테마는 앱 설정을 따른다.
- 위에서부터:

| 영역 | 내용 |
|---|---|
| 머리 (높이 44) | 왼쪽 **"오늘 ⌄"**(목록 전환), 오른쪽 `⋯`. Pomo 탭은 v1에 없다 [sprout] |
| 추가 바 | 02의 추가 바와 같은 모양(높이 38). 문구는 보고 있는 목록을 따른다: 오늘 → `"기본함"에 할일 추가` [틱틱 2020: Add task to "Inbox" on "Today"] |
| 목록 | 02의 행(체크박스 · 제목 · 오른쪽 날짜, 높이 40). 그룹 머리는 "만료됨 · 오늘 …"(02와 같은 시간 그룹). 하위 태스크는 들여쓰기만, 펼침 버튼 없이 [임시] |
| 빈 상태 | 일러스트 자리(직접 만든 그림 [다음]) + 제목 **"오늘 할 일이 없어요"** + 시간대별 한 줄 [임시: 아침 "좋은 하루 시작해요" · 낮 "잠깐 쉬어가요" · 밤 "오늘도 수고했어요"] |

## 3. 구성 요소 상태
| 요소 | 상태 |
|---|---|
| 목록 전환 "오늘 ⌄" | 누르면 메뉴: 오늘 · 내일 · 다음 7일 · 기본함 / (구분선) / 리스트들 [임시]. 고른 값은 기기에 기억 |
| `⋯` 메뉴 | 메인 창 열기 (⇧⌘E) · 설정 · (구분선) · sprout 종료 [임시] |
| 행 체크 | 바로 완료(02 §0과 같다), 행은 목록에서 빠진다. 토스트는 패널 아래 [임시] |
| 행 클릭 | 메인 창을 앞으로 가져와 그 태스크를 선택(상세 열림)하고 패널은 닫는다 [임시] |
| 추가 바 | Enter로 만들고 입력칸을 비운다(02 §4). 날짜 인식은 02와 같은 규칙. 오늘 목록에서 만들면 날짜 = 오늘 |
| 로그아웃 상태 | 패널에 "로그인이 필요해요" + [메인 창 열기] (08 A안) |

## 4. 인터랙션
- 전역 단축키 **⇧⌘O / Alt+Shift+O**: 패널 열기·닫기(앱이 뒤에 있어도). [틱틱 Mac]
- 패널이 열리면 추가 바에 포커스 [임시]. Esc = 닫기.
- 키보드: ↑↓ 행 이동, Space = 완료 [임시].
- 메인 창을 닫아도 앱은 메뉴 막대에 남는다(알림도 울림). Dock 아이콘을 누르면 메인 창이 다시 열린다. 완전 종료는 `⋯` → 종료 또는 ⌘Q. [틱틱 상주 구조]

## 5. 데이터

## 6. 완료 기준
- [ ] 메뉴 막대 아이콘 클릭·⇧⌘O로 패널이 열리고 닫힌다. 밖을 누르면 닫힌다.
- [ ] 오늘 목록이 메인 창과 같은 항목·순서·날짜 표기로 보인다. 한쪽에서 바꾸면 다른 쪽에 바로 반영된다.
- [ ] 체크로 완료, 추가 바로 오늘 할 일 만들기가 된다.
- [ ] 행을 누르면 메인 창에서 그 태스크가 열린다.
- [ ] 메인 창을 닫아도 메뉴 막대에 남고 알림이 울린다.
