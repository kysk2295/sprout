## 3. 첫 둘러보기(코치 마크)
### 3.1 언제 · 몇 번
- 그 탭을 이 기기에서 **처음 열고, 그 탭 자료가 다 읽힌 뒤 0.6초**. 탭별 "다 읽힘": 할 일 = 목록 쿼리, 캘린더 = 범위 할 일 쿼리, 성장 = `useGrowth().loaded`, AI 비서 = 연결 확인 끝(`connecting` 아님), 수집함 = 항목 쿼리, 일기 = 일기 쿼리 **+ 동의 창에 답함**(15 §9.7 동의가 먼저), 작업 지도 = 지도 자료 + 계획(프로젝트) 화면일 때만(34).
- **기다림:** 팝오버·`[aria-modal]` 창·첫 실행 안내(`.onb-scrim`)·옵션 보기 같은 막(`.modal-scrim`)·다른 둘러보기가 떠 있으면 0.8초마다 다시 본다. **첫 실행 안내 중에는 절대 안 뜬다.**
- **한 번에 하나:** 둘러보기 자리(`claimTour`)는 하나뿐. 떠 있는 동안 다른 탭 둘러보기는 기다린다(탭을 옮기면 떠 있던 것은 접히고, 다음에 그 탭을 열면 다시).
- **끼어들기:** 둘러보기 중에 첫 실행 안내·성향 조사 같은 큰 창(`.onb-scrim`·`.modal-scrim`·`.desktop-dialog`)이 뜨면 조용히 접고(이번 실행 닫기 아님), 그 창이 닫히면 1단계부터 다시.
- 닫기 규칙(18 §4·34와 같음): **✕ · Esc · 막(카드 밖) 누르기 = 이번 실행 동안만 닫기**(앱을 다시 켜면 다시), **`다시 보지 않기` · 마지막 `시작하기` = 끝**(그 탭에서 다시 저절로 뜨지 않음).
- 기기 기억(동기화 안 함, 18 §0-3과 같은 이유): `localStorage['sprout.guide.<tab>'] = { tour: 'new' | 'done' }`, 탭 = `tasks · calendar · growth · assistant · collect · diary`. 작업 지도는 34 때 키 `sprout.map.guide`를 그대로 쓴다(이미 끝낸 사람에게 다시 뜨지 않게, 옛 `hints`는 지우지 않음).

### 3.2 모양 · 동작 (34 §2.3 그대로)
- 막 = 가리키는 곳 둘레 6px만 뚫린 `color.overlay.scrim`(구멍 모서리 8, 강조색 2px 테두리). **가리킬 곳이 없으면 화면 전체 막 + 카드는 화면 가운데**(34 버그 수정 — 막만 남는 일 없음). 후보를 차례로 보고 처음 보이는 것, `@all:선택자` = 맞는 것 모두를 감싼 상자(스마트 목록 다섯 줄 등).
- 카드 폭 300, 위 진행 점(현재 16px 막대) + `1 / 3` + ✕, 제목 15/600, 설명 13 2차 글자, (단계에 따라) 그림 112×77, 아래 회색 `다시 보지 않기` · `이전`(1단계 숨김) · 주 버튼 `다음`/`시작하기`.
- 키보드: → / Enter 다음, ← 이전, Esc 닫기. 포커스는 주 버튼. 둘러보기 중엔 앱 단축키가 막힌다(`role=dialog aria-modal`).
- 0.25초마다·창 크기 바뀔 때 다시 잰다. 카드 페이드+4px 160ms, 구멍 이동 200ms. 동작 줄이기 = 끔. 층 85.

## 4. 사용법 창 (34 §3.2 모양 그대로)
- 머리 `?` 아래 팝오버 폭 380, 높이 최대 `min(640, 창-120)` 스크롤. 바깥·Esc 닫기. 맨 위 제목 `<탭> 사용법` 15/600 + 한 줄.
- **절** = 그림 64×44 왼쪽 + 제목 13/600 + 설명 12.5 2차. AI를 쓸 수 없을 때 해당 절 아래 회색 한 줄(할 일 ✦ · 성장 일기 · AI 비서 빠른 창 · 수집함 등록 · 일기 대화 · 지도 같이 짜기).
- **이렇게 쓰면 좋아요** = 번호 3줄 + 오른쪽 동사 글자 단추(누르면 창을 닫고 진짜로 그 동작).
- 맨 아래 줄: 왼쪽 `둘러보기 다시 하기`(1단계부터) · 오른쪽 `? 단축키 모음`(단축키 시트 — 레일 도움말이 사용법으로 바뀌어서 여기로 옮김). 작업 지도는 오른쪽에 `N 지금 집중`(34).

| 작업 지도 | 34 §3.2 그대로(6절) |

## 5. 들어가는 곳
- **머리 `?` 버튼**(lucide `HelpCircle`, icon-btn 30×30, 툴팁 `<탭> 사용법`) — **모든 탭에서 ⋯ 바로 왼쪽**(작업 지도와 같은 자리). 할 일: 그룹·정렬 › `?` › 리스트 메뉴(완료·휴지통 같은 보관 목록에서도 `?`는 보인다). 캘린더: 보기 · ‹오늘› · `?` · ⋯. 성장: 오른쪽 `?` · ⋯. AI 비서: 상태 · 새 대화 · `?` · ⋯. 수집함: 검색 · `?` · ⋯. 일기: 쓰기 = 가운데 머리 `?` · ⋯, 돌아보기 = 제목 줄 오른쪽 `?`. 열려 있으면 강조색 + 선택 배경(`.guide-btn.is-on`).
- **레일 도움말**(왼쪽 아래 `?`, 01 §3): 지금 탭의 사용법 창을 그 탭 머리 `?` 아래에 연다. 머리 `?`가 없는 화면(정리 화면, 성장 › 주간 점검 화면, 외부 캘린더 목록)에서는 예전처럼 단축키 시트.
- **⌘K › 지원 › 이 화면 사용법** — 레일 도움말과 같은 동작.
- `?` 키는 그대로 단축키 시트(App 전체 — 겹치지 않게).

## 7. 문구 · 테마 · 접근성
- 해요체, 한 문장에 한 동작, 짧게. 단추는 동사. 글 표시는 `**굵게**` · `` `키` ``(kbd) 두 가지만.
- 색은 앱 토큰만(`bg.popover`, `text.*`, `accent`, `accent-subtle`, `overlay.scrim`, `holiday`, `saturday`) → 13개 테마 라이트·다크. 그림 SVG도 토큰 클래스만.
- 카드 `role="dialog" aria-modal`, `aria-label="<탭> 둘러보기 — 3단계 중 1단계"`. 그림 `role="img" aria-label`. 절 제목 `h3`. 동작 줄이기 = 움직임 끔.

## 9. 완료 기준
- [ ] 새 계정으로 탭 6개를 처음 열면 각각 둘러보기 1단계가 실제 화면을 가리키며 뜬다(첫 실행 안내가 떠 있는 동안은 안 뜬다, 일기는 동의 창 뒤).

- [ ] 가리킬 곳이 없으면 가운데 카드(막만 남지 않음). 작업 지도 둘러보기·사용법은 예전과 같다.
