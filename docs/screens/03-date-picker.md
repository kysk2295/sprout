## 3. 날짜 탭 [틱틱 — 도움말 03]
```
┌──────────────────────────────┐
│  [ Date ]   Duration         │ ← 분절 탭
│  ☀   🌅   📅+7   🌙          │ ← 빠른 선택
│  Dec 2025            ‹ ○ ›  │
│  M  T  W  T  F  S  S        │
│  1  2  3  4  5  6  7        │
│  …     (23) …               │ ← 오늘 = 옅은 파란 원, 선택 = 파란 채움
│  ⏱ Time               ›     │
│  ⏰ Reminder           ›     │
│  ⟲ Repeat             ›     │
│  [ Clear ]   [   OK   ]     │
└──────────────────────────────┘
```
| 요소 | 규칙 | 출처 |
|---|---|---|
| 분절 탭 | Date / Duration. 선택 탭은 흰 배경 + 그림자, 바탕 `color.bg.input` | [틱틱] |
| 빠른 선택 4개 | 오늘(해) · 내일(해 뜨는 모양) · 다음 주(📅+7) · 달 모양 | [틱틱] 아이콘. 달 모양의 뜻은 **[임시] "오늘 밤 20:00"** |
| 빠른 선택 동작 | 누르면 날짜가 정해지고 **바로 닫힌다**(OK 없이) | [임시] |
| 머리 | "Dec 2025" (`text.body-strong`) + 오른쪽 `‹ ○ ›` (○ = 이번 달로) | [틱틱] |
| 요일 | 설정의 주 시작 요일(기본 **일요일** — 실제 앱 실측 research 17). `text.caption` `color.text.tertiary` | [틱틱] |
| 날짜 칸 | 32×32px, 원형. 오늘 = `color.accent.subtle` 원 + `color.accent` 글자. 선택 = `color.accent` 채움 + 흰 글자. 다른 달 = `color.text.quaternary` | [틱틱] |
| 6주 고정 | 달력 높이가 달마다 바뀌지 않게 항상 6줄 | [틱틱] (Dec 2025 캡처가 6줄) |
| Time / Reminder / Repeat 행 | 높이 36px, 왼쪽 아이콘 + 이름, 오른쪽에 값(설정됐으면 `color.accent` 글자 + ×) 또는 `›` | [틱틱] 값 표시는 iOS 캡처 |
| Clear | 날짜·시간·알림·반복 모두 지움 | [틱틱] |
| OK | 저장 후 닫기 (`color.accent` 버튼) | [틱틱] |

### 3.1 Time 하위 패널 [임시 — 데스크톱 화면 미확보]
- 행을 누르면 팝오버 안에서 오른쪽으로 슬라이드되는 하위 화면(뒤로 `‹`).
- 위: 시간 입력칸(키보드로 "1730", "5:30pm", "17시 30분" 입력 가능). 아래: 30분 간격 목록(현재 시각 근처로 스크롤).
- "시간 없음" 버튼으로 종일 태스크로 되돌린다.
- 시간을 넣으면 **알림 기본값 "정각에"가 자동으로 붙는다**(설정 → 태스크 기본값으로 바꿀 수 있음) [틱틱: 기간 탭 캡처에서 시간 설정 시 "On time" 표시].

### 3.2 Reminder 하위 패널 [틱틱 목록 / 데스크톱 배치는 임시]
| 종일 태스크 | 시각 있는 태스크 |
|---|---|
| 없음 | 없음 |
| 당일 (09:00) | 정각에 |
| 1일 전 (09:00) | 5분 전 |
| 2일 전 (09:00) | 30분 전 |
| 3일 전 (09:00) | 1시간 전 |
| 1주 전 (09:00) | 1일 전 |
| 직접 설정 › | 직접 설정 › |
- **여러 개를 고를 수 있다**(체크 표시 토글) [틱틱].
- 종일 태스크의 알림 시각 09:00은 설정값 [틱틱 iOS 캡처].
- 직접 설정: [Day/Week] 탭 + 휠(○일 전 / 시 / 분), 지난 시각이면 빨간 "이미 지난 알림입니다", 취소·추가 [틱틱 iOS 캡처].
- 기간 태스크는 "끝날 때" 항목이 추가된다 [틱틱 research 09].
- 계속 알림(Constant Reminder) 토글 [후보].

### 3.3 Repeat 하위 패널 [틱틱]
| 항목 | 보조 표기 (선택한 날짜 기준) |
|---|---|
| 없음 | |
| 매일 | |
| 매주 | (화요일) |
| 매월 | (20일) |
| 매년 | (1월 20일) |
| 평일마다 | (월~금) |
| 직접 설정 › | |
- 날짜가 없는 태스크에서 반복을 고르면 날짜를 오늘로 정한다 [임시].
- 반복 종료 "N회 후"는 `COUNT=남은 횟수`로 저장하고, 회차를 완료할 때마다 1씩 줄인다. 1에서 완료하면 반복이 끝난다 [sprout 저장 방식].
- 반복을 정하면 행 아래에 **"반복 종료"** 행이 생긴다: 안 함 / 날짜까지 / N회 후 [틱틱].

#### 직접 설정 화면 [틱틱 iOS 캡처 → 데스크톱 배치 임시]
| 항목 | 입력 |
|---|---|
| 반복 기준 (?) | 마감일 기준 / 완료일 기준 / 특정 날짜 |
| 주기 | "매 [1] [일·주·월·년]" (숫자 입력 + 단위 선택) |
| 주 단위일 때 | 요일 알약 월~일 여러 개 선택 (선택 = `color.accent` 채움) |
| 월 단위일 때 | "매월 [20]일" / "매월 [셋째] [화요일]" / "매월 마지막 날" [임시]. 31일처럼 그 달에 없는 날은 그 달 마지막 날로 [임시] |
| 특정 날짜일 때 | 달력에서 날짜 여러 개 선택 |
| 요약 문구 | 아래에 "매주 금요일" 같은 문장 (`text.meta` `color.text.secondary`) |
- 완료일 기준을 고르면 주기만 쓰고 요일·날짜 선택은 숨긴다 [틱틱 의미 기준].

## 4. 기간 탭 [틱틱 — 도움말 04]
```
┌──────────────────────────────┐
│   Date   [ Duration ]        │
│  Start  [12/23/25] [17:00]  │
│  End    [12/23/25] [18:00]  │
│  All Day                ◯   │
│  [ Floating Time       ⌄ ] │
│  ⏰ On time              ›   │
│  ⟲ Repeat               ›   │
│  [ Clear ]   [   OK   ]     │
└──────────────────────────────┘
```
| 요소 | 규칙 | 출처 |
|---|---|---|
| 시작·끝 | 날짜 칸 + 시간 칸(각각 클릭 시 작은 달력 / 시간 목록) | [틱틱] |
| 기본값 | 기간 탭으로 바꾸면 시작 = 선택한 날짜의 다음 정각, 끝 = 시작 + 1시간 | [임시] (캡처 17:00–18:00) |
| 끝 < 시작 | 끝을 시작 + 1시간으로 자동 보정 | [임시] |
| All Day | 켜면 시간 칸이 사라지고 날짜 범위만 남음 (여러 날 종일 태스크) | [틱틱] |
| 시간대 | "Floating Time" 드롭다운 — 기본값. 다른 시간대 고정은 [후보] | [틱틱] |
| 알림 | 시간이 있으면 "On time"이 기본으로 붙어 `color.accent`로 보인다 | [틱틱] |
| 날짜 표기 | 상세 머리: 하루 안 "오늘, 9월 6일, 09:00 - 10:00" / 여러 날 "12월 23일 - 12월 26일" | [틱틱] |
| 목록 행 표기 | 시작 기준으로 02 §6 규칙을 따르고, 하루 안 기간이면 "오전 9:00 - 10:00" 처럼 끝 시각을 붙인다. 여러 날이면 "10월 3일 - 10월 5일" [임시] |
| 스마트 리스트·시간 그룹 | 기간 태스크는 [시작, 끝] 범위로 본다. Today = 시작 ≤ 오늘(만료됨 포함), Tomorrow·Next 7 Days = 범위가 그 기간과 겹침. 시간 그룹은 끝 < 오늘이면 만료됨, 진행 중이면 오늘, 아니면 시작 날짜 기준 [임시] |

## 5. 우클릭·일괄 편집의 날짜 줄 [틱틱]
- 아이콘 5개: 오늘 · 내일 · 다음 주 · 날짜 지정(팝오버) · 날짜 지우기(8.0).
- 오늘/내일/다음 주는 **날짜만** 바꾸고 시간·알림·반복은 유지한다 [임시].
- "다음 주" = 다음 주 같은 요일이 아니라 **다음 주 월요일**인지 **+7일**인지 — 아이콘이 "+7"이므로 **+7일**로 한다 [틱틱 아이콘 기준].

### 미루기 메뉴 (02 Overdue "Postpone", 일괄 편집) [틱틱]
- 15분 · 30분 · 1시간 · 2시간 · 1일 · 1주 · 직접 설정.
- 시간이 없는 태스크는 "1일·1주·직접 설정"만 보인다 [임시].
- Overdue 그룹 Postpone은 **오늘로 / 내일로 / 다음 주로 / 날짜 지정**을 먼저 보여준다 [임시].

## 7. 알림이 울릴 때 [틱틱 동작 / 데스크톱 화면 임시]
- **OS 알림**(Mac 알림 센터 / Windows 알림)으로 띄운다. 제목 = 태스크 이름, 본문 = 날짜·리스트. 버튼: **완료 · 다시 알림** [틱틱 항목: 닫기·집중 시작·완료·다시 알림 중 v1 범위].
- 앱이 앞에 있으면 화면 오른쪽 위에 **앱 안 팝업 카드**를 같이 띄운다: 제목 · 날짜 · [닫기] [다시 알림 ▾] [완료] [임시].
- 다시 알림 선택지: 5분 · 15분 · 30분 · 1시간 · 내일 [임시].
- 알림을 누르면 앱을 앞으로 가져오고 그 태스크의 상세를 연다 [임시].
- **예약은 기기에서** 한다(로컬 퍼스트, 서버 푸시 없음). 메인 프로세스가 로컬 DB를 `watch`해서 앞으로 48시간 안의 알림을 예약하고, 다른 기기에서 바뀐 값이 동기화되면 다시 계산한다 [sprout].
- 앱이 꺼져 있는 동안 지나간 알림: 다음 실행 때 지난 1시간 안의 것만 한 번에 띄운다 [임시].
- 완료한 태스크·휴지통 태스크의 알림은 취소한다.
- 메뉴바(트레이)에 상주하는 동안에도 알림은 울린다(창을 닫아도 앱은 살아 있음) [틱틱 메뉴바 상주 구조].

## 8. 반복 태스크의 완료·편집 규칙
| 상황 | 동작 | 출처 |
|---|---|---|
| 마감일 기준 반복을 완료 | 이번 회차를 **완료 기록 태스크로 복사**(status=1, 반복 없음)하고, 원래 태스크의 날짜를 **다음 회차**로 옮긴다 | [틱틱 동작 / 저장 방식은 sprout] |
| 다음 회차 계산 | 원래 마감일 다음의 규칙 날짜. 그 날짜가 아직 과거여도 그대로 둔다(만료됨으로 보임) | [임시] |
| 완료일 기준 반복을 완료 | 다음 회차 = **완료 시각 + 주기** | [틱틱 research 07] |
| 반복 종료 조건 도달(날짜·횟수) | 마지막 회차를 완료하면 반복 없이 끝난다 | [틱틱] |
| 반복 태스크의 날짜·제목 편집 | 반복 전체(앞으로의 모든 회차)에 적용 | [임시] |
| 이번 회차만 건너뛰기 | 우클릭 → "이번 회차 건너뛰기" | [후보] |
| 캘린더의 미래 회차 표시 | 보기 옵션 "Show All Repeat Cycle"를 켜면 계산해서 표시(저장하지 않음) | [틱틱] — 06에서 |
- 완료 기록 태스크는 "완료 & 하지 않음" 영역과 Completed 목록에 보인다.
- 완료 기록에서 체크를 풀면 기록을 지우고 원래 태스크의 날짜를 그 회차로 되돌린다 [임시].
- 반복 태스크를 완료할 때 하위 태스크는 함께 완료하지 않고, 체크 항목은 다음 회차를 위해 모두 체크 해제한다 [임시].
- 완료 기록 태스크는 제목·본문·우선순위·리스트·태그를 복사한다(알림·반복은 복사하지 않음) [sprout].

## 9. 데이터
| 필드 (`tasks`) | 의미 |
|---|---|
| `is_all_day` | 1 = 시간 없음 |
| `start_at` | 기간 태스크의 시작. 기간이 아니면 NULL |
| `due_at` | 마감(기간 태스크면 끝) |
| `time_zone` | `floating`(기본) 또는 IANA 이름([후보]) |
| `repeat_rule` | RRULE 문자열. 예: `FREQ=WEEKLY;INTERVAL=1;BYDAY=FR`, 종료 `UNTIL=…` / `COUNT=…`. 특정 날짜 반복은 `RDATE` 목록 |
| `repeat_from` | `due` / `completion` |
| `repeat_origin_id` | 완료 기록 태스크가 가리키는 원래 반복 태스크 |

- **시간 저장 규칙:** floating 시간은 오프셋 없는 로컬 시각 문자열(`2026-10-03T17:00`), 종일은 날짜만(`2026-10-03`). 고정 시간대([후보])는 UTC ISO + `time_zone`.
- `reminders`(id, task_id, trigger): trigger는 상대값(`-PT0M` 정각에, `-PT5M`, `-P1D`, 종일은 마감일 0시 기준 — `PT9H` 당일 09:00, `-PT15H` 1일 전 09:00, `-P1DT15H` 2일 전 09:00 …) 또는 절대 시각. 기간 태스크의 "끝날 때"는 `END+PT0M`.
- 알림 예약 상태(예약됨, 울림, 다시 알림 시각)는 **기기에만** 저장한다(`local_reminder_state`).
  - 데스크톱 구현: 메인 프로세스가 `userData/reminder-state.json`에 울린 알림 키(`reminder_id@울릴 시각`)와 다시 알림 시각을 둔다 [sprout].

## 10. 완료 기준 (틱틱과 나란히 놓고 확인)
- [ ] 날짜 탭을 [도움말 03](../ticktick-captures/_help/task-details-and-editing-526720/03-desktop-date-and-duration.png)과 나란히 놓으면 탭·빠른 선택 4개·달력(6주, 월요일 시작, 오늘 원)·행 3개·버튼 배치가 같다.
- [ ] 기간 탭을 [도움말 04](../ticktick-captures/_help/task-details-and-editing-526720/04-desktop-date-and-duration.png)와 나란히 놓으면 시작·끝·All Day·Floating Time·알림·반복 배치가 같다.
- [ ] 시간을 넣으면 알림 "정각에"이 자동으로 붙는다.
- [ ] 반복 목록의 보조 표기가 선택한 날짜에 따라 바뀐다(화요일 20일 → "매주(화요일)", "매월(20일)").
- [ ] 마감일 기준 반복을 완료하면 완료 기록이 남고 다음 회차로 옮겨진다. 완료일 기준은 완료 시각 + 주기가 된다.
- [ ] 앱 창을 닫고(트레이 상주) 있어도 알림이 OS 알림으로 울리고, 완료·다시 알림 버튼이 동작한다.
- [ ] 다른 기기에서 알림 시각을 바꾸면 동기화 후 이 기기의 예약이 바뀐다.
- [ ] 오프라인에서도 모든 날짜·반복·알림 설정과 알림 울림이 동작한다.
