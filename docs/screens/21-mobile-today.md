## 2. 레이아웃 (휴대폰 세로, 폭 360~430 기준)
| 영역 | 내용 |
|---|---|
| 상태 막대 + 머리 | 큰 제목 **"오늘"**(28/700, 왼쪽 16) + 아래 작은 날짜 `10월 4일 토요일`(12, 3차 글자) [임시]. 스크롤하면 가운데 작은 제목 `오늘`(17/600)로 접힌다. 오른쪽: 동기화 점(20 §4.5) · `⋯` |

| 행 (52) | 체크박스 20(테두리 = 우선순위 색) · 간격 12 · 제목(16, 한 줄 말줄임) · 오른쪽 메타(12): 리스트 이름(색 점 6 + 이름, 스마트 리스트라 보임) · ⟲(반복) · ⏰(알림) · 날짜/시각. 하위 할 일은 들여쓰기 없이 부모 아래 한 칸(20) 들여 표시, 펼침은 [다음] |

| 탭 바 | 20 §2 |
- 안전 영역(노치·홈 막대) 안쪽에 그린다. 가로 모드는 같은 배치(가운데 최대 폭 600) [임시].
- 날짜 표기는 02 §6 한국어 그대로: 만료 `어제`·`10월 2일`(빨강), 오늘 시각 `오후 3:00`(강조색, 시간 없으면 비움 — 오늘 목록이라 "오늘" 글자 생략 [틱틱 관찰·임시]).

## 3. 구성 요소와 상태
| 요소 | 상태 |
|---|---|
| 행 | 기본 · 누름(배경 `color.bg.selected`, 100ms) · 스와이프 중(§4) · 완료 직후(체크가 우선순위 색으로 채워지고 ✓, **바로** 완료 그룹으로 이동 — 02 §0) · 완료(회색 체크, 흐린 제목, 취소선 없음 — 02 §0) |
| 체크박스 | 누르는 칸은 44×44(보이는 상자 20) — 손가락 크기 [sprout 접근성] |
| 완료 토스트 | 아래 가운데(탭 바·+ 버튼 위) 둥근 사각형: **`작업이 완료되었습니다.`** + 되돌리기 아이콘(주황), 약 2초 [틱틱 02 §0]. XP 문구는 넣지 않는다(10 §2.3) |
| XP 표시 | 완료하면 탭 바 **성장 아이콘** 위로 작은 `+1`이 떠올랐다 사라짐(0.9초) [sprout — 데스크톱 사이드바 카드 대신]. 하루 상한이면 표시 없음 |
| 그룹 머리 | 누르면 접힘/펼침(기기에 저장). 완료 그룹은 처음에 접힘 [임시] |
| 빈 상태 | 가운데 캐릭터(지금 단계, 80) + **`오늘 할 일이 없어요`** + 3차 글자 `+를 눌러 추가하세요` [02 §12 sprout 문구] |
| 모두 완료 | 캐릭터 기쁨 표정 + **`모두 완료했어요`** [02 §12] |
| 불러오는 중(첫 동기화) | 행 자리 회색 막대 6줄. 첫 동기화가 10초 넘으면 아래 `처음 데이터를 내려받는 중…` [임시] |
| 오프라인 | 목록은 그대로. 머리 동기화 점이 빨강, 누르면 토스트 `오프라인 — 연결되면 자동으로 올라가요`(08 §6 문구) |
| 저장 실패(거의 없음) | 빨간 테두리 토스트 `저장하지 못했어요. 다시 시도해 주세요`(02 §12) |
| 당겨서 새로 고침 | 목록을 아래로 당기면 즉시 동기화 [모바일 관례·임시]. 로컬 퍼스트라 결과 화면은 바뀌지 않을 수 있다 |

## 4. 인터랙션
### 4.1 누르기
| 동작 | 결과 | 출처 |
|---|---|---|
| 체크박스 누름 | 완료 / 완료 취소 + 가벼운 흔들림 + 완료음(설정 켬일 때) | [틱틱] 02 §7·§12 |
| 행 누름 | **간단 상세 시트**(§5) | [틱틱 상세 → v1 축소] |
| 행 길게 누름 | 메뉴 시트: 날짜 줄(오늘 · 내일 · +7 · 날짜 지정) · 우선순위 줄(깃발 4개) · `상단 고정`/`고정 해제` · `이동 ›` · (구분선) · `삭제` | [틱틱 02 §0 우클릭 메뉴를 모바일로, 하위 할일·태그·복사는 [다음]] |
| `미루기`(만료됨 머리) | 메뉴: 오늘로 · 내일로 · 다음 주로 · 날짜 지정 → 날짜만 바꾸고 시각 유지 + 토스트 `오늘로 미뤘어요 ⟲` | 02 §12 |
| 머리 `⋯` | `완료된 할일 숨기기/보기` · `자세히 보기`(행 아래 본문 한 줄, 행 높이 64) | 02 §0 목록 `⋯` 줄임 |
| 탭 바 `오늘`을 다시 누름 | 맨 위로 스크롤 | [모바일 관례·임시] |

### 4.2 스와이프 [틱틱 기본값 — research 20 §3]
| 방향 | 결과 |
|---|---|
| **오른쪽으로 밀기** | 왼쪽에 초록 칸(✓ 완료)이 드러난다. 끝까지(행 폭 40% 이상) 밀고 놓으면 **완료**. 짧게 밀고 놓으면 `완료`·`고정` 두 칸이 열린 채 남고 눌러서 고른다 |
| **왼쪽으로 밀기** | 오른쪽에 세 칸: **`이동`**(파랑) · **`날짜`**(주황) · **`삭제`**(빨강) [순서·색 임시]. 칸을 눌러 실행. 끝까지 밀면 실행하지 않고 열린 채 둔다(실수 삭제 방지) [임시] |
| 다른 행을 누르거나 스크롤 | 열린 칸이 닫힌다 |
- `날짜` → 날짜 시트(22 §3.3, 03의 축소판). `이동` → 리스트 고르기 시트(기본함 + 리스트, 폴더는 접힌 묶음) → 토스트 `업무로 옮겼어요 ⟲`(받침 로/으로, 02 §12). `삭제` → 바로 휴지통 + 토스트 `휴지통으로 옮겼어요 ⟲`(5초).
- 완료 스와이프 = 체크박스와 같은 결과(XP·토스트·소리). 완료된 행을 오른쪽으로 밀면 `완료 취소`.
- 끝 도달 지점에서 선택 틱 흔들림 한 번.
- 스와이프 동작 사용자 지정(짧게/길게 × 좌우 네 칸)은 [다음].

### 4.3 되돌리기
- 토스트의 ⟲ = 마지막 동작 되돌리기(완료·미루기·이동·삭제). 완료 되돌리기는 같은 날 XP도 되돌린다(10 §6).
- 흔들어서 되돌리기(iOS)는 쓰지 않는다 [임시].

## 5. 간단 상세 시트 [틱틱 상세를 v1 범위로 줄임]
- 아래에서 올라오는 시트, 처음 높이 화면의 60%, 위로 끌면 전체. 끌어 내리거나 바깥 누르면 닫힘(자동 저장).
- 위에서부터: 손잡이 · 머리 줄(체크박스 · 📅 날짜 글자(강조색, 누르면 날짜 시트) · 오른쪽 깃발(우선순위 메뉴)) · **제목**(19/700, 바로 편집) · **본문**(16, 자리 표시 `설명`은 편집 중일 때만 — 02 §0) · 아래 줄 `[→] 리스트 이름`(누르면 리스트 고르기) · `⋯`(상단 고정 · 삭제).
- 편집은 0.6초 뒤 자동 저장(02 §13 규칙). 제목을 비우고 닫으면 이전 제목으로 되돌린다 [임시].
- 체크리스트 모드 본문·하위 할 일·태그·반복 편집은 **읽기만**(있으면 보여 주고 `컴퓨터에서 고칠 수 있어요` 3차 글자) [임시 / 편집은 다음].

## 6. 데이터
| 동작 | 읽기·쓰기 |
|---|---|
| 목록 | `tasks` WHERE `status=0` AND `deleted_at IS NULL` AND `due_at < 내일 0시`(02 §14 Today 조건, 만료 포함) + `show_in_smart != 'none'`인 리스트, JOIN `lists`(이름·색), `reminders` 있음 여부. 완료 그룹 = 오늘 마감이면서 `status=1`, 최근 완료순. `watch`로 다시 그림 |
| 완료 | `tasks.status=1, completed_at` + `xp_events`(공용 규칙, 결정적 id `task:<id>:<day>`) — 데스크톱 `grantTaskXp`와 같은 문장(20 §4.2 공용 로직). 반복이면 03 §8 다음 회차 |
| 완료 취소 | `status=0, completed_at=NULL` + 같은 날 XP 되돌림(`task_revoke`) |

| 이동 | `tasks.list_id`, `section_id=NULL` |
| 삭제 | `tasks.deleted_at`(휴지통), 되돌리기 = NULL |
| 고정 | `tasks.pinned_at` |
| 알림 다시 예약 | 위 쓰기가 끝나면 20 §4.4 예약 다시 계산 |

## 7. 완료 기준 (틱틱 모바일과 나란히)
- [ ] 만료됨·오늘·완료 그룹, 날짜 표기 색·문구가 02 한국어 규칙과 같다.
- [ ] 체크 → 바로 완료 그룹 + `작업이 완료되었습니다.` 토스트 + 성장 탭 `+1`. 11번째 완료부터 `+1` 없음.
- [ ] 오른쪽 끝까지 밀어 완료, 짧게 밀어 완료·고정 칸. 왼쪽 밀어 이동·날짜·삭제, 각각 ⟲ 되돌리기.
- [ ] 길게 누름 메뉴, `미루기` 메뉴가 동작한다.
- [ ] 간단 상세에서 제목·본문·날짜·우선순위·리스트를 바꾸면 데스크톱에 반영된다.
- [ ] 비행기 모드에서 위 동작이 모두 되고 다시 연결하면 올라간다.
- [ ] 라이트·다크, iPhone·Android, 큰 글자 설정에서 행이 깨지지 않는다.
