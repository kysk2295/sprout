### 4.2 스와이프 [틱틱 기본값 — research 24 §4 캡처]
| 방향 | 결과 |
|---|---|
| **오른쪽으로 밀기** | 왼쪽에 아이콘 칸 2개: **완료(초록 `--m-swipe-done`) · 고정(노랑 `--m-swipe-pin`)**. 끝까지(행 폭 40% 이상) 밀고 놓으면 **완료**(칸이 초록으로 꽉 차며 `놓으면 완료`) [임시 문구] |
| **왼쪽으로 밀기** | 오른쪽에 아이콘 칸 3개: **이동(파랑) · 삭제(빨강) · 날짜(주황)** — v0.1의 "이동·날짜·삭제"를 캡처 순서로 고침. 칸 폭 약 60. 칸을 눌러 실행. 끝까지 밀어도 실행하지 않고 열린 채 둔다(실수 삭제 방지) [임시] |
| 다른 행을 누르거나 스크롤 | 열린 칸이 닫힌다 |
- 칸은 아이콘만(글자 없음) [틱틱]. 묶음 카드 안에서 밀리고 카드 모서리가 칸을 자른다.
- `날짜` → 날짜 시트(22 §3.3, 03의 축소판). `이동` → 리스트 고르기 시트("이동" · 검색 칸 · 기본함 + 리스트(지금 것 ✓) · 폴더 묶음 · `+ 리스트 추가`) → 토스트 `업무로 옮겼어요 ⟲`(받침 로/으로, 02 §12). `삭제` → 바로 휴지통 + 토스트 `휴지통으로 옮겼어요 ⟲`(5초).
- 완료 스와이프 = 체크박스와 같은 결과(XP·토스트·소리). 완료된 행을 오른쪽으로 밀면 `완료 취소`.
- 끝 도달 지점에서 선택 틱 흔들림 한 번.
- 스와이프 동작 사용자 지정(짧게/길게 × 좌우 네 칸)은 [다음].

### 4.3 되돌리기
- 토스트의 ⟲ = 마지막 동작 되돌리기(완료·미루기·이동·삭제). 완료 되돌리기는 같은 날 XP도 되돌린다(10 §6).
- 흔들어서 되돌리기(iOS)는 쓰지 않는다 [임시].

## 5. 상세 시트 [틱틱 — research 24 §7]
- 행을 누르면 **아래에서 반쯤 올라오는 시트**(위 모서리 22, 뒤 덮개). 위로 끌면 **전체 화면**(머리 `‹ 리스트 이름 ⌃⌄`). 끌어 내리거나 바깥 누르면 닫힘(자동 저장).
- 위에서부터:
  1. 손잡이 · 머리 줄: 왼쪽 **리스트 이름 ⌃⌄**(누르면 이동 시트) · 오른쪽 **둥근 깃발**(우선순위 팝오버: 높음·중간·낮음·없음, 깃발 색, 지금 값 ✓) · **둥근 ⋯**.
  2. **체크박스 + 날짜 글자**(15, 강조색 `오늘, 오후 3:00` + 🔔/⟲ 아이콘, 비면 회색 `날짜와 알림`) → 누르면 날짜 시트.
  3. **제목**(20/600, 바로 편집).
  4. **설명**(16, 2차 글자, 비면 자리 표시 `설명`). 체크리스트 모드면 설명 대신 항목 줄(체크 16 · 글 · 오른쪽 끌기 손잡이 · 맨 끝 `+ 항목 추가`), 체크 아이콘이 목록 모양.
  5. 태그 칩 줄(있을 때) · `하위 할 일 n` 머리 + 하위 행.
  6. 맨 아래 도구 줄: **태그 · 체크리스트로 바꾸기 · 하위 할 일** [틱틱 순서, 첨부는 v1 밖이라 뺌] · 오른쪽 3차 `저장됨`.
     - **키보드가 올라오면 도구 줄이 키보드 바로 위에 붙는다**(제목·설명·체크 항목 편집 중 — research 24 §7 "toggle button located just above the right side of the keyboard"). 키보드 애니메이션과 같은 시간·곡선으로 따라 오르내리고, 키보드 위에서는 아래 안전 영역 여백 없이 위아래 5·8. 키보드가 없으면 시트 맨 아래 + 아래 안전 영역(20 §3.1). 본문 스크롤 아래 여백도 키보드 높이만큼 늘려 마지막 줄이 도구 줄에 가리지 않는다. Android(창 크기 줄임)는 창이 이미 키보드 위에서 끝나므로 같은 결과.
- ⋯ → 아래 시트: 위 **큰 아이콘 줄** `고정 · 복사 · 하지 않음 · 삭제` + 목록 `하위 할 일 추가 · 노트로 바꾸기 · 태그 · 링크 복사` [틱틱 배치, 공유·집중·첨부·위치·댓글은 뺌]. "주간 목표에 연결"은 넣지 않음(20 M8).
- 편집은 0.6초 뒤 자동 저장(02 §13 규칙). 제목을 비우고 닫으면 이전 제목으로 되돌린다 [임시].
- 편집 범위(20 M3 제안): 제목·설명·날짜·우선순위·리스트·**체크리스트 체크·항목 추가·태그**는 v1, 하위 할 일 만들기·반복 직접 설정·서식 막대는 v1.1. 그 전에는 있으면 보여 주고 3차 글자 `컴퓨터에서 고칠 수 있어요`.

### 5.1 여러 개 고르기 [틱틱 iOS · 20 M4 — 확정: v1에 없음, 다음]
