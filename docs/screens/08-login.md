## 2. 언제 보이나 — **결정: A안** (2026-10-04)
- **A안 [틱틱]**: 로그아웃 상태면 앱을 열자마자 로그인 화면이 창 전체를 덮는다. 로그인해야 쓸 수 있다.
- **B안 [sprout]**: 로그인 없이도 로컬로 다 쓸 수 있고(로컬 퍼스트), 레일 아래 아바타·설정의 계정 화면·동기화 버튼에서 로그인을 연다. 로그인하면 이 기기 데이터가 계정으로 올라간다.
- 두 안 모두 로그인 화면 자체(§3~§5)는 같다.
- A안 세부: 첫 실행(로그아웃)에도 로컬 첫 실행 데이터(기본함·예시)는 만들어 두고, **새로 가입하면 그 데이터가 새 계정의 시작 데이터로 올라간다**. 기존 계정으로 로그인하면 지우고 서버 데이터를 내려받는다. 웹 미리보기(`npm run web`)에는 서버가 없어 로그인 화면을 띄우지 않는다.

## 3. 레이아웃 [틱틱 웹 실측]
- 창 전체 바탕 `#f9f9f9`(라이트) / `color.bg.app`(다크). 가운데 흰 카드(다크는 `color.bg.popover`) **382×(내용) 모서리 16**, 안쪽 좌우 46(입력칸 폭 290).
- 카드 안 위에서부터: 제목 → 이메일 → 비밀번호 → 주 버튼 → (로그인만) "비밀번호를 잊어버림" → 구분선 → 소셜 버튼 → (가입만) 약관 문구.
- 카드 아래 가운데: 전환 링크 "계정이 없으세요? **등록하기**" / "이미 계정이 있으신가요? **로그인**"(13px, 링크는 강조색).
- 창 맨 위 오른쪽의 같은 전환 버튼과 왼쪽 로고는 웹 전용이라 넣지 않는다 [sprout]. 로고 자리는 sprout 로고(제품명 확정 전 "sprout").
- 창이 작아도(최소 800×560) 카드는 가운데, 세로가 모자라면 스크롤.

| 요소 | 크기·글자 [틱틱] | sprout 토큰 |
|---|---|---|
| 제목 "로그인" / "등록하기" | 약 22px 굵게, 왼쪽 정렬 | `text.title` 계열 |
| 입력칸 | 290×40, 모서리 10, 테두리 1 `rgba(25,25,25,.1)`, 14px, 칸 사이 14 | `color.border.divider` |
| 자리 표시 | 로그인 "이메일" · "비밀번호" / 가입 "이메일" · **"비밀번호: 6-64자"** | `color.text.quaternary` |
| 주 버튼 | 290×40, 모서리 10, 강조색 채움, 흰 14px 500, 위 간격 14 | `color.accent` |
| 약관 문구(가입) | 12px 60% 회색: "가입함으로써 **이용 약관** 및 **개인정보 처리방침**에 동의하게 됩니다." 두 링크는 밑줄 | 링크는 sprout 문서 주소 [다음: 문서 작성] |
| 소셜 버튼 | 288×38 테두리 버튼 "Google로 계속하기" · "Apple로 계속하세요" | **[다음]** 구글·애플 로그인을 붙일 때 넣는다. 그 전에는 버튼·구분선을 보이지 않는다 |
| "비밀번호를 잊어버림" | 13px 회색, 가운데 | **[다음]** 메일 발송 수단이 생기면 넣는다(공개 출시 전 필수) |

## 5. 인터랙션
- Enter: 이메일 칸 → 비밀번호 칸, 비밀번호 칸 → 제출. Tab 순서 위→아래.
- 전환 링크: 로그인 ↔ 가입, 입력한 이메일은 유지, 오류는 지움.
- (A안) Esc·창 닫기: 앱 종료가 아니라 창만 닫힘(Mac 관례).

## 6. 동기화 상태 (레일 ⟳ 버튼) [틱틱 위치 / 동작 임시]
| 상태 | 표시 |
|---|---|
| 로그아웃 | ⟳ 회색. 누르면 로그인 화면(B안) |
| 동기화 중(업로드·다운로드) | ⟳ 회전 |
| 완료 | 정지. 툴팁 "마지막 동기화: 오후 3:21" |
| 오프라인·오류 | ⟳ 오른쪽 위 작은 빨간 점. 툴팁: 끊김 → "오프라인 — 연결되면 자동으로 올라가요", 오류 → "동기화에 실패했어요 — 다시 시도하는 중". 변경은 로컬에 쌓였다가 연결되면 자동으로 올라간다 |
| 누르기 | 즉시 다시 연결·동기화 |

## 7. 계정 설정 (설정 → 계정) [틱틱 settings-account 기준, v1 줄임]
- 아바타(이메일 첫 글자) · 이메일 · 동기화 상태 한 줄.
- **로그아웃** 버튼: 확인 대화상자 "로그아웃하면 이 기기의 데이터가 지워지고 서버에만 남아요." → 로컬 데이터 삭제 후 첫 실행 상태(B안) 또는 로그인 화면(A안).
- [다음] 비밀번호 변경, 로그인 기기 관리, 계정 삭제(공개 출시 전 필수 — 개인정보).

## 8. 데이터
| 동작 | 읽기·쓰기 |
|---|---|
| 가입·로그인 | API `POST /auth/signup` · `/auth/login` → 토큰. 메인 프로세스가 키체인 암호화로 `userData/auth.bin`에 저장 |
| 첫 로그인 | `GET /auth/me`의 `has_data`: 없음 → 로컬 모든 테이블 `owner_id`를 내 id로 바꿔 올림 / 있음 → 로컬 비우고 내려받음(로그인 전 이 기기에서 만든 것은 사라진다 — 확인 대화상자 필요 [임시]) |
| 동기화 상태 | PowerSync `currentStatus` → IPC `auth:state` |
| 로그아웃 | `POST /auth/logout`, 로컬 DB 비움 |
- 비밀번호 규칙: 틱틱과 같이 **6-64자** (지금 서버는 8자 이상 → 6-64로 맞춘다).
