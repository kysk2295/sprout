# 사용자 필터 — 일반 조건

근거: [Mac 관찰](../ticktick-captures/filter-edit/NOTES.md), [필터 조사](../ticktick-research/13-filters.md). 2026-10-04 라이브에서 필터 섹션·안내 문구 확인. 편집 모달 세부는 기존 프레임 근거이며 이번 라이브에서 재확인하지 못했다.

- 사이드바 리스트 아래 필터 구역, 호버/키보드 포커스 시 +, 행 우클릭 편집·삭제.
- 편집 모달 520px. 이름·이모지, 리스트·태그 선택, 날짜, 우선순위 다중 선택, 포함 키워드, 취소·저장. Advanced·노트는 v1 제외.
- 모양(filter-edit NOTES 기준): 제목 "필터 추가/편집"(가운데). 첫 줄은 이모지 칸(40) + 이름 입력(리스트 편집과 같은 칸). 그 아래 **조건 행 = 왼쪽 라벨(폭 72, 13px 회색) · 오른쪽 입력**: 리스트 · 태그(알약 모양 켜고 끄기 버튼, 아무것도 안 고르면 "전체" 알약이 켜짐) · 날짜(드롭다운) · 우선순위(전체·높음·중간·낮음·없음 알약, 여러 개) · 포함("작업 키워드" 입력). 아래 오른쪽 취소 · 저장(강조색). 입력칸 포커스는 강조색 테두리(기본 브라우저 테두리 없음).
- 일반 필터: 같은 종류의 여러 선택은 OR, 종류 사이 AND. 날짜는 전체·오늘·내일·다음7일·만료됨·날짜없음. 기간 일정은 해당 날짜 범위와 겹치는지 비교. 빈 선택은 전체. 키워드는 제목·본문 부분 일치(%, _도 문자로).
- 데이터 filters.name/emoji/rule_json/sort_order. 완료·휴지통 조건은 기존 목록 규칙과 동일. 보관 리스트 제외. 새 작업은 기본함으로.
- 상태: 이름 공백 저장 불가, 저장 중 중복 제출 방지, 오류 메시지와 입력 유지, 조건 결과 없으면 기존 빈 목록, 삭제는 확인창.
- 완료 기준: 생성·편집 즉시 결과 갱신, 앱 재시작 후 유지, 날짜/태그/우선순위 조합 조회 테스트, 빈 조건 및 잘못된 저장값에서 전체 작업이 잘못 노출되지 않음.
