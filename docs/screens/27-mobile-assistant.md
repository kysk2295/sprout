## 1. 틱틱 기준 자료
틱틱에 AI 대화 화면이 없다(틱틱 AI는 음성 추가·한 줄 지시 — research 25 §4) → 화면 자체는 [sprout]. 부품은 키트·틱틱 것:
| 부품 | 근거 |
|---|---|
| 머리(둥근 ‹ · 가운데 제목 · 둥근 버튼) · 아래 시트 · 키보드 · 토스트 | [mobile-kit.css](mockups/mobile-kit.css) |
| 결과 카드 안 할 일 행(체크 · 제목 · 오른쪽 강조색 날짜) | [21](21-mobile-today.md) 행, [13 §3](13-assistant.md) |
| 입력창 = 맨 아래 고정 둥근 입력 + 보내기/정지 | 모바일 AI 대화 공통 패턴(research 25 §4), 13 §3 |

## 2. 레이아웃
### 2.1 대화 화면 (전체 화면, 탭 알약 숨김 — D1)
| 영역 | 내용 |
|---|---|
| 머리 (52) | 둥근 `‹` · 가운데 `AI 비서` + 상태 알약(`● 연결됨` / `● 대기 중 · 앞에 N명` 주황 / `● 지금은 쓸 수 없어요` 회색 — 13 §2.1) · 오른쪽 둥근 연필(새 대화, 13의 ⌘N 자리). 아래 0.5 구분선 |
| 대화 | 좌우 16, 위에서 아래로. 내 말 = 오른쪽 회색 면(모서리 16/16/4/16, 최대 80%) · AI = 왼쪽 ✦ 원(28) + 본문 15.5/22 |
| 결과 카드 | 13 §3 그대로, 모서리 12: 머리 줄(아이콘 · `등록한 일정` · 개수) + 할 일 행(48: 체크 18 · 제목 · 오른쪽 강조색 `내일 15:00`). 아래 `↶ 되돌리기`(강조색 글자) |
| 집계 카드 | 머리 `완료 기록 · 이번 주(10/5–10/11)` · 큰 숫자 24/700 · 기준 문구(3차, 13 부록 A) · 근거 행 최대 5개 |
| 진행 단계 줄 | `● 연결 › ● 해석 › ● 확인 · 3초`(12, 지난 단계 강조색) |
| 입력창 | 맨 아래 좌우 12, 둥근(22) 회색 면, 1줄 44 → 최대 6줄. 자리 글자 `무엇이든 물어보세요`. 오른쪽 원 32: 보내기(강조색 ↑) / 빈칸이면 흐림 / 처리 중 = 정지(■, 진한 원) |
| 바닥 한 줄 | 3차 11 `sprout AI는 운영자의 Mac mini에서 돌아가요 · 결과는 카드에서 되돌릴 수 있어요` |
- 키보드가 올라오면 입력창이 키보드 위로, 대화는 맨 아래를 따라간다(보고 있을 때만, 13 §4).

### 2.2 빠른 진입 반 시트 (D3)
| 영역 | 내용 |
|---|---|
| 여는 곳 | 오늘 머리 오른쪽 둥근 **✦**(강조색) · 빠른 입력 도구 막대 **✦ AI에게** |
| 모양 | 아래 시트(키트, 위 모서리 22), 처음 높이 = 키보드 위 약 300 (중간 단), 끌어 올리면 전체 = 대화 화면 |
| 머리 (44) | `AI 비서`(17/700) + 상태 알약 · 오른쪽 둥근 `↗`(전체 화면 D1) · `×` |
| 비었을 때 | 13 §3 빈 상태 문장 + 예시 카드 2개(누르면 채우고 바로 보냄) |
| 입력 | 바로 초점 + 키보드. 빠른 입력에서 넘어오면 쓴 글이 이미 채워져 있다 |
| 결과 | 결과 카드가 시트 안에 쌓인다. 시트를 닫아도 대화·초안은 전체 화면과 공유(13 §4) |

## 3. 구성 요소와 상태 (문구는 13 §6 그대로)
| 상태 | 표시 |
|---|---|
| 빈 대화 | ✦ 원 + `할 일을 말로 등록하거나, 내 일정과 완료 기록을 물어보세요.` + 예시 3개 |
| 받는 중 | 글자가 점점 늘어나고 끝에 깜빡이는 강조색 커서 · 보내기 자리 ■ |
| 대기열 | 머리 알약 `● 대기 중 · 앞에 2명`(주황) + 답 자리 `순서를 기다리는 중…` + 단계 줄 |
| Mac mini 꺼짐 | 회색 상자: ⚠ `지금은 AI를 쓸 수 없어요. 할 일·캘린더는 그대로 쓸 수 있어요.` + 3차 `1분 뒤 저절로 다시 확인해요` + [다시 시도] |
| 서버 연결 안 됨(오프라인) | `sprout AI에 연결하지 못했어요. 인터넷 연결을 확인해 주세요.` + [다시 시도]. 머리 알약 회색 |
| 상한(429)·혼잡(503) | 서버 문구 + `(오늘 남은 요청 N회)` · [다시 시도]가 30초 흐림(`다시 시도 · 28초`) |
| 사용자가 멈춤 | `요청을 멈췄어요. 내용을 확인한 뒤 다시 보내 주세요.` + [다시 시도] [입력으로 가져오기] |
| 오래 걸림 | `AI 응답이 너무 오래 걸려요. 다시 시도해 주세요.` |
| 되돌리기 불가 | 흐린 `↶ 되돌리기` 누르면 토스트 `등록 뒤에 바뀐 항목은 되돌릴 수 없어요` (휴대폰엔 마우스 툴팁이 없어서) |
| 최신으로 | 위로 읽는 중 새 답 → 입력창 위 가운데 알약 `↓ 최신으로` |
- 원문 오류(JSON·스택)는 보이지 않는다(13 §6).

## 4. 인터랙션
| 동작 | 결과 |
|---|---|
| 보내기 | 키보드 `보내기`(Return) 또는 원 버튼. 한글 조합 중 Return은 보내지 않는다. 줄바꿈은 Shift가 없으므로 [임시] 키보드 Return = 보내기, 여러 줄은 붙여 넣기로만 |
| 결과 행 누름 | 할 일 간단 상세 시트(21 §5) |
| 결과 행 체크 | 그 자리에서 완료(XP 포함, 21과 같은 완료) |
| 되돌리기 | 13 §5 규칙. 성공 토스트 `등록을 되돌렸어요` |
| 연필(새 대화) | 대화 비우기(처리 중·빈 대화면 흐림) |
| 머리 알약 누름 | 다시 연결 |
| 반 시트 끌어 올림 / ↗ | 전체 화면 대화(같은 대화) |
| 반 시트 끌어 내림 / × | 닫기 — 처리 중이면 닫기만, 요청은 계속(13 §4 Esc와 같음) |
| 다시 시도 | 같은 말을 말풍선으로 또 쌓지 않는다(13 §4) |
- 모션 감소 설정이면 커서 깜빡임·시트 튕김 끔.

## 5. 데이터 (13 §5 그대로)
| 동작 | 읽기·쓰기 |
|---|---|
| 조회 | `lists`, `tasks`(삭제·취소 제외) — 앱이 SQL을 만든다(공용 코드로 옮김) |
| 등록 | `tasks` 일정 필드, `status=0` — 13 `askAssistant` 검증 경로를 공용으로 옮겨 같이 쓴다 |
| 되돌리기 | 생성 직후와 수정 시각·상태가 같을 때만 `deleted_at` |
| 대화 기록 | 기기 로컬 파일(expo-file-system, `sprout.assistant.history.<계정>`) 최근 100개, 동기화 안 함(M-A5) |
| 모델 호출 | `POST /ai/assistant`(JWT, NDJSON 스트림) — 데스크톱 배포판과 같은 서버 프록시. 서버 변경 없음 |
- 옮길 공용 코드(구현 때): 의도 해석 검증·조회 SQL 생성·등록 검증(지금 `apps/desktop/src/renderer/src/data/` 쪽) → `packages/`.

## 6. 완료 기준
- [ ] "내일 오후 3시 기획 회의 한 시간" → 결과 카드 행 1개, 누르면 상세 시트, 되돌리기 동작, 데스크톱에도 같은 할 일.
- [ ] "이번 주 공부 몇 시간" → 집계 카드 숫자가 데스크톱과 같다.
- [ ] 오늘 ✦ 반 시트 ↔ 전체 화면이 같은 대화·초안. 빠른 입력 ✦가 쓴 글을 넘긴다. + 길게 누르기는 그대로 음성 입력.
- [ ] 13 §6의 오류가 모두 사람 말로 보인다(서버 끔·Ollama 끔·429·오프라인 강제).
- [ ] 앱을 뒤로 보냈다 돌아오면 이어서 보이고, 앱을 닫으면 서버 요청이 멈춘다.
- [ ] 시안 D1~D3과 나란히(라이트·다크).

## 7. 구현 메모 (v1.0, 2026-10-05)
| 곳 | 결정 | 왜 |
|---|---|---|
| 서버 호출 | `POST {API}/ai/assistant`(Bearer, `stream:true`) — `expo/fetch`로 NDJSON을 줄 단위로 읽는다. 대기열 줄 `{"queue":{"position":n}}` → 머리 알약 `대기 중 · 앞에 N명` + 답 자리 `순서를 기다리는 중… (앞에 N명)`. 모델 = `GET /ai/status`의 기본 모델(없으면 첫 모델) | 데스크톱 배포판(main/assistant.ts)과 같은 경로·같은 시간 제한(330초) |
| 오류 | 서버 한국어 문구 그대로, 429면 `(오늘 남은 요청 N회)`(주 상한 제외), 상한·혼잡이면 [다시 시도 · N초] 30초 흐림, 네트워크 = `sprout AI에 연결하지 못했어요…`, 꺼짐 = `지금은 AI를 쓸 수 없어요…` + `1분 뒤 저절로 다시 확인해요` | 13 §6 |
| 해석·실행 | 지시문·의도 검증·후처리(길이 안 만들기, 읽기 요청 살리기, 기간은 달력 계산)·조회 SQL·집계를 데스크톱 코드에서 그대로 옮김(`src/assistant/core.ts`, 시험이 데스크톱 parseIntent와 같은 결과인지 확인) | 같은 말 → 두 기기 같은 결과 |
| 결과 카드 | 행 체크 = 21과 같은 완료(`completeTasks`, XP 포함), 행 누름 = 할 일 상세 시트(`/task/<id>`), 삭제된 항목은 취소선 `삭제됨` | §4 |
