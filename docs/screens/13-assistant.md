# AI 비서 실제 연결
승인된 설계의 첫 구현: Ollama 로컬 모델 선택/연결 상태, 공유 대화, 자연어 일정 생성, 최신 태스크 조회, 완료 집계, 생성 실행 취소.
모델은 요청을 create/query/stats/reply 구조로 해석한다. 앱은 날짜/리스트/기간을 검증하고 SQL은 직접 구성한다. 모델이 임의 SQL을 반환하거나 호출하지 않는다. 집계는 완료 시각 기준, 종일/단일 시각은 건수만, 부모 기간 우선. 반복 생성은 검증 가능한 RRULE만 허용한다.
미리보기는 로컬 Ollama 직접 연결, Electron은 메인 프로세스 IPC 연결. 원격/클라우드 모델로 자동 대체하지 않는다. 오류 시 입력 유지, 중단은 저장 전까지만 가능. 이미 생성된 항목은 결과에 표시하고 이후 변경이 있으면 실행 취소 거부.
전용 화면/FAB는 같은 요청 상태·대화 이력·모델 선택 공유. 결과 카드로 태스크 상세 열기. 대화 기록은 기기 로컬 계정별 저장, 새 대화로 비우기. 요청당 읽기 결과 최대 100개 표시하되 집계는 전체 조회로 계산.
현재 미구현: 작업 지도용 새 분류 생성/메모 위키는 별도 단계. 여기서는 기존 리스트를 선택한다.

## 화면과 조작
기존 `12-workspace-tabs.md`의 rail/FAB 배치를 유지한다. TickTick에 없는 로컬 비서 화면으로 기존 앱 색상·입력·버튼 토큰을 사용한다. 상단 연결 상태/모델 선택/재연결/새 대화, 가운데 스크롤 대화와 원본 카드, 하단 입력으로 구성한다. 좁은 FAB에서는 카드의 날짜가 다음 줄로 내려간다. Enter 전송, Shift+Enter 줄바꿈, IME 조합 중 Enter는 전송하지 않는다. 처리 중 입력/모델 변경을 잠그고 중단 버튼을 표시한다. 오류 시 초안 보존, 빈 상태에는 요청 예시를 제공한다.

## 읽기·쓰기와 완료 기준
읽기: lists, tasks(삭제·취소 제외). 생성: tasks 일정 필드, status=0. 되돌리기: 생성 직후 수정 시각과 상태가 같을 때만 deleted_at 갱신. 반복은 기존 앱 완료 후 다음 항목 생성 규칙을 사용하며 미래 모든 회차를 펼쳐 조회하지 않는다. 새 대화는 현재 기기에 보관된 대화만 지운다.
검증: 로컬 모델 연결, 자연어 날짜/시간 생성, 결과 원본 열기, 주간 조회/집계, FAB 공유, 취소/오류, 잘못된 날짜/목록 차단, 중복 ID 차단, 변경된 항목 되돌리기 거부.

## 맥미니 연결 (2026-10-04)
사용자 지정 실행 장비는 SSH 별칭 `macmini`의 M1 16GB다. Electron 메인/개발 서버가 필요할 때 SSH 로컬 포워딩을 열어 원격 127.0.0.1:11434에 연결한다. 포트는 OS가 선택하고 루프백에만 바인딩하며 서버 종료 시 SSH 자식을 종료한다. 로컬 Ollama로 자동 대체하지 않는다. 화면에 ‘맥미니 AI’를 표시하고 연결 오류는 맥미니/SSH 확인을 안내한다. qwen3.5:9b 우선 선택, 임베딩 모델은 숨긴다. 메모리 사용을 위해 컨텍스트 4096, 출력 700 토큰, 5분 유지로 제한한다.

## 실시간 대화 UX (2026-10-04 사용자 승인)
범위는 AI 비서 전용 화면과 FAB다. 맥미니 Ollama의 실제 NDJSON 스트림을 Electron IPC/웹 개발 서버로 전달한다. 연결→응답 수신→검증→조회/저장 단계는 실제 작업 시점에 갱신한다. 모델 내부 사고/구조화 JSON을 그대로 노출하지 않는다. reply의 사용자용 message만 점진적으로 표시하며 등록/조회는 검증 이후 결과 카드를 표시한다. 중단·오류 시 이미 수신된 진행 상태와 사용자 입력을 유지하고 재시도 동작을 제공한다. 입력창은 전송 중에도 다음 초안을 작성할 수 있다. 하단을 보고 있을 때만 자동 스크롤, 위로 읽는 동안은 ‘최신으로’ 버튼 제공. 실행 시간, 연결 상태, 새 대화, 결과 원본 열기/되돌리기 유지. 모션 감소 설정을 존중한다.
기능 안내·사용법·인사 등 명확한 안내 질문은 별도 자연어 스트림으로 답한다. 이 경로는 DB 조회/쓰기 없이 기능을 설명하며, 사용자 일정 내용을 아는 것처럼 답하지 않는다. 실제 작업 요청은 기존 구조화 해석·검증 경로를 유지한다.
