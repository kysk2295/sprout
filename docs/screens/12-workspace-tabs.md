# 기능 탭과 AI 빠른 창 — 2026-10-04

> **2026-10-04 v2 재설계:** 각 탭의 화면은 개별 명세로 옮겼다 — AI 비서·빠른 창 [13](13-assistant.md), 메모함·주제 위키 [11](11-notes.md), 작업 지도 [14](14-work-map.md), AI 사용량 [10-ai-usage](10-ai-usage.md). 레일 순서는 [01](01-app-shell.md)이 정본이다(주제 위키는 메모함 안 탭으로 통합). 아래는 진입 화면 단계의 기록이다.

사용자 요청: 앞서 합의한 기능의 탭을 우선 모두 만든다. 이 단계는 진입점과 준비 화면이며 AI 실행·위키 생성·계정 연결 구현이 아니다.

레일 순서: 태스크, 캘린더, 성장, AI 비서, 메모함, 작업 지도, 주제 위키, AI 사용량, 검색. 성장도 태스크로 잘못 연결하지 않고 독립 준비 화면을 제공한다. 기존 메모함은 유지한다.

작업 지도는 메모 관계도가 아니라 할 일·일정을 학교/과목, 회사/프로젝트 등으로 AI가 자동 분류하는 화면이다. 큰 영역과 세부 분류를 모두 자동 생성하고 사용자가 이동·이름 변경·합치기를 할 수 있는 방향이다. 수동 수정이 AI보다 우선한다. 이전 ‘카테고리 자동 생성 금지’ 설계는 이 결정으로 대체한다.

준비 화면은 제목, 기능 설명, 미연결 상태와 다음 기능 안내를 보여준다. 가짜 그래프·사용량·대화 응답은 만들지 않는다. 주제 위키는 메모함으로 이동할 수 있다. AI 사용량은 네 서비스별 미연결 카드로 표시한다.

AI FAB는 화면 오른쪽 아래, 작은 대화창 열기/닫기/전용 화면 확장. 전용 화면과 같은 입력 초안을 공유한다. 아직 모델 미연결이므로 전송 불가를 표시한다. 모달·팝오버·편집 폼이 활성화되면 FAB/빠른 창을 숨겨 가리지 않는다. Escape로 빠른 창 닫기. 기존 보던 화면 유지. 창 크기에 맞춰 너비 축소.

검증: 모든 탭 고유 제목/활성 표시, 메모 유지, FAB 입력 초안 확장 후 유지, 닫기/ESC, 좁은 높이에서 레일 스크롤, 미연결 기능을 사용 가능한 것처럼 표시하지 않기.
