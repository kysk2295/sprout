## 0. 저작권 경계 (공개 상업 제품)
- 가져오는 것은 **방향과 품질 수준**뿐이다: 무광 비닐·점토 인형 같은 3D 렌더 기법(넓은 면광, 속살 빛, 접촉 그림자), 절제된 색 배분, 장면 위 유리 카드, 큰 숫자 하나, 꼬리 칩, 한 화면 한 가지 일, 태어나는 순간을 기다리게 하는 한 박자. 이런 것은 업계 공용 기법이다.
- 가져오지 않는 것: 럭키즈 캐릭터(구름·해·네잎클로버·토끼·터키석)와 그 디자인 요소(**고무장화 발**, **나무 그루터기 받침**, 몸 전체가 상징 모양인 실루엣), 화면 구도 그대로, 문구("두근두근 ○○가 탄생하고 있어요", "행운 카드"), 형광 초록 단색, 로고 모양, 그림 파일. 레퍼런스 이미지는 저장소·앱·사이트 어디에도 넣지 않는다.
- 우리 것으로 대신한 것: 캐릭터 = **꿈틀 정원 친구들**(씨앗에서 태어난 정원 생물 — 달팽이·꿀벌·애벌레→나비·올챙이→개구리, 머리에 작은 새싹 = 브랜드 실), 발 = 몸과 같은 재질의 둥근 발(신발 없음), 받침 = **이끼 낀 둥근 돌**, 장면 = 둥근 언덕 정원(낮·새벽·밤), 색 = 45 깊은 숲 청록 + 꿀·살구, 만들기 = **씨앗 고르기 → 성향 카드 → 두드려 깨우기**(10 §2.2 성향 조사를 놀이로).
- 모든 그림은 `kk3d.py`의 절차 모델(타원체·관·곡선을 코드로 놓은 것)에서 나온다. 외부 3D 모델·텍스처·남의 그림을 쓰지 않는다. 사람이 다듬을 때도 이 경계를 지킨다(§4.6).

## 1. 왜 레퍼런스는 고급스럽고 v2는 유치해 보였나
이번에 원본 7장(홈·성장 4단계·랜덤 배정 흐름·가든·리그·공유 카드·브랜드 판)을 다시 보고, v2 시안(character-raising-v2.html)과 나란히 놓고 비교했다.

| 무엇 | 레퍼런스 | v2(지금) | v3에서 |
|---|---|---|---|
| 렌더 | 진짜 3D: 넓고 흐린 위쪽 면광, 맞닿은 곳이 어두워짐(AO), 빛이 살짝 비쳐 나오는 속살(subsurface), 바닥에 번진 접촉 그림자, 뒤 테두리 빛 | SVG 그라데이션 하나 + 흰 하이라이트 + 얇은 선. 빛 방향은 있지만 물체끼리 그림자·맞닿음이 없어 스티커처럼 납작 | Blender Cycles로 실제 빛·그림자·속살 빛(§2) |
| 얼굴 | 아주 작은 점 눈 둘 + 가는 웃는 선. 몸 높이의 3~5%. 볼 없음 | 눈이 머리 반지름의 25%, 빛점 둘 + 아래 반사, 볼 번짐 + 빗금, ω 입, 혀 | 작은 유광 점 눈(몸 높이 약 4%), 볼 없음, 입은 가는 선 하나. 표정은 눈·입 모양만 |
| 형태 | 한 덩어리 몸이 곧 캐릭터. 부품이 적다 | 큰 머리 + 몸 + 팔다리 + 새싹 + 종 표시 + 단계 소품 + 색 테 → 한 그림에 부품 10~20개 | 몸 덩어리 하나(타원체를 녹여 붙임) + 종을 알리는 부품 하나(껍데기·연잎·줄무늬·더듬이) + 새싹 |
| 단계 차이 | 크기 + 실루엣(덩어리 → 반구 → 테두리 → 모티프 완성) | 소품 쌓기(꽃·리본·관·장면 조각) | 단계마다 **실루엣 하나**(씨앗 그릇 → 나선 껍데기 → 껍데기 위 작은 숲) |
| 색 | 캐릭터 하나에 한 색 계열, 그 밖의 UI는 무채색 + 강조 하나 | 캐릭터마다 8~10색, 채도 높은 파스텔 | 종마다 한 색 계열 + 무채색 받침, 소품 한 색 |
| 여백·구성 | 장면이 상태 막대 뒤까지, 캐릭터가 화면 높이의 1/3, 위는 하늘·아래는 유리 카드 | 흰 카드 안 작은 무대(높이 210~260), 둘레에 버튼·칩이 많다 | 장면 끝까지 + 유리 카드 둘(위 주 달력·아래 성장) — §6 |
| 글자 | 굵고 큰 두 줄 제목, 큰 숫자(`75%`, 단위 절반), 회색 보조 한 줄, 단계 적음 | 20px 제목, 숫자·칩·라벨이 많고 크기가 비슷 | 31px/800 두 줄 제목 · 60px/850 숫자 · 회색 한 줄 |
| 움직임·흐름 | 한 화면 한 가지 일. 눌러서 깨우기 → 이름 → 기다리는 한 박자 → 화면 가득 번쩍 → 등장 | 성향 조사가 설정 창 같은 카드(질문 + 버튼 둘), 결과에서 알 깨짐 | 씨앗 돌려 고르기 → 카드가 날아가는 질문 → 세 번 두드려 깨우기 → 빛 → 등장 → 이름 → 첫 할 일(§5) |
| 캐릭터를 처음 보여 주는 법 | 실루엣·덩어리만 보여 주고 이름을 먼저 짓게 한 뒤 공개 | 결과 화면에 바로 다 보임 | 씨앗만 보여 주다가 깨어나는 순간 공개, 이름은 그 뒤(공개가 보상) |

**요약:** 유치함의 원인은 ① 얼굴이 너무 크고 장식이 많고 ② 입체가 가짜라 스티커처럼 보이고 ③ 장면 없이 흰 카드에 있었기 때문이다. 귀여움은 비율(큰 덩어리, 짧은 팔다리)로만 남기고, 얼굴·장식을 덜고, 진짜 빛과 장면을 준다.

| (c) Rive / Lottie | 벡터라 v2와 같은 한계(가짜 입체). Lottie에 구운 이미지를 넣으면 결국 (a) | 작다 | 좋다 | Rive 상태 기계는 좋다 | 손으로 그리는 툴 작업 | (a) 그림 위 움직임 보조로만 [다음] |

**고른 이유:** 사용자가 원한 것은 "레퍼런스 같은 3D 품질"이고, 그 품질은 경로 추적 렌더에서 나온다. 미리 구우면 휴대폰은 그림만 그리므로 v2(SVG 수십 개 도형)보다 오히려 가볍다. 생성기가 코드라 종·단계·옷을 바꿔 다시 굽기 쉽고, 버전 관리가 된다.

### 4.2 생성기 (`scripts/characters3d/kk3d.py`)
- 모델: 몸은 **타원체 여러 개를 한 메시에 넣고 voxel remesh(0.022)로 녹여 붙인 뒤 Smooth**(`fused`) — 이음매가 둥근 필렛이 되고 크기가 정확하다(메타볼은 표면이 반지름보다 작아져 부품이 떠서 버렸다). 껍데기는 로그 나선 관(`shell`), 잎·꽃잎은 끝을 좁힌 구(`leaf`), 연잎·돌은 납작한 타원체.
- 붙이기: 더듬이·새싹·이끼는 **위에서 쏜 광선**으로 표면 높이를 재서(`top_of`), 눈·입은 **카메라 쪽 광선**으로 표면 자리·법선을 찾아(`surface`), 목도리는 **목 높이에서 둘레를 광선으로 재서**(`ring_fit`) 붙인다. 그래서 같은 옷 정의가 다른 몸에 맞는다.
- 렌더: Cycles **CPU**(Metal은 재질 조합마다 커널을 새로 컴파일해 첫 장이 수 분 — 시험에서 10분), 샘플 96 + OIDN 노이즈 제거, 투명 배경 + 그림자 받는 바닥(shadow catcher), 유리·물방울은 `film_transparent_glass`. 768px 한 장 ≈ 30~45초.
- 장면: `do_scene` — 하늘 판(위→아래 색), 언덕 7, 덤불, 꽃 점, 잔디 결 재질(`turf`, 노이즈 범프), 돌 받침, 해(sun) 그림자, 피사계 심도. 받침 윗면의 화면 자리(`perch`)를 메타데이터로 낸다. `band: true`면 받침 없는 가로 띠(할 일 화면 머리, §8.2).
- 접촉 그림자 손질(`encode.py contact`): 그림자 받는 바닥이 캔버스 전체에 옅은 그림자(α 30~50)를 남겨 장면 위에 네모 테가 보였다 → 발밑 타원 안만 남기고 바깥으로 지우며 62%로 옅게.
- 굽기: `sh scripts/characters3d/build.sh [characters|seeds|scenes]` → `build/`(PNG, 커밋 안 함) → `encode.py` → WebP + `meta.json`(목 자리·머리 꼭대기·배율·받침 자리).

### 4.3 층 — 몸 · 얼굴 · 옷
| 층 | 굽는 법 | 개수(종 4 × 단계 5 × 갈래 2 ≈ 36 몸) |
|---|---|---|
| 몸 | 얼굴 빼고 | 36 |
| 얼굴 | 몸을 **그림자만 받는 투명면**(shadow catcher)으로 두고 눈·입만. 같은 크기 캔버스 | 36 × 표정 5 = 180 (작다: 얼굴 영역만 보이는 투명 WebP ≈ 2~4 KB) |
| 옷 | 몸·얼굴을 그림자 받는 투명면으로 두고 옷만 → 몸 뒤로 도는 부분은 가려지고, **옷이 몸에 드리운 그림자는 남는다** | 옷 23 × 36 ≈ 830 (받은 옷만 내려받기) |
| 실루엣 | 몸 + 소품을 흰 한 색으로(진화 연출 · 도감 잠김) | 36 |
- 앱은 같은 크기 그림을 `[등 옷 뒤] [몸] [얼굴] [목] [손] [모자]` 순서로 겹친다. 기준점 계산이 앱에 없다 — 구울 때 맞춘다. 시안 0의 "겹친 결과"와 "한 번에 구운 것"이 같은지 눈으로 확인했다(겹친 쪽에서 옷 그림자가 몸에 남는다).
- 2D 기준점 + 한 장짜리 옷 그림(43 방식)은 쓰지 않는다: 3D에서는 옷이 몸을 감고 돌아가며 그림자가 지므로, 한 장을 옮겨 붙이면 바로 티가 난다.
- 표정 11종(40 §6·42)은 5종으로 줄인다(결정 ④). 깜빡임 = 얼굴 층을 "감은 눈"으로 0.12초 바꾸기.

### 4.5 이번 시제품 (품질 판단용)
- 구운 것: 달팽이·개구리 × 아기·친구·전설 × 기본·웃음(12) · 꿀벌·애벌레 × 아기·친구 × 기본·웃음(8) · 층 검증(달팽이 친구 몸 / 얼굴 2 / 목도리, 달팽이 전설·개구리 친구 목도리) · 씨앗 4 × 12컷 + 금 2단계 · 장면 낮·새벽·밤 + 띠 낮·밤.
- 품질 메모: 비닐 재질·속살 빛·접촉 그림자·작은 얼굴은 레퍼런스 수준에 가깝다. 달팽이 껍데기(로그 나선)와 개구리 물방울 알(투명)이 특히 좋다. 약한 곳 — ① 꿀벌 날개가 아직 납작한 판, ② 개구리 목도리는 목이 없어 튜브처럼 보인다(개구리는 목 칸 대신 손·모자 옷이 맞다), ③ 씨앗 금이 만화 선 같다(실제 깨진 틈 모양으로 다시), ④ 장면이 아직 단순(돌 받침 질감, 먼 숲), ⑤ 옷 층은 몸을 투명면으로 두고 구워 몸에서 튕기는 빛을 못 받아 한 번에 구운 것보다 한 톤 어둡다(시안 0의 마지막 두 칸) — 옷 층만 노출 +0.15로 맞춘다 [다음], ⑥ 시안의 진화 흰 실루엣은 CSS filter로 흉내 낸 것(앱은 구운 실루엣 층). 출시 전 사람 아트 디렉터가 생성기 숫자를 다듬는 1~2주를 잡는다(§4.6).

### 4.6 사람이 다듬을 때
- 다듬는 곳은 `kk3d.py`의 숫자(타원체 자리·크기, 색, 빛)다. Blender에서 손으로 조각한 모델을 쓸 때는 `.blend`를 `scripts/characters3d/models/`에 두고 같은 카메라·빛·층 규칙으로 굽는다. 남의 모델·텍스처·레퍼런스 이미지를 따라 그리지 않는다(§0).

## 6. 성장 홈 [sprout]
- 장면 끝까지(라이트 = 낮, 다크 = 밤, 새벽 장면은 만들기 흐름 · 아침 5~9시 [다음]). 상태 막대 글자색은 장면 밝기에 따라.
- 위: `꿈틀`(글자 로고) + 유리 알약 불꽃 + `12일 연속`(2026-10-10 43 §19 — 예전 `한 날 12일`, 해금은 누적 그대로) + 알림. 그 아래 유리 주 달력 띠(오늘 = 강조색 원, 한 날 = 옅은 원 — 레퍼런스 기법, 43 누적 그대로).
- 가운데: 이끼 돌 받침 위 캐릭터 250pt(받침 자리 `perch`에 발밑), 숨쉬기. 누르면 웃는 얼굴 + 깡충 + 유리 말풍선 한 줄(43 §4.1 만지기 규칙 그대로 — 보상 없음).
- 아래 유리 카드(좌우 14, 아래 탭 막대 위): `Lv 6` 배지 + `이름 · 단계 이름` / **`62%`**(60/850, `%` 28) + 꼬리 칩 `할 일 4개 더 하면 Lv 7` / `다음 레벨까지` / 막대 14px(강조색 그라데이션, 둥근 끝) / 옷장 · 도감 · 이번 주 세 칸(3D 썸네일).

- 보상 없음(43 §4.1): 만지기는 XP·아이템을 주지 않고 횟수도 세지 않는다.

### 7.2 말풍선이 캐릭터를 따라간다 [sprout] (2026-10-10 요청 "말풍선이 캐릭터를 따라가면서 움직이게 해줘")
- 지금: 말풍선이 받침 위 **쉬는 자리의 머리 위**에 붙어 있어서, 깡충·한 바퀴·끌기·딴짓·레벨업 통통 중에는 캐릭터만 움직이고 말풍선은 제자리(데스크톱은 끌기만 따라감).
- 바꿈: 말풍선 꼬리 끝 = **지금 머리 꼭대기**(`headTop3d` + 모자 보정). 캐릭터를 움직이는 같은 값(무대 감싸개 hopY·rot·scale·숨쉬기 + 만지기 감싸개 끌기 dx·dy·기울기 + 몸 y·rot·scale)으로 머리 점을 계산해 말풍선을 transform으로 옮긴다.
- **살짝 늦게, 통통하게:** 머리 점을 그대로 붙이지 않고 스프링으로 쫓는다(강성 260 · 감쇠비 0.7 — 약 0.12초 늦고 살짝 넘쳤다 돌아옴). 끌다 놓으면 말풍선이 한 박자 늦게 따라와 자리를 잡는다. 말풍선이 새로 뜰 때는 늦음 없이 그 자리에서 시작.
- **회전은 따라가지 않는다** — 말풍선은 늘 똑바로(글 읽기). 위치만.
- **화면 안에 둔다:** 화면(데스크톱 = 성장 무대) 좌우 끝에서 12 안쪽으로 가둔다(clamp). 가둔 만큼 꼬리가 머리 쪽으로 옮겨 가 머리를 계속 가리킨다(꼬리는 말풍선 모서리 18 안쪽까지만). 위는 머리 줄(휴대폰 = 상태 막대 + 4) 아래로 가둔다. 옆으로 뒤집기는 하지 않는다(머리 위가 늘 비어 있어서).
- 움직임 줄이기: 스프링 없이 머리 점에 바로(그래도 끌기·맥박 위치는 따라감).
- **성능(39 §11):** React 다시 그리기 없음. 휴대폰 = 같은 Reanimated 공유 값을 읽는 `useFrameCallback`(말풍선이 떠 있을 때만 켬)이 스프링을 한 걸음씩 → 말풍선 감싸개 `translateX/Y` + 꼬리 `translateX`만(UI 스레드). 말풍선 크기는 뜰 때 한 번 `onLayout`. 데스크톱 = 만지기 rAF와 같은 자리의 `requestAnimationFrame`이 `style.transform`만 쓴다(말풍선이 붙어 있는 동안만, 다 멈추면 쉼). 크기·무대 상자는 붙일 때 한 번 잰다.
- 머리 점 계산·스프링·가두기는 순수 함수(휴대폰 `src/growth/art/follow.ts` worklet, 시험 `follow.test.ts` / 데스크톱 같은 식 `components/growth/follow.ts`).

## 12. 완료 기준 (시안과 나란히, 라이트·다크)
- [ ] 4종 × 5단계(+갈래) 몸·얼굴 5·실루엣이 같은 카메라·빛·크기로 구워져 있다. 단계 이름을 가린 20장을 섞어도 순서를 맞힌다(사람 2명).
- [ ] 레퍼런스와 나란히 놓았을 때 재질·빛·그림자 품질이 같은 급이다(사용자 확인). 신발·그루터기·럭키즈 모티프·문구가 없다(§0 체크).
- [ ] 겹친 층(몸 + 얼굴 + 옷)과 한 번에 구운 그림이 눈으로 같다. 옷 그림자가 몸에 진다. 옷 23개가 4종 × 단계에 떠 보이지 않는다.
- [ ] 만들기 흐름 0~6이 시안과 같은 순서·움직임이다. 씨앗 회전 12컷이 끊기지 않는다(미리 올림). 두드림 3번 → 빛 → 등장 → 유형 카드. 움직임 줄이기 = 페이드만.
- [ ] 성장 홈: 장면 끝까지, 캐릭터 발밑이 받침 위(±4pt), 큰 숫자·꼬리 칩·막대. 누르면 웃음 + 깡충 + 한 줄.
- [ ] 휴대폰 성능(39 §11 방식): 성장 탭 숨쉬기·깡충 중 UI 스레드 120Hz 유지, 층 바꿀 때 디코드 끊김 없음, 도감 20칸 스크롤 그대로.
- [ ] 앱 기본 묶음 ≤ 2 MB, 내 종 내려받기 ≤ 1.5 MB, 한 화면 그림 메모리 ≤ 12 MB.
- [ ] 할 일 화면(은은하게): 오늘 목록 첫 줄 높이가 지금과 같고, 스크롤하면 장면 띠가 사라진다. 다크에서 띠가 밤 장면이다.
- [ ] 위젯·사이트·아바타가 같은 그림을 쓴다. 저장된 아바타 `char-<종>-<단계>` 값이 그대로 보인다.

## 15. 마스코트 꿈틀이 — 성향 조사 전 기본 캐릭터 (v1.3, 2026-10-10)
- 요청: "이 친구를 우리 앱의 마스코트로 해서 로그인 화면에도 알 대신 넣어 줘. 성향 조사를 하지 않았을 때 이 친구를 기본으로" + 아이콘 D안(45 v1.1).
- **마스코트 = `snail-1s0`**(달팽이 1단계 · 흙빛 씨앗 — 알껍질 그릇에 앉은 크림 몸 + 더듬이 + 머리 새싹). 공용 `@sprout/schema/art3d` `MASCOT`·`mascotLayers`·`MASCOT_NAME = '꿈틀이'`·`MASCOT_LINES`. 이름은 임시(제품명에서) — 바꾸려면 `MASCOT_NAME` 한 곳.
- **규칙:** 종이 없고(`species = null`) 씨앗 컷(`cracks`·`turn`)도 넘기지 않으면 `CharacterArt`·`PlayableCharacter`(두 앱)가 마스코트를 그린다 — 옷·고른 씨앗·레벨 단계와 상관없이 늘 아기 달팽이, 표정(기본·웃음·졸림·놀람·생각)은 그대로. **데이터는 바꾸지 않는다**(characters.species는 여전히 비어 있고, 성향 조사를 하면 그 결과 종으로 바뀐다).
- **씨앗은 만들기 의식에만 남는다:** 만들기 흐름(§5: 시작 · 씨앗 고르기 · 성향 카드 · 두드려 깨우기)과 부화 장면은 `SeedPic`·`FloatingSeed`·`cracks`로 씨앗을 그대로 그린다.
