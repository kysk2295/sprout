# 41 · 프로젝트를 직접 쉽게 고치기 (31 §12.14)

- 상태: **초안: 사용자 확인 전** (2026-10-06). 시안: [mockups/project-planning.html](mockups/project-planning.html). 데스크톱 시안은 직접 만져 볼 수 있다(끌기·끝 끌기·이름 고치기·줄 추가·여러 개 미루기·되돌리기).

- 사용자 말(2026-10-06):
  - "작업지도는 조금 더 직관적으로 프로젝트를 만들고 … 투자자산운용사 시험을 보면 여기서 할일을 계획하고 태깅하도록"
  - 방향 바꿈: "계획을 그렇게 짤 필요는 없을 거 같아. 어차피 짜 줘 봤자 그렇게 못 하니까. 지금 현재 UI에 있는 게 최선인데, 그거를 좀 더 직접적으로 편집하고 할 수 있게 하면 좋을 것 같아. 쉽게"
- 그래서 **계획을 대신 짜지 않는다.** AI가 거꾸로 일정을 짜는 초안, 계획 표, 시험 과목 단계 만들기는 모두 하지 않는다. 사람이 한 줄로 만들고, 보이는 그 자리에서 고치고, 태그 줄로 묶는다. 보드·타임라인·관계도의 모양은 지금 그대로다.
- 개념은 그대로 A다: **폴더 › 리스트 › 할 일 + 태그**. 프로젝트 = 특정한 하나에 붙는 🚀 프로젝트 태그(31 §12.13). 줄은 **보통 태그**(33)를 그 프로젝트 안에서 보여 주는 것뿐이다. 새 개념은 없다.
- 표기: **[틱틱]** 틱틱과 같음 · **[sprout]** 틱틱에 없어 틱틱 디자인 언어로 새로 만듦 · **[미확인]** 조사 보강이 필요함.

## 2. 만들기: 한 줄
### 2.1 입구 (하나)
- 보드 머리 오른쪽 **`＋ 새 프로젝트`**(주 단추, 강조색). 카드 격자 끝 점선 카드도 **`＋ 새 프로젝트`**(지금의 `같이 계획 짜기` 카드 자리)다. 빈 상태의 주 단추도 같다.
- 누르면 **그 점선 카드가 그 자리에서 입력 카드로 바뀐다**(창을 따로 띄우지 않음). 머리 단추를 누르면 점선 카드로 스크롤하고 초점을 옮긴다. 빈 상태에서는 가운데 입력칸이 바로 보인다.
- 다른 길은 그대로 둔다: 제안 카드 [만들기], 할 일 우클릭 `이걸로 프로젝트 만들기`(31 §12.13.1).

### 2.2 입력 카드
| 영역 | 내용 |
|---|---|
| 입력칸 | 높이 34, 자리글 `예: 투자자산운용사 시험 11/23`. 빠른 추가 인식기(`parseAdd`)로 날짜를 읽고, 날짜 글자는 강조한다(02 §4와 같은 모양). 나머지 글은 이름(20자, 앞 이모지는 아이콘)이 된다. 날짜는 하나만 읽는다. 기간(`10/12~10/18`)이면 끝날을 쓴다 |
| 미리보기 줄(회색 12.5) | `📜 투자자산운용사 시험 · ⚑ 시험 11/23(월) · D-48`. 날짜가 없으면 `날짜 없이 만들어도 돼요`. 이름이 비면 `이름을 적어 주세요` |
| 날짜 이름 칩 | 날짜를 읽었을 때만 보인다: `시험 · 제출 · 마감 · 발표`(+ 이름에서 짐작한 말이 이 넷에 없으면 그 말). 짐작한 것이 미리 골라져 있고, 한 번 누르면 바뀐다(§2.4) |
| 접힌 줄 `팀원 · 아이콘 ›` | 누르면 펼쳐진다. 팀원 한 줄(31 §12.13.2 그대로, 자리글 `예: 민수, 지은`)과 아이콘 고르기(30 이모지 선택기) |
| 안내 `이럴 때 써요` | §2.5 |
| 단추 | `취소` · `만들기`(주). Enter = 만들기, Esc = 취소(카드는 점선으로 돌아간다). 한글 조합 중 Enter는 무시한다 |
- **분류 칸(31 §12.10.4)은 뺀다.** 고를 것이 없다(§2.4).

### 2.3 만들면 생기는 것 (이것뿐)
1. 프로젝트 태그: `tags` kind project, source user, 이름, 아이콘(앞 이모지).
2. 날짜가 있으면 **⚑ 핵심 날짜 할 일 하나**:
   - 제목: 이름 + 날짜 이름 + `일`. 이름이 이미 그 말로 끝나면 이름 + `일`만 붙인다(`투자자산운용사 시험` → `투자자산운용사 시험일`).
   - 종일 마감 = 그 날짜. 리스트 = 기본함(입력에 `~리스트`가 있으면 그것). 프로젝트 태그는 user.
   - 그리고 **프로젝트 마감으로 잇는다**(§9). `projectDeadline`의 `explicit`가 이 날짜가 된다.
3. 팀원을 적었으면 사람 태그 + 잇기(31 §12.13.2).
- **다른 할 일은 만들지 않는다.** AI도 부르지 않는다.
- 토스트 `'투자자산운용사 시험' 프로젝트를 만들었어요` + 되돌리기(태그·⚑ 할 일·팀원 잇기를 함께 지움). 그다음 **바로 그 프로젝트 화면을 연다**(타임라인, 줄 기준 = 태그(결정 2), 핵심 날짜 줄이 보이게 스크롤).

### 2.4 종류는 따로 두지 않는다 (사용자 결정 2026-10-06)
- **종류 칸(필수 칸·고르기)을 만들지 않는다.** 빼 버린 분류(31 §12.10)와 같은, 또 하나의 개념이 되기 때문이다.
- 이름에서 **말없이 짐작해 겉모습 기본값에만** 쓴다. 저장하지 않고, 바꾸고 싶으면 그 값을 직접 고친다.

| 이름에 든 낱말 | 아이콘 기본값 | 날짜 이름 기본값 | 만든 직후 줄 나누기 제안 |
|---|---|---|---|
| 시험·자격증·시험 이름(SQLD·ADsP·토익…, 31 §12.1 목록) | 📜 | 시험 | `줄을 과목별로 나눌까요?` [＋ 과목 추가] [괜찮아요] |
| 공모전·경진대회·대회·해커톤·챌린지 | 🏆 | 제출 | `회의·조사·개발·제출로 나눌까요?` [그렇게] [괜찮아요] |
| 창업·지원사업·장학금 | 🌱 | 제출 | `서류·면접·결과로 나눌까요?` [그렇게] [괜찮아요] |
| 취업·채용·공채 | 🚀 | 마감 | `회사별로 나눌까요?` [＋ 회사 추가] [괜찮아요] |
| 그 밖 | 🚀 | 마감 | 없음 |
- 아이콘은 사람이 언제든 바꾼다(머리 아이콘 누르기). 이름 앞에 이모지를 적었으면 그것을 쓴다(30 §A.5).
- **줄 나누기 제안**(타임라인 위 캐릭터 한 줄, 31 §11.9 말씨):
  - **만든 직후 한 번만**, 누를 때만 뭔가가 생긴다. 저절로 만들지 않는다.
  - `[그렇게]` = 그 이름의 태그 줄을 만든다(있는 태그면 그것). 할 일은 만들지 않는다. 토스트 되돌리기.
  - `[＋ 과목 추가]`·`[＋ 회사 추가]` = `＋ 줄 추가` 입력칸을 연다(과목·회사 이름은 사람이 적는다. 이름을 대신 짓지 않는다).
  - `[괜찮아요]`·✕ = 그 프로젝트에서는 다시 안 뜬다(기기 `sprout.map.projects.v1` `starterSeen` 태그 id).
  - 이 제안이 AI가 하는 일의 전부다. 이 제안도 결정적 낱말 표에서 나오고, AI는 부르지 않는다.

### 2.5 `이럴 때 써요` 안내 (빈 상태 · 새 프로젝트 입력 카드 · 휴대폰 시트)
- 자리: 빈 상태 입력칸 아래, 입력 카드 아래(회색 구분선 위). 휴대폰은 새 프로젝트 시트의 입력칸 아래.
- 머리: `이럴 때 써요`(12/600 2차).
- 예시(작은 회색 단추, 이름 + 옅은 부연):
  - `자격증 시험 · 과목별 줄`
  - `공모전·해커톤 · 회의·조사·개발·제출`
  - `팀 과제·졸업작품`
  - `장학금·지원사업 · 서류·면접·결과`
  - `취업 · 회사별 줄`
  - `업무 프로젝트·행사`
  - `이사·여행`
- **누르면 입력칸을 채운다.** 날짜 자리는 비워 두고 커서를 끝에 둔다: `투자자산운용사 시험 ` · `K 데이터 공모전 ` · `졸업작품 ` · `창업지원장학금 ` · `하반기 취업 ` · `신제품 런칭 행사 ` · `부산 이사 `. 날짜를 적고 Enter. 예시 이름은 바꿔 쓰라는 뜻이다(회색 자리글이 아니라 진짜 글).
- 안 쓸 때 한 줄(11.5 3차): `이럴 땐 다른 걸 써요: 한 번 하고 끝나는 일은 리스트, 끝없이 하는 습관은 반복, 막연한 주제는 태그.` 휴대폰: `한 번 하고 끝 → 리스트 · 습관 → 반복 · 막연한 주제 → 태그`.
- 같은 글을 **34 사용법 창 1절**에 한 줄로 붙인다(`이럴 때 써요: 자격증 시험 · 공모전 · …`).
- **소개 사이트(`site/`)용 글**(나중에, 이번에는 고치지 않음): 제목 `날짜가 있는 큰 일은 프로젝트로` · 위 예시 7개 + 안 쓸 때 한 줄 + 그림 1장(시안 ② 타임라인, 태그 줄). 문구는 이 절과 같게 둔다(앱과 사이트가 다른 말을 하지 않게).

## 4. 줄 = 태그로 묶기 (프로젝트 안)
### 4.1 줄 기준
- 타임라인 도구 줄 보기 세그먼트 오른쪽에 **`줄: 태그 ▾`**를 둔다. 메뉴는 `태그 · 일의 종류`(✓ 표시)와 회색 `프로젝트마다 기억해요`이고, 틱틱 그룹 기준 말씨를 따른다. 기억은 기기 `sprout.map.projgroup.v1` `{태그 id: 'tag'|'kind'}`.
- 기본값: §2로 새로 만든 프로젝트는 `태그`, 원래 있던 프로젝트는 `일의 종류`(결정 2).
- `일의 종류`로 두면 지금 그대로다(31 §12.3·§12.9.4). 줄 목록 아래 회색 `일의 종류 줄은 정해져 있어요. 줄을 직접 만들려면 줄: 태그로 바꿔요.`

### 4.2 어떤 태그가 줄이 되나
- 줄 = ⓐ 이 프로젝트에서 만든 줄(빈 줄 포함, §9 `lane` 행) ∪ ⓑ 구성원에 붙은 **보통 태그**(kind topic, accepted). 사람·프로젝트·장소 태그는 줄이 되지 않는다(사람은 머리 팀원). 맨 아래는 늘 `태그 없음`.
- 순서: 손으로 정한 순서(줄 이름 칸을 끌어 바꿈, 기기 `sprout.map.projgroup.v1` `order`) → 없으면 만든 순서 → ⓑ는 구성원 많은 순.
- 한 할 일에 줄 태그가 둘 이상이면 **앞 줄에만** 보이고 칩 끝에 회색 `+1`(결정 3). 끌어 옮기면 그 앞 줄 태그만 바뀐다.
- 태그 개수 상한(33 §7.6)은 그대로다. 줄로 만든 태그도 보통 태그로 센다.

### 4.3 직접 고치기
| 동작 | 결과 | 되돌리기 |
|---|---|---|
| 줄 목록 맨 아래 `＋ 줄 추가` | 입력칸(앞에 `#`가 채워짐). 33 §6.2 태그 자동 완성(있는 태그 먼저). Enter = 줄이 생기고(있는 태그면 그것, 없으면 새 태그 topic·user) **초점이 그 줄의 `＋ 할 일 추가`로 옮겨 감**. Esc·빈 채로 벗어나기 = 닫기 | 토스트 `'#금융상품' 줄을 만들었어요` |
| 칩을 다른 줄로 끌기(세로) | 원래 줄 태그를 떼고(`태그 없음`이면 뗄 것 없음) 놓은 줄 태그를 붙인다(user). `태그 없음`에 놓기 = 줄 태그만 뗀다. 놓을 줄은 옅은 강조 바탕 | `'#법규' 태그를 붙였어요` + ⌘Z |
| 줄 이름 누르기 | 그 자리에서 태그 이름을 고친다(`#` 뒤만). 다른 곳에도 붙은 태그면 입력 아래 회색 `다른 할 일 N개에도 붙어 있어요 — 모두 바뀌어요`. 같은 이름 태그가 있으면 `'#…'와 합칠까요?` [합치기](33 §6.5) | 토스트 |
| 줄 머리 호버 ✕ `줄 지우기` | 이 프로젝트 할 일에서 그 태그를 떼고 `lane` 행을 지운다. **태그 자체와 프로젝트 밖 연결은 남는다**(태그 삭제는 태그 페이지에서). 할 일은 `태그 없음`으로 간다 | `'#법규' 줄을 지웠어요 · 할 일 2개는 태그 없음으로 · 태그는 남아요` |
| 줄 안 `＋ 할 일 추가` | 31 §12.12.1 그대로. 그 줄 태그를 붙여 만든다. 입력에 `#다른태그`를 적으면 그 줄로 간다(없으면 줄도 생김) | 그대로 |
| 줄 이름 칸 끌기 | 줄 순서 바꾸기(기기 기억) | — |
- 줄 이름 안내는 AI 없이 결정적 낱말 검사로만 한다(31 §12.1 ⑤와 같은 `keywords`). `태그 없음` 줄에 같은 뚜렷한 낱말이 든 할 일이 3개 이상이면, 그 줄 머리 아래에 옅은 글 `‘기출’로 줄을 만들까요? 3개` [만들기]를 둔다(누를 때만). **AI는 줄 이름 제안까지만 하고 계획은 만들지 않는다.** v1은 AI를 부르지 않는다.

## 6. 여러 개 한꺼번에
- 고르기: ⌘/Ctrl 누르기 = 더하기·빼기, ⇧ 누르기 = 더하기(31 §12.12.2 그대로). 빈 곳 끌어 사각형 고르기는 [다음]이다(틱틱 근거 [미확인]).
- **고른 띠:** `3개 고름 · 하루 미루기 · 일주일 미루기 · 날짜 고르기… · 태그 › · 완료 · 프로젝트에서 빼기 · 삭제 · 고름 풀기 ✕`
  - 미루기: 날짜가 있는 열린 일마다 +1 / +7일(시작·끝 함께, 기간 그대로). 날짜 없는 일과 끝낸 일은 그대로 둔다. 토스트 `3개를 일주일 미뤘어요` + 되돌리기 하나.
  - 날짜 고르기: 달력. **가장 이른 일이 그 날짜로 가고 나머지는 간격을 그대로 둔다.** 회색 안내 `가장 이른 일이 그 날짜로, 나머지는 간격 그대로`.
  - 태그 ›: 이 프로젝트 줄 태그 목록 + `태그 없음으로`. 고르면 고른 것 모두를 그 줄로 보낸다(§4.3 끌기와 같음).
- **함께 끌기:** 고른 칩 하나를 끌면 고른 것 모두가 같은 날 수만큼 움직이고, 세로로 놓으면 모두 그 줄로 간다. 되돌리기는 하나다 [sprout — 틱틱 목록 여러 개 끌기 말씨].
- 우클릭(여러 개 고른 채) = 같은 메뉴가 전체에 적용된다(그대로).

## 7. 머리 도구 정리
- 도구 줄: `[단계 · 타임라인 · 관계도]` · `줄: 태그 ▾`(타임라인만) · 빈 곳 · `자동으로 넣은 것만 N`(있을 때만, 그대로) · **`＋ 할 일`**(주 단추).
- `＋ 할 일` 팝오버(폭 340):
  - 위에 새 할 일 입력(31 §12.12.1 인식·Enter 계속 그대로, 자리글 `예: 수험표 출력 11/16 #법규`).
  - 그 아래 `이미 있는 할 일` 목록: 적는 글로 거른 프로젝트 밖 할 일. 31 §12.9.3 `할 일 넣기`의 퍼지 검색을 그대로 쓰고, 행을 누르거나 체크하면 넣는다. 끌어서 줄에 놓아도 된다.
  - Enter = 새로 만들기, ↓ = 목록으로 내려가기.
  - 지금의 `새 할 일`과 `할 일 넣기` 두 단추를 이것으로 합친다.
- `다음 단계 같이 짜기`는 ⋯로 옮긴다(결정 4). 대화 규칙(31 §11)은 그대로다.

## 8. 휴대폰 (29 §9.2에 더함, 규칙·데이터는 이 절 그대로)
- 보드: 맨 아래 강조 글자 줄 `＋ 새 프로젝트`(지금 `＋ 같이 계획 짜기` 자리)를 누르면 아래 시트가 열린다: 제목 `새 프로젝트` · 입력칸 · 미리보기 줄 · 날짜 이름 칩 · `이럴 때 써요`(짧은 글) · `팀원 · 아이콘 ›` · `만들기`. 만들면 프로젝트 화면이 밀려 들어온다.
- 프로젝트 화면 머리:
  - 큰 제목을 누르면 그 자리에서 고친다.
  - 그 아래 알약 줄 `⚑ 시험 11/23 D-48`(누르면 날짜 시트) · `팀원 ＋` · `집중`.
- 묶음 기준: `⋯ › 묶기: 일의 종류 · 태그`. 태그면 묶음 = §4.2의 줄과 같다. 줄 나누기 제안(§2.4)은 회색 한 줄 + 단추로 보여 준다.
- 묶음 머리:
  - 이름을 누르면 그 자리에서 고친다(태그 이름).
  - 길게 누르면 `이름 바꾸기 · 묶음 지우기`.
  - 맨 아래 `＋ 묶음 추가`(= `＋ 줄 추가`).
- 행:
  - 길게 눌러 끌면 다른 묶음으로 간다(= 태그 바꾸기, 39 끌어 순서 바꾸기와 같은 움직임).
  - 행 날짜를 누르면 날짜 시트가 열린다.
  - `＋ 할 일 추가`의 완료 = 다음 것 적기(그대로).
- 기간 막대·끝 끌기·여러 개 고르기는 휴대폰에서 하지 않는다(상세에서 시작·끝을 고친다).

## 10. 결정 필요 (추천안 먼저)
1. **핵심 날짜는 무엇으로 둘까.** **(가) ⚑ 진짜 할 일 하나 + 마감 연결 행 [추천]**: 캘린더·오늘·알림·위젯에 그대로 뜨고, 새 개념이 없고, 31 §12.3 마감 규칙과도 맞는다. (나) 프로젝트 태그에만 날짜(`relations` 값): 캘린더에 안 뜨고 D-day만 보인다.
2. **새 프로젝트의 줄 기준.** **(가) 태그 [추천]**: 손으로 만든 프로젝트는 처음부터 태그 줄로 연다. 원래 있던 프로젝트(자동·제안)는 일의 종류 그대로 둔다. (나) 모두 일의 종류로 두고 사람이 바꾼다.
3. **줄 태그가 둘 붙은 할 일.** **(가) 앞 줄에만 보이고 `+1` 표시 [추천]**: 끌어 옮길 때 무엇이 바뀌는지 분명하다. (나) 줄마다 같은 칩을 보인다. 틱틱 태그 그룹이 여러 태그를 어떻게 보이는지는 [미확인]이라, 구현 전에 research 08을 보강한다.
4. **보드의 `같이 계획 짜기` 카드.** **(가) 보드에서 빼고 프로젝트 ⋯ `다음 단계 같이 짜기`만 남김 [추천]**: 만드는 길을 하나로 하고, 계획을 짜 주는 화면을 앞에 두지 않는다. 대화 기능은 그대로 남는다. (나) 그대로 둔다.

## 11. 완료 기준 (틱틱과 나란히 + 시안과 나란히)
- [ ] 보드 `＋ 새 프로젝트` → 점선 카드가 입력칸으로 → `투자자산운용사 시험 11/23` → 미리보기 `📜 투자자산운용사 시험 · ⚑ 시험 11/23(월) · D-48` → Enter. 생기는 것은 태그와 `투자자산운용사 시험일`(11/23 종일) 둘뿐이고, 프로젝트 화면이 열린다. 되돌리기 하나로 모두 사라진다.
- [ ] 이름에서 아이콘(📜·🏆·🌱·🚀)과 날짜 이름 기본값을 짐작하고, 칩·아이콘으로 바꿀 수 있다. 종류 칸·분류 칸이 없다.
- [ ] 만든 직후 `줄을 과목별로 나눌까요?`. [＋ 과목 추가]는 줄 입력만 열고, [괜찮아요] 뒤에는 다시 안 뜬다. 공모전 이름이면 [그렇게] → 줄 4개, 할 일 0개.
- [ ] 빈 상태·입력 카드·휴대폰 시트에 `이럴 때 써요` 예시 7개와 안 쓸 때 한 줄이 있고, 예시를 누르면 입력칸이 채워진다.
- [ ] 머리: 이름을 한 번 눌러 고치고, D-day 알약으로 날짜·날짜 이름을 바꾸고(⚑ 할 일과 타임라인 점선이 같이 바뀜), 팀원 ＋·✕, 집중을 켜고 끈다.
- [ ] `＋ 줄 추가` `#금융상품` Enter → 줄이 생기고 초점이 그 줄 `＋ 할 일 추가`로 간다 → `1과목 1회독 10/12~10/18` Enter → 막대 → 이어서 `세제 암기 카드 10/20` Enter.
- [ ] 칩을 다른 줄로 끌면 태그가 바뀌고, `태그 없음`에 놓으면 줄 태그가 떨어진다. 줄 이름 그 자리 고치기(다른 곳 N개 안내), 줄 ✕ = 태그는 남음. `줄: 일의 종류`로 돌리면 예전 줄이 보인다.
- [ ] 칩 끝 끌기로 기간, 날짜 글자로 날짜 팝오버, 고른 칩 제목 다시 누르기로 이름, 끝에서 Enter로 같은 줄에 다음 것.
- [ ] ⌘ 누르기로 3개 → `일주일 미루기`(기간 그대로) · `날짜 고르기`(간격 그대로) · `태그 ›` · 함께 끌기 · ⌘Z 한 번에 되돌림.
- [ ] `＋ 할 일` 하나에서 새로 만들기와 있는 할 일 넣기가 모두 된다. `다음 단계 같이 짜기`는 ⋯에 있다.
- [ ] 휴대폰: 시트로 만들기, 큰 제목 고치기, `묶기: 태그`, 묶음 이름 고치기, `＋ 묶음 추가`, 행을 길게 눌러 다른 묶음으로.
- [ ] 위키·백링크·관계도에 `deadline`·`lane` 행이 선으로 나오지 않는다. 라이트·다크. 동작 줄이기 = 끌기 그림자·튀어 오름 없음.
