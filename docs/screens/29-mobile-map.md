## 2. 레이아웃
### 2.1 영역 목록 (F1, 기본)
| 영역 | 내용 |
|---|---|
| 머리 (52) | 둥근 `‹`(더보기) · 오른쪽 둥근 ✦(AI로 다시 정리 — [다음]엔 흐림) · `⋯`(기간 `이번 주 · 전체` · 완료 보이기 · 보관한 주제 보이기) |
| 큰 제목 (48) | **작업 지도** |
| 세그먼트 | `목록 · 보드` (고른 보기 기억, 14 §0.5) |
| 알림 띠 | AI 정리 직후만: ✦ `새 할 일 6개를 분류했어요` · `되돌리기`(14 §2) |
| 목표 줄 | 주황 연한 면: 🎯 `이번 주 목표에 연결된 할 일 5` · `›` → 목표별 묶음 목록(목표 이름 = 묶음 머리) |
| 영역 카드 | 머리(44): 영역 색 점 · 이름(16/700) · 개수 · 오른쪽 `⋯`. 행(46): **진행 고리 22**(완료/전체) · 주제 이름 · 최근 정리 점 · `1/4` · `›` |
| 미분류 카드 | 점선 테두리, 회색 이름 · 개수 · 주황 `확인 필요` 꼬리표 · `›`. 비어 있으면 숨김 |
| 맨 아래 | `+ 새로운 영역`(강조색 글자) |

### 2.2 주제 → 할 일 (F2, 밀려 들어옴)
| 영역 | 내용 |
|---|---|
| 머리 | 둥근 `‹`(영역 이름) · `⋯`(이름 바꾸기 · 다른 주제와 합치기 · 보관 · 삭제) |
| 큰 제목 | 진행 고리(30) + 주제 이름 |
| **순서** 카드 | 머리 `순서 3` + 오른쪽 3차 `위에서부터 먼저`. 행 왼쪽에 **번호 원(20)** 과 위아래 이은 세로선 — 끝난 단계는 회색 채움. 아직 앞이 안 끝난 행은 꼬리표 `⛓ 먼저 1` |
| AI 제안 줄 | 점선 테두리 카드: ✦ `AI 제안: '화면 시안'은 '기획서 최종본' 다음` · ✓(초록) · ✕ |
| **나머지** 카드 | 순서 없는 할 일. 꼬리표: 목표 연결 `🎯 포트폴리오 첫 장`(주황) · 직접 옮김 `📌 직접 옮김` · 날짜(강조색, 지난 날짜 빨강) |
| 행 | 21 행과 같다(체크 18 · 제목 · 둘째 줄 꼬리표) — 체크 = 완료(XP 포함) |

### 2.3 보드 (F3)
| 영역 | 내용 |
|---|---|
| 열 | 폭 = 화면 − 77(다음 열 약 28이 보임), 회색 면 모서리 14. 머리: 영역 색 점 · 이름 · 개수 · `+` · `⋯` |
| 열 안 | 주제 묶음 머리 `⌄ 운영체제 3`(12.5/600) → 카드(흰 면, 모서리 8, 체크 · 제목 15 · 둘째 줄 날짜 / `⛓ 먼저 N`) |

| 끝 | 마지막 열 오른쪽 `+ 새로운 영역`, 미분류 열은 맨 오른쪽 |

## 3. 구성 요소와 상태
| 상태 | 표시 |
|---|---|
| 처음(영역 없음) | 지도 아이콘 + `할 일이 쌓이면 AI가 영역별로 나눠 드려요` + `컴퓨터에서 정리하거나 직접 영역을 만들 수 있어요` + [영역 만들기] |
| AI 없음 | 띠 자리에 `지금은 AI를 쓸 수 없어요 — 새 할 일은 미분류에 둘게요`(14 §0.3) |
| 정리 중(다른 기기) | 동기화로 바뀐 행에 강조색 점(14 §3 최근 정리 점) |
| 순서 고리 | 이으려는 순간 거부 + 토스트 `순서가 돌고 돌아서 이을 수 없어요`(14 §0.2) |
| 앞 할 일 완료 | 토스트 `이제 '<뒤 할 일>'을 시작할 수 있어요`(14 §0.2) |
| 목표 연결 할 일 다 끝냄 | 토스트 `'<목표>'에 연결된 할 일을 다 끝냈어요 · 달성으로 표시`(누르면 성장과 같은 달성 처리) |
| 끄는 중(보드) | 카드가 살짝 커지고 그림자(키트 `.lifted`), 화면 가장자리에 대면 옆 열로 넘어감 |
| 오프라인 | 목록·보드·옮기기 그대로(로컬). AI 띠 없음 |

## 4. 인터랙션
| 동작 | 결과 |
|---|---|
| 영역 행(주제) 누름 | 주제 화면(F2) |
| 할 일 행 누름 | 할 일 간단 상세 시트(21 §5) |
| 할 일 **길게 누름** | 메뉴: `다른 주제로 옮기기 ›`(영역 › 주제 고르기 시트 → 📌) · `다음에 할 일 고르기`(순서 잇기 시트) · `순서 끊기` · `목표와 연결 ›`(이번 주 목표 목록) · (구분선) · 날짜 · 삭제 |
| 순서 카드에서 끌기 | 순서 안에서 위아래로 끌어 순서 바꿈 [임시] |
| AI 제안 ✓ / ✕ | 받기(실선이 됨 = 사슬·꼬리표에 반영) / 무시(같은 제안 다시 안 함, 14 §0.2) |
| 띠 `되돌리기` | 14 §2 되돌리기 |
| 보드 카드 길게 눌러 끌기 | 다른 주제 묶음·옆 열로 옮김 → 📌 직접 옮김 |
| 영역·주제 `⋯` | 이름 바꾸기(그 자리 입력, 20자) · 합치기 · 삭제(할 일은 미분류로, 확인 대화) |
| 당겨서 새로 고침 | 동기화 |

## 5. 데이터 (14 그대로, 스키마 변경 없음)
| 동작 | 읽기·쓰기 |
|---|---|
| 영역·주제 | `map_areas`(영역·주제 계층) — 이름 바꾸기·합치기·삭제·보관 |
| 할 일 배치 | `task_areas`(할 일 → 주제, `source` = ai/user — 옮기면 user = 📌) |

| 진행 고리 | 주제의 `tasks` 완료/전체(계산) |
