## 9. v2 — 작업 지도 = 프로젝트 한 화면 (모바일, 2026-10-05)
> 데스크톱 31 §12를 휴대폰으로 옮긴다. **2026-10-05 사용자 결정: 작업 지도는 프로젝트 한 화면**(계획·점검·정리 탭 없음). 점검(31 R.*)은 **성장 탭 `주간 점검`**으로, 정리(31 T.*)는 **기본함 정리·밀린 일 입구**(오늘 목록 기본함 카드 · 밀린 일 묶음)로 간다 — 지도 안이 아니다.
> **규칙·문구·데이터는 31 §12 그대로**, 이 절은 휴대폰 모양만 정한다. 31과 다르면 31이 이긴다(다른 점은 이 절에 적는다).
> 틱틱 기준: 카드 묶음·행(21) · 왼쪽 밀기 칸(21 §4.2) · 아래 시트·토스트 되돌리기(21 §3) · 전체 화면으로 올라오는 시트(틱틱 모바일 할 일 상세·검색과 같은 움직임). 프로젝트·점검·분류 책상 자체는 틱틱에 없다 [sprout].

### 9.1 머리 · 들어가는 곳
| 영역 | 내용 |
|---|---|
| 머리 (52) | `‹` · 오른쪽 `⧉`(전체 지도 — 누르면 §2 폴더 › 리스트 목록·보드가 그대로, 눌린 상태 = 강조색, 다시 누르면 프로젝트 화면) · `⋯`(전체 지도에서만 §2 메뉴) |
| 큰 제목 | **작업 지도** |
| 본문 | 프로젝트 보드(§9.2). 전체 지도에서는 §2의 `목록 · 보드` 세그먼트 |
- 전체 지도 여부는 기기 기억 `sprout.map.mobile` `whole`.
- **휴대폰은 자동 프로젝트 패스(31 §12.1 ①~③ 만들기·붙이기·넓히기)를 돌리지 않는다.** 데스크톱이 만든 `tags.kind='project'`와 `task_tags`를 동기화로 받아 **보여 주기만** 한다. 구성원 계산(`projectMembers` — 붙은 태그 ∪ 집 ∪ 하위 − ✕)은 결정적이고 가벼워 휴대폰에서도 같은 공용 함수로 센다. 제안 카드 `묶일 것 같은 일 N개`(§12.1 ⑤)는 데스크톱에서만.
- **31 §12.13(2026-10-06):** 휴대폰은 점수로 넣기·말풍선 묻기를 하지 않는다(보드에 말풍선 없음, 결과는 동기화로). 대신 ⓐ 카드 길게 누름 메뉴 맨 위 `지금 집중`/`집중 끄기` + 카드 이름 옆 강조색 `집중` ⓑ 빠른 입력 설명 아래 `🚀 이름 ✕` 칩(공용 `focusApplies`, 누르면 뗌) ⓒ 같이 계획 짜기(프로젝트 만들기) 끝 팀원 물음 — 코드 `src/map/v2/focus.ts`. 휴대폰 주간 점검 끝 `들어갈 것 같은 일` 줄은 [다음](휴대폰 화면 정리 뒤).
- 순수 계산은 데스크톱과 같은 공용 모듈: `@sprout/schema/projects`(구성원·일의 종류·마감) · `planView`(보드·⚡) · `planChat`(대화 상태 기계·날짜 읽기) · `breakdown`(AI 답 검증·순서 잇기) · `review`(점검 3단계) · `tidy`(더미·제안) · `keywords`(낱말 검사).

- 효과: 큰 할 일 만들기(기본함) · 마감 · 단계 만들기 · 완료(XP 규칙 그대로) · 프로젝트 태그(`project` = 그 프로젝트, `make` = 큰 일 이름으로 프로젝트 태그 source user, 같은 뜻 태그가 있으면 그것).
- **단계 만들기 AI**: 사용자가 대화에서 직접 요청한 것이라 휴대폰도 `POST /ai/breakdown`(stream false, 31 §4.4 보내는 것 그대로 — 제목·리스트 이름·마감·이미 있는 하위 제목)을 부른다 — M-M5의 예외(자동으로 부르는 AI는 여전히 없음). 429 = `limit`, 그 밖 실패 = `down`, 연결 안 됨 = `offline`, 멈추기 = `stopped`, 형식 깨짐 = `format` → 모두 `split-manual`(쉼표로 직접 적기).
- 되돌리기(대화 하나 단위, 31 §11.5 규칙 — 만든 선 삭제 → 손대지 않은 만든 할 일 삭제 → 대화가 끝낸 것 다시 열기(XP 회수) → 대화가 바꾼 마감 되돌림). 프로젝트 만들기로 생긴 태그는 남는다(31 §12.4와 같음). 닫을 때 바꾼 게 있으면 토스트 `'…' 계획을 짰어요` + 되돌리기. 24시간 기록(`⋯` 메뉴)은 데스크톱만.

### 9.3 주간 점검 — 성장 탭 (31 R.* 그대로, 전체 화면 단계)
- 입구: 성장 탭 `주간 리포트` 카드 바로 위 `주간 점검 ›` 줄(회색 `돌아보기 · 밀린 일 · 다음 주 목표`, 일요일 20시~월요일 12시에는 강조색 면 + `지금 점검할 때예요 · 약 5분`, 이 주에 끝냈으면 `이번 주 점검 끝 ✓`) → `growth/review` 화면(밀려 들어옴). 끝 화면 `작업 지도 보기`.
- **모양 v2(2026-10-06, 사용자 "너무 AI 스러워") = 31 R.10.** 머리 `‹ 성장` + 큰 제목 `주간 점검` + 회색 `9/29 – 10/5 돌아보기` → 세그먼트 `돌아보기 · 밀린 일 · 다음 주` → 단계 본문은 설정 같은 묶음 목록(① `이번 주` 숫자 행 3 · `프로젝트` 행 + 2px 진행선 · `요일별` 7행(누르면 그날 할 일 펼침) ② 밀린 일 행 + 작은 세그먼트 `다음 주 · 언젠가 · 끝냄 · 지우기` + `안 고른 n개 모두 다음 주로` ③ 체크 상자 행 + `＋ 직접 적기` 행 + `다음 주` 7행 `목표 n`). 아래 바 `이전` · 오른쪽 강조색 단추 `다음`/`점검 끝내기`(높이 44, 모서리 10).
- 뺀 것: `이건 뭐예요?` 상자 · 단계별 캐릭터 말풍선 · 번호 원 알약 스테퍼 · 색 큰 숫자 3칸 · 2×2 큰 단추 · 색 날짜 막대 · 이모지 장식 · 가운데 영웅 문장 · XP 알약.

### 9.4 정리 — 기본함 정리 · 밀린 일 (31 T.* — 끌기 대신 밀기·옮기기 시트)
- 입구: 기본함 목록 `⋯ › 기본함 정리`(기본함 탭) · 목록의 만료됨(밀린 일) 묶음 `미루기 › 정리 화면에서 보기`(기한 지난 일 탭) · 작업 지도 지금 할 일 카드 `기한 지난 일 N개는 정리에서 볼게요 ›`(기한 지난 일 탭) → 뿌리 스택 `tidy` 화면(밀려 들어옴). 딥 링크 `sprout://tidy?tab=`.
- 위: 캐릭터 한마디(T.6 탭마다) + 칩(같은 동작).
- 탭 알약 가로 스크롤 `기본함 n · 기한 지난 일 n · 프로젝트 밖 n · 태그 없음 n`.
- 행(카드 묶음 안): 고르기 상자 · 제목 · 회색 줄(T.2) · 제안이 있으면 셋째 줄 강조색 `→ 수업·과제` / `→ 공모전 (프로젝트)` + `좋아`(강조색 채움) · `아니`(회색). 제안 없는 기본함 행은 회색 줄 끝에 `· 확실하지 않아요 — 밀어서 옮겨요`.
- 캐릭터 한마디(T.6)는 휴대폰 말로: `끌어다 놓으면` → `밀어서 옮기기로`. 칩이 없으면 ✕도 없다.
- **왼쪽 밀기 → `옮기기`**(파랑) — 옮기기 시트(현재 화면 안 아래 시트): 위 `프로젝트에 묶기 · 리스트는 그대로` 프로젝트 알약 → 아래 폴더 › 리스트(31 T.1 상자 순서). 리스트 = 옮김, 프로젝트 = 태그만. 고른 게 있으면 고른 것 전부를 옮긴다. 기한 지난 일 탭은 밀기 칸 `오늘`·`다음 주`도.
- 고르기: 체크 상자 누름 = 더하기·빼기. 고름이 있으면 아래 바 `n개 고름 · 옮기기 · 고름 풀기`(기한 지난 일 탭은 `오늘로 · 다음 주로 · 완료(XP 없음) · 지우기`, 묶음 머리 `모두 고르기`).
- 아래 `제안 N개 모두 옮기기`(주) · `하나씩 볼래`(첫 제안 행만 강조, 좋아/아니 하면 다음).
- **제안 출처(휴대폰은 AI를 부르지 않음):** 기본함 → 리스트 = 공용 낱말 검사(`keywords` — 30 §B.3 (가)와 같은 규칙: 한 리스트의 최근 할 일 3개 이상과 뚜렷한 낱말이 겹침). 프로젝트 = 31 T.3 그대로(`suggestProjects`). `아니` = 기기 기억(`sprout.map.tidy.no` · 리스트 제안은 `sprout.map.tidy.noList`).
- 네 탭이 모두 0이면 `다 정리했어!` + 회색 요약 + **`+20 XP`**(하루 1회, 이번에 1개 이상 처리했을 때 — 성장 공용 규칙) + `작업 지도 보기`.
