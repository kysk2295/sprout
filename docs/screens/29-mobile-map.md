- 상태: **확정 v1.0 · 구현(2026-10-05)** — 사용자 결정 두 가지:
  1. **모바일 v1 = 데스크톱 기능 전부(v1 full parity)** — 초안 v0.1의 [다음] 표시를 없앤다.
  2. **"리스트"와 "AI 영역"을 하나로 합친다**(2026-10-05): 작업 지도 = **내 폴더 › 리스트 › 할 일**(틱틱처럼 사용자가 직접 고치는 구조). `map_areas`·`task_areas`(영역·주제) 모델은 쓰지 않는다. AI는 리스트를 만들거나 옮기지 않고, 기본함·새 할 일에 `→ ○○로 옮길까요?` 제안 칩만 보인다(누르면 `tasks.list_id` 변경). 순서·목표 선(`map_links`)은 그대로. 데스크톱 작업 지도(14)도 같은 방향으로 바뀐다(다른 담당).
- 시안: [mockups/mobile-sprout.html](mockups/mobile-sprout.html) **F1**(목록) · **F2**(한 묶음 → 할 일, 순서·목표) · **F3**(보드) — 시안의 "영역"은 **폴더**, "주제"는 **리스트**, "미분류"는 **기본함**으로 읽는다.

## 2. 레이아웃
### 2.1 목록 (F1, 기본)
| 영역 | 내용 |
|---|---|
| 머리 (52) | 둥근 `‹`(더보기) · 오른쪽 `⋯`(기간 `이번 주 · 전체` · 완료 보이기 · 날짜 없는 항목 보이기 · 새로운 리스트 · 새 폴더) |
| 큰 제목 · 세그먼트 | **작업 지도** · `목록 · 보드`(고른 보기 기기에 기억) |
| 목표 달성 띠 | 이번 주 목표에 연결된 할 일을 다 끝냈으면 `'<목표>'에 연결된 할 일을 다 끝냈어요 · 달성으로 표시`(성장과 같은 달성 처리) |
| 목표 줄 | 주황 연한 면: 🎯 `이번 주 목표에 연결된 할 일 N` · `›` → 목표별 묶음 화면 |
| 폴더 없는 리스트 카드 | 머리 없이 리스트 행만(틱틱 서랍처럼 맨 위) |
| 폴더 카드 | 머리(44): 폴더 이름(16/700) · 미완료 수 · `⋯`(이름 바꾸기 · 새 리스트 · 그룹 해제). 행(46): **진행 고리 22**(최근 30일 완료/전체) · 리스트 색 점/이모지 · 이름 · `완료/전체` · `›` |
| 기본함 카드 | 점선 테두리, 받은 편지함 아이콘 · `기본함` · 미완료 수 · 주황 `정리할 것`(미완료가 있으면) · `›` |
| 맨 아래 | `+ 새로운 리스트` · `새 폴더`(강조색 글자) |

### 2.2 리스트 → 할 일 (F2, 밀려 들어옴)
| 영역 | 내용 |
|---|---|
| 머리 | `‹ 폴더 이름`(강조색) · `⋯`(이름 바꾸기 · 보관 — 기본함은 없음) |
| 큰 제목 | 진행 고리 30 + (이모지) + 리스트 이름 |
| **순서** 카드 | 머리 `순서 N` + `위에서부터 먼저`. 이 리스트 안 할 일끼리 받아들인 순서 선을 위상 순서로: **번호 원 20** + 위아래 세로선, 끝난 단계는 회색 채움. 아직 앞이 안 끝난 행은 `⛓ 먼저 N` |
| AI 제안 줄 | 점선 테두리: ✦ `AI 제안: '<뒤>'은(는) '<앞>' 다음` 또는 `'<할 일>' → 🎯 <목표>` · ✓(초록) · ✕ |
| **나머지** 카드 | 순서 없는 할 일. 꼬리표: `🎯 목표`(주황) · 날짜(강조색, 지난 날짜 빨강) |
| 행 | 21 행과 같다(체크 · 제목 · 둘째 줄 꼬리표). 체크 = 완료(XP 포함, 토스트 되돌리기) |

### 2.3 보드 (F3)
| 영역 | 내용 |
|---|---|
| 열 | **열 = 폴더**(폴더 없는 리스트는 `리스트` 열, **기본함 열은 맨 오른쪽**). 폭 = 화면 − 77(다음 열이 보임), 모서리 14. 머리: 이름 · 미완료 수 · `⋯`(폴더만) |
| 열 안 | 리스트 묶음 머리 `⌄ 졸업 프로젝트 3 ›`(접기 / `›` = 리스트 화면) → 카드(체크 · 제목 · 꼬리표) |
| 넘기기 | 한 열씩 딱 멈춤, 아래 페이지 점. 열 이름 누름 → 모든 열 격자 → 바로 이동 [틱틱] |
| 끝 | `+ 새로운 리스트` |
| 기간 | 보드는 기간 없이 "전체"(데스크톱 보드와 같음) |

### 2.4 목표별 묶음
이번 주 목표(성장 `kpis`) 이름 = 묶음 머리 + `완료/전체`(달성이면 `달성`), 아래 연결된 할 일 행.

## 3. 상태
| 상태 | 표시 |
|---|---|
| 처음(리스트 없음·기본함 비어 있음) | 지도 아이콘 + `폴더와 리스트로 할 일을 한눈에 봐요` + [리스트 만들기] |
| 폴더 안 리스트 없음 | `리스트가 없어요 · ⋯에서 새 리스트` |
| 순서 고리 | 잇는 순간 거부 + 토스트 `순서가 돌고 돌아서 이을 수 없어요`(14 §0.2) |
| 앞 할 일 완료 | 토스트 `이제 '<뒤 할 일>'을 시작할 수 있어요`(+ 되돌리기) |
| 목표 연결 할 일 다 끝냄 | 목록 위 띠 `… · 달성으로 표시` |
| 오프라인 | 전부 로컬 쓰기, 동기화가 나중에 올린다 |
