## 2. 레이아웃
| 영역 | 내용 |
|---|---|
| 레일 | `메모함` 다음에 **일기**(책 + 하트 아이콘, 직접 그림) [임시 위치] |
| 머리 | 제목 **"일기"** + 세그먼트 `쓰기 · 돌아보기` · 검색 |
| 쓰기 — 왼쪽(300) | 미니 달력(일기 쓴 날 아래 기분 색 점, 고른 날 강조색 칸) → 월 그룹 머리 `10월 4` → 날짜 행(기분 이모지 · `10월 4일 토 · 오늘` · 첫 줄 미리보기) |
| 쓰기 — 오른쪽 | 머리: `10월 4일 토요일` + `오후 11:02 · 자동 저장됨` + 나만 보기(🔒) · `⋯`. 본문: 기분 5단계 → (빈 날이면 오늘의 질문) → 일기 글 → **오늘 한 일 줄** → **캐릭터와 이야기**(§3.1) |
| 바닥 줄 | `🔥 4일 연속 기록` … `도토리만 같이 읽어요 · 🔒 나만 보기로 바꾸면 AI가 읽지 않아요` (AI를 꺼 두었으면 `일기는 나만 봐요`) |
| 돌아보기 | 머리 오른쪽 `월 · 연` + `‹ 2026년 10월 ›`. 왼쪽 월 달력(칸마다 기분 이모지, 오늘 테두리), 오른쪽 카드: 이번 달 기록 일수·연속 기록, 기분 비율 막대, 한 줄 발견("할 일을 5개 넘게 끝낸 날 기분이 좋았어요") |
| 좁은 창 | 왼쪽 목록이 접히고 머리의 달력 버튼으로 연다 [임시] |

## 3. 구성 요소와 상태
| 요소 | 상태 |
|---|---|
| 기분 | 😢 😕 😐 😊 🤩 (1~5). 고른 것은 강조색 테두리 + 옆에 말(`좋았어요`). 다시 누르면 해제. 기분만 고르고 글이 없어도 저장 |
| 오늘의 질문 | 미리 준비한 질문 목록에서 날마다 하나(예: 오늘 가장 뿌듯했던 순간은?). `다른 질문`으로 바꿈. AI 없이 동작. 질문을 누르면 본문에 `Q. …` 줄로 넣는다 |
| 일기 글 | 15/26 큰 글씨, 그냥 글자(서식 없음 [임시]). 0.6초 뒤 자동 저장. 비어 있으면 자리 글자 `오늘 하루는 어땠나요?` |
| 오늘 한 일 줄 | `✓ 오늘 한 일 6개 · +6 XP · 할 일 탭에서 보기` 한 줄(누르면 그날 완료 목록 펼침). **자동으로 만들며 저장하지 않는다**. AI 대화를 꺼 둔 사람에게는 v0.1의 카드(캐릭터 + 미리 준비한 한마디)를 보여 준다 |
| 지난 날 | 달력·목록에서 지난 날짜를 고르면 그날 일기. 일기가 없는 날 = 빈 편집기 + 그날 한 일 카드(지난 날도 쓸 수 있음) |
| 미래 날 | 고를 수 없음(회색) |
| 빈 일기장 | 오른쪽에 캐릭터 + `오늘 하루를 한 줄로 남겨 볼까요?` |
| 잠금 | [다음] 일기 탭 열 때 Touch ID/암호. v1은 아이콘 자리만 |
| 연속 기록 | 오늘까지 이어진 날 수(오늘 아직 안 썼으면 어제까지 + `오늘도 이어 가요`) |

### 3.1 캐릭터와 이야기 (AI 공감·고민 상대)
| 항목 | 내용 |
|---|---|
| 대화 상대 | **내 성장 캐릭터**(성장 탭과 같은 그림·이름, 예: 다람쥐 "도토리"). 말투는 종마다 조금 다르게(거북이 느긋 · 다람쥐 밝음 · 고양이 담백 · 수달 다정) [임시] |
| 시작 | 일기를 쓰면 글 아래 구분선 `도토리와 이야기` + 캐릭터가 **먼저 한 번** 답한다(저장 뒤 3초 동안 더 쓰지 않으면). 바로 원치 않으면 `⋯` → `오늘은 혼자 쓸게` |
| 첫 답 원칙 | **공감 1~2문장 + 열린 질문 1개.** 조언·해결책부터 쏟아내지 않는다. 일기 내용을 구체적으로 짚는다("기획서를 반이나 썼구나!") |
| 대화 방식 | 입력칸 왼쪽 세그먼트 `들어만 줘 · 같이 고민해 줘`. 들어만 줘 = 맞장구·감정 읽기, 질문 최소 / 같이 고민해 줘 = 질문으로 생각 정리, 원하면 선택지 2~3개 |
| 말풍선 | 캐릭터: 왼쪽, 작은 캐릭터 얼굴 + 카드색 말풍선 / 나: 오른쪽, 강조색 연한 말풍선. 받는 중엔 글자가 점점 늘어남(AI 비서와 같은 스트림) |
| 할 일로 | 고민이 구체적인 행동으로 이어지면 말풍선 아래 칩 `＋ 할 일로: 면담용 차별점 한 장 정리` — 누르면 기본함에 생성(작업 지도 자동 분류) |
| 기억하기 | 켜면 최근 7일 일기의 **짧은 요약**을 함께 보내 "지난주에 걱정하던 면접은 어떻게 됐어?"처럼 이어서 묻는다. 끄면 그날 일기만 |
| 켜기(동의) | 처음 일기 탭을 열 때 한 번: `일기를 도토리와 나눌까요? 일기 글이 sprout AI(운영자의 Mac mini)에서 처리돼요. 언제든 끌 수 있어요` [나누기] [혼자 쓸게요]. 설정에서 바꿈 |
| 나만 보기 | 머리 🔒로 그날 일기를 AI에게 보내지 않는다(대화 영역 숨김) |
| **위기 안전장치** | 자해·자살·극단적 생각·폭력 피해 신호가 보이면(앱의 단어 검사 + 모델 판단 둘 다) 평소 대화를 멈추고 **안내 카드**를 먼저: `지금 많이 힘들구나. 혼자 견디지 않아도 돼` + 자살예방상담전화 **109**(24시간) · 정신건강위기상담 **1577-0199** · 긴급 **112/119**. 캐릭터는 진단·치료 조언을 하지 않는다 |
| 한계 알림 | 대화 영역 아래 작게 `도토리는 친구처럼 들어 주지만 전문 상담은 아니에요` (처음 몇 번만) |
| AI 없음 | `지금은 도토리가 쉬고 있어요. 일기는 그대로 저장돼요` |

## 4. 인터랙션
- 날짜 행·달력 칸 클릭 = 그날 열기. ↑↓ = 하루 앞뒤, `T` = 오늘 [임시].
- ⌘F = 일기 검색(글 부분 일치, 결과는 날짜 행 목록).
- `⋯` 메뉴: `이 날 일기 지우기`(확인) · `텍스트로 내보내기`[다음].
- 돌아보기 칸 클릭 = 쓰기로 바뀌며 그날.
- 일기를 쓴다고 XP를 주지 않는다(일기가 숙제가 되지 않게, XP 규칙 그대로) [추천안 — 사용자가 "너가 하는대로"].

## 5. 데이터
| 테이블(새로) | 칸 | 설명 |
|---|---|---|
| `diary_entries` | common + `date`(YYYY-MM-DD, 사용자당 하루 1개), `mood`(1~5 또는 null), `content`, `prompt`, `private`(나만 보기 0/1), `summary`(기억하기용 짧은 요약, AI가 만듦) | id = 날짜로 결정적(`diary-<날짜>`)이라 두 기기에서 같은 날 써도 한 행으로 모인다(마지막 저장이 이김) [임시] |
| `diary_messages` | common + `entry_id`, `role`(`me`/`buddy`), `content`, `mode`(`listen`/`think`), `safety`(0/1) | 그날 캐릭터와 나눈 대화 |
- 오늘 한 일 카드: `tasks.completed_at`이 그날인 것 + `xp_events` 그날 합계(읽기만).
- **개인정보:** 일기는 사용자가 "나누기"를 켰을 때만, 나만 보기가 아닌 날만 AI(Mac mini, `POST /ai/diary`)로 보낸다. 서버 프록시는 원문을 남기지 않는다(PRD AI 원칙). 대화 내용은 사용자 데이터로 동기화된다. **공개 출시 전 검토:** 일기·대화를 기기에서 암호화해 운영자도 읽을 수 없게(종단 간 암호화) — 이 경우 AI 대화는 기기가 복호화해 보낸 요청에서만 처리.
- ⚠️ 새 테이블 2개 → 서버 스키마·마이그레이션·동기화 규칙 변경 필요(작업 지도·수집함과 함께 적용).
