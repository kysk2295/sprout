## 2. 레이아웃
| 영역 | 내용 |
|---|---|
| 레일 | `메모함` 다음에 **일기**(책 + 하트 아이콘, 직접 그림) [임시 위치] |
| 머리 | 제목 **"일기"** + 세그먼트 `쓰기 · 돌아보기` · 검색 |
| 쓰기 — 왼쪽(300) | 미니 달력(일기 쓴 날 아래 기분 색 점, 고른 날 강조색 칸) → 월 그룹 머리 `10월 4` → 날짜 행(기분 이모지 · `10월 4일 토 · 오늘` · 첫 줄 미리보기) |
| 쓰기 — 오른쪽 | 머리: `10월 4일 토요일` + `오후 11:02 · 자동 저장됨` + 잠금 · `⋯`. 본문: 기분 5단계 → 오늘의 질문 → 일기 글 → **오늘 한 일 카드** |
| 바닥 줄 | `🔥 4일 연속 기록 · 글자 142` … `일기는 나만 봐요 · AI가 읽지 않아요` |
| 돌아보기 | 머리 오른쪽 `월 · 연` + `‹ 2026년 10월 ›`. 왼쪽 월 달력(칸마다 기분 이모지, 오늘 테두리), 오른쪽 카드: 이번 달 기록 일수·연속 기록, 기분 비율 막대, 한 줄 발견("할 일을 5개 넘게 끝낸 날 기분이 좋았어요") |
| 좁은 창 | 왼쪽 목록이 접히고 머리의 달력 버튼으로 연다 [임시] |

## 3. 구성 요소와 상태
| 요소 | 상태 |
|---|---|
| 기분 | 😢 😕 😐 😊 🤩 (1~5). 고른 것은 강조색 테두리 + 옆에 말(`좋았어요`). 다시 누르면 해제. 기분만 고르고 글이 없어도 저장 |
| 오늘의 질문 | 미리 준비한 질문 목록에서 날마다 하나(예: 오늘 가장 뿌듯했던 순간은?). `다른 질문`으로 바꿈. AI 없이 동작. 질문을 누르면 본문에 `Q. …` 줄로 넣는다 |
| 일기 글 | 15/26 큰 글씨, 그냥 글자(서식 없음 [임시]). 0.6초 뒤 자동 저장. 비어 있으면 자리 글자 `오늘 하루는 어땠나요?` |
| 오늘 한 일 카드 | 그날 완료한 할 일(최대 3개 + `외 N개`)과 그날 XP(`+6 XP`), 오른쪽에 내 캐릭터(성장 탭과 같은 그림, 기분 좋은 얼굴) + 말풍선 한마디(완료 수·시간대에 따라 미리 준비한 문장). **자동으로 만들며 저장하지 않는다** |
| 지난 날 | 달력·목록에서 지난 날짜를 고르면 그날 일기. 일기가 없는 날 = 빈 편집기 + 그날 한 일 카드(지난 날도 쓸 수 있음) |
| 미래 날 | 고를 수 없음(회색) |
| 빈 일기장 | 오른쪽에 캐릭터 + `오늘 하루를 한 줄로 남겨 볼까요?` |
| 잠금 | [다음] 일기 탭 열 때 Touch ID/암호. v1은 아이콘 자리만 |
| 연속 기록 | 오늘까지 이어진 날 수(오늘 아직 안 썼으면 어제까지 + `오늘도 이어 가요`) |

## 4. 인터랙션
- 날짜 행·달력 칸 클릭 = 그날 열기. ↑↓ = 하루 앞뒤, `T` = 오늘 [임시].
- ⌘F = 일기 검색(글 부분 일치, 결과는 날짜 행 목록).
- `⋯` 메뉴: `이 날 일기 지우기`(확인) · `텍스트로 내보내기`[다음].
- 돌아보기 칸 클릭 = 쓰기로 바뀌며 그날.
- 일기를 처음 쓴 날 성장 XP? → **아니오**(일기는 부담 없이, XP 규칙 그대로) [사용자 확인 필요].
