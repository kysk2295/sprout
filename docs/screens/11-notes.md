## 2. 레이아웃 — 메모 탭
| 영역 | 내용 |
|---|---|
| 머리 (57) | 제목 **"메모함"** + 바로 옆 세그먼트 `메모 · 주제 위키` · 오른쪽 검색(🔍) · `⋯` |
| 추가 바 (38) | `+ 메모 추가하기` [틱틱 노트 리스트 문구]. 초점 시 강조색 1px, 오른쪽 끝에 `Enter 저장` (11, 3차 글자) |
| 목록 | 작성일 그룹: `오늘` · `어제` · `이번 주` · `이전`(처음엔 접힘) [임시 — 틱틱 "날짜별 그룹"의 메모판] |
| 행 (40) | 문서 아이콘(14, 3차 글자) · 첫 줄(한 줄, 넘치면 …) · 오른쪽: 오늘 그룹은 시각(`오후 1:12`), 그 밖은 날짜(`10월 3일`) |
| 전환된 메모 | 오른쪽 메타 자리에 작은 꼬리표 `할 일` / `일정`(강조색 연한 배경). 연결 항목이 지워졌으면 `일정 · 삭제됨`(회색) |
| 상세 패널 (336) | 행을 누르면 오른쪽에 열린다. 아무것도 안 골랐으면 패널 자리에 빈 상태(문서 아이콘 + `메모를 고르면 여기에서 고칠 수 있어요`) |
| 좁은 창 | 목록 폭 < 360이면 상세가 목록 위에 겹쳐 열리고 `←`로 닫는다(02 §2 규칙과 같다) |

## 3. 레이아웃 — 주제 위키 탭
| 영역 | 내용 |
|---|---|
| 머리 | 같은 머리, 세그먼트만 `주제 위키` 선택. 검색 대신 `⋯` |
| 왼쪽 주제 목록 (240) | 그룹 머리 `주제 N` · 행: 책 아이콘 · 주제 이름 · 오른쪽 메모 수 · 맨 아래 `+ 주제 추가`(강조색) |
| 오른쪽 위키 문서 | 여백 28. 위에 알림 띠(필요할 때만) → 제목(19/700) → 정보 줄(`메모 12개 · 10월 3일 정리 · 버전 4` + `원본 변경 N` 꼬리표 + 오른쪽 `이력`) → 구역들 |
| 구역 | `개요` · `결정한 것` · `아이디어` · `열린 질문` · `연결된 할 일`. 근거가 없는 구역은 숨긴다(정책 유지) |
| 구역 줄 | 점 목록. 줄 끝에 출처 꼬리표 `메모 7`(강조색 연한 배경) — 누르면 메모 탭에서 그 메모를 선택 |
| 직접 고친 구역 | 구역 제목 옆 🔒 + `직접 고침`. AI 정리가 덮어쓰지 않는다. 바꿀 내용이 있으면 구역 아래 `제안 1개 보기` |
| 알림 띠 | `새 메모 3개가 있어요. 정리하면 바뀌는 부분을 먼저 보여드려요.` + `AI로 정리하기`(주 버튼) · `나중에` |

## 4. 구성 요소와 상태
| 요소 | 상태 |
|---|---|
| 추가 바 | 빈칸 Enter = 아무 일 없음 · 저장 중 = 입력 잠금 없이 바로 비우고 목록 맨 위에 새 행(낙관적) · 실패 = 행 제거 + 추가 바에 글 되돌림 + 토스트 `저장하지 못했어요. 다시 시도해 주세요.` |
| 행 | 기본 · 호버(`--color-bg-hover`) · 선택(`--color-bg-selected`, 모서리 6, 좌우 10 안쪽) · 검색 일치 글자 강조(`--color-search-highlight`) |
| 검색 | 🔍 누르면 추가 바 자리가 검색칸(`메모 검색`)으로 바뀐다. 글자 그대로 부분 일치(`%`·`_`도 글자로). Esc = 검색 닫고 추가 바로. 결과 없음 = `"<검색어>"와 맞는 메모가 없어요` |
| 빈 메모함 | 목록 자리 가운데: 문서 아이콘(48, 4차 글자) + `생각나는 것을 바로 적어 두세요` + `필요할 때 할 일이나 일정으로 바꿀 수 있어요`(3차) |
| 불러오는 중 | 행 자리 회색 막대 5줄(깜빡임 없이) |
| 상세 편집 | 글자를 고치면 0.6초 뒤 자동 저장(02 상세와 같다). 첫 줄을 모두 지우면 둘째 줄이 제목이 된다. 내용을 전부 지우고 나가면 `빈 메모는 저장하지 않아요` 토스트 + 직전 내용 유지 |
| 전환 팝오버 | ☑ 또는 메뉴 `할 일로 만들기`/`일정으로 만들기` → 버튼 아래 팝오버(폭 300): 제목(첫 줄로 채움) · 리스트 고르기(05의 리스트 피커) · 날짜(03 날짜 피커; `일정으로`는 날짜 필수, 시각·종료 선택) · `원본 메모는 그대로 두고 설명에 함께 저장해요` · [취소] [등록] |
| 전환 후 | 행에 꼬리표, 상세 바닥에 연결 줄. 같은 메모에서 다시 전환 메뉴 = `연결된 할 일 열기`로 바뀐다(중복 생성 없음, 정책 유지) |
| 위키 — AI 쓸 수 없음 | `AI로 정리하기` 비활성 + 툴팁 `지금은 AI를 쓸 수 없어요` (13 §6 문구) |
| 위키 — 주제 없음 | 오른쪽 가운데: 책 아이콘 + `메모가 쌓이면 주제별로 정리해 드려요` + `메모 5개 이상이면 AI가 주제를 제안해요` + [메모로 돌아가기] |
| 위키 — 정리 중 | 알림 띠 자리에 진행 줄 `메모 12개를 읽는 중… ■ 멈추기`. 다 되면 바뀌는 부분을 초록·빨강 줄로 보여 주고 [적용] [버리기] |

| 동작 | 결과 |
|---|---|
| 추가 바 Enter | 저장 **⚠️ 변경 · 확인됨** (v1.x: Enter 줄바꿈 · ⌘Enter 저장 → 틱틱 추가 바와 같게) |

| 행 우클릭 / `⋯` | 메뉴: `할 일로 만들기` · `일정으로 만들기` · `복사` · 구분선 · `삭제` |

| 세그먼트 | 클릭 또는 ←→ / Home / End로 `메모 ↔ 주제 위키`. 전환해도 추가 바 초안·검색어·선택 행은 유지(정책 유지) |

| 위키 구역 직접 고침 | 구역 글을 누르면 그 자리에서 편집 → 저장 시 그 구역 🔒 |

## 부록 A. v1.x 명세 원문 (다른 세션, 2026-10-04) — 위 ⚠️ 변경 외 정책은 유효
### 메모함 1단계
승인된 메모함 설계의 수동 기능 구현. AI/위키는 후속 단계다.
성장 아래 메모함 레일 메뉴. 제목·검색을 위에, 최신순 원문 카드를 가운데, 항상 보이는 입력창을 아래에 배치한다. 기존 앱 토큰을 사용하며 작은 창에서는 한 열로 표시한다.
Enter는 줄바꿈, Cmd/Ctrl+Enter 또는 저장 버튼으로 저장한다. 공백 저장 금지. 저장 실패 시 입력 보존 및 오류 안내. 저장 중 버튼 비활성화.
카드에서 수정/취소/저장. 원문은 일반 텍스트로 렌더링한다. 검색은 원문의 부분 문자열로 %와 _도 문자 그대로 찾는다.
전환 버튼에서 제목·리스트를 수정하고 일정은 날짜·시각·선택 종료 시각을 입력하여 확인한다. 종일은 날짜만 저장한다. 한 메모는 한 항목에 연결한다. 이미 전환하면 연결 항목 열기 제공. 삭제된 항목은 삭제됨으로 안내한다. 전환은 원문을 보존하며 작업 생성과 연결을 단일 트랜잭션으로 처리한다.
notes(id, common fields, content, task_id)를 공통 스키마에 추가한다. task_id는 동일 메모 재시도 시 같은 ID가 되도록 결정적으로 생성한다. 수정과 전환은 별도이며 이후 메모 수정이 생성된 할 일을 변경하지 않는다.
검증: 빈 메모/검색 특수문자/수정 보존/시간 검증/전환 원문/중복 방지/실패 롤백/연결 열기/좁은 창. 서버 새 스키마 생성 및 기존 서버 적용 절차를 기록한다.

### 메모함·주제 위키 통합 (2026-10-04)
사용자 결정: 별도 주제 위키 rail 항목을 제거하고 메모함 한 곳에서 ‘메모’/‘주제 위키’ 내부 탭으로 전환한다. 메모 탭은 기존 검색·작성·수정·전환을 유지하며 내부 탭 전환 시 초안과 검색·편집 상태를 보존한다. 위키는 아직 생성 기능 준비 상태임을 표시하고 ‘메모로 돌아가기’를 제공한다. 기존 저장된 wiki 화면 값도 통합 메모함의 위키 탭으로 열린다. 키보드 좌우/Home/End로 내부 탭을 전환한다. AI 비서 진입점은 유지한다.
