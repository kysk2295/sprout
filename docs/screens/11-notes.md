# 11 · 수집함 (메모함 v3 — 수집 · 볼 것 · 위키)

- 상태: **확정 v3.0** (2026-10-04 사용자 결정). 탭 이름 메모함 → **수집함**, 안을 `수집 · 볼 것 · 위키`로 나눈다. v2(노트 목록형, 구현됨)의 목록·상세·전환·삭제 동작은 그대로 쓰고 그 위에 AI 자동 분류·링크·LLM 위키·카톡 가져오기를 얹는다(부록 B).
- 사용자 말: "카카오톡에 유튜브든, 급하게 할 일이나 메모 등을 전부 보내는데 정리가 안 된다 — 여기서 해결해 줬으면", "LLM 위키처럼 활용하고 싶다". 결정: 수집 경로는 **지난 카톡 가져오기 먼저 → 카톡 채널 챗봇은 다음**, 링크는 **제목 + 주소만**(요약 없음), 탭 구성은 제안대로.
- 시안: [mockups/new-tabs.html](mockups/new-tabs.html) ② 수집, ②-b 볼 것 + 카톡 가져오기, ②-c 위키

## v3-3. 수집 — AI 자동 분류
들어온 것(추가 바·카톡 가져오기·[다음] 카톡 채널)은 **바로 저장**하고 AI가 뒤에서 네 갈래로 나눈다.
| 갈래 | 행 표시 | 결과 |
|---|---|---|
| **할 일·일정** | 점선 체크 칸 + 꼬리표 `할 일 제안 · 내일 오후 3:00` + 작은 `등록` 버튼 | **자동으로 만들지 않는다.** `등록` 한 번 = v2 전환과 같은 경로로 할 일 생성(작업 지도 자동 분류도 탐). 등록 후 꼬리표 `할 일로 등록됨` |
| **볼 것**(링크) | 링크 아이콘 + 꼬리표 `볼 것` | 볼 것 탭에 들어감. 제목은 메인 프로세스가 가져온다(유튜브 oEmbed, 그 밖은 페이지 `<title>`), 못 가져오면 주소 그대로. **요약하지 않는다** |
| **위키** | 책 아이콘 + 초록 꼬리표 `위키 · LLM 공부` | 해당 주제 페이지에 자동 반영(v3-5). 맞는 주제가 없으면 AI가 새 주제를 만든다 |
| **메모** | 문서 아이콘 + 꼬리표 `메모` | 그대로 남김 |
- 정리 중 = 작은 회전 표시 + `정리 중…`. 실패·AI 없음 = 꼬리표 없이 두고 나중에 다시(작업 지도 §0.3과 같은 규칙).
- 글 안에 링크와 할 일이 섞여 있으면(예: "이 영상 보고 금요일까지 요약") 할 일 제안 + 링크를 볼 것에도 넣는다.
- 상세(336): 원문(편집 가능, v2와 같음) + **AI 판단 카드**(`AI가 할 일로 봤어요` · 제목/날짜/리스트 · [할 일로 등록] [메모로 두기] · `다른 종류로: 볼 것 · 위키 · 메모`). 사용자가 바꾼 종류는 AI가 다시 바꾸지 않는다.
- `카톡` 꼬리표(테두리만) = 카카오톡에서 가져온 것.

## v3-4. 카카오톡 대화 가져오기
- `⋯` → `카카오톡 대화 가져오기` → 대화 상자(폭 440): 안내 3단계(나와의 채팅 열기 → 메뉴 → 대화 내보내기 → 텍스트 저장 → 파일 놓기) → 파일 놓기 칸 → **미리보기**(`메시지 312개 · 기간 · 링크 84 · 글 228 · 이미 가져온 40개는 건너뜀 · 사진·이모티콘·파일은 빼고`) → [취소] [가져와서 정리하기].
- 가져온 뒤 수집 탭 위 진행 띠 `카카오톡에서 가져온 312개를 정리하는 중 · 120/312 · 멈추기`. 정리는 Mac mini 부담을 줄이려고 묶어서 천천히(한 번에 20개).
- 파싱: 카카오톡 PC·모바일 내보내기 형식(날짜 줄 + `[이름] [오후 3:12] 내용` / `2026. 10. 4. 오후 3:12, 이름 : 내용`)을 읽는다. 여러 줄 메시지는 이어 붙인다. **원래 보낸 시각**을 작성 시각으로 쓴다.
- 중복: (보낸 시각 + 내용) 지문으로 이미 가져온 것은 건너뛴다(같은 파일을 두 번 올려도 안전).
- 파일은 기기 안에서만 읽고 서버에 올리지 않는다(메시지만 수집함 항목으로 저장).
- **[다음] sprout 카카오톡 채널(챗봇):** 채널에 보내면 바로 수집함으로. 서버 공개 주소·카카오 채널/챗봇 신청·계정 연결 코드가 필요.

## v3-5. 위키 (LLM 위키)
| 항목 | 내용 |
|---|---|
| 자동 반영 | 위키로 분류된 자료가 들어오면 AI가 **알아서** 그 주제 페이지를 고친다("AI로 정리하기" 버튼 없음). 위에 띠 `방금 들어온 자료 1개를 '핵심 정리'에 반영했어요 · 바뀐 곳 · 되돌리기`, 새로 들어간 줄은 잠시 강조색 배경 |
| 페이지 구역 | `개요` · `핵심 정리` · `볼 것`(이 주제 링크들) · `관련 주제`(다른 주제로 가는 링크) · `열린 질문`. 근거 없는 구역은 숨김 |
| 출처 | 문장마다 꼬리표(`카톡 10/2`, `메모 9/30`, `오늘`) → 누르면 수집 탭에서 그 항목 |
| 직접 고침 보호 | 구역을 직접 고치면 🔒, 이후 AI는 그 구역을 덮어쓰지 않고 `제안 1개`로만 보여 준다 |
| 이력 | 버전마다 저장, `이력`에서 이전 버전 보기·되돌리기 |
| 주제 관리 | AI가 새 주제를 만들 수 있다. 사용자는 이름 바꾸기·합치기·삭제(자료는 메모로) |
| 찾기 | AI 비서가 위키·볼 것을 찾아 답한다("저번에 저장한 LangGraph 영상 뭐였지?" → 그 링크) |

| 행 | 기본 · 호버(`--color-bg-hover`) · 선택(`--color-bg-selected`, 모서리 6, 좌우 10 안쪽) · 검색 일치 글자 강조(`--color-search-highlight`) |
| 검색 | 🔍 누르면 추가 바 자리가 검색칸(`메모 검색`)으로 바뀐다. 글자 그대로 부분 일치(`%`·`_`도 글자로). Esc = 검색 닫고 추가 바로. 결과 없음 = `"<검색어>"와 맞는 메모가 없어요` |
| 빈 메모함 | 목록 자리 가운데: 문서 아이콘(48, 4차 글자) + `생각나는 것을 바로 적어 두세요` + `필요할 때 할 일이나 일정으로 바꿀 수 있어요`(3차) |
| 불러오는 중 | 행 자리 회색 막대 5줄(깜빡임 없이) |
| 상세 편집 | 글자를 고치면 0.6초 뒤 자동 저장(02 상세와 같다). 첫 줄을 모두 지우면 둘째 줄이 제목이 된다. 내용을 전부 지우고 나가면 `빈 메모는 저장하지 않아요` 토스트 + 직전 내용 유지 |
| 전환 팝오버 | ☑ 또는 메뉴 `할 일로 만들기`/`일정으로 만들기` → 버튼 아래 팝오버(폭 300): 제목(첫 줄로 채움) · 리스트 고르기(05의 리스트 피커) · 날짜(03 날짜 피커; `일정으로`는 날짜 필수, 시각·종료 선택) · `원본 메모는 그대로 두고 설명에 함께 저장해요` · [취소] [등록] |
| 전환 후 | 행에 꼬리표, 상세 바닥에 연결 줄. 같은 메모에서 다시 전환 메뉴 = `연결된 할 일 열기`로 바뀐다(중복 생성 없음, 정책 유지) |
| 위키 — AI 쓸 수 없음 | `AI로 정리하기` 비활성 + 툴팁 `지금은 AI를 쓸 수 없어요` (13 §6 문구) |
| 위키 — 주제 없음 | 오른쪽 가운데: 책 아이콘 + `메모가 쌓이면 주제별로 정리해 드려요` + `메모 5개 이상이면 AI가 주제를 제안해요` + [메모로 돌아가기] |
| 위키 — 정리 중 | 알림 띠 자리에 진행 줄 `메모 12개를 읽는 중… ■ 멈추기`. 다 되면 바뀌는 부분을 초록·빨강 줄로 보여 주고 [적용] [버리기] |

### 5. 인터랙션
| 동작 | 결과 |
|---|---|
| 추가 바 Enter | 저장 **⚠️ 변경 · 확인됨** (v1.x: Enter 줄바꿈 · ⌘Enter 저장 → 틱틱 추가 바와 같게) |
| 추가 바 Shift+Enter | 줄바꿈(추가 바가 최대 5줄까지 늘어남) [틱틱: Shift+Enter 설명 줄] |
| 행 클릭 | 선택 + 상세. ↑↓ 행 이동, Enter = 상세 본문으로 초점 |
| 행 우클릭 / `⋯` | 메뉴: `할 일로 만들기` · `일정으로 만들기` · `복사` · 구분선 · `삭제` |
| 삭제 | 바로 지우고 토스트 `메모를 삭제했어요 · 실행 취소`(5초) [틱틱 토스트]. 전환으로 만든 할 일은 지우지 않는다 |
| ⌘F (메모함 안) | 검색 열기 |
| 세그먼트 | 클릭 또는 ←→ / Home / End로 `메모 ↔ 주제 위키`. 전환해도 추가 바 초안·검색어·선택 행은 유지(정책 유지) |
| 위키 출처 꼬리표 | 메모 탭으로 바뀌며 그 메모 선택 + 상세 |
| 위키 구역 직접 고침 | 구역 글을 누르면 그 자리에서 편집 → 저장 시 그 구역 🔒 |

### 메모함 1단계
승인된 메모함 설계의 수동 기능 구현. AI/위키는 후속 단계다.
성장 아래 메모함 레일 메뉴. 제목·검색을 위에, 최신순 원문 카드를 가운데, 항상 보이는 입력창을 아래에 배치한다. 기존 앱 토큰을 사용하며 작은 창에서는 한 열로 표시한다.
Enter는 줄바꿈, Cmd/Ctrl+Enter 또는 저장 버튼으로 저장한다. 공백 저장 금지. 저장 실패 시 입력 보존 및 오류 안내. 저장 중 버튼 비활성화.
카드에서 수정/취소/저장. 원문은 일반 텍스트로 렌더링한다. 검색은 원문의 부분 문자열로 %와 _도 문자 그대로 찾는다.
전환 버튼에서 제목·리스트를 수정하고 일정은 날짜·시각·선택 종료 시각을 입력하여 확인한다. 종일은 날짜만 저장한다. 한 메모는 한 항목에 연결한다. 이미 전환하면 연결 항목 열기 제공. 삭제된 항목은 삭제됨으로 안내한다. 전환은 원문을 보존하며 작업 생성과 연결을 단일 트랜잭션으로 처리한다.

### 메모함·주제 위키 통합 (2026-10-04)
사용자 결정: 별도 주제 위키 rail 항목을 제거하고 메모함 한 곳에서 ‘메모’/‘주제 위키’ 내부 탭으로 전환한다. 메모 탭은 기존 검색·작성·수정·전환을 유지하며 내부 탭 전환 시 초안과 검색·편집 상태를 보존한다. 위키는 아직 생성 기능 준비 상태임을 표시하고 ‘메모로 돌아가기’를 제공한다. 기존 저장된 wiki 화면 값도 통합 메모함의 위키 탭으로 열린다. 키보드 좌우/Home/End로 내부 탭을 전환한다. AI 비서 진입점은 유지한다.
