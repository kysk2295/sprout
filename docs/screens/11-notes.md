# 메모함 1단계
승인된 메모함 설계의 수동 기능 구현. AI/위키는 후속 단계다.
성장 아래 메모함 레일 메뉴. 제목·검색을 위에, 최신순 원문 카드를 가운데, 항상 보이는 입력창을 아래에 배치한다. 기존 앱 토큰을 사용하며 작은 창에서는 한 열로 표시한다.
Enter는 줄바꿈, Cmd/Ctrl+Enter 또는 저장 버튼으로 저장한다. 공백 저장 금지. 저장 실패 시 입력 보존 및 오류 안내. 저장 중 버튼 비활성화.
카드에서 수정/취소/저장. 원문은 일반 텍스트로 렌더링한다. 검색은 원문의 부분 문자열로 %와 _도 문자 그대로 찾는다.
전환 버튼에서 제목·리스트를 수정하고 일정은 날짜·시각·선택 종료 시각을 입력하여 확인한다. 종일은 날짜만 저장한다. 한 메모는 한 항목에 연결한다. 이미 전환하면 연결 항목 열기 제공. 삭제된 항목은 삭제됨으로 안내한다. 전환은 원문을 보존하며 작업 생성과 연결을 단일 트랜잭션으로 처리한다.
notes(id, common fields, content, task_id)를 공통 스키마에 추가한다. task_id는 동일 메모 재시도 시 같은 ID가 되도록 결정적으로 생성한다. 수정과 전환은 별도이며 이후 메모 수정이 생성된 할 일을 변경하지 않는다.
검증: 빈 메모/검색 특수문자/수정 보존/시간 검증/전환 원문/중복 방지/실패 롤백/연결 열기/좁은 창. 서버 새 스키마 생성 및 기존 서버 적용 절차를 기록한다.

## 메모함·주제 위키 통합 (2026-10-04)
사용자 결정: 별도 주제 위키 rail 항목을 제거하고 메모함 한 곳에서 ‘메모’/‘주제 위키’ 내부 탭으로 전환한다. 메모 탭은 기존 검색·작성·수정·전환을 유지하며 내부 탭 전환 시 초안과 검색·편집 상태를 보존한다. 위키는 아직 생성 기능 준비 상태임을 표시하고 ‘메모로 돌아가기’를 제공한다. 기존 저장된 wiki 화면 값도 통합 메모함의 위키 탭으로 열린다. 키보드 좌우/Home/End로 내부 탭을 전환한다. AI 비서 진입점은 유지한다.
